## A走廊：估值类公式（绿色宫殿）🟢

> 场景：一间绿色温室，阳光透过玻璃照在展板上。

### A1. 复利公式（Compound Interest）

**公式**：FV = PV × (1 + r)^n

| 字母 | 含义 | 编码画面 |
|------|------|---------|
| FV | 终值（Future Value） | 最终的大金库 |
| PV | 现值（Present Value） | 现在投入的种子 |
| r | 利率/收益率 | 阳光（让种子生长的光） |
| n | 期数 | 生长的年轮 |

- **画面**：一颗种子（PV）在阳光（r）下生长n年，长成大树（FV）
- **实例**：10万元，年利率8%，10年后：100000 × (1.08)^10 = 215,892元
- **口诀**："复利是第八大奇迹"——时间越长，增长越惊人
- **速算**：72法则→72÷利率=翻倍年数，72÷8=9年翻倍

### A2. 现值公式（Present Value）

**公式**：PV = FV / (1 + r)^n

- **画面**：从未来的大金库（FV）倒推回来，折算成现在的种子值多少
- **含义**：未来的100元，今天值多少？
- **实例**：10年后收到100万，折现率10%，现值=100万/(1.1)^10 = 38.6万
- **记忆**：复利的"倒放电影"

### A3. 年金现值公式（PV of Annuity）

**公式**：PV = PMT × [1 - (1+r)^(-n)] / r

| 字母 | 含义 | 编码画面 |
|------|------|---------|
| PMT | 每期支付额 | 水龙头流出的水量 |
| r | 折现率 | 水管的粗细 |
| n | 期数 | 流水的时间 |

- **画面**：一个水龙头（PMT）每天流出固定水量，流了n天，这些水加起来的"现值"
- **实例**：每年收到10万元，持续20年，折现率8%，现值=10×[1-(1.08)^(-20)]/0.08 = 98.2万
- **应用**：房贷、养老金、债券定价

### A4. 永续年金公式（Perpetuity）

**公式**：PV = PMT / r

- **画面**：一个永不停歇的水龙头，水流（PMT）除以水管粗细（r）=总水量
- **实例**：每年分红5元，要求收益率10%，股票价值=5/0.1=50元
- **口诀**："永续年金最简单，一除就完"
- **应用**：优先股估值、永续债估值

### A5. Gordon增长模型（Gordon Growth Model）

**公式**：P = D₁ / (r - g)

| 字母 | 含义 | 编码画面 |
|------|------|---------|
| P | 股票价格 | 苹果树的价格 |
| D₁ | 下一期股息 | 明年结的苹果 |
| r | 要求收益率 | 你期望的回报 |
| g | 股息增长率 | 苹果树每年多结的苹果 |

- **画面**：一棵苹果树（股票），每年结的苹果（股息）以g速度增长
- **实例**：明年分红2元，要求回报率12%，股息增长率4%，P=2/(0.12-0.04)=25元
- **限制**：r必须>g，否则价格无穷大

### A6. 债券定价公式（Bond Pricing）

**公式**：P = Σ[C/(1+r)^t] + F/(1+r)^n

- **画面**：一张债券像一棵摇钱树，每年摇下利息（C），最后到期摇下本金（F）
- **含义**：所有未来现金流（利息+本金）的现值之和
- **实例**：面值1000元，票面利率5%，10年期，市场利率6%→价格低于1000元（折价）
- **关键**：市场利率>票面利率→折价；市场利率<票面利率→溢价

### A7. 市盈率估值公式

**公式**：P = EPS × P/E

- **画面**：每股收益（EPS）是"种子"，市盈率（P/E）是"倍数放大镜"
- **实例**：EPS=3元，行业平均P/E=20倍，合理股价=3×20=60元
- **应用**：快速估算股票合理价格

### A8. DCF折现公式（自由现金流折现）

**公式**：V = Σ[FCFₜ/(1+WACC)^t] + TV/(1+WACC)^n

| 字母 | 含义 | 编码画面 |
|------|------|---------|
| V | 企业价值 | 金矿的总价值 |
| FCF | 自由现金流 | 每年挖出的金子 |
| WACC | 加权平均资本成本 | 挖矿的成本率 |
| TV | 终值 | 矿脉最后的储量价值 |

- **画面**：一座金矿，每年挖出金子（FCF），用成本率（WACC）折现
- **应用**：最严谨的企业估值方法

## B走廊：风险类公式（红色宫殿）🔴

> 场景：一间红色警示厅，每块展板上都有⚠️标志。

### B1. 标准差公式（Standard Deviation）

**公式**：σ = √[Σ(Rᵢ - R̄)² / n]

- **画面**：一群人射箭，箭的散布程度=标准差
- **含义**：衡量收益率的波动性/不确定性
- **实例**：股票A收益率标准差20%，股票B标准差10%→A更不稳定
- **记忆**：标准差=风险的"尺子"

### B2. 夏普比率（Sharpe Ratio）

**公式**：Sharpe = (Rₚ - Rf) / σₚ

| 字母 | 含义 | 编码画面 |
|------|------|---------|
| Rₚ | 投资组合收益率 | 你的成绩单 |
| Rf | 无风险收益率 | 银行存款基准线 |
| σₚ | 投资组合标准差 | 成绩的波动幅度 |

- **画面**：考试成绩（Rₚ）减去及格线（Rf），再除以成绩波动（σ）→"性价比"
- **实例**：组合收益15%，无风险利率3%，标准差10%，Sharpe=(15-3)/10=1.2
- **口诀**："夏普比率=每单位风险的超额收益"
- **参考**：>1良好，>2优秀，>3卓越

### B3. CAPM模型（资本资产定价模型）

**公式**：E(Rᵢ) = Rf + βᵢ × (Rm - Rf)

| 字母 | 含义 | 编码画面 |
|------|------|---------|
| E(Rᵢ) | 期望收益率 | 你该得的分数 |
| Rf | 无风险利率 | 基础工资 |
| βᵢ | 系统性风险系数 | 跟着大盘跑的程度 |
| Rm - Rf | 市场风险溢价 | 大盘的额外奖金 |

- **画面**：工资=基础工资（Rf）+ 绩效奖金（β × 市场溢价）
- **实例**：Rf=3%，β=1.2，Rm=10%，E(R)=3%+1.2×(10%-3%)=11.4%
- **β含义**：β=1跟大盘同步，β>1比大盘波动大，β<1比大盘稳
- **口诀**："期望收益=无风险+风险补偿"

### B4. β系数公式

**公式**：βᵢ = Cov(Rᵢ, Rm) / Var(Rm)

- **画面**：你在跳舞（Rᵢ），大盘也在跳舞（Rm），β衡量你们步伐的一致程度
- **实例**：β=1.5→大盘涨10%，你涨15%；大盘跌10%，你跌15%
- **记忆**：β是股票相对于大盘的"弹性系数"

### B5. 投资组合方差（两资产）

**公式**：σ²ₚ = w₁²σ₁² + w₂²σ₂² + 2w₁w₂Cov(1,2)

- **画面**：两杯不同颜色的颜料混合，混合后的颜色波动=组合方差
- **关键**：相关系数<1时，组合风险<单独风险之和→分散化降低风险
- **口诀**："不把鸡蛋放一个篮子"

### B6. Black-Scholes期权定价模型

**公式**：C = S·N(d₁) - K·e^(-rT)·N(d₂)

| 字母 | 含义 | 编码画面 |
|------|------|---------|
| C | 看涨期权价格 | 买彩票的价格 |
| S | 标的资产现价 | 商品现在的价格 |
| K | 执行价格 | 约定的购买价 |
| r | 无风险利率 | 时间价值 |
| T | 到期时间 | 彩票有效期 |
| N(d) | 累积正态分布 | 概率的尺子 |

- **画面**：一张彩票（期权），S是商品现价，K是你能买到的价格，差价越大彩票越值钱
- **记忆口诀**："B-S模型：现价概率 - 执行价折现概率"
- **应用**：欧式期权定价的理论基础

### B7. VaR（在险价值）

**公式**：VaR = μ - z × σ（参数法）

- **画面**：站在悬崖边，VaR告诉你"95%的概率你不会掉下超过这个距离"
- **实例**：μ=1%，σ=5%，95%VaR=1%-1.65×5%=-7.25%→最大亏损7.25%
- **含义**：在给定置信水平下，最大可能损失
- **记忆**："VaR=最坏情况的边界线"

### B8. 久期（Duration）

**公式**：D = Σ[t × PV(CFₜ)] / P

- **画面**：债券的"回本时间"——加权平均的现金流回收期
- **含义**：利率变动1%时，债券价格变动约D%
- **实例**：久期5年→利率上升1%→债券价格下跌约5%
- **口诀**："久期越长，利率风险越大"

### B9. 凸性（Convexity）

**公式**：Convexity = Σ[t(t+1) × PV(CFₜ)] / [P × (1+y)²]

- **画面**：债券价格-收益率曲线的弯曲程度
- **含义**：久期的"修正项"，利率大幅变动时需要考虑
- **记忆**："凸性是久期的保险——利率跌时多涨一点，利率涨时少跌一点"

## C走廊：收益类公式（黄色宫殿）🟡

> 场景：一间金黄色的奖杯陈列室，每块展板展示一种收益计算。

### C1. 持有期收益率（Holding Period Return）

**公式**：HPR = (P₁ - P₀ + D) / P₀

- **画面**：买入一只股票，卖出时的价格差+分红，除以买入价
- **实例**：买入100元，卖出120元，分红5元，HPR=(120-100+5)/100=25%
- **口诀**："持有收益=（卖价-买价+分红）/买价"

### C2. 年化收益率（Annualized Return）

**公式**：AR = (1 + HPR)^(1/n) - 1

- **画面**：把非一年期的收益"拉伸"到一年的尺度
- **实例**：3年总收益60%，年化=(1.6)^(1/3)-1=16.96%
- **口诀**："总收益开n次方减1"

### C3. ROE公式（杜邦分析）

**公式**：ROE = 净利润/净资产 = 净利率 × 资产周转率 × 权益乘数

| 因子 | 公式 | 含义 | 画面 |
|------|------|------|------|
| 净利率 | 净利润/收入 | 每元收入赚多少 | 蛋糕的厚度 |
| 资产周转率 | 收入/总资产 | 资产的利用效率 | 蛋糕的翻转速度 |
| 权益乘数 | 总资产/净资产 | 杠杆程度 | 蛋糕的层数 |

- **画面**：ROE是一块三层蛋糕——利润率（厚薄）×周转率（翻转速度）×杠杆（层数）
- **实例**：净利率10%×周转率1.5×杠杆2=ROE 30%
- **三种商业模式**：高利润（茅台）、高周转（沃尔玛）、高杠杆（银行）

### C4. ROA公式

**公式**：ROA = 净利润 / 总资产

- **画面**：企业用全部家当（资产）赚了多少钱
- **实例**：净利润1000万，总资产1亿，ROA=10%
- **与ROE区别**：ROA看全部资产效率，ROE看股东回报（含杠杆效应）

### C5. 内部收益率（IRR）

**公式**：NPV = Σ[CFₜ/(1+IRR)^t] = 0

- **画面**：让投资的现值流入=现值流出的那个折现率
- **含义**：项目本身能产生的实际收益率
- **实例**：投资100万，5年每年回收25万，IRR≈7.9%
- **决策**：IRR>要求收益率→接受项目

### C6. 净现值（NPV）

**公式**：NPV = Σ[CFₜ/(1+r)^t] - C₀

- **画面**：未来现金流的现值之和，减去初始投资
- **实例**：投资100万，5年每年回收25万，折现率10%，NPV=25×3.791-100=-5.2万→不值得投资
- **决策**：NPV>0→接受；NPV<0→拒绝

### C7. 杜邦分解延伸公式

**公式**：ROE = (净利润/收入) × (收入/总资产) × (总资产/净资产)

- **画面**：把ROE拆成三个齿轮——利润率齿轮、周转齿轮、杠杆齿轮
- **分析**：ROE下降→查是哪个齿轮出了问题
- **记忆**："杜邦三分法：利×转×杠"

### C8. 资本充足率（CAR）

**公式**：CAR = (Tier 1 + Tier 2) / 风险加权资产

- **画面**：银行的安全气囊——资本越多，气囊越大
- **巴塞尔要求**：总资本充足率≥8%，核心一级≥6%
- **实例**：一级资本80亿，二级资本20亿，风险加权资产1000亿，CAR=(80+20)/1000=10%

## 易混公式对比记忆

### 对比1：复利 vs 单利

| | 单利 | 复利 |
|--|------|------|
| 公式 | FV = PV(1+rn) | FV = PV(1+r)^n |
| 区别 | 利息不生利息 | 利息也生利息 |
| 画面 | 直线增长 | 指数增长 |
| 记忆 | "单利老实，只算本金" | "复利狡猾，利滚利" |

### 对比2：夏普比率 vs 特雷诺比率 vs 信息比率

| | 夏普 | 特雷诺 | 信息比率 |
|--|------|--------|---------|
| 公式 | (Rp-Rf)/σp | (Rp-Rf)/βp | (Rp-Rb)/σ(Rp-Rb) |
| 分母 | 总风险(σ) | 系统风险(β) | 跟踪误差 |
| 应用 | 充分分散化组合 | 未充分分散组合 | 主动管理基金 |
| 记忆 | "夏普看全部风险" | "特雷诺看系统风险" | "信息看超额波动" |

### 对比3：NPV vs IRR

| | NPV | IRR |
|--|-----|-----|
| 结果 | 金额（元） | 比率（%） |
| 决策 | NPV>0接受 | IRR>r接受 |
| 优点 | 反映绝对价值 | 直观比较收益率 |
| 缺点 | 需要设定折现率 | 非常规现金流可能多解 |
| 记忆 | "NPV告诉你赚多少钱" | "IRR告诉你赚多少%" |

### 对比4：P/E vs P/B vs P/S

| 指标 | 公式 | 适用场景 | 记忆 |
|------|------|---------|------|
| P/E | 股价/每股收益 | 盈利稳定的公司 | "看赚钱能力" |
| P/B | 股价/每股净资产 | 重资产行业（银行、地产） | "看家底厚薄" |
| P/S | 股价/每股收入 | 亏损但有收入的成长公司 | "看卖货能力" |

### 对比5：久期 vs 修正久期 vs 凸性

| | 久期 | 修正久期 | 凸性 |
|--|------|---------|------|
| 公式 | D=Σ[t×PV(CF)]/P | MD=D/(1+y) | 二阶导数 |
| 含义 | 回本时间 | 利率敏感度 | 曲线弯曲度 |
| 应用 | 粗估利率风险 | 精确估利率风险 | 大幅变动修正 |
| 记忆 | "多久回本" | "多敏感" | "多弯曲" |

## 速算技巧与记忆口诀

### 72法则
- **用途**：快速计算翻倍年数
- **公式**：翻倍年数 ≈ 72 ÷ 年利率(%)
- **例子**：8%利率→72÷8=9年翻倍；12%→72÷12=6年翻倍

### 连续复利
- **公式**：FV = PV × e^(rt)
- **记忆**："e的rt次方，复利的极限"

### 永续增长的现值
- **公式**：PV = C / (r-g)
- **记忆**："现金流除以（折现率减增长率）"

### 杠杆效应公式
- **公式**：ROE = ROA + (ROA - 利率) × D/E
- **含义**：如果ROA>借款利率，加杠杆能提高ROE
- **记忆**："借钱赚的比利息多→杠杆有利"

### WACC公式
- **公式**：WACC = E/(D+E)×Re + D/(D+E)×Rd×(1-T)
- **画面**：资本成本是股权成本和债权成本的加权平均
- **记忆**："WACC=股东要的×比例+债权人要的×比例×(1-税率)"
- **关键**：债务利息可以抵税→税后成本更低
