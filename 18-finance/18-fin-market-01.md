# 金融市场记忆 — 编码手册

> 20种金融产品的编码，每种配有特征→风险→收益→画面。
> 市场参与者编码与交易规则记忆。

---

## 一、金融产品编码（20种）

> 设定：想象一座**金融百货大楼**，每层卖不同产品。

### 一楼：基础证券层

#### 1. 股票（Stock）
- **特征**：代表公司所有权的凭证，持有者为股东
- **风险**：中高风险（价格波动大，可能亏损本金）
- **收益**：股息 + 资本利得（买卖差价）
- **画面**：一张股票=一块蛋糕的切片，公司越大你的切片越小
- **编码**：股票 → "骨票"——买股票像买骨头，啃得到肉（分红）也可能啃到空
- **记忆**：股票是权益类资产，没有到期日，风险收益适中偏高

#### 2. 债券（Bond）
- **特征**：代表债权的凭证，持有者为债权人，有固定到期日
- **风险**：低-中风险（国债最低，企业债看信用等级）
- **收益**：固定利息 + 到期还本
- **画面**：一张债券=一张借条，国家或企业打的欠条
- **编码**：债券 → "债卷"——卷起来的欠条，到期打开还钱
- **关键**：债券价格与利率反向变动

#### 3. 基金（Fund）
- **特征**：集合投资，专业管理，分散风险
- **风险**：取决于基金类型（货币基金低，股票基金高）
- **收益**：取决于底层资产表现
- **画面**：一群人把钱放进一个大篮子，交给基金经理去买菜
- **编码**：基金 → "鸡金"——大家凑钱养一只金鸡，收益共享
- **分类**：股票型、债券型、混合型、货币型、指数型

#### 4. 银行存款（Bank Deposit）
- **特征**：最安全的金融产品，受存款保险保障
- **风险**：极低（50万以内受存款保险保护）
- **收益**：固定利息（活期0.2-0.35%，定期1.5-3%）
- **画面**：钱放进银行的保险箱，每月拿利息
- **编码**：存款 → "存捆"——把钱捆好存起来
- **记忆**：安全但收益低，跑不赢通胀

---

### 二楼：衍生品层

#### 5. 期货（Futures）
- **特征**：标准化合约，约定在未来某日以某价格买卖某资产
- **风险**：高风险（保证金交易，杠杆放大）
- **收益**：双向交易，可做多也可做空
- **画面**：今天签合同说"3个月后以100元/桶买原油"→3个月后不管市价多少都按100元执行
- **编码**：期货 → "期祸"——期货玩不好是祸
- **关键**：保证金交易（通常5-15%），杠杆效应大

#### 6. 期权（Options）
- **特征**：赋予持有者在未来某日以某价格买入/卖出资产的权利（非义务）
- **风险**：买方风险有限（最多亏权利金），卖方风险可能很大
- **收益**：看涨期权在标的上涨时获利，看跌期权在标的下跌时获利
- **画面**：一张"优惠券"——给你权利以100元买某商品，但你也可以不买
- **编码**：期权 → "弃权"——可以放弃的权利
- **分类**：看涨期权（Call）=买入权；看跌期权（Put）=卖出权

#### 7. 远期合约（Forward）
- **特征**：非标准化的场外合约，约定未来交易
- **风险**：信用风险（对手方可能违约）
- **收益**：锁定未来价格
- **画面**：两个商人私下签订的"3个月后交易"的协议
- **编码**：远期 → "远骑"——骑马去远方交货
- **与期货区别**：远期=场外非标准化；期货=场内标准化

#### 8. 互换（Swap）
- **特征**：双方约定交换未来现金流
- **风险**：信用风险+市场风险
- **收益**：降低融资成本或对冲风险
- **画面**：两个人握手——A把固定利率给B，B把浮动利率给A
- **编码**：互换 → "互唤"——互相呼唤交换
- **主要类型**：利率互换、货币互换、信用违约互换（CDS）

### 三楼：外汇与贵金属层

#### 9. 外汇（Forex）
- **特征**：全球最大的金融市场，24小时交易
- **风险**：中高风险（汇率波动+杠杆）
- **收益**：汇率差价 + 利息差（套息交易）
- **画面**：机场的货币兑换窗口，汇率每秒都在变
- **编码**：外汇 → "外换"——外国货币的兑换
- **交易对**：EUR/USD、USD/JPY、GBP/USD等

#### 10. 黄金（Gold）
- **特征**：避险资产，抗通胀，全球流通
- **风险**：中等风险（价格波动但长期保值）
- **收益**：资本利得（无利息/股息）
- **画面**：金灿灿的金条，在危机时刻人人争抢
- **编码**：黄金 → "黄斤"——一斤黄金
- **规律**：美元跌→黄金涨；危机来→黄金涨

#### 11. 白银（Silver）
- **特征**：贵金属+工业金属双重属性
- **风险**：高于黄金（波动更大）
- **收益**：资本利得
- **画面**：白银既是首饰材料又是电子元件原料
- **编码**：白银 → "白银"——比黄金便宜但波动更大
- **记忆**：金银比（Gold/Silver Ratio）通常60-80

---

### 四楼：另类投资层

#### 12. 房地产（Real Estate）
- **特征**：实物资产，流动性低，需要大额资金
- **风险**：中等（政策风险+流动性风险）
- **收益**：租金收入 + 资产增值
- **画面**：一栋楼，每月收租，多年后房价涨了卖掉
- **编码**：房产 → "房铲"——用铲子铲出金砖
- **REITs**：房地产投资信托基金=不用买房也能投资房地产

#### 13. 私募股权（Private Equity, PE）
- **特征**：投资未上市企业股权，长期锁定
- **风险**：高风险（流动性差、信息不透明）
- **收益**：高收益（企业上市或被收购时退出）
- **画面**：在企业还小时就投钱，等它长大上市后赚百倍
- **编码**：私募 → "私木"——私下种的小树苗
- **阶段**：天使轮→A轮→B轮→C轮→Pre-IPO→IPO

#### 14. 风险投资（Venture Capital, VC）
- **特征**：投资早期创业企业，高风险高回报
- **风险**：极高风险（90%的创业公司会失败）
- **收益**：可能百倍千倍回报（投中独角兽）
- **画面**：在车库里的创业公司投10万，10年后变成1亿
- **编码**：风投 → "风投"——在风中投骰子
- **记忆**：VC=高风险的"买彩票"

#### 15. 对冲基金（Hedge Fund）
- **特征**：灵活策略，使用杠杆和衍生品，追求绝对收益
- **风险**：中高风险（策略风险+杠杆风险）
- **收益**：追求无论市场涨跌都赚钱
- **画面**：基金经理像游击队员，灵活切换各种武器
- **编码**：对冲 → "对冲"——对着冲，两边下注
- **策略**：多空、套利、事件驱动、宏观策略

#### 16. 信托（Trust）
- **特征**：受人之托代人理财，门槛较高
- **风险**：中等（看底层资产质量）
- **收益**：固定收益为主（年化5-8%）
- **画面**：把钱交给信托公司，它帮你投资，定期给你分红
- **编码**：信托 → "信拖"——信任地拖付给别人
- **门槛**：通常100万起

### 五楼：新兴金融层

#### 17. ETF（交易所交易基金）
- **特征**：像股票一样交易的基金，跟踪指数
- **风险**：取决于跟踪的指数
- **收益**：跟踪指数的表现
- **画面**：一篮子股票打包成一个产品，在交易所像股票一样买卖
- **编码**：ETF → "一摊份"——一份包含一摊股票
- **优势**：费用低、透明、分散化

#### 18. REITs（房地产投资信托基金）
- **特征**：投资房地产的基金，可像股票交易
- **风险**：中等（利率风险+房地产市场风险）
- **收益**：租金分红 + 资产增值
- **画面**：不用买房也能当"房东"——买REITs份额
- **编码**：REITs → "瑞瓷"——像瓷砖一样实在的房地产
- **强制分红**：通常要求将90%以上收入分红

#### 19. 结构性产品（Structured Products）
- **特征**：将固定收益产品与衍生品组合
- **风险**：中等（取决于结构设计）
- **收益**：通常有保本条款+浮动收益
- **画面**：一个"套餐"——主食（债券）+ 甜点（期权）
- **编码**：结构性 → "结构"——搭建出来的金融积木
- **例子**：保本票据=零息债券+看涨期权

#### 20. 数字货币（Cryptocurrency）
- **特征**：去中心化、区块链技术、高波动
- **风险**：极高风险（价格剧烈波动、监管不确定）
- **收益**：可能极高回报（也可能归零）
- **画面**：虚拟世界里的金币，没有央行发行，靠算法"挖矿"
- **编码**：数字货币 → "数字币"——数字化的虚拟币
- **代表**：比特币（BTC）、以太坊（ETH）

## 二、市场参与者编码

> 设定：金融市场的"角色扮演游戏"——每个参与者是一个游戏角色。

### 1. 央行（Central Bank）
- **角色**：游戏的"裁判"
- **职能**：制定货币政策、发行货币、维护金融稳定
- **画面**：央行行长站在山顶，手中握着利率的"遥控器"
- **编码**：央行 → "央hang"——中央的银行，站在最顶端
- **工具**：利率、准备金率、公开市场操作
- **中国**：中国人民银行（PBoC）
- **美国**：美联储（Fed）

### 2. 商业银行（Commercial Bank）
- **角色**：金融体系的"毛细血管"
- **职能**：吸收存款、发放贷款、支付结算
- **画面**：银行像一个大水池，存款流入、贷款流出
- **编码**：商业银行 → "商银"——做生意的银行
- **盈利模式**：存贷利差（贷款利率-存款利率）
- **代表**：工农中建交（五大行）

### 3. 证券公司（Securities Firm / Broker）
- **角色**：股票交易的"中介"
- **职能**：经纪（代理交易）、承销（帮企业上市）、自营（自己投资）
- **画面**：券商像房产中介——帮你买卖股票，收佣金
- **编码**：券商 → "券伤"——手续费让人受伤
- **收入**：佣金+承销费+自营投资收益

### 4. 基金公司（Fund Company）
- **角色**：专业"管家"
- **职能**：募集基金份额，专业投资管理
- **画面**：基金经理像厨师——用投资者的食材（钱）做菜（投资组合）
- **编码**：基金公司 → "基金"——积累金钱的机构
- **收入**：管理费（通常1-1.5%/年）+ 业绩报酬

### 5. 保险公司（Insurance Company）
- **角色**：风险的"吸收器"
- **职能**：承保风险、投资管理
- **画面**：保险公司像海绵——吸收大家的风险，用保费去投资
- **编码**：保险 → "保伞"——给你撑一把保护伞
- **盈利**：承保利润 + 投资收益
- **巨量资金**：保险公司是最大的机构投资者之一

### 6. 养老基金（Pension Fund）
- **角色**：长期"存钱罐"
- **职能**：管理养老金资产，追求长期稳健收益
- **画面**：一个巨大的存钱罐，每个人定期往里投钱，退休后取出
- **编码**：养老 → "养牢"——养到老的牢靠资金
- **特点**：规模最大、投资期限最长、最稳健

### 7. 外汇交易商（Forex Dealer）
- **角色**：货币兑换的"中间商"
- **职能**：提供外汇买卖报价，撮合交易
- **画面**：机场换汇窗口的放大版，24小时不停歇
- **编码**：外汇交易商 → "换商"——专门换钱的商人

### 8. 评级机构（Rating Agency）
- **角色**：信用的"裁判"
- **职能**：评估债券发行人的信用等级
- **画面**：裁判举牌——AAA（最高分）到D（违约）
- **编码**：评级 → "评鸡"——给每只"鸡"（债券）打分
- **三大机构**：标普（S&P）、穆迪（Moody's）、惠誉（Fitch）
- **等级**：AAA > AA > A > BBB > BB > B > CCC > CC > C > D

### 9. 交易所（Exchange）
- **角色**：交易的"舞台"
- **职能**：提供交易平台、制定交易规则、信息披露
- **画面**：一个巨大的舞台，所有金融产品在上面表演
- **编码**：交易所 → "交蚁"——像蚂蚁一样密集的交易
- **中国**：上交所、深交所、港交所、中金所
- **美国**：NYSE、NASDAQ

### 10. 监管机构（Regulator）
- **角色**：金融市场的"警察"
- **职能**：制定规则、监督市场、处罚违规
- **画面**：警察拿着警棍在市场巡逻
- **编码**：监管 → "监关"——监督和关押违规者
- **中国**：证监会（CSRC）、银保监会（CBIRC）
- **美国**：SEC（证券交易委员会）、CFTC

## 三、交易规则记忆

### 股票交易规则

```
📍 交易时间：
  - A股：9:30-11:30（上午），13:00-15:00（下午）
  - 集合竞价：9:15-9:25（开盘），14:57-15:00（收盘）
  - 记忆："早九半到十一半，下午一点到三点"

📍 涨跌幅限制：
  - 主板：±10%
  - 创业板/科创板：±20%
  - ST股：±5%
  - 北交所：±30%
  - 记忆："主板十个点，创科二十个点，ST五个点"

📍 交易单位：
  - 最低买入1手=100股
  - 科创板最低200股
  - 记忆："一手一百股，科创两百股"

📍 T+1交易：
  - 当天买入，次日才能卖出
  - 记忆："今天买，明天卖"
  - 例外：港股T+0，美股T+0

📍 交易费用：
  - 佣金：万2.5（双向）
  - 印花税：千1（卖出单向）
  - 过户费：万0.1（双向）
  - 记忆："佣金双面收，印花卖方出"
```

### 债券交易规则

```
📍 交易场所：
  - 银行间市场（机构为主）
  - 交易所市场（个人可参与）
  - 记忆："银行间大玩家，交易所散户也行"

📍 计息方式：
  - 面值发行、折价发行、溢价发行
  - 记忆："面值平卖，折价便宜卖，溢价贵着卖"

📍 到期收益率（YTM）：
  - 买入持有到期的年化收益率
  - 记忆："YTM=真正的回报率"

📍 信用等级与利率：
  - AAA利率最低（最安全）
  - BBB以下为"垃圾债券"
  - 记忆："等级越高利率越低，越安全越便宜"
```

### 期货交易规则

```
📍 保证金制度：
  - 通常5-15%的保证金
  - 杠杆=1/保证金率
  - 记忆："十万保证金控制百万合约"

📍 每日结算（逐日盯市）：
  - 每天按结算价计算盈亏
  - 记忆："每天算账，盈亏即时反映"

📍 强制平仓：
  - 保证金不足时会被强平
  - 记忆："钱不够就强行卖掉"

📍 合约到期：
  - 到期必须交割或平仓
  - 记忆："到期必须了结"

📍 双向交易：
  - 可做多（看涨）也可做空（看跌）
  - 记忆："涨跌都能赚钱"
```

### 期权交易规则

```
📍 权利金：
  - 买方支付权利金获得权利
  - 卖方收取权利金承担义务
  - 记忆："买方花钱买权利，卖方收钱担义务"

📍 到期日：
  - 到期不行权则权利作废
  - 记忆："过期作废"

📍 行权价：
  - 约定的买入/卖出价格
  - 记忆："约定的交易价"

📍 盈亏结构：
  - 买方：亏损有限（最多亏权利金），收益可能很大
  - 卖方：收益有限（最多赚权利金），亏损可能很大
  - 记忆："买方风险有限收益无限，卖方相反"

📍 美式vs欧式：
  - 美式：到期前任何时间可行权
  - 欧式：只能到期日行权
  - 记忆："美式自由，欧式固定"
```

## 四、市场关系记忆网络

### 产品风险-收益阶梯

```
高收益 ↑  [数字货币] [风投/PE] [期货/期权]
        |  [股票] [对冲基金]
        |  [混合基金] [REITs]
        |  [企业债] [信托]
        |  [国债] [货币基金]
低收益 ↓  [银行存款]
        +————————————————→ 高风险
```

### 市场参与者关系图

```
央行（裁判）
  ↓ 制定规则
```

## 速记口诀汇总

1. **股票vs债券**："股票是股东（所有权），债券是债权人（债权）"
2. **期货vs期权**："期货必须执行，期权可以放弃"
3. **远期vs期货**："远期私下谈，期货场内标准化"
4. **做多vs做空**："做多=先买后卖（看涨），做空=先卖后买（看跌）"
5. **系统风险vs非系统风险**："系统风险逃不掉（大盘跌），非系统风险可分散（个股风险）"
6. **牛市vs熊市**："牛市向上冲（牛角向上），熊市向下拍（熊掌向下）"
7. **一级市场vs二级市场**："一级=发行市场（新股），二级=交易市场（二手股）"
8. **现货vs衍生品**："现货=现在交易，衍生品=未来交易"
9. **β>1vsβ<1**："β>1比大盘猛，β<1比大盘稳"
10. **Alpha收益**："Alpha=超越大盘的超额收益"
