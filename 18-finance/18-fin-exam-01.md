# 金融考试速记 — CFA/CPA/证券从业

> 50个高频考点编码、计算题快速解题模板、法规条款记忆策略、案例分析框架记忆。

---

## 一、50个高频考点编码

### A组：证券从业资格（15个）

#### 1. 证券的定义与分类
- **考点**：股票、债券、基金、衍生品的定义与区别
- **编码**："证四宝"——股票（股东）、债券（债主）、基金（基友）、衍生品（衍生）
- **画面**：证券市场是一个动物园——牛（多）和熊（空）在对峙
- **速记**：股票=所有权，债券=债权，基金=委托，衍生品=约定未来

#### 2. 股票发行条件
- **考点**：IPO条件、增发条件、配股条件
- **编码**："发三关"——财务关（3年盈利）、治理关（规范运作）、合规关（无重大违法）
- **画面**：企业上市像闯三关——第一关看账本，第二关看制度，第三关看守法
- **速记**：IPO=首次公开发行，条件最严；增发=再次发行

#### 3. 信息披露制度
- **考点**：定期报告（年报、半年报、季报）、临时报告（重大事件）
- **编码**："信三报"——年报（4个月内）、半年报（2个月内）、季报（1个月内）
- **画面**：上市公司像透明鱼缸——定期向公众展示内部情况
- **速记**：年报最详细（审计），季报最简单（不需审计）

#### 4. 内幕交易
- **考点**：内幕信息知情人、内幕信息定义、处罚
- **编码**："内三禁"——禁止知情人交易、禁止泄露内幕信息、禁止建议他人交易
- **画面**：内幕人士像考场里的"泄题者"——提前知道答案就下注
- **处罚**：没收违法所得+1-5倍罚款；情节严重5年以下有期徒刑

#### 5. 操纵市场
- **考点**：连续交易操纵、约定交易操纵、洗售操纵等
- **编码**："操四术"——连续交易、约定交易、洗售、虚假申报
- **画面**：操纵市场像在赌场出老千——人为制造假象
- **速记**：操纵=人为影响价格，内幕交易=利用未公开信息

#### 6. 证券公司业务
- **考点**：经纪、承销与保荐、自营、资产管理、融资融券
- **编码**："券五业"——经（经纪）、承（承销）、自（自营）、管（资管）、融（融资融券）
- **画面**：证券公司像百货商场——一楼经纪（代理买卖），二楼承销（帮企业卖股票），三楼自营（自己投资），四楼资管（帮客户投资），五楼融资融券（借钱借股票）

#### 7. 基金当事人
- **考点**：基金份额持有人、基金管理人、基金托管人
- **编码**："基三者"——持有人（出钱的）、管理人（管钱的）、托管人（存钱的）
- **画面**：基金是一笔钱——持有人是老板，管理人是厨师，托管人是仓库保管员
- **制衡**：管理人管投资，托管人管资产→相互监督

#### 8. 基金类型
- **考点**：开放式vs封闭式、公募vs私募
- **编码**："基四分"——开放（随时申赎）、封闭（固定期限）、公募（大众）、私募（少数人）
- **画面**：开放式基金像自助餐（随时进出），封闭式像包间（固定时间）
- **速记**：开放式规模可变，封闭式规模固定

#### 9. 期货交易制度
- **考点**：保证金、每日结算、涨跌停板、持仓限额
- **编码**："期四制"——保证金（杠杆）、日结算（每日盯市）、涨跌停（幅度限制）、持仓限（头寸限制）
- **画面**：期货交易像走钢丝——保证金是安全绳，每日结算看你在不在钢丝上

#### 10. 期权基本策略
- **考点**：买入/卖出看涨期权、买入/卖出看跌期权的盈亏
- **编码**："权四策"——买Call（看涨赚钱）、卖Call（收权利金）、买Put（看跌赚钱）、卖Put（收权利金）
- **画面**：期权像保险——买方交保费，卖方收保费承担风险
- **盈亏**：买方亏损有限收益无限，卖方收益有限亏损无限

#### 11. 证券登记结算
- **考点**：中国结算公司的职能、T+1交收
- **编码**："登三职"——登记（记录持有人）、托管（保管证券）、结算（资金清算）
- **画面**：中国结算像证券的"户籍管理局+银行"

#### 12. 投资者适当性管理
- **考点**：不同产品对应不同投资者门槛
- **编码**："适三看"——看资产、看经验、看风险承受能力
- **画面**：游乐场的身高限制——不同项目要求不同"身高"（资产+经验）

#### 13. 证券法修订重点
- **考点**：注册制、加大违法处罚、投资者保护
- **编码**："法三新"——注册制（发行改革）、严处罚（提高违法成本）、强保护（投资者权益）
- **画面**：证券法像交通法规——注册制=考驾照更容易，严处罚=超速罚更重

#### 14. 债券信用评级
- **考点**：评级符号含义、评级机构、评级方法
- **编码**："评三看"——看财务（偿债能力）、看经营（盈利能力）、看行业（竞争地位）
- **画面**：信用评级像体检报告——AAA最健康，D已经"去世"

#### 15. 证券市场监管体系
- **考点**：证监会、交易所、行业协会的职责分工
- **编码**："监三层"——证监会（立法+执法）、交易所（一线监管）、行业协会（自律管理）
- **画面**：监管像三层防火墙——证监会是总指挥，交易所是前线，协会是自律

### B组：CPA财务成本管理（15个）

#### 16. 财务报表分析
- **考点**：三大报表（资产负债表、利润表、现金流量表）的关系
- **编码**："报三表"——资产表（家底）、利润表（赚钱）、现金表（造血）
- **画面**：三张表像体检——资产表量体重，利润表量血压，现金表量心率
- **关系**：净利润连接利润表和资产负债表（未分配利润）

#### 17. 杜邦分析体系
- **考点**：ROE=净利率×资产周转率×权益乘数
- **编码**："杜三因"——利（赚钱）、转（效率）、杠（杠杆）
- **画面**：ROE是一把三股叉——每股叉代表一个驱动因素
- **解题**：ROE下降→先拆三个因子看哪个下降最多

#### 18. 资本成本计算
- **考点**：WACC、债务成本、股权成本
- **编码**："资三本"——债务成本（利息）、股权成本（CAPM算）、加权平均（WACC）
- **公式**：WACC = E/(D+E)×Ke + D/(D+E)×Kd×(1-T)
- **画面**：资本成本像"融资的价格"——借钱要利息，发股要分红

#### 19. 资本预算（投资决策）
- **考点**：NPV、IRR、回收期、PI
- **编码**："投四法"——NPV（净现值）、IRR（内含报酬率）、回收期（多久回本）、PI（现值指数）
- **决策**：NPV>0接受，IRR>资本成本接受，PI>1接受
- **画面**：投资决策像选餐厅——NPV看总价值，IRR看性价比

#### 20. 资本结构理论
- **考点**：MM定理、权衡理论、代理理论
- **编码**："资三论"——MM（无关论）、权衡（最优结构）、代理（代理成本）
- **画面**：MM定理说"在理想世界里，借钱不借钱无所谓"
- **修正**：现实中有税→借钱有税盾好处；有破产成本→不能借太多

#### 21. 股利政策
- **考点**：股利无关论、信号理论、代理理论、税差理论
- **编码**："股四论"——无关（MM）、信号（分红传递信心）、代理（减少自由现金流）、税差（少分红避税）
- **画面**：股利政策像给孩子的零花钱——给多少、什么时候给都有讲究

#### 22. 营运资本管理
- **考点**：现金管理、应收账款管理、存货管理
- **编码**："营三管"——现金（最佳持有量）、应收（信用政策）、存货（EOQ模型）
- **公式**：EOQ = √(2KD/Kc)——经济订货量
- **画面**：营运资本管理像管理家庭日常开支——要够用但不能闲置太多

#### 23. 产品成本计算
- **考点**：品种法、分批法、分步法
- **编码**："成三法"——品种法（大量单步骤）、分批法（定制小批量）、分步法（大量多步骤）
- **画面**：品种法像流水线（标准化），分批法像裁缝店（定制），分步法像汽车厂（多工序）

#### 24. 本量利分析（CVP）
- **考点**：盈亏平衡点、安全边际、边际贡献
- **编码**："本三算"——盈亏平衡（不赚不亏）、安全边际（距离平衡点多远）、边际贡献（每多卖一个贡献多少）
- **公式**：盈亏平衡量 = 固定成本 / (单价 - 单位变动成本)
- **画面**：盈亏平衡点像"零界线"——卖到这里刚好不亏

#### 25. 标准成本与差异分析
- **考点**：直接材料差异、直接人工差异、制造费用差异
- **编码**："差三因"——价格差异（买贵了）、数量差异（用多了）、效率差异（干活慢了）
- **公式**：材料价格差异 = (实际价-标准价) × 实际量
- **画面**：差异分析像查账——找出"哪里花多了"

#### 26. 作业成本法（ABC）
- **考点**：作业识别、成本动因、作业成本分配
- **编码**："作三步"——找作业、找动因、分配成本
- **画面**：ABC像精确制导——把间接成本精确分配到每个产品
- **与传统区别**：传统用单一分配基础，ABC用多个成本动因

#### 27. 全面预算
- **考点**：销售预算、生产预算、现金预算
- **编制**："预三步"——销售起点→生产预算→财务预算
- **画面**：全面预算像"年度计划书"——从卖多少倒推要生产多少、需要多少钱
- **关键**：销售预算是全面预算的起点

#### 28. 责任中心与业绩评价
- **考点**：成本中心、利润中心、投资中心
- **编码**："责三心"——成本中心（只管成本）、利润中心（管收入和成本）、投资中心（管投资回报）
- **指标**：成本中心→可控成本；利润中心→边际贡献；投资中心→ROI/RI

#### 29. 期权定价（二叉树模型）
- **考点**：单期二叉树、风险中性概率、看涨看跌平价
- **编码**："树三步"——建树（价格路径）、算概率（风险中性）、定价（折现）
- **公式**：C = [p×Cu + (1-p)×Cd] / (1+r)
- **画面**：二叉树像分叉路——股票价格在每个节点涨或跌

#### 30. 企业价值评估
- **考点**：DCF法、相对估值法、经济利润法
- **编码**："估三法"——DCF（现金流折现）、相对估值（P/E、P/B）、经济利润（EVA）
- **公式**：EVA = NOPIC - WACC × 投入资本
- **画面**：企业估值像给房子估价——DCF看未来租金，相对估值看邻居房价

### C组：CFA一级高频考点（20个）

#### 31. 货币时间价值（TVM）
- **考点**：PV、FV、年金、永续年金
- **编码**："时四算"——PV（现值）、FV（终值）、年金（定期支付）、永续（无限期）
- **公式**：FV=PV(1+r)^n；PV=PMT×[1-(1+r)^(-n)]/r
- **画面**：时间价值像"时光机"——今天的100元比明天的100元值钱

#### 32. 统计学基础
- **考点**：均值、中位数、标准差、正态分布、偏度、峰度
- **编码**："统六数"——均值（平均）、中位数（中间）、标准差（波动）、正态（钟形）、偏度（歪不歪）、峰度（尖不尖）
- **画面**：统计学像给数据"画像"——画出数据的形状特征

#### 33. 概率分布
- **考点**：二项分布、正态分布、t分布、蒙特卡洛模拟
- **编码**："概四布"——二项（成功失败）、正态（连续对称）、t（小样本）、蒙特卡洛（随机模拟）
- **画面**：概率分布像"骰子的规律"——告诉你每个结果的可能性

#### 34. 假设检验
- **考点**：原假设、备择假设、p值、显著性水平、I型/II型错误
- **编码**："检五步"——设假设→选统计量→定显著性→算p值→做决策
- **画面**：假设检验像法庭审判——原假设是"无罪推定"，证据足够才能定罪
- **I型错误**：冤枉好人（拒绝了真的原假设）；**II型错误**：放过坏人（接受了假的原假设）

#### 35. 财务报告分析（FRA）
- **考点**：IFRS vs GAAP差异、收入确认、存货计量、长期资产
- **编码**："报三比"——IFRS（国际准则）、GAAP（美国准则）、差异对比
- **画面**：IFRS像"原则导向"（看精神），GAAP像"规则导向"（看条文）

#### 36. 公司金融
- **考点**：NPV、IRR、资本结构、股利政策
- **编码**："公三策"——投资（NPV/IRR）、融资（资本结构）、分配（股利）
- **画面**：公司金融像"家庭理财"——决定怎么花钱、怎么借钱、怎么分钱

#### 37. 权益投资
- **考点**：股票估值（DDM、P/E、P/B）、市场效率
- **编码**："权三估"——DDM（股利折现）、乘数估值（P/E等）、EMH（有效市场）
- **EMH三种形式**：弱式（历史价格）、半强式（所有公开信息）、强式（所有信息）
- **画面**：有效市场像"透明鱼缸"——所有信息都被价格反映了

#### 38. 固定收益
- **考点**：债券定价、久期、凸性、利率期限结构
- **编码**："固四算"——定价（现金流折现）、久期（利率敏感度）、凸性（修正项）、期限结构（收益率曲线）
- **画面**：债券像"定时炸弹"——久期告诉你利率变动时炸弹的威力

#### 39. 衍生品
- **考点**：远期、期货、期权、互换的定价与策略
- **编码**："衍四品"——远期（私下约定）、期货（标准化）、期权（权利）、互换（交换现金流）
- **期权策略**：牛市价差、熊市价差、蝶式价差、跨式策略
- **画面**：衍生品像"金融乐高"——可以组合出各种形状

#### 40. 另类投资
- **考点**：私募股权、对冲基金、房地产、大宗商品
- **编码**："另四类"——PE（私募）、HF（对冲基金）、RE（房地产）、CM（大宗商品）
- **画面**：另类投资像"非主流"——不在股票债券的主流世界里

#### 41. 投资组合管理
- **考点**：马科维茨理论、CML、SML、CAPM
- **编码**："组四线"——有效前沿（马科维茨）、CML（资本市场线）、SML（证券市场线）、CAPM（定价模型）
- **画面**：投资组合像"调鸡尾酒"——混合不同酒（资产）达到最佳口感（风险收益）

#### 42. 职业道德（Ethics）
- **考点**：七大准则、GIPS、案例分析
- **编码**："道七则"——专业、诚信、独立、保密、勤勉、公平、忠诚
- **画面**：CFA道德像"金融界的圣经"——七大准则像七条戒律
- **重点**：道德在CFA考试中权重最高（15-20%）

#### 43. 经济学
- **考点**：供需弹性、GDP、通胀、货币政策、财政政策
- **编码**："经五论"——微观（供需弹性）、宏观（GDP/通胀）、货币（央行政策）、财政（政府政策）、国际（汇率/贸易）
- **画面**：经济学像"天气预报"——预测经济的阴晴雨雪

#### 44. 数量方法
- **考点**：货币时间价值、统计学、概率、假设检验、回归分析
- **数量**："量五算"——TVM、统计、概率、检验、回归
- **回归公式**：Y = a + bX + ε
- **画面**：数量方法像"数学工具箱"——给你各种计算工具

#### 45. 固定收益（利率期限结构）
- **考点**：收益率曲线、远期利率、利率理论
- **编码**："利三论"——预期理论（长期利率=短期利率预期平均）、市场分割（各期限独立）、流动性偏好（长债要补偿流动性）
- **画面**：收益率曲线像"山坡"——正常向上倾斜（长期>短期）

#### 46. 权益估值模型
- **考点**：DDM（股利折现模型）、FCFE、FCFF
- **编码**："估三模"——DDM（股利折现）、FCFE（股权自由现金流）、FCFF（公司自由现金流）
- **公式**：DDM：P = D₁/(r-g)
- **画面**：DDM像"苹果树"——每年结的苹果（股息）的现值之和

#### 47. 财务报告（收入确认）
- **考点**：IFRS 15收入确认五步法
- **编码**："收五步"——识别合同→识别履约义务→确定交易价格→分摊价格→确认收入
- **画面**：收入确认像"上菜"——签了合同（点菜）、做出菜品（履约）、标好价格、分配到每道菜、端上桌才算收入

#### 48. 财务报告（存货计量）
- **考点**：FIFO、LIFO、加权平均法
- **编码**："存三法"——FIFO（先进先出）、LIFO（后进先出）、加权平均
- **IFRS**：不允许LIFO；**GAAP**：允许LIFO
- **通胀时**：FIFO利润高（成本低），LIFO利润低（成本高）

#### 49. 投资组合（风险与收益）
- **考点**：系统风险vs非系统风险、分散化、β系数
- **编码**："险二分"——系统风险（不可分散）、非系统风险（可分散）
- **CAPM**：E(R) = Rf + β(Rm - Rf)
- **画面**：分散化像"不把鸡蛋放一个篮子"——非系统风险可以消除

#### 50. 道德案例分析
- **考点**：识别违规行为、判断准则、选择最佳行动
- **编码**："案三步"——识别违规→引用准则→选择行动
- **框架**：1)谁违规了？2)违反了哪条准则？3)应该怎么做？
- **画面**：道德案例像"法官判案"——找到事实、引用法律、做出判决

## 二、计算题快速解题模板

### 模板1：货币时间价值（TVM）

```
已知：PV/FV/PMT/r/n 中的若干项
求：未知项

步骤：
1. 确定已知量和未知量
2. 画时间轴（标注现金流方向）
3. 选公式：
   - 一次性：FV=PV(1+r)^n 或 PV=FV/(1+r)^n
   - 年金：PV=PMT×[1-(1+r)^(-n)]/r
   - 永续：PV=PMT/r
4. 代入计算

速算：
- 72法则：翻倍年数≈72÷利率
- 增长年金：PV=PMT×[1-((1+g)/(1+r))^n]/(r-g)
```

### 模板2：债券定价

```
已知：票面利率、市场利率、面值、期限
求：债券价格

步骤：
1. 确定现金流：每期利息C + 到期面值F
2. 用市场利率r折现：
   P = Σ[C/(1+r)^t] + F/(1+r)^n
3. 判断：P>面值=溢价，P<面值=折价，P=面值=平价

速记：
票面利率>市场利率 → 溢价
票面利率<市场利率 → 折价
票面利率=市场利率 → 平价
```

### 模板3：CAPM计算

```
已知：Rf、β、Rm
求：期望收益率E(R)

公式：E(R) = Rf + β × (Rm - Rf)

步骤：
1. 确定无风险利率Rf
2. 确定β系数
3. 确定市场收益率Rm
4. 代入计算

例子：Rf=3%，β=1.2，Rm=10%
E(R) = 3% + 1.2×(10%-3%) = 3% + 8.4% = 11.4%
```

### 模板4：WACC计算

```
已知：债务成本Kd、股权成本Ke、资本结构D/E、税率T
求：WACC

公式：WACC = E/(D+E)×Ke + D/(D+E)×Kd×(1-T)

步骤：
1. 算股权权重：E/(D+E)
2. 算债务权重：D/(D+E)
3. 算税后债务成本：Kd×(1-T)
4. 加权平均

例子：Ke=12%，Kd=6%，D/E=40/60，T=25%
WACC = 0.6×12% + 0.4×6%×(1-25%) = 7.2% + 1.8% = 9%
```

### 模板5：杜邦分析

```
已知：财务报表数据
求：ROE及其驱动因素

公式：ROE = 净利率 × 资产周转率 × 权益乘数

步骤：
1. 算净利率 = 净利润/收入
2. 算资产周转率 = 收入/总资产
3. 算权益乘数 = 总资产/净资产
4. 三者相乘=ROE

分析：
ROE下降→检查哪个因子下降最多→针对性改善
```

### 模板6：盈亏平衡分析

```
已知：固定成本F、单位变动成本V、单价P
求：盈亏平衡量Q*

公式：Q* = F / (P - V)

步骤：
1. 确定固定成本F
2. 确定单位边际贡献(P-V)
3. 除法计算

例子：固定成本100万，单价500元，变动成本300元
Q* = 1,000,000 / (500-300) = 5000件
```

### 模板7：期权盈亏计算

```
已知：标的现价S、执行价K、权利金C/P
求：到期盈亏

看涨期权：
- 买方盈亏 = max(S-K, 0) - C
- 卖方盈亏 = C - max(S-K, 0)

看跌期权：
- 买方盈亏 = max(K-S, 0) - P
- 卖方盈亏 = P - max(K-S, 0)

例子：买入Call，K=100，权利金5元，到期S=120
盈亏 = max(120-100, 0) - 5 = 20-5 = 15元（盈利）
```

## 四、案例分析框架记忆

### 框架1：道德案例分析（CFA）

```
步骤1：识别事实
- 谁？做了什么？涉及哪些利益相关者？

步骤2：识别违规
- 违反了哪条CFA准则？
  - I(A) 知识与能力
  - I(B) 独性与客观性
  - I(C) 不当陈述
  - I(D) 不当行为
  - II(A) 非公开信息
  - II(B) 市场操纵
  - III(A) 忠诚审慎
  - III(B) 公平交易
  - III(C) 适当性
  - V(A) 勤勉与合理基础

步骤3：选择最佳行动
- 最严格的合规选项通常是正确答案
- 先向上级/合规部门报告
- 如不解决→向监管机构报告
- 如仍不解决→与公司脱离关系

记忆："识别→引用→行动"
```

### 框架2：财务分析案例

```
步骤1：计算关键指标
- 偿债：流动比率、速动比率、资产负债率
- 营运：存货周转、应收周转
- 盈利：毛利率、净利率、ROE
- 发展：营收增长率、利润增长率

步骤2：趋势分析
- 3年趋势是上升还是下降？
- 与行业平均对比如何？

步骤3：杜邦分析
- ROE变化由哪个因子驱动？
- 利润率？周转率？杠杆？

步骤4：综合判断
- 财务状况健康吗？
- 有哪些风险？
- 有哪些改善建议？

记忆："算→比→拆→判"
```

### 框架3：投资决策案例

```
步骤1：项目概况
- 投资多少？期限多长？预期收益？

步骤2：现金流预测
- 初始投资（第0年）
- 经营现金流（各年）
- 终结现金流（最后一年）

步骤3：决策指标
- NPV = Σ[CF/(1+r)^t] - C₀
- IRR = NPV=0时的折现率
- 回收期 = 多少年回本

步骤4：敏感性分析
- 关键变量变化时NPV如何变化？
- 盈亏平衡点在哪里？

步骤5：风险评估
- 项目风险vs公司风险
- 需要调整折现率吗？

步骤6：决策建议
- NPV>0且IRR>WACC→接受
- NPV<0或IRR<WACC→拒绝

记忆："概→流→指→感→险→决"
```

### 框架4：资本结构案例

```
步骤1：现状分析
- 当前D/E比率多少？
- 当前WACC多少？

步骤2：计算不同结构下的WACC
- 假设D/E从当前变为20/80、30/70、40/60...
- 分别计算WACC

步骤3：找到最优结构
- WACC最低的D/E比率

步骤4：考虑约束条件
- 破产风险（D/E太高有破产风险）
- 代理成本（债务约束管理层）
- 税盾效应（利息抵税）

步骤5：决策建议
- 建议调整到最优资本结构
- 考虑逐步调整而非一步到位

记忆："现→算→优→约→决"
```
