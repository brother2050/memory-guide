# 🧘 冥想记忆练习

> 冥想是提升记忆力的"隐形武器"。每天10分钟，效果显著。

## 练习1：呼吸专注冥想（5分钟）

### 步骤
1. 找一个安静的地方坐下，坐直
2. 闭眼，深呼吸3次
3. 关注呼吸——感受空气进出鼻孔
4. 当思绪飘走时，温柔地将注意力带回呼吸
5. 持续5分钟

### 自评
- 能持续专注30秒以上：⭐⭐⭐
- 能持续专注15-30秒：⭐⭐
- 频繁走神：⭐（正常，继续练习）

## 练习2：学习前专注冥想（5分钟）

### 步骤
1. 学习前，闭眼坐下
2. 深呼吸3次
3. 设定意图："我将专注于学习XX"
4. 想象自己高效学习的画面
5. 睁眼，开始学习

## 练习3：学习后回顾冥想（5分钟）

### 步骤
1. 学习结束后，闭眼
2. 不看笔记，尝试回忆刚才学了什么
3. 想不起来的，标记为"需要复习"
4. 深呼吸3次，释放学习压力

## 练习4：睡前巩固冥想（10分钟）

### 步骤
1. 躺在床上，闭眼
2. 做10次深呼吸
3. 回顾今天的收获（不看笔记）
4. 释放所有思绪，专注于呼吸
5. 自然入睡

## 练习5：身体扫描冥想（15分钟）

### 步骤
1. 躺下或坐下
2. 从脚趾开始，逐渐扫描全身
3. 注意每个部位的感觉
4. 不评判，只观察
5. 持续15分钟

## 每日训练计划

| 天数 | 练习内容 | 时间 |
|------|---------|:----:|
| 第1天 | 练习1（呼吸专注） | 5分钟 |
| 第2天 | 练习2（学习前冥想） | 5分钟 |
| 第3天 | 练习3（学习后回顾） | 5分钟 |
| 第4天 | 练习1+2（综合） | 10分钟 |
| 第5天 | 练习4（睡前巩固） | 10分钟 |
| 第6天 | 练习5（身体扫描） | 15分钟 |
| 第7天 | 综合：学习前+学习后+睡前 | 20分钟 |
