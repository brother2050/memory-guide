# 🌍 地理记忆实操练习

## 练习1：中国省份记忆（15分钟）

### 任务
用宫殿法记忆34个省级行政区。

### 材料
```
北京、天津、上海、重庆（4个直辖市）
河北、山西、辽宁、吉林、黑龙江、江苏、浙江、安徽、福建、江西、山东、河南、湖北、湖南、广东、海南、四川、贵州、云南、陕西、甘肃、青海、台湾（25个省）
内蒙古、广西、西藏、宁夏、新疆（5个自治区）
香港、澳门（2个特别行政区）
```

### 步骤
1. 构建一个有34个站点的宫殿
2. 将每个省份的特征与站点建立联想
3. 按顺序回忆34个省份
4. 记录正确数：____/34
