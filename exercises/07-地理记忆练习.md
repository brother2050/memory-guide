# 🌍 地理记忆实操练习

## 🎯 练习目标

通过本练习，你将掌握：
1. **省份记忆**：用宫殿法记忆34个省级行政区
2. **省会配对**：联想法记忆省份-省会对应关系
3. **世界首都**：记忆15个重要国家的首都
4. **地理数据编码**：记忆面积、人口、GDP等数字

**预计用时**：15-25分钟/练习 | **前置知识**：记忆宫殿基础

## 练习1：中国省份记忆（15分钟）

### 任务
用宫殿法记忆34个省级行政区。

### 材料
```
北京、天津、上海、重庆（4个直辖市）
河北、山西、辽宁、吉林、黑龙江、江苏、浙江、安徽、福建、江西、山东、河南、湖北、湖南、广东、海南、四川、贵州、云南、陕西、甘肃、青海、台湾（25个省）
内蒙古、广西、西藏、宁夏、新疆（5个自治区）
香港、澳门（2个特别行政区）
```

### 步骤
1. 构建一个有34个站点的宫殿
2. 将每个省份的特征与站点建立联想
3. 按顺序回忆34个省份
4. 记录正确数：____/34

## 练习4：地理编码挑战（15分钟）

### 任务
记忆10个国家的地理数据（面积、人口、GDP）。

### 材料
| 国家 | 面积(万km²) | 人口(亿) | GDP(万亿美元) |
|------|:-----------:|:--------:|:-------------:|
| 中国 | 960 | 14.1 | 17.7 |
| 美国 | 937 | 3.3 | 25.5 |
| 俄罗斯 | 1710 | 1.4 | 1.8 |
| 加拿大 | 998 | 0.4 | 2.1 |
| 巴西 | 851 | 2.1 | 1.9 |
| 澳大利亚 | 769 | 0.3 | 1.7 |
| 印度 | 329 | 14.2 | 3.4 |
| 日本 | 38 | 1.3 | 4.2 |
| 德国 | 36 | 0.8 | 4.1 |
| 英国 | 24 | 0.7 | 3.1 |

### 步骤
1. 将每个数字编码为画面（如960=九六零=酒楼）
2. 将数字画面与国家特征建立联想
3. 用宫殿法放置10组数据
4. 回忆10个国家的面积、人口、GDP
5. 记录正确数：____/30（每个国家3个数据）

### 自评标准
| 正确数 | 等级 | 建议 |
|--------|------|------|
| 27-30/30 | ⭐⭐⭐ | 完美！可以挑战更多国家 |
| 20-26/30 | ⭐⭐ | 很好，检查数字编码的准确性 |
| 12-19/30 | ⭐ | 不错，先掌握数字编码再做地理 |
| <12/30 | 继续练习 | 先练习省份和首都配对 |
