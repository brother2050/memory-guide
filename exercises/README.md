## 🎯 使用建议

1. **初学者**：从01（记忆宫殿）和02（数字编码）开始
2. **进阶者**：每天选1-2个练习，交替训练不同能力
3. **竞赛选手**：重点练习02（数字）和03（扑克牌），配合05（综合挑战）
4. **考试备考**：选择对应学科的专项练习（06历史/07地理/08英语/09法律/10金融）

## 📊 训练原则

- **每天15-30分钟**：比一周练一次、每次2小时更有效
- **先准确再速度**：正确率>90%后再提速
- **记录成绩**：每次练习记录用时和正确率，追踪进步
- **间隔复习**：用Anki巩固练习中编码的内容
