# 📚 词汇记忆实操练习

> 词汇记忆是日常学习中最常见的需求。用联想法、编码法、宫殿法综合训练。

## 练习1：随机词语记忆（15分钟）

### 任务
记忆20个随机词语，然后回忆。

### 测试词语
```
钢琴  大象  火山  月亮  西瓜
机器人  雨伞  蝴蝶  钻石  吉他
企鹅  火箭  书本  自行车  苹果
围巾  雪人  螃蟹  热气球  望远镜
```

### 步骤
1. 将每个词语转化为具体画面
2. 用故事法或宫殿法串联
3. 合上书，回忆20个词语（可以打乱顺序）
4. 记录正确数：____/20

### 自评标准
| 正确数 | 等级 | 建议 |
|--------|------|------|
| 20/20 | ⭐⭐⭐ | 完美！尝试更长的列表 |
| 17-19/20 | ⭐⭐ | 很好，检查遗漏的联想 |
| 14-16/20 | ⭐ | 不错，加强联想的荒诞性 |
| <14/20 | 继续练习 | 用更夸张的联想 |

## 练习2：英语单词记忆（20分钟）

### 任务
用词根词缀法记忆20个英语单词。

### 测试单词
```
transport（运输）    predict（预测）    produce（生产）
inspect（检查）      export（出口）     import（进口）
review（复习）       preview（预览）    interview（面试）
telephone（电话）    photograph（照片） biology（生物）
psychology（心理学） philosophy（哲学） geography（地理）
democracy（民主）    monarchy（君主制） anarchy（无政府）
thermometer（温度计）microscope（显微镜）
```

### 步骤
1. 分析每个单词的词根词缀
   - trans-（跨越）+ port（搬运）= 运输
   - pre-（预先）+ dict（说）= 预测
2. 将词根含义与单词意思建立联想
3. 合上书，回忆20个单词的意思
4. 记录正确数：____/20

### 常用词根速查
| 词根 | 含义 | 示例 |
|------|------|------|
| port | 搬运 | transport, export, import |
| dict | 说 | predict, dictionary |
| spect | 看 | inspect, spectator |
| graph/gram | 写/画 | photograph, diagram |
| bio | 生命 | biology, biography |
| psycho | 心灵 | psychology |
| philo | 爱 | philosophy |
| geo | 地 | geography |
| demo | 人民 | democracy |
| mono | 单一 | monarchy |

## 练习3：成语记忆（15分钟）

### 任务
用画面法记忆15个成语。

### 测试成语
```
画蛇添足  守株待兔  亡羊补牢
掩耳盗铃  刻舟求剑  叶公好龙
杯弓蛇影  对牛弹琴  狐假虎威
鹤立鸡群  龙飞凤舞  虎头蛇尾
鸡犬不宁  狼吞虎咽  鱼目混珠
```

### 步骤
1. 将每个成语转化为具体画面
   - 画蛇添足 → 一个人画了一条蛇，然后给蛇画上了脚
   - 守株待兔 → 一个人抱着树桩等兔子撞上来
2. 用宫殿法放置15个画面
3. 回忆15个成语
4. 记录正确数：____/15

### 联想提示
- 越荒诞越好——正常的画面容易忘
- 加入动作和情感——画面"活"起来
- 用谐音辅助——如"叶公好龙"→ 叶子上的公爵爱龙

## 练习4：专业术语记忆（20分钟）

### 任务
选择你正在学习的学科，记忆10个专业术语的定义。

### 步骤
1. 选择10个核心术语
2. 用联想法将术语与定义建立联系
3. 用宫殿法放置
4. 回忆10个术语的定义
5. 记录正确数：____/10

### 示例（经济学术语）
| 术语 | 定义 | 联想画面 |
|------|------|----------|
| GDP | 国内生产总值 | 一个巨大的GDP字母堆在国境线内 |
| 通货膨胀 | 物价持续上涨 | 钱像气球一样膨胀 |
| 供给侧 | 生产端的改革 | 工厂在源源不断地生产 |
| 边际效益 | 每增加一单位的收益 | 一个人吃第10个包子时的表情 |

> 💡 选择你自己的学科，效果更好。

## 练习5：文章关键词记忆（15分钟）

### 任务
记忆一篇短文的核心关键词，然后复述文章大意。

### 测试文章
> 人工智能正在改变教育方式。个性化学习让每个学生都能按自己的节奏进步。AI教师可以24小时答疑，分析学生的学习数据，找出薄弱环节。但技术不能替代师生之间的情感连接。最好的教育是人机协作——AI处理知识传递，人类教师负责启发思考和情感支持。

### 步骤
1. 提取5-7个关键词：人工智能、教育、个性化、AI教师、数据、情感、人机协作
2. 用宫殿法放置关键词
3. 不看原文，用关键词复述文章大意
4. 自评复述的完整性：____/10

## 练习6：反向测试（10分钟）

### 任务
给定含义，回忆词语——这比正向记忆更难。

### 测试
```
1. 能在天上飞的金属交通工具 → ____
2. 一种能发出音乐的黑白键乐器 → ____
3. 一种会喷火的自然现象 → ____
4. 夜空中最亮的天体 → ____
5. 一种绿色的、能跳的昆虫 → ____
6. 一种透明的、能折射光线的宝石 → ____
7. 一种能在冰上行走的黑白鸟类 → ____
8. 一种能飞上太空的运载工具 → ____
9. 一种能放大远处物体的光学仪器 → ____
10. 一种冬天堆的雪做的小人 → ____
```

### 步骤
1. 根据描述写出对应的词语
2. 记录正确数：____/10
3. 这个练习检验你是否真正建立了"含义→画面→词语"的通路
