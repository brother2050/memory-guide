# 📅 历史年代记忆实操练习

## 🎯 练习目标

通过本练习，你将掌握：
1. **朝代顺序**：用故事法/口诀记忆中国15个朝代
2. **年份编码**：将重要历史年份转化为画面编码
3. **世界历史**：记忆10个关键世界历史事件及年份
4. **时间线构建**：在宫殿中构建完整的年代体系

**预计用时**：15-25分钟/练习 | **前置知识**：基本数字编码

## 练习1：中国朝代顺序（10分钟）

### 任务
用故事法或宫殿法记忆中国朝代顺序。

### 材料
```
夏 → 商 → 周 → 秦 → 汉 → 三国 → 两晋 → 南北朝 → 隋 → 唐 → 五代十国 → 宋 → 元 → 明 → 清
```

### 步骤
1. 将每个朝代转化为具体画面
2. 用故事法串联15个画面
3. 合上书，按顺序回忆
4. 记录正确数：____/15

## 练习4：时间线构建（15分钟）

### 任务
将中国历史关键年份按时间线排列，构建完整的年代宫殿。

### 材料
| 年份 | 事件 | 时间段 |
|------|------|--------|
| 前221 | 秦统一六国 | 古代 |
| 105 | 蔡伦改进造纸术 | 古代 |
| 618 | 唐朝建立 | 古代 |
| 960 | 北宋建立 | 古代 |
| 1271 | 元朝建立 | 古代 |
| 1368 | 明朝建立 | 古代 |
| 1644 | 清军入关 | 近代 |
| 1840 | 鸦片战争 | 近代 |
| 1911 | 辛亥革命 | 近代 |
| 1949 | 新中国成立 | 现代 |

### 步骤
1. 在纸上画一条时间轴（前221→1949）
2. 将10个年份标注在时间轴上
3. 为每个年份创建编码画面
4. 按时间顺序回忆所有年份和事件
5. 随机抽查：说事件→回忆年份，说年份→回忆事件
6. 记录正确数：____/10

### 自评标准
| 正确数 | 等级 | 建议 |
|--------|------|------|
| 10/10 | ⭐⭐⭐ | 完美！尝试扩展到更多年份 |
| 8-9/10 | ⭐⭐ | 很好，检查遗漏的编码 |
| 6-7/10 | ⭐ | 不错，加强时间线的整体感 |
| <6/10 | 继续练习 | 先练习15个朝代顺序再做年份 |
