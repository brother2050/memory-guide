# 📅 历史年代记忆实操练习

## 练习1：中国朝代顺序（10分钟）

### 任务
用故事法或宫殿法记忆中国朝代顺序。

### 材料
```
夏 → 商 → 周 → 秦 → 汉 → 三国 → 两晋 → 南北朝 → 隋 → 唐 → 五代十国 → 宋 → 元 → 明 → 清
```

### 步骤
1. 将每个朝代转化为具体画面
2. 用故事法串联15个画面
3. 合上书，按顺序回忆
4. 记录正确数：____/15

## 练习2：重要年份（15分钟）

### 任务

| 年份 | 事件 |
|------|------|
| 221 BC | 秦始皇统一中国 |
| 1840 | 鸦片战争 |
| 1911 | 辛亥革命 |
| 1919 | 五四运动 |
| 1921 | 中国共产党成立 |
| 1937 | 抗日战争全面爆发 |
| 1945 | 抗日战争胜利 |
| 1949 | 新中国成立 |
| 1966 | 文化大革命开始 |
| 1978 | 改革开放 |
| 1997 | 香港回归 |
| 1999 | 澳门回归 |

### 步骤
1. 将年份拆分为编码
2. 将编码与事件建立联想

5. 记录正确数：____/15
