# 🏛️ 记忆宫殿实操练习

> 不是看懂了就行——动手做才算学会。

## 练习1：构建你的第一个宫殿（15分钟）

### 步骤
1. **选择空间**：选择你最熟悉的5个地点（如你的家）
2. **设定站点**：在每个地点设定3个具体的站点（如客厅-沙发、茶几、电视）
3. **走动练习**：闭眼，按顺序"走"一遍15个站点，计时
4. **记录成绩**：走完15个站点用时____秒

### 自评标准
| 用时 | 等级 | 建议 |
|------|------|------|
| <30秒 | ⭐⭐⭐ | 优秀，可以开始放置信息 |
| 30-60秒 | ⭐⭐ | 良好，多走几遍会更快 |
| >60秒 | ⭐ | 需要更多练习，每天走3遍 |

---

## 练习2：在宫殿中放置信息（20分钟）

### 任务
用你的宫殿记忆以下15个随机词语：

```
苹果  自行车  大象  月亮  书本
钢琴  火山  钻石  蝴蝶  雨伞
机器人  西瓜  吉他  企鹅  火箭
```

### 步骤
1. 将每个词语与宫殿站点建立荒诞联想
2. 例如：站点1（沙发）→ 一个巨大的苹果坐在沙发上看电视
3. 完成15个联想后，闭眼走一遍宫殿
4. 不看原文，回忆15个词语
5. 记录正确数：____/15

### 自评标准
| 正确数 | 等级 | 建议 |
|--------|------|------|
| 15/15 | ⭐⭐⭐ | 完美！尝试更长的列表 |
| 12-14/15 | ⭐⭐ | 很好，检查遗漏的站点联想是否足够生动 |
| 9-11/15 | ⭐ | 不错，加强联想的荒诞性和具体性 |
| <9/15 | 继续练习 | 回到练习1，先熟悉宫殿再放置信息 |

---

## 练习3：宫殿扩展（15分钟）

### 任务
为你的家添加第二个房间的站点（如卧室），再记忆15个新词语。

### 测试词语
```
雪人  螃蟹  热气球  望远镜  摩天轮
恐龙  彩虹  潜水艇  向日葵  拳击手套
仙人掌  龙卷风  水晶球  长颈鹿  电风扇
```

### 步骤
1. 在卧室设定15个站点（如：床头、枕头、衣柜、梳妆台……）
2. 为每个词语建立荒诞联想
3. 从客厅走到卧室，连续回忆30个词语
4. 记录正确数：____/30

### 自评标准
| 正确数 | 等级 | 建议 |
|--------|------|------|
| 28-30/30 | ⭐⭐⭐ | 完美！宫殿已成型 |
| 24-27/30 | ⭐⭐ | 很好，检查过渡区域是否流畅 |
| 18-23/30 | ⭐ | 不错，加强新房间的熟悉度 |
| <18/30 | 继续练习 | 先单独练习新房间，再串联 |

---

## 练习4：宫殿维护（10分钟）

### 任务
回忆你之前放在宫殿里的信息，检查是否遗忘。

### 步骤
1. 不看任何笔记
2. 闭眼走一遍之前的宫殿
3. 记录遗忘的站点：____个
4. 对遗忘的站点重新建立联想
5. 再走一遍，确认全部记住

### 维护要点
- 遗忘的站点往往是联想不够荒诞
- 重新联想时加入更多感官细节（声音、气味、触感）
- 如果某个站点反复遗忘，考虑替换为更鲜明的物品

---

## 练习5：宫殿实战——演讲稿记忆（20分钟）

### 任务
用宫殿法记忆一段10个要点的演讲提纲。

### 模拟提纲
```
1. 开场：用一个惊人的统计数据吸引注意力
2. 问题：当前教育面临的核心挑战
3. 原因：传统方法的局限性
4. 案例：芬兰教育改革的成功经验
5. 方案：个性化学习路径设计
6. 技术：AI辅助教学的可能性
7. 障碍：实施过程中的阻力
8. 解决：分阶段推进策略
9. 愿景：未来教育的理想形态
10. 号召：每个人都可以参与改变
```

### 步骤
1. 选择一个新宫殿（如你的学校或公司）
2. 为每个要点创建一个生动画面
3. 闭眼走一遍宫殿
4. 不看原文，复述10个要点
5. 记录正确数：____/10
