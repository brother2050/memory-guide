# ⚖️ 法律记忆实操练习

## 🎯 练习目标

通过本练习，你将掌握：
1. **概念对比**：用对比法区分民法与刑法的核心区别
2. **法条编码**：将法条编号转化为画面编码
3. **宪法条款**：记忆6条核心宪法条文
4. **法考高频考点**：系统记忆20个高频考点

**预计用时**：15-20分钟/练习 | **前置知识**：基本法律概念

## 练习1：民法vs刑法对比（15分钟）

### 任务
用对比法记忆民法和刑法的核心区别。

### 材料
| 对比项 | 民法 | 刑法 |
|--------|------|------|
| 调整对象 | 平等主体之间的人身和财产关系 | 犯罪和刑罚 |
| 法律关系 | 横向（平等） | 纵向（国家→个人） |
| 追究方式 | 当事人起诉（不告不理） | 国家公诉 |
| 法律后果 | 民事责任（赔偿、道歉） | 刑事责任（管制、拘役、有期、无期、死刑） |
| 举证原则 | 谁主张谁举证 | 控方举证 |
| 追诉时效 | 2-20年 | 5-20年 |

### 步骤
1. 将每个对比项编码为对比画面
2. 用宫殿法放置6个对比
3. 回忆6个对比项
4. 记录正确数：____/6

## 练习4：法条编码（15分钟）

### 任务
用编码法记忆8个法考高频法条。

### 材料
| 法条 | 核心内容 | 编码联想 |
|------|----------|----------|
| 民法典第143条 | 民事法律行为有效条件：行为人有相应行为能力+意思表示真实+不违反法律强制性规定 | 143=一四三=一试三关（过三关才有效） |
| 民法典第1165条 | 过错责任：行为人因过错侵害他人民事权益造成损害的，应承担侵权责任 | 1165=一一六五=一一六五（有过错就有责任） |
| 刑法第20条 | 正当防卫：为制止不法侵害而采取的防卫行为 | 20=二十=防卫（20岁正当防卫的年龄） |
| 刑法第22条 | 犯罪预备：为了犯罪准备工具、制造条件 | 22=二二=准备（两手准备） |
| 刑法第23条 | 犯罪未遂：已着手实行但由于意志以外原因未得逞 | 23=二三=未遂（差一点就成了） |
| 刑法第24条 | 犯罪中止：自动放弃或自动有效地防止犯罪结果发生 | 24=二四=中止（自己停下来的） |
| 宪法第33条 | 公民在法律面前一律平等 | 33=三三=平等（天平两端一样重） |
| 宪法第46条 | 公民有受教育的权利和义务 | 46=四六=上学（四六级考试要上学） |

### 步骤
1. 理解每个法条的核心含义
2. 将法条编号编码为画面
3. 将编号画面与法条内容建立联想
4. 用宫殿法放置8个联想
5. 随机抽查：说编号→回忆内容，说内容→回忆编号
6. 记录正确数：____/8

### 自评标准
| 正确数 | 等级 | 建议 |
|--------|------|------|
| 8/8 | ⭐⭐⭐ | 完美！可以挑战更多法条 |
| 6-7/8 | ⭐⭐ | 很好，检查编号编码的准确性 |
| 4-5/8 | ⭐ | 不错，加强编号与内容的关联 |
| <4/8 | 继续练习 | 先练习民法vs刑法对比 |
