# ⚖️ 法律记忆实操练习

## 练习1：民法vs刑法对比（15分钟）

### 任务
用对比法记忆民法和刑法的核心区别。

### 材料
| 对比项 | 民法 | 刑法 |
|--------|------|------|
| 调整对象 | 平等主体之间的人身和财产关系 | 犯罪和刑罚 |
| 法律关系 | 横向（平等） | 纵向（国家→个人） |
| 追究方式 | 当事人起诉（不告不理） | 国家公诉 |
| 法律后果 | 民事责任（赔偿、道歉） | 刑事责任（管制、拘役、有期、无期、死刑） |
| 举证原则 | 谁主张谁举证 | 控方举证 |
| 追诉时效 | 2-20年 | 5-20年 |

### 步骤
1. 将每个对比项编码为对比画面
2. 用宫殿法放置6个对比
3. 回忆6个对比项
4. 记录正确数：____/6

## 练习2：刑法核心概念（15分钟）

### 任务
记忆6个刑法核心概念及其定义。

### 材料
| 概念 | 定义 |
|------|------|
| 犯罪构成四要件 | 犯罪客体、客观方面、主体、主观方面 |
| 正当防卫五条件 | 起因、时间、主观、对象、限度 |
| 紧急避险 | 为避免更大损害而损害较小利益 |
| 犯罪未遂 | 已着手实行但因意志外原因未得逞 |
| 犯罪中止 | 自动放弃或自动有效防止结果发生 |
| 共同犯罪 | 二人以上共同故意犯罪 |

### 步骤
1. 将每个概念编码为画面
2. 用宫殿法放置
3. 回忆6个概念的定义
