# 🔤 英语词根记忆实操练习

## 🎯 练习目标

通过本练习，你将掌握：
1. **常用词根**：记忆20个高频词根及其含义
2. **前后缀**：掌握15个常用前缀和10个常用后缀
3. **词根网络**：以核心词根扩展出8-10个相关单词
4. **词汇推测**：用词根词缀推测生词含义

**预计用时**：15-25分钟/练习 | **前置知识**：基本英语词汇

## 练习4：词根网络构建（15分钟）

### 任务
以一个核心词根为中心，扩展出相关单词网络。

### 材料
以词根 **duct/duc**（引导）为例：

| 单词 | 词根拆解 | 含义 |
|------|----------|------|
| produce | pro-（向前）+ duc（引导） | 生产（向前引导） |
| reduce | re-（回）+ duc（引导） | 减少（往回引导） |
| conduct | con-（共同）+ duct（引导） | 引导、指挥 |
| introduce | intro-（进入）+ duc（引导） | 介绍（引入） |
| educate | e-（出）+ duc（引导） | 教育（引导出来） |
| deduce | de-（向下）+ duc（引导） | 推导（向下引导） |
| induce | in-（向内）+ duc（引导） | 诱导（向内引导） |
| seduce | se-（离开）+ duc（引诱） | 诱惑（引开） |

### 步骤
1. 选择一个核心词根（如duct/duc）
2. 列出包含该词根的8-10个单词
3. 分析每个单词的前缀+词根+后缀
4. 将词根含义与每个单词建立联想
5. 闭眼回忆所有单词及其含义
6. 记录正确数：____/8

### 自评标准
| 正确数 | 等级 | 建议 |
|--------|------|------|
| 8/8 | ⭐⭐⭐ | 完美！尝试其他词根 |
| 6-7/8 | ⭐⭐ | 很好，检查遗漏的联想 |
| 4-5/8 | ⭐ | 不错，加强词根与前缀的关联 |
| <4/8 | 继续练习 | 先单独记忆词根再扩展 |
