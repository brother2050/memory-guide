# 🔤 英语词根记忆实操练习

## 练习1：常用词根（20分钟）

### 任务
记忆20个常用词根及其含义。

### 材料
| 词根 | 含义 | 示例单词 |
|------|------|---------|
| port | 搬运 | transport, export, import |
| dict | 说 | predict, dictionary, contradict |
| duc/duct | 引导 | produce, conduct, introduce |
| scrib/script | 写 | describe, prescription |
| spect | 看 | inspect, respect, expect |
| struct | 建造 | construct, structure, destroy |
| vert/vers | 转 | convert, reverse, university |
| ced/cess | 走 | proceed, success, access |
| mit/miss | 送 | transmit, mission, permit |
| pos/pon | 放 | position, component, opponent |
| cap/cep | 拿 | capture, accept, concept |
| fac/fic | 做 | factory, efficient, perfect |
| ject | 投 | project, reject, inject |
| tract | 拉 | attract, extract, contract |
| pend/pens | 挂 | depend, suspend, expense |
| graph/gram | 写 | photograph, diagram |
| log/logy | 学科 | biology, psychology, technology |
| path | 感受 | sympathy, empathy, pathetic |
| gen | 产生 | generate, gene, genetic |
| rupt | 断 | interrupt, corrupt, erupt |

### 步骤
1. 将词根与含义建立联想
2. 将词根与示例单词建立联系
3. 回忆20个词根的含义
4. 记录正确数：____/20
