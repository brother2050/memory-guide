# 🎮 记忆游戏练习

> 游戏是最好的学习方式。通过游戏训练记忆力，既有趣又有效。

## 练习1：记忆卡片配对游戏（10分钟）

### 任务
用扑克牌或专门的记忆卡片玩配对游戏。

### 材料
- 一副扑克牌（取出20张，组成10对）
- 或20张图片卡片（10对相同图片）

### 步骤
1. 将20张卡片正面朝下，随机排列成4×5的网格
2. 翻开两张卡片
3. 如果相同，拿走；如果不同，翻回去
4. 记住每张卡片的位置
5. 继续翻牌，直到所有配对完成
6. 记录翻牌次数：____次

### 自评标准
| 翻牌次数 | 等级 |
|:--------:|------|
| <25次 | ⭐⭐⭐ 记忆大师 |
| 25-35次 | ⭐⭐ 良好 |
| 35-50次 | ⭐ 入门 |
| >50次 | 需要更多练习 |

## 练习2：记忆迷宫（10分钟）

### 任务
在脑海中走一个迷宫，记住路径。

### 步骤
1. 看迷宫30秒
2. 合上迷宫
3. 在纸上画出正确路径
4. 对比原迷宫，检查正确性
5. 记录正确率：____%

### 自评标准
| 正确率 | 等级 |
|:------:|------|
| >90% | ⭐⭐⭐ 完美 |
| 70-90% | ⭐⭐ 良好 |
| 50-70% | ⭐ 入门 |
| <50% | 需要更多练习 |

## 练习3：数字记忆接龙（10分钟）

### 任务
与朋友玩数字记忆接龙游戏。

### 规则
1. A说一个数字（如"3"）
2. B重复A的数字，再加一个（如"3-7"）
3. 继续，直到有人记不住
4. 记录最长序列：____位

### 自评标准
| 最长序列 | 等级 |
|:--------:|------|
| >10位 | ⭐⭐⭐ 记忆大师 |
| 7-10位 | ⭐⭐ 良好 |
| 5-7位 | ⭐ 入门 |
| <5位 | 需要更多练习 |

## 练习4：故事串联游戏（10分钟）

### 任务
与朋友玩故事串联游戏。

### 规则
1. A说一个词语（如"大象"）
2. B重复A的词语，再加一个（如"大象-钢琴"）
3. 继续，直到有人记不住
4. 记录最长序列：____个词语

### 自评标准
| 最长序列 | 等级 |
|:--------:|------|
| >15个 | ⭐⭐⭐ 记忆大师 |
| 10-15个 | ⭐⭐ 良好 |
| 7-10个 | ⭐ 入门 |
| <7个 | 需要更多练习 |

## 练习5：购物清单记忆（10分钟）

### 任务
用记忆宫殿法记忆购物清单。

### 材料
```
牛奶  鸡蛋  面包  苹果  香蕉
牙膏  洗衣液  纸巾  酱油  醋
```

### 步骤
1. 在家中设定10个站点
2. 将每个物品与站点建立荒诞联想
3. 闭眼走一遍宫殿
4. 回忆10个物品
5. 记录正确数：____/10

### 自评标准
| 正确数 | 等级 |
|:------:|------|
| 10/10 | ⭐⭐⭐ 完美 |
| 8-9/10 | ⭐⭐ 良好 |
| 6-7/10 | ⭐ 入门 |
| <6/10 | 需要更多练习 |

## 练习6：人脸记忆挑战（10分钟）

### 任务
记忆10张人脸和名字。

### 步骤
1. 从杂志/手机中找10张人脸照片
2. 看每张脸30秒，提取最显著特征
3. 将名字与特征建立联想
4. 合上照片，回忆10张脸的名字
5. 记录正确数：____/10

## 练习7：诗词记忆挑战（10分钟）

### 任务
用画面法记忆一首古诗。

### 材料
《静夜思》李白
```
床前明月光，疑是地上霜。
举头望明月，低头思故乡。
```

### 步骤
1. 将每句诗转化为画面
2. 用宫殿法放置4个画面
3. 闭眼走宫殿，回忆诗句
4. 脱稿背诵
5. 记录正确数：____/4句

## 练习8：反向记忆（10分钟）

### 任务
将信息反向回忆。

### 材料
数字序列：1-3-5-7-9-2-4-6-8-10

### 步骤
1. 正向记忆数字序列（2分钟）
2. 反向回忆：10-8-6-4-2-9-7-5-3-1
3. 记录正确数：____/10
