# 💰 金融记忆实操练习

## 🎯 练习目标

通过本练习，你将掌握：
1. **金融指标**：记忆10个核心金融指标及其含义
2. **股票vs债券**：用对比法区分两种投资工具
3. **财务公式**：记忆PE、PB、ROE等核心公式
4. **指标临界值**：用编码法记忆10个指标的判断标准

**预计用时**：15-20分钟/练习 | **前置知识**：基本金融概念

## 练习1：核心金融指标（15分钟）

### 任务
记忆10个核心金融指标及其含义。

### 材料
| 指标 | 含义 | 公式/说明 |
|------|------|---------|
| GDP | 国内生产总值 | 一定时期内国内生产的最终产品和服务总值 |
| CPI | 消费者价格指数 | 反映居民消费价格变动 |
| PPI | 生产者价格指数 | 反映生产领域价格变动 |
| 市盈率(PE) | 股价/每股收益 | 衡量股票估值 |
| 市净率(PB) | 股价/每股净资产 | 衡量股票估值 |
| ROE | 净资产收益率 | 净利润/净资产 |
| 资产负债率 | 总负债/总资产 | 衡量财务风险 |
| 流动比率 | 流动资产/流动负债 | 衡量短期偿债能力 |
| 毛利率 | (收入-成本)/收入 | 衡量盈利能力 |
| 净利率 | 净利润/收入 | 衡量最终盈利能力 |

### 步骤
1. 将每个指标编码为画面
2. 将指标与含义/公式建立联想
3. 用宫殿法放置
4. 回忆10个指标
5. 记录正确数：____/10

## 练习3：财务公式记忆（15分钟）

### 任务
记忆5个核心财务公式。

### 材料
| 公式 | 含义 |
|------|------|
| PE = 股价 / EPS | 市盈率 |
| PB = 股价 / 每股净资产 | 市净率 |
| ROE = 净利润 / 净资产 | 净资产收益率 |
| WACC = E/(E+D)*Re + D/(E+D)*Rd*(1-T) | 加权平均资本成本 |
| DCF = Σ(CF/(1+r)^t) | 现金流折现 |

### 步骤
1. 将每个公式编码为画面
2. 将公式各部分与含义建立联想
3. 回忆5个公式
4. 记录正确数：____/5

## 练习4：指标编码（15分钟）

### 任务
用编码法记忆10个金融指标的临界值。

### 材料
| 指标 | 临界值 | 含义 | 编码联想 |
|------|--------|------|----------|
| 流动比率 | >2 | 短期偿债能力强 | 2=双倍（流动资产是负债的两倍） |
| 速动比率 | >1 | 更严格的偿债能力 | 1=一倍（去掉存货也够还） |
| 资产负债率 | <60% | 负债水平合理 | 60=六成（借的钱不超过六成） |
| 市盈率(PE) | 10-20 | 估值合理 | 10-20=十到二十（合理区间） |
| 市净率(PB) | <3 | 估值较低 | 3=三倍（股价不超净资产三倍） |
| ROE | >15% | 盈利能力强 | 15=一五（超过一成五算优秀） |
| 毛利率 | >30% | 产品有竞争力 | 30=三成（毛利超三成） |
| 净利率 | >10% | 盈利能力好 | 10=一成（净利超一成） |
| 存货周转率 | >5次 | 存货管理高效 | 5=五次（一年转五次） |
| 应收账款周转率 | >6次 | 收款效率高 | 6=六次（一年收六次） |

### 步骤
1. 理解每个指标的含义和临界值
2. 将临界值编码为画面
3. 将编码与指标含义建立联想
4. 用宫殿法放置10组数据
5. 随机抽查：说指标→回忆临界值
6. 记录正确数：____/10

### 自评标准
| 正确数 | 等级 | 建议 |
|--------|------|------|
| 10/10 | ⭐⭐⭐ | 完美！可以挑战更多指标 |
| 8-9/10 | ⭐⭐ | 很好，检查编码的准确性 |
| 6-7/10 | ⭐ | 不错，加强数值与含义的关联 |
| <6/10 | 继续练习 | 先练习核心金融指标 |
