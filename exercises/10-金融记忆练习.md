# 💰 金融记忆实操练习

## 练习1：核心金融指标（15分钟）

### 任务
记忆10个核心金融指标及其含义。

### 材料
| 指标 | 含义 | 公式/说明 |
|------|------|---------|
| GDP | 国内生产总值 | 一定时期内国内生产的最终产品和服务总值 |
| CPI | 消费者价格指数 | 反映居民消费价格变动 |
| PPI | 生产者价格指数 | 反映生产领域价格变动 |
| 市盈率(PE) | 股价/每股收益 | 衡量股票估值 |
| 市净率(PB) | 股价/每股净资产 | 衡量股票估值 |
| ROE | 净资产收益率 | 净利润/净资产 |
| 资产负债率 | 总负债/总资产 | 衡量财务风险 |
| 流动比率 | 流动资产/流动负债 | 衡量短期偿债能力 |
| 毛利率 | (收入-成本)/收入 | 衡量盈利能力 |
| 净利率 | 净利润/收入 | 衡量最终盈利能力 |

### 步骤
1. 将每个指标编码为画面
2. 将指标与含义/公式建立联想
3. 用宫殿法放置
4. 回忆10个指标
5. 记录正确数：____/10

## 练习2：股票vs债券对比（10分钟）

### 任务
用对比法记忆股票和债券的核心区别。

### 材料
| 对比项 | 股票 | 债券 |
|--------|------|------|
| 性质 | 所有权凭证 | 债权凭证 |
| 收益 | 股息+资本利得 | 利息 |
| 风险 | 高 | 低 |
| 期限 | 无固定期限 | 有固定期限 |
| 清偿顺序 | 最后 | 优先 |
| 发行主体 | 股份公司 | 政府/企业 |

### 步骤
1. 将每个对比项编码为对比画面
2. 用宫殿法放置6个对比
3. 回忆6个对比项
4. 记录正确数：____/6

## 练习3：财务公式记忆（15分钟）

### 任务
记忆5个核心财务公式。

### 材料
| 公式 | 含义 |
|------|------|
| PE = 股价 / EPS | 市盈率 |
| PB = 股价 / 每股净资产 | 市净率 |
| ROE = 净利润 / 净资产 | 净资产收益率 |
| WACC = E/(E+D)*Re + D/(E+D)*Rd*(1-T) | 加权平均资本成本 |
| DCF = Σ(CF/(1+r)^t) | 现金流折现 |

### 步骤
1. 将每个公式编码为画面
2. 将公式各部分与含义建立联想
3. 回忆5个公式
4. 记录正确数：____/5
