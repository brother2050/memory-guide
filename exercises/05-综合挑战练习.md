## 挑战4：日常应用挑战

### 任务
用记忆技巧完成以下日常任务：

| 任务 | 方法 | 完成 |
|------|------|:----:|
| 记住今天遇到的5个人的名字 | 联想+特征提取 | □ |
| 记住今天的10项待办事项 | 宫殿法或编码 | □ |
| 记住今天学到的5个新概念 | 编码+宫殿 | □ |
| 记住一个电话号码 | 数字编码 | □ |
| 记住一篇短文的核心内容 | 关键词提取+宫殿 | □ |

### 名字记忆技巧
1. **特征提取**：观察对方最突出的外貌特征
2. **名字联想**：将名字转化为具体画面
3. **绑定**：将名字画面与外貌特征绑定
4. **重复**：在对话中使用对方的名字

### 示例
遇到一个叫"李明"的人，他戴着一副圆框眼镜：
- 李 → 李子（水果）
- 明 → 明亮的太阳
- 联想：圆框眼镜里装着两个李子，李子在发光

## 进阶建议

### 当你能稳定完成挑战1（>90分）后：
1. 减少时间限制（30分钟→20分钟）
2. 增加内容量（数字50位→100位）
3. 加入干扰（在有噪音的环境中练习）
4. 尝试连续记忆（不休息，连续完成多个挑战）

### 竞赛准备
如果你的目标是参加记忆竞赛：
1. 熟记PAO系统（扑克牌）
2. 熟记两位数编码系统（数字）
3. 构建至少30个宫殿站点
4. 每天练习1小时以上
5. 目标：5分钟内记住一副扑克牌，3分钟内记住50位数字
