# 15-proc-experiment-01.md — 实验步骤记忆

## 记忆方法概述

实验步骤记忆采用**四阶段编码法**：

| 阶段 | 编码 | 含义 |
|------|------|------|
| P | Preparation | 器材准备 |
| O | Operation | 操作步骤 |
| V | Observation | 观察记录 |
| C | Conclusion | 结论分析 |

**记忆锚点公式**：`实验名→P(器材)→O(操作)→V(现象)→C(结论)`

将实验室空间映射为记忆宫殿：

| 位置 | 区域 | 存放器材 |

## 三、物理实验4个

### 🔬 实验1：测量固体密度

**器材清单（挂钩法）**：

| 挂钩 | 器材 | 联想 |
|------|------|------|
| 1 | 电子天平 | "天平像跷跷板" |
| 2 | 量筒（100mL） | "量筒像试管的爸爸" |
| 3 | 细线 | "细线绑住物体" |
| 4 | 待测固体（金属块） | "金属块沉甸甸" |
| 5 | 水 | "透明的水" |
| 6 | 纸和笔 | "记录数据" |

**步骤编码**：

```
步骤1 [P] 检查天平是否归零 → 调平
步骤2 [O] 用天平称量固体质量 m = ___g（记为m₁）
步骤3 [O] 量筒中倒入适量水 → 记录体积 V₁ = ___mL
步骤4 [O] 用细线绑住固体 → 缓慢浸入水中（不溅出）
步骤5 [V] 记录水面上升后体积 V₂ = ___mL
步骤6 [C] 计算：
   - 固体体积 V = V₂ - V₁
   - 密度 ρ = m / V
   - 查表对比，判断材质
```

**记忆口诀**：
```
先称质量后量体积，
浸入水中读液面，
两次体积相减得体积，
质量除以体积得密度。
```

**常见错误对比记忆**：

| 正确操作 | 错误操作 | 后果 |
|----------|----------|------|
| 先称质量再量体积 | 先量体积再称质量 | 固体沾水影响质量 |
| 细线绑住浸入 | 直接扔进量筒 | 砸碎量筒底部 |
| 读凹液面最低处 | 读液面最高处 | 体积偏大 |

### 🔬 实验2：探究凸透镜成像规律

**器材清单**：

| 挂钩 | 器材 |
|------|------|
| 1 | 光具座 |
| 2 | 凸透镜（f=10cm） |
| 3 | 蜡烛 |
| 4 | 光屏 |
| 5 | 火柴 |
| 6 | 尺子 |

**步骤编码**：

```
步骤1 [P] 在光具座上依次放：蜡烛→凸透镜→光屏
步骤2 [P] 调节三者中心等高（"三心一线"）
步骤3 [O] 点燃蜡烛 → 放在2f以外（>20cm处）
步骤4 [V] 移动光屏 → 找到最清晰的像 → 记录像的特点
步骤5 [O] 将蜡烛移到2f处（20cm）
步骤6 [V] 移动光屏找到像 → 记录
步骤7 [O] 将蜡烛移到f和2f之间（10-20cm）
步骤8 [V] 移动光屏找到像 → 记录
步骤9 [O] 将蜡烛移到f处（10cm）
步骤10 [V] 观察：光屏上无像 → 正立放大虚像
步骤11 [O] 将蜡烛移到f以内（<10cm）
步骤12 [V] 从透镜另一侧观察：正立放大虚像
步骤13 [C] 总结规律
```

**成像规律记忆表**：

| 物距(u) | 像的性质 | 像距(v) | 记忆口诀 |
|---------|----------|---------|----------|
| u > 2f | 倒立、缩小、实像 | f < v < 2f | "远小倒" |
| u = 2f | 倒立、等大、实像 | v = 2f | "等距等大" |
| f < u < 2f | 倒立、放大、实像 | v > 2f | "中大倒" |
| u = f | 不成像 | ∞ | "焦点无像" |
| u < f | 正立、放大、虚像 | — | "近大正" |

**记忆故事**：
> 物体从远处走来（u从大到小）：
> - 远处看：人很小（缩小的实像）
> - 走到两倍焦距：和你一样大（等大实像）
> - 继续走近：越来越大（放大实像）
> - 走到焦点：突然消失了（不成像）
> - 走过焦点：变成正立的了（虚像，像放大镜）

### 🔬 实验3：测量小灯泡的电功率

**器材清单**：

| 挂钩 | 器材 |
|------|------|
| 1 | 小灯泡（3.8V） |
| 2 | 电流表 |
| 3 | 电压表 |
| 4 | 滑动变阻器 |
| 5 | 电源（电池组） |
| 6 | 开关、导线 |

**步骤编码**：

```
步骤1 [P] 画出电路图（伏安法）
步骤2 [P] 按电路图连接实物（开关断开、滑动变阻器调到最大）
步骤3 [P] 检查：电流表串联、电压表并联、量程合适
步骤4 [O] 闭合开关 → 调节滑动变阻器 → 使电压表示数为额定电压(3.8V)
步骤5 [V] 读出电流表示数 I = ___A
步骤6 [O] 调节滑动变阻器 → 使电压略低于额定电压(3.0V)
步骤7 [V] 读出电流表示数 I = ___A
步骤8 [O] 调节滑动变阻器 → 使电压略高于额定电压(4.2V)
步骤9 [V] 读出电流表示数 I = ___A
步骤10 [C] 计算三种情况下的功率 P = UI
         分析：实际功率与亮度的关系
```

**记忆口诀**：
```
画图连接先检查，
开关断开滑最大，
闭合调阻到额定，
电压电流同时读，
三次实验三组数，
P等于U乘I。
```

**常见错误对比**：

| 正确 | 错误 | 危害 |
|------|------|------|
| 开关断开时连接电路 | 带电操作 | 触电/短路 |
| 滑动变阻器调到最大 | 不调直接合开关 | 烧毁灯泡 |
| 电压表并联灯泡 | 电压表串联 | 灯泡不亮、读数错误 |
| 量程选0-15V | 量程选0-3V | 超量程损坏电表 |

### 🔬 实验4：探究杠杆平衡条件

**器材清单**：

| 挂钩 | 器材 |
|------|------|
| 1 | 杠杆尺 |
| 2 | 铁架台 |
| 3 | 钩码（多个） |
| 4 | 弹簧测力计 |
| 5 | 细线 |

**步骤编码**：

```
步骤1 [P] 将杠杆尺安装在铁架台上 → 调节平衡螺母使杠杆水平平衡
步骤2 [O] 在左侧第2格挂3个钩码
步骤3 [V] 观察：杠杆倾斜（左侧下沉）
步骤4 [O] 在右侧第3格挂2个钩码
步骤5 [V] 观察：杠杆恢复水平平衡！
步骤6 [O] 改变钩码数量和位置，重复5次
步骤7 [V] 记录每次数据：F₁×L₁ 和 F₂×L₂
步骤8 [C] 结论：F₁×L₁ = F₂×L₂（动力×动力臂=阻力×阻力臂）
```

**记忆要点**：
- "调平"是第一步（像天平归零）
- 力臂是从支点到力的作用线的垂直距离（不是到力的作用点！）
- 每次实验都要让杠杆在水平位置平衡（方便读力臂）

### 🧪 实验5：制取氧气（加热高锰酸钾法）

**器材清单**：

| 挂钩 | 器材 |
|------|------|
| 1 | 试管 |
| 2 | 铁架台（含铁夹） |
| 3 | 酒精灯 |
| 4 | 集气瓶 |
| 5 | 水槽 |
| 6 | 导管、橡皮塞 |
| 7 | 高锰酸钾 |
| 8 | 棉花 |

**步骤编码**：

```
步骤1 [P] 检查装置气密性（手握试管看气泡）
步骤2 [P] 装入高锰酸钾 → 试管口塞一团棉花（防粉末堵塞）
步骤3 [P] 连接装置：试管口略向下倾斜（防冷凝水回流炸裂）
步骤4 [P] 集气瓶装满水倒扣在水槽中
步骤5 [O] 点燃酒精灯 → 先预热试管（来回移动）→ 再集中加热药品部位
步骤6 [V] 观察：气泡从导管口连续均匀冒出
步骤7 [O] 将导管口伸入集气瓶 → 排水法收集气体
步骤8 [V] 集气瓶口有大气泡冒出 → 收集满
步骤9 [O] 先将导管移出水面 → 再熄灭酒精灯！（防止水倒吸炸裂试管）
步骤10 [C] 将带火星的木条伸入集气瓶 → 木条复燃 → 证明是氧气
```

**⚠️ 安全记忆锚点**：

```
"S9-S4"：
- S9（先撤导管后灭灯）→ 水倒吸会炸裂试管！
- S4（试管口略向下）→ 冷凝水回流会炸裂！
- 试管口棉花 → 防止高锰酸钾粉末喷出
```

**操作顺序口诀**：
```
查装定点收移熄
（检查→装药→定装置→点灯→收集→移管→熄灯）
记住：移管在熄灯之前！
```

|------|------|
| 1 | 锥形瓶 |
| 2 | 长颈漏斗 |
| 3 | 导管 |

| 5 | 石灰石（大理石） |
| 6 | 稀盐酸 |
| 7 | 澄清石灰水 |

**步骤编码**：

```

步骤2 [P] 锥形瓶中放入石灰石 → 连接长颈漏斗（漏斗下端浸入液面以下）
步骤3 [P] 从长颈漏斗倒入稀盐酸
步骤4 [V] 观察：大量气泡产生（CaCO₃+2HCl→CaCl₂+H₂O+CO₂↑）
步骤5 [O] 向上排空气法收集（CO₂比空气重）
步骤6 [V] 将燃着的木条放集气瓶口 → 熄灭 → 收集满
步骤7 [C] 检验CO₂：
   - 将气体通入澄清石灰水 → 变浑浊 ✓
```

- 长颈漏斗下端必须浸入液面（防止气体从漏斗逸出）
- CO₂用向上排空气法（密度比空气大）
- 验满：燃着木条放瓶口（不是瓶内！）

### 🧪 实验7：配制50g 5%的氯化钠溶液

**器材清单**：

| 挂钩 | 器材 |
|------|------|
| 1 | 托盘天平 |
| 2 | 量筒（50mL） |
| 3 | 烧杯 |
| 4 | 玻璃棒 |
| 5 | 药匙 |
| 6 | 氯化钠（食盐） |
| 7 | 胶头滴管 |

**步骤编码**：

```
步骤1 [C] 计算：需NaCl = 50g × 5% = 2.5g，需水 = 50g - 2.5g = 47.5g（≈47.5mL）
步骤2 [P] 用托盘天平称量2.5g氯化钠（左物右码）
步骤3 [P] 用量筒量取47.5mL水（平视凹液面最低处）
步骤4 [O] 将氯化钠倒入烧杯
步骤5 [O] 将量取的水倒入烧杯
步骤6 [O] 用玻璃棒搅拌至完全溶解
步骤7 [V] 观察：得到无色透明溶液
步骤8 [C] 装瓶贴标签："5% NaCl溶液 50g"
```

**记忆口诀**：
```
算称量倒搅装贴
（计算→称溶质→量溶剂→倒入→搅拌→装瓶→贴标签）
```

**易错对比**：

| 正确 | 错误 | 后果 |
|------|------|------|
| 先称盐再量水 | 先量水再称盐 | 盐可能吸潮 |
| 玻璃棒搅拌 | 用温度计搅拌 | 温度计易碎 |
| 量取47.5mL水 | 量取50mL水 | 溶液浓度偏稀 |

## 六、实验报告结构记忆

### 标准实验报告模板

| 部分 | 内容 | 记忆锚点 |
|------|------|----------|
| 1. 实验目的 | 为什么做这个实验 | "为什么" |
| 2. 实验原理 | 理论依据/公式 | "依据什么" |
| 3. 实验器材 | 所有用品清单 | "用什么" |
| 4. 实验步骤 | 操作过程（编号） | "怎么做" |
| 5. 数据记录 | 表格记录原始数据 | "看到什么" |
| 6. 数据处理 | 计算/画图 | "算出什么" |
| 7. 实验结论 | 总结规律 | "证明了什么" |
| 8. 误差分析 | 可能的误差来源 | "哪里不准" |

**记忆口诀**："目原器步数处结误"→"木圆七步数处结雾"
