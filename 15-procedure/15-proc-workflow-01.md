# 15-proc-workflow-01.md — 工作流程记忆

## 记忆方法概述

工作流程记忆的核心是**流程图+决策树+编码**：
- 每种流程用标准流程图符号编码
- 关键决策点用"如果...那么..."结构
- 表单/文件清单用挂钩法
- 流程起点和终点用定位法定位

### 流程图符号编码

| 符号 | 含义 | 编码 | 记忆形象 |
|------|------|------|----------|
| ⬜ | 开始/结束 | T | 信封（打开/封口） |
| 🔷 | 操作/步骤 | A | 方块积木 |
| 🔷? | 判断/决策 | D | 菱形钻石（要选择） |
| ➡️ | 流向 | → | 箭头（方向） |
| ⬛ | 文档 | R | 文件（Record） |

## 一、10种工作流程

### 📋 流程1：请假审批流程

**流程图**：

```
[开始] ⬜
  ↓
[填写请假申请表] 🔷 → 提交OA系统
  ↓
{直属上级审批} 🔷?
  ├─ 批准 → {HR审核} 🔷?
  │           ├─ 批准 → [更新考勤系统] 🔷 → [通知申请人] ⬜
  │           └─ 驳回 → [通知申请人修改] 🔷 → 回到填写申请
  └─ 驳回 → [通知申请人原因] 🔷 → [结束] ⬜
```

**记忆编码**：
```
T(开始) → A1(填表) → D1(上级批?) 
  → [是] → D2(HR审?) → [是] → A2(更新考勤) → T(通知) → T(结束)
  → [否] → A3(通知原因) → T(结束)
  → D2[否] → A4(通知修改) → 回到A1
```

**表单清单（挂钩法）**：

| 挂钩 | 表单/材料 |
|------|----------|
| 1 | 请假申请表 |
| 2 | 假期类型证明（病假需病历） |
| 3 | 工作交接单 |
| 4 | 紧急联系人信息 |
| 5 | 审批流转记录 |

**关键决策记忆**：
- 1天以内：直属上级批即可
- 1-3天：需要部门经理批
- 3天以上：需要HR+总经理批
- 病假3天以上：需要医院证明

### 📋 流程4：急救流程（心肺复苏CPR）

**流程图**：

```
[发现有人倒地] ⬜
  ↓
[确认安全环境] 🔷 → 不安全 → [撤离求助]
  ↓ 安全
[轻拍双肩呼唤] 🔷
  ↓
{有反应?} 🔷?
  ├─ 有 → [询问情况] 🔷 → [拨打120] → [结束]
  └─ 无 → [检查呼吸(看听感)] 🔷 (5-10秒)
              ↓
          {有呼吸?} 🔷?
          ├─ 有 → [恢复体位] 🔷 → [持续观察] → [等待120]
          └─ 无 → [立即呼救120] 🔷
                      ↓
                  [胸外按压30次] 🔷
                      ↓
                  [开放气道(仰头抬颏)] 🔷
                      ↓
                  [人工呼吸2次] 🔷
                      ↓
                  [重复30:2] 🔷 → 直到120到达或患者恢复
```

**CPR记忆口诀**：
```
叫叫CAB
（叫患者→叫120→Compression按压→Airway气道→Breathing呼吸）

按压口诀：
"100-120次/分钟，深度5-6厘米，
 30次按压2次吹气，
 每2分钟换人按压"
```

**按压位置记忆**：
- 两乳头连线中点（胸骨下半段）
- 掌根重叠，手指交叉翘起
- 手臂伸直，垂直向下按

**错误操作对比**：

| 正确 | 错误 | 后果 |
|------|------|------|
| 先确认环境安全 | 直接冲上去 | 可能造成二次伤害 |
| 按压深度5-6cm | 按压太浅 | 无法有效泵血 |
| 按压频率100-120次/分 | 太快或太慢 | 影响效果 |
| 按压后完全回弹 | 不完全回弹 | 心脏无法充盈 |

## 二、流程图记忆策略

### 策略1：起点-终点定位法

每种流程用"信封"（开始/结束）标记首尾：

| 流程 | 起点（信封开） | 终点（信封封） |
|------|----------------|----------------|
| 请假 | 填写申请表 | 通知结果 |
| 招聘 | 发布职位 | 入职完成 |
| 项目 | 需求分析 | 项目总结 |
| 急救 | 发现倒地 | 患者恢复/120到达 |
| 报销 | 收集发票 | 到账通知 |

### 策略2：决策点标记法

所有判断节点用"钻石"标记，记住每个分支：

```
{条件} 🔷?
  ├─ 是 → 路径A（正常流程）
  └─ 否 → 路径B（异常处理/退回）
```

### 策略3：并行任务标记法

当多个任务同时进行时，用分叉线表示：

```
[主流程] ─┬─ [任务A]
           ├─ [任务B]
           └─ [任务C]
               ↓
           [汇合点]
```

## 记忆方法对比表

| 方法 | 优点 | 缺点 | 适合人群 | 推荐指数 |
|------|------|------|----------|----------|
| **流程图符号编码法** | 标准化符号，一目了然 | 需要记住符号系统 | 职场人士/项目管理者 | ⭐⭐⭐⭐⭐ |
| **挂钩法（表单清单）** | 文件/材料清单快速记忆 | 需要建立挂钩体系 | 需要记忆清单的人 | ⭐⭐⭐⭐ |
| **决策点标记法** | 分支清晰，不易遗漏 | 分支太多时容易混乱 | 流程设计者 | ⭐⭐⭐⭐ |
| **起点-终点定位法** | 快速把握流程框架 | 只能记住首尾，中间细节不足 | 考前快速回顾 | ⭐⭐⭐ |
| **故事串联法** | 把流程编成故事，生动有趣 | 故事可能与实际流程脱节 | 喜欢故事的人 | ⭐⭐⭐⭐ |
| **实操演练法** | 动手做一遍胜过看十遍 | 需要实际场景 | 所有人（最有效） | ⭐⭐⭐⭐⭐ |

### 🎮 流行文化增强编码示例

| 流程 | 原编码 | 增强版（动漫/游戏/影视） | 记忆点 |
|------|--------|--------------------------|--------|
| 请假审批 | 填表→上级→HR | 像《火影忍者》下忍→中忍→火影的审批链 | 🔗 审批=升级考试 |
| CPR急救 | 叫叫CAB | 像《工作细胞》血小板紧急救援的流程 | 🔗 急救=细胞救援 |
| 项目管理 | 需→设→开→测→部 | 像《我的世界》建房子：先画图纸→设计→建造→检查→入住 | 🔗 建房子=项目管理 |
| 招聘面试 | 简历→电话→一面→二面 | 像《海贼王》路飞过五关斩六将加入草帽团 | 🔗 面试=闯关 |
| Bug修复 | 提交→确认→修复→测试 | 像《精灵宝可梦》发现Bug→抓捕→修复→放回 | 🔗 修Bug=抓宝可梦 |

## 方法选择指南

### 🎯 根据你的场景选择

```
你需要记忆什么类型的工作流程？
│
├── 🏢 日常办公流程（请假/报销/采购）
│   → 推荐：流程图符号编码法 + 挂钩法
│   → 用标准符号画出流程，清单用挂钩法
│   → 每个流程：30分钟编码
│
├── 💻 技术流程（项目管理/Bug修复）
│   → 推荐：决策点标记法 + 实操演练法
│   → 标记每个决策分支，实际操作一遍
│   → 每个流程：1小时编码+演练
│
├── 🚨 应急流程（急救/消防/投诉处理）
│   → 推荐：故事串联法 + 实操演练法
│   → 把应急流程编成故事，定期演练
│   → 每个流程：20分钟编码+定期演练
│
└── 📝 考试复习（流程图绘制/流程选择题）
    → 推荐：起点-终点定位法 + 口诀速记法
    → 快速把握框架，口诀记住关键步骤
    → 每个流程：10分钟快速回顾
```
