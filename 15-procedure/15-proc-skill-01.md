# 15-proc-skill-01.md — 技能步骤记忆

## 记忆方法概述

技能学习的步骤记忆采用**阶段编码+错误对比**策略：
- 每种技能分为"生疏→入门→熟练→精通"四个阶段
- 关键步骤用数字编码锁定顺序
- 常见错误用对比表格强化正确操作
- 从生疏到熟练的路径用里程碑标记

### 技能阶段编码

| 阶段 | 编码 | 特征 | 记忆锚点 |
|------|------|------|----------|
| 生疏期 | S1 | 需要刻意记忆每一步 | "像背课文" |
| 入门期 | S2 | 能完成但不流畅 | "像走路看脚" |
| 熟练期 | S3 | 自动化执行 | "像骑自行车" |
| 精通期 | S4 | 能灵活应变创新 | "像呼吸一样自然" |

## 一、10种技能的步骤记忆

### 🏊 技能1：游泳（自由泳）

**关键步骤编码**：

```
阶段S1（陆上练习）：
  步骤1 [呼吸] 岸上练习：嘴吸鼻呼，侧头呼吸
  步骤2 [打腿] 扶池壁练习：大腿带动小腿，脚踝放松，上下打水
  步骤3 [划手] 站立练习：手臂入水→抱水→推水→移臂

阶段S2（水中入门）：
  步骤4 [漂浮] 扶墙漂浮：身体平展，头埋水中，全身放松
  步骤5 [蹬壁滑行] 蹬壁后保持流线型，不划手不打腿
  步骤6 [打腿+呼吸] 扶板打腿，侧头呼吸

阶段S3（协调配合）：
  步骤7 [完整配合] 打腿6次 + 划手2次 + 呼吸1次（6:2:1节奏）
  步骤8 [换气时机] 手臂推水时侧头，嘴出水面快速吸气
  步骤9 [身体转动] 以身体纵轴为轴，左右转动30-45°

阶段S4（提高效率）：
  步骤10 [高肘移臂] 手臂出水后肘高于手，前伸入水
  步骤11 [二次打腿] 简化为2次打腿1次划手（2:1节奏）
  步骤12 [翻滚转身] 接近池壁时团身翻滚，蹬壁出发
```

**呼吸口诀**：
```
水下用鼻慢慢呼，
转头用嘴快快吸，
呼三吸一节奏稳，
不要抬头要侧头。
```

**错误对比**：

| 正确 | 错误 | 后果 |
|------|------|------|
| 侧头呼吸 | 抬头呼吸 | 腿部下沉，阻力大 |
| 高肘入水 | 直臂拍水 | 肩膀受伤，效率低 |
| 脚踝放松 | 脚尖绷直 | 打腿费力，推进小 |
| 身体平直 | 身体弯曲 | 阻力大，速度慢 |

### 🚗 技能2：驾驶（手动挡汽车）

**关键步骤编码**：

```
阶段S1（基础操作）：
  步骤1 [座椅调整] 座椅前后/高低，靠背角度，方向盘距离
  步骤2 [后视镜调整] 左右后视镜+中央后视镜
  步骤3 [安全带] 系安全带（必做！）
  步骤4 [认识踏板] 左离合、中刹车、右油门

阶段S2（起步停车）：
  步骤5 [点火] 踩离合→挂空挡→拧钥匙→启动
  步骤6 [起步] 踩离合→挂1挡→慢抬离合→感觉车抖动（半联动）→松手刹→轻踩油门
  步骤7 [停车] 松油门→踩刹车→车停稳→踩离合→挂空挡→拉手刹→熄火

阶段S3（换挡行驶）：
  步骤8 [升挡] 加速到2000转→松油门→踩离合→挂高挡→松离合
  步骤9 [降挡] 减速→踩离合→挂低挡→松离合（必要时补油）
  步骤10 [转向] 打转向灯→看后视镜→确认安全→打方向盘→回正

阶段S4（综合驾驶）：
  步骤11 [坡道起步] 半联动+手刹配合（防止溜车）
  步骤12 [倒车入库] 看后视镜+方向盘修正
  步骤13 [高速公路] 保持车距、变道规则
```

**离合器口诀**：
```
一快二慢三联动，
（抬离合：第一段快抬，第二段慢抬，第三段找到联动点）
联动点上停一停，
（感觉到车抖动，稳住离合）
油门跟上松手刹，
（轻踩油门，同时松手刹）
车辆平稳就起步。
```

**错误对比**：

| 正确 | 错误 | 后果 |
|------|------|------|
| 先踩离合再挂挡 | 不踩离合硬挂 | 打齿轮，损坏变速箱 |
| 半联动时稳住 | 离合抬太快 | 熄火 |
| 停车先踩刹车 | 停车先踩离合 | 没有发动机制动，刹车距离长 |
| 变道前看后视镜 | 不看直接变道 | 事故！ |

```

阶段S3（实战应用）：
  步骤9 [列表操作] 增删改查、切片、排序
  步骤10 [字典操作] key-value存取、遍历
  步骤11 [文件读写] open()、read()、write()
  步骤12 [异常处理] try/except/finally

阶段S4（项目实战）：
  步骤13 [模块化] import、自己写模块
  步骤14 [类和对象] class、__init__、self
  步骤15 [项目] 从需求分析到代码实现到测试
```

**Python入门记忆口诀**：
```
变量赋值用等号，
字符串要加引号，
if判断缩进齐，
for循环遍历忙，
函数定义def起，
return返回值别忘。
```

**错误对比**：

| 正确 | 错误 | 错误信息 |
|------|------|----------|
| `print("Hello")` | `print "Hello"` | SyntaxError（Python3需要括号） |
| `if x == 5:` | `if x = 5:` | SyntaxError（==是比较，=是赋值） |
| `for i in range(5):` | `for i in 5:` | TypeError（range才能迭代） |
| `def func():` | `def func:` | SyntaxError（需要括号） |

### 🩹 技能4：急救（止血包扎）

**关键步骤编码**：

```
阶段S1（评估现场）：
  步骤1 [安全] 确认现场安全（无危险源）
  步骤2 [防护] 戴手套（或塑料袋代替）
  步骤3 [评估] 判断出血类型：动脉（喷射）、静脉（涌出）、毛细血管（渗出）

阶段S2（止血）：
  步骤4 [直接压迫] 用干净布料直接按压伤口（最常用！）
  步骤5 [抬高] 将受伤部位抬高过心脏水平
  步骤6 [加压包扎] 用绷带加压缠绕（不能过紧，检查远端脉搏）

阶段S3（特殊止血）：
  步骤7 [止血带] 大出血时使用：上臂/大腿上1/3，记录时间
  步骤8 [填塞] 深伤口用干净纱布填塞后再加压包扎

阶段S4（后续处理）：
  步骤9 [观察] 监测生命体征（意识、呼吸、脉搏）
  步骤10 [送医] 拨打120或送医
```

**止血口诀**：
```
一压二抬三包扎，
大出血用止血带，
记录时间每小时，
松一次来五分钟。
```

**错误对比**：

| 正确 | 错误 | 后果 |
|------|------|------|
| 直接按压伤口 | 用止血带绑手指 | 组织坏死 |
| 止血带上1/3 | 止血带绑关节处 | 压不住动脉 |
| 记录止血带时间 | 不记录时间 | 组织缺血坏死 |
| 异物刺入不拔出 | 直接拔出异物 | 大出血 |

### 🍳 技能5：做饭（刀工基础）

**关键步骤编码**：

```
阶段S1（握刀姿势）：
  步骤1 [握刀] 握刀柄，食指抵住刀背（不是放在刀刃上！）
  步骤2 [握菜] 手指弯曲如猫爪（指尖内收，指关节抵住刀面）
  步骤3 [站姿] 身体微前倾，左手固定食材，右手握刀

阶段S2（基础切法）：
  步骤4 [直切] 刀垂直上下，用于切土豆、黄瓜
  步骤5 [推切] 刀向前推的同时下切，用于切肉片
  步骤6 [拉切] 刀向后拉的同时下切，用于切软食材

阶段S3（花式切法）：
  步骤7 [切丝] 先切薄片→叠起来→切细丝
  步骤8 [切丁] 先切条→转90°→切丁
  步骤9 [滚刀块] 边切边转动食材（45°斜切+滚动）

阶段S4（速度提升）：
  步骤10 [连刀] 刀不离开砧板，前后快速切割
  步骤11 [指法] 左手控制进刀量（手指间距=食材厚度）
```

**刀工口诀**：
```
握刀如握笔，
猫爪护手指，
直切上下提，
推切向前移，
切丝先切片，
切丁先切条。
```

### 📸 技能6：摄影（相机基础操作）

**关键步骤编码**：

```
阶段S1（认识相机）：
  步骤1 [模式转盘] Auto（自动）、P（程序）、A/Av（光圈优先）、S/Tv（快门优先）、M（手动）
  步骤2 [三要素] 光圈、快门、ISO（曝光三角）
  步骤3 [对焦] 单点对焦、区域对焦、全自动对焦

阶段S2（曝光控制）：
  步骤4 [光圈] f值越小→光圈越大→景深越浅（背景虚化）
  步骤5 [快门] 速度越快→冻结动作；速度越慢→运动模糊
  步骤6 [ISO] ISO越高→越亮→噪点越多

阶段S3（构图）：
  步骤7 [三分法] 将画面分为3×3格，主体放在交叉点
  步骤8 [引导线] 利用道路、河流等线条引导视线
  步骤9 [前景] 加入前景元素增加纵深感

阶段S4（进阶）：
  步骤10 [RAW格式] 拍RAW而非JPG（后期空间大）
  步骤11 [白平衡] 根据光源调整色温
  步骤12 [包围曝光] 拍多张不同曝光合成HDR
```

**曝光三角记忆**：
```
光圈控制虚化（景深），
快门控制动静（运动），
ISO控制明暗（亮度），
三者互相关联牵一发动全身。
```

### 🧶 技能7：编织（棒针基础）

**关键步骤编码**：

```
阶段S1（起针）：
  步骤1 [绕线] 线绕在左手（小指和食指控制张力）
  步骤2 [起针] 用双针起针法（或钩针辅助起针）

阶段S2（基础针法）：
  步骤4 [下针（正针）] 右针从前往后穿入→绕线→挑出
  步骤5 [上针（反针）] 右针从后往前穿入→绕线→挑出
  步骤6 [平针] 一行下针、一行上针交替（正面是"V"形）

阶段S3（花样）：
  步骤7 [罗纹针] 下针和上针交替（1×1或2×2）→ 弹性好
  步骤8 [麻花针] 用辅助针交叉针目→形成麻花纹
  步骤9 [镂空针] 两针并一针+加针→形成镂空花样

阶段S4（收尾）：
  步骤10 [收针] 两针并一针→将后针套过前针→重复
  步骤11 [缝合] 用毛衣针将两片缝合
  步骤12 [藏线头] 将线头穿入针目中隐藏
```

### 🎸 技能8：弹吉他（入门）

**关键步骤编码**：

```
阶段S1（持琴姿势）：
  步骤1 [坐姿] 古典姿势（琴颈朝上45°）或民谣姿势（琴身放在右腿）
  步骤2 [左手] 拇指放在琴颈背面，手指弯曲按弦
  步骤3 [右手] 拨弦用指尖肉垫，扫弦用手腕

阶段S2（基础和弦）：
  步骤4 [Em和弦] 最简单：中指2弦2品+无名指3弦2品
  步骤5 [Am和弦] 食指2弦1品+中指4弦2品+无名指3弦2品
  步骤6 [C和弦] 食指2弦1品+中指4弦2品+无名指5弦3品
  步骤7 [G和弦] 食指5弦2品+中指6弦3品+无名指1弦3品

阶段S3（节奏型）：
  步骤8 [4/4拍] 下下上上下上（T T U T U T）
  步骤9 [扫弦] 手腕放松，下扫用指甲背面上扫用指甲正面

阶段S4（弹唱结合）：
  步骤10 [和弦转换] Em→Am→C→G（最常用进行）
  步骤11 [边弹边唱] 先练节奏不唱，再哼旋律，最后加歌词
```

**和弦转换记忆**：
```
Em最简单两根指，
Am三指排成排，
C和弦食指不动换其他，
G和弦跨度大要多练。
```

### ✍️ 技能9：书法（硬笔楷书）

**关键步骤编码**：

```
阶段S1（执笔姿势）：
  步骤1 [握笔] 拇指食指捏笔，中指托笔，笔杆靠虎口
  步骤2 [坐姿] 头正身直足安，一尺一拳一寸

  步骤4 [横] 起笔顿→行笔轻→收笔顿（左低右高5°）
  步骤5 [竖] 起笔顿→行笔直→收笔（悬针竖出尖，垂露竖回收）
  步骤6 [撇] 起笔顿→向左下撇出→渐轻出尖
  步骤7 [捺] 起笔轻→渐重→捺脚顿→出尖
  步骤8 [点] 轻入→顿→回收（像小雨滴）

阶段S3（偏旁部首）：
  步骤9 [三点水] 两个点+一个提
  步骤10 [提手旁] 横+竖钩+提
  步骤11 [言字旁] 点+横折+横+横

阶段S4（结构布局）：
  步骤12 [左右结构] 左窄右宽或左宽右窄
  步骤13 [上下结构] 上紧下松
  步骤14 [包围结构] 外框端正，内部紧凑
```

捺如扫帚点如桃，
钩要踢出折要顿，
提要快出像燕尾。

### 🧘 技能10：冥想（正念呼吸）

**关键步骤编码**：

```
阶段S1（准备）：
  步骤1 [环境] 安静、不被打扰的地方
  步骤2 [姿势] 盘腿坐或坐在椅子上，脊背挺直但不僵硬
  步骤3 [计时] 设定5分钟（初学者）

阶段S2（基础练习）：
  步骤4 [闭眼] 轻轻闭上眼睛，或微微低垂视线
  步骤5 [呼吸] 自然呼吸，不要刻意控制
  步骤6 [专注] 把注意力放在鼻尖感受空气进出
  步骤7 [数息] 吸气数1，呼气数2，数到10重新开始

阶段S3（处理杂念）：
  步骤8 [觉察] 发现走神了，不要自责
  步骤9 [标记] 心里默念"想法"或"走神"
  步骤10 [回归] 温柔地把注意力带回呼吸

阶段S4（进阶）：
  步骤11 [延长] 从5分钟→10分钟→20分钟
  步骤12 [身体扫描] 从头到脚依次关注身体各部位
  步骤13 [开放觉知] 不专注某一点，觉知所有感受
```

**冥想口诀**：
```
坐好闭眼深呼吸，
专注鼻尖数到十，
走神不要怪自己，
温柔拉回就成功。
```

**错误对比**：

| 正确 | 错误 | 后果 |
|------|------|------|
| 自然呼吸 | 刻意深呼吸 | 头晕、不自然 |
| 走神后温柔拉回 | 走神后自责烦躁 | 越练越焦虑 |
| 脊背挺直 | 驼背或太僵硬 | 背痛或紧张 |
| 从短时间开始 | 一上来就30分钟 | 坐不住、放弃 |

## 二、技能学习路径记忆

```
能力
 ↑
 │                    ┌───── S4精通（创新应变）
 │                ╱───┘
 │            ╱─── S3熟练（自动化）
 │        ╱───
 │    ╱─── S2入门（能完成）
 │╱───
 │ S1生疏（需要记忆）
 └──────────────────────→ 时间
   瓶颈期        高原期
```

### 四阶段记忆标志

| 阶段 | 标志 | 记忆锚点 |
|------|------|----------|
| S1→S2 | 能独立完成基本操作 | "不再看说明书" |
| S2→S3 | 速度和流畅度明显提升 | "不用想就能做" |
| S3→S4 | 能处理异常情况 | "什么状况都能搞定" |

## 三、错误操作的对比记忆框架

### 通用对比表模板

| 维度 | 正确操作 | 错误操作 | 后果 | 预防 |
|------|----------|----------|------|------|
| 姿势 | 例：脊背挺直 | 例：驼背 | 例：背痛 | 例：定时检查 |
| 顺序 | 例：先A后B | 例：先B后A | 例：结果错误 | 例：画流程图 |
| 力度 | 例：适中 | 例：过猛 | 例：损坏 | 例：先轻后重 |
| 时机 | 例：及时 | 例：延迟 | 例：错过窗口 | 例：设提醒 |

### "三不"原则（适用于所有技能）

```
不急：不急于求成，基础打牢再进阶
不怕：不怕犯错，错误是最好的老师
不停：不要三天打鱼两天晒网，持续练习
```
