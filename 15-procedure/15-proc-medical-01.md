## 一、十大常见医疗流程编码

### 流程 01：就医挂号流程

```
编码：身体不适 → 判断科室 → 选择医院 → 挂号 → 候诊 → 就诊 → 检查 → 取药/治疗 → 复诊/结案
```

| 阶段 | 步骤 | 记忆锚点 |
|------|------|----------|
| 起点 | 身体出现不适症状 | "不适是起点" |
| 判断① | 症状属于哪个科室？ | "对症选科" |
| 判断② | 去社区还是三甲？ | "小病社区、大病三甲" |
| 步骤1 | 线上/线下挂号 | "先挂号再看病" |
| 步骤2 | 候诊叫号 | "带好医保卡和病历" |
| 步骤3 | 医生问诊+体查 | "如实描述症状、时间、程度" |
| 步骤4 | 开检查单（血检/影像等） | "检查是诊断的依据" |
| 步骤5 | 拿结果复诊 | "结果找医生看" |
| 步骤6 | 取药或安排治疗 | "遵医嘱用药" |
| 终点 | 好转/复诊/转诊 | "康复是终点" |

**科室速查编码（谐音法）：**
- **头** → 神经内科/耳鼻喉科 → "头疼看神经、耳朵鼻子各有科"
- **胸** → 心内科/呼吸科 → "心慌看心内、咳嗽看呼吸"
- **腹** → 消化内科/普外科 → "肚子疼先消化、严重看普外"
- **骨** → 骨科 → "骨折扭伤找骨科"
- **皮** → 皮肤科 → "皮痒皮疹皮肤科"
- **心理** → 精神心理科 → "焦虑抑郁看心理"

### 流程 02：体检流程

```
编码：体检通知/预约 → 选择套餐 → 空腹准备 → 到院登记 → 抽血 → 各科室检查 → 餐后项目 → 报告解读 → 后续随访
```

| 阶段 | 步骤 | 关键提醒 |
|------|------|----------|
| 起点 | 单位安排或个人预约 | "提前3天预约" |
| 步骤1 | 选套餐（基础/深度/专项） | "年龄越大查越深" |
| 步骤2 | 体检前准备 | "空腹8-12小时、禁酒、穿宽松衣服" |
| 步骤3 | 到院登记领表 | "带身份证、体检表" |
| 步骤4 | 抽血（必须空腹最先做） | "抽血优先、B超紧跟" |
| 步骤5 | 各科室逐项检查 | "按指引顺序走" |
| 步骤6 | 吃早餐（如有餐后项目） | "餐后等30分钟再查" |
| 步骤7 | 交回体检表 | "确认项目全做完" |
| 步骤8 | 等报告（3-7天） | "报告异常要复查" |
| 终点 | 拿到报告+医生解读 | "指标异常≠有病、需综合判断" |

**体检顺序口诀：** "抽血B超先空腹、餐后验尿心电图、内外五官影像最后走"

### 流程 03：急救步骤（通用急救流程）

```
编码：发现伤患 → 确认安全 → 判断意识 → 呼叫120 → 初步急救 → 持续监护 → 交接急救人员
```

| 阶段 | 步骤 | 记忆编码 |
|------|------|----------|
| 起点 | 发现有人倒地/受伤 | "看到就是起点" |
| 判断① | 环境是否安全？ | "先保己再救人" |
| 判断② | 有无意识？轻拍双肩呼唤 | "拍肩呼唤判断意识" |
| 判断③ | 有无呼吸？观察胸廓起伏 | "看听感觉10秒内" |
| 步骤1 | 拨打120（说清地点、人数、伤情） | "120三要素：地点-人数-伤情" |
| 步骤2 | 根据情况实施急救 | "见下文专项急救" |
| 步骤3 | 持续观察生命体征 | "不能离开、持续关注" |
| 终点 | 急救人员到达、交接 | "交接伤情和已做措施" |

**急救电话口诀：** "120急救、119火警、110报警、122交通事故"

### 流程 04：用药流程

```
编码：确诊 → 开药 → 了解药物 → 按时服用 → 观察反应 → 复诊调整 → 停药/换药
```

| 阶段 | 步骤 | 关键信息 |
|------|------|----------|
| 起点 | 医生确诊并开药 | "确诊才用药、不自行买处方药" |
| 步骤1 | 领药/购药 | "核对药名、剂量、有效期" |
| 步骤2 | 了解用法用量 | "饭前饭后？一天几次？" |
| 步骤3 | 了解副作用和禁忌 | "看说明书、问药师" |
| 步骤4 | 按时按量服药 | "定闹钟提醒、不擅自增减" |
| 步骤5 | 记录用药反应 | "异常反应立即就医" |
| 步骤6 | 定期复诊 | "按医生要求复查" |
| 终点 | 病情好转停药/长期管理 | "不擅自停药、遵医嘱" |

**用药安全口诀：** "看清名字和剂量、饭前饭后要分清、不良反应记下来、擅自停药最要命"

### 流程 05：手术准备流程

```
编码：术前评估 → 知情同意 → 术前准备 → 手术 → 术后监护 → 康复 → 出院
```

| 阶段 | 步骤 | 记忆要点 |
|------|------|----------|
| 起点 | 医生建议手术 | "充分了解手术必要性" |
| 步骤1 | 术前检查（血常规、心电图等） | "评估身体能否承受手术" |
| 步骤2 | 签署知情同意书 | "了解风险、签字确认" |
| 步骤3 | 术前准备 | "禁食禁水8h、备皮、换手术服" |
| 步骤4 | 进入手术室 | "核实身份、麻醉" |
| 步骤5 | 手术进行 | "家人在等候区" |
| 步骤6 | 术后苏醒/监护 | "观察麻醉恢复" |
| 步骤7 | 术后护理 | "遵医嘱翻身、饮食、用药" |
| 终点 | 恢复达标出院 | "出院带药+复诊时间" |

**术前准备口诀：** "检查签字禁食水、备皮换衣进手术"

### 流程 06：康复训练流程

```
编码：评估功能障碍 → 制定康复计划 → 康复训练 → 定期评估 → 调整方案 → 恢复/维持
```

| 阶段 | 步骤 | 关键点 |
|------|------|--------|
| 起点 | 手术/疾病后遗留功能障碍 | "康复从评估开始" |
| 步骤1 | 康复科评估（肌力、关节活动度等） | "评估定目标" |
| 步骤2 | 制定个性化康复计划 | "循序渐进、不能急" |
| 步骤3 | 物理治疗（PT） | "被动→主动→抗阻" |
| 步骤4 | 作业治疗（OT） | "恢复日常生活能力" |
| 步骤5 | 言语治疗（ST，如有需要） | "针对语言/吞咽障碍" |
| 步骤6 | 每2-4周评估进展 | "进步记下来" |
| 终点 | 达到最大功能恢复 | "坚持是康复的密码" |

**康复阶段口诀：** "评估定目标、计划分阶段、训练要循序、评估再调整"

### 流程 07：疫苗接种流程

```
编码：了解疫苗 → 预约接种 → 健康评估 → 接种 → 留观 → 不良反应处理
```

| 阶段 | 步骤 | 关键信息 |
|------|------|----------|
| 起点 | 了解需要接种的疫苗种类 | "一类免费、二类自愿" |
| 步骤1 | 预约接种时间 | "社区卫生中心/疾控中心" |
| 步骤2 | 携带接种证/身份证 | "儿童带接种本" |
| 步骤3 | 健康评估（有无发热、过敏等） | "生病暂缓接种" |
| 步骤4 | 核对疫苗名称、批号、有效期 | "三查七对" |
| 步骤5 | 接种（注射/口服） | "注射部位：上臂三角肌" |
| 步骤6 | 留观30分钟 | "观察有无过敏反应" |
| 终点 | 记录接种信息、预约下次 | "接种证要保存好" |

**接种口诀：** "预约评估核对打、留观半小时再走"

### 流程 08：体检报告解读流程

```
编码：拿到报告 → 看总检结论 → 逐项核对异常指标 → 分类判断 → 后续处理
```

| 阶段 | 步骤 | 解读技巧 |
|------|------|----------|
| 起点 | 拿到体检报告 | "先看最后的总检结论" |
| 步骤1 | 看总检建议 | "医生已标出重点异常" |
| 步骤2 | 标记异常指标（↑↓符号） | "箭头向上偏高、向下偏低" |
| 步骤3 | 分类：需复查/需专科就诊/生活方式调整 | "三类分清轻重缓急" |
| 步骤4 | 需复查的指标：1-3个月后复查 | "一次异常不代表有病" |
| 步骤5 | 需专科就诊的：尽快挂号 | "不要拖延" |
| 步骤6 | 生活方式调整：饮食、运动、作息 | "管住嘴迈开腿" |
| 终点 | 建立个人健康档案 | "每年对比看趋势" |

**报告速读口诀：** "先看结论再看项、箭头指标要标亮、三类分清不慌张、年度对比看走向"

```
编码：确诊慢性病 → 建档 → 制定管理方案 → 日常监测 → 定期复诊 → 方案调整 → 长期维持
```

| 阶段 | 步骤 | 管理要点 |

| 步骤3 | 日常自我监测 | "血压/血糖/体重日记" |
| 步骤4 | 按时服药 | "长效药每天定时吃" |

| 步骤6 | 每年全面体检 | "关注并发症" |
| 终点 | 指标达标、生活质量维持 | "达标就是胜利" |

## 二、医院楼层/科室定位法

### 医院布局通用规律

```
编码记忆：一楼大厅挂号急、二楼检验影像集、三楼以上专科齐、顶楼手术ICU
```

| 楼层 | 通常布局 | 记忆口诀 |
|------|----------|----------|
| 1F | 急诊、挂号、收费、药房、导诊台 | "进门先挂号、急诊在一楼" |
| 2F | 检验科、影像科（CT/X光/B超） | "二楼查血查骨头" |
| 3F | 内科门诊群 | "三楼内科占大头" |
| 4F | 外科门诊群 | "四楼外科排排坐" |
| 5F | 妇产科/儿科 | "五楼妈妈和宝宝" |
| 6F | 五官科（眼/耳鼻喉/口腔） | "六楼看脸看牙看眼" |
| 7F+ | 住院病房 | "七楼以上住下来" |
| 顶层 | 手术室/ICU | "手术室在最顶层" |

### 科室定位法（按身体部位）

```
头部问题 → 神经内科 / 耳鼻喉科 / 眼科 / 口腔科
胸部问题 → 心内科 / 呼吸科 / 胸外科
腹部问题 → 消化内科 / 普外科 / 泌尿外科
四肢问题 → 骨科 / 康复科
皮肤问题 → 皮肤科
心理问题 → 精神心理科
全身问题 → 全科医学科（不知道挂什么科时的万能选择）
```

**万能法则：** "不知道挂什么科 → 全科/导诊台"

### 快速定位口诀

```
"头不舒服看神经、胸口闷痛看心内、肚子难受看消化、骨头关节找骨科、
  皮肤痒疹皮肤科、心情不好看心理、不知道就挂全科"
```

## 三、急救流程关键步骤记忆

### 3.1 心肺复苏（CPR）流程

```
编码：确认环境安全 → 判断意识 → 呼叫120 → 胸外按压 → 开放气道 → 人工呼吸 → 持续循环
```

**完整步骤：**

1. **确认环境安全** — "先看四周、确保安全"
2. **判断意识** — 拍打双肩、大声呼唤 "喂！你怎么了？"
3. **呼叫120** — 指定具体人拨打、说清地点
4. **判断呼吸** — 观察胸廓起伏，10秒内完成
5. **胸外按压（C）**
   - 位置：两乳头连线中点（胸骨中下1/3）
   - 深度：5-6厘米
   - 频率：100-120次/分钟
   - 回弹：每次按压后胸廓完全回弹
6. **开放气道（A）** — 仰头抬颏法
7. **人工呼吸（B）** — 捏鼻吹气、每次吹气1秒、见胸廓起伏
8. **比例** — 30次按压 : 2次吹气 = 1个循环
9. **持续** — 直到AED到达或急救人员接手

**CPR速记口诀：**
```
"叫叫CAB" — 叫（判断意识）、叫（呼叫120）、C（按压）、A（气道）、B（呼吸）
"按压30吹2下、频率一百一二不差、深度五六要到位、回弹充分别偷懒"
```

**按压要点记忆：**
- **位置** → "两乳连线中点按"
- **深度** → "5到6厘米要到底"（约一个拳头深度）
- **频率** → "100到120、跟着《小苹果》节奏"
- **手势** → "双手交叠、掌根发力、手臂伸直"

### 3.2 海姆立克急救法（气道异物梗阻）

```
编码：识别梗阻 → 鼓励咳嗽 → 腹部冲击 → 重复 → 无效则就医
```

**成人/儿童版：**

1. **识别** — 无法说话、无法咳嗽、双手抓喉（V字手势）
2. **鼓励咳嗽** — "能咳就让它咳"
3. **站到身后** — 双臂环绕腰部
4. **定位** — 肚脐上方、剑突下方
5. **手法** — 一手握拳、拳心向内；另一手包住拳头
6. **冲击** — 快速向内向上冲击
7. **重复** — 直到异物排出或失去意识

**婴儿版（<1岁）：**

1. **面朝下** — 头低脚高、放在前臂上
2. **拍背** — 掌根拍击肩胛骨之间5次
3. **翻转** — 面朝上、两指按压胸骨下半段5次
4. **交替** — 背部拍击+胸部按压，直到异物排出

**海姆立克口诀：**
```
"站后方、抱腰间、肚脐上面找位置、拳头顶住向里收、快速冲击向上提"
"婴儿面朝下拍五下、翻过来按五下、交替进行不要怕"
```

---

### 3.3 止血急救流程

```
编码：评估出血类型 → 直接压迫 → 抬高肢体 → 加压包扎 → 止血带（必要时）→ 送医
```

| 出血类型 | 特征 | 处理方法 |
|----------|------|----------|
| 动脉出血 | 鲜红色、喷射状 | 最紧急、需加压+止血带 |
| 静脉出血 | 暗红色、持续流出 | 加压包扎即可 |
| 毛细血管出血 | 渗血、量少 | 消毒+创可贴 |

**止血步骤：**

1. **直接压迫** — 用干净纱布/布料用力按住伤口
2. **抬高肢体** — 受伤部位抬高过心脏水平
3. **加压包扎** — 纱布覆盖+绷带加压缠绕
4. **止血带**（四肢大出血时）— 上臂上1/3或大腿上1/3、记录时间、每1-2小时松开一次
5. **送医** — 尽快就医处理

**止血口诀：**
```
"压住别松手、抬高过心脏、包扎要加压、止血带记时间"
```

---

### 3.4 烧烫伤急救流程

```
编码：脱离热源 → 冷水冲洗 → 覆盖保护 → 送医
```

**五步法：**

1. **脱** — 脱去伤处衣物（粘连处不要硬撕）
2. **冲** — 流动冷水冲洗15-30分钟
3. **泡** — 冷水中浸泡（疼痛缓解）
4. **盖** — 无菌纱布/保鲜膜覆盖
5. **送** — 严重烧伤立即送医

**口诀：** "冲脱泡盖送、五字记心中"

**禁忌：**
- ❌ 不涂牙膏、酱油、醋等偏方
- ❌ 不挑破水泡
- ❌ 不用冰块直接接触伤口

### 3.5 骨折急救流程

```
编码：识别骨折 → 固定制动 → 冷敷消肿 → 送医
```

| 步骤 | 操作 | 记忆 |
|------|------|------|
| 识别 | 畸形、肿胀、疼痛、功能障碍 | "四个特征认骨折" |
| 固定 | 用夹板/硬物固定上下两个关节 | "上下关节都要固定" |
| 冷敷 | 冰袋包裹毛巾冷敷 | "消肿止痛" |
| 送医 | 不要自行复位 | "骨折不要自己掰回去" |

**骨折口诀：**
```
"不动不掰不乱搬、夹板固定找硬板、冷敷消肿别太冰、赶紧送医拍片子"
```

---

### 3.6 溺水急救流程

```
编码：确保自身安全 → 救出水面 → 判断意识呼吸 → CPR → 保暖 → 送医
```

1. **确保自身安全** — 不要盲目跳水、用竹竿/绳子/救生圈
2. **救出后平放** — 头偏向一侧
3. **清除口腔异物** — 擦除泥沙
4. **判断意识和呼吸** — 10秒内
5. **无呼吸立即CPR** — 先做5次人工呼吸、再按30:2
6. **保暖** — 湿衣物换干衣物
7. **送医** — 即使恢复意识也要送医检查

**口诀：**
```
"先保己再救人、救上来先看呼吸、没呼吸立刻CPR、五次吹气再按压"
```

## 四、急救流程综合记忆卡

### 急救通用编码

```
D-R-S-A-B-C-D
D = Danger（确认安全）
R = Response（判断反应/意识）
S = Shout（呼叫帮助/120）
A = Airway（开放气道）
B = Breathing（检查呼吸）
C = CPR（心肺复苏）
D = Defibrillation（AED除颤）
```

### 速拨电话

| 号码 | 用途 | 记忆 |
|------|------|------|
| 120 | 急救 | "120保命" |
| 119 | 火警 | "119灭火" |
| 110 | 报警 | "110抓坏人" |
| 122 | 交通事故 | "122车祸" |

### 急救卡携带信息

建议随身携带急救卡，内容包括：
- 姓名、年龄、血型
- 过敏药物
- 慢性病（如糖尿病、高血压）
- 紧急联系人及电话
- 正在服用的药物

## 六、医疗流程练习建议

1. **急救流程优先练** — CPR、海姆立克、止血，关键时刻救命

5. **慢性病管理制度化** — 设定每日监测闹钟和复诊提醒
6. **急救卡随身带** — 手机壳里放一张急救信息卡
