# 15-proc-daily-01.md — 日常流程记忆

## 记忆方法概述

日常流程记忆的核心是**时间定位+习惯锚点**：
- 用定位法将时间段映射到固定位置
- 用挂钩法记忆待办事项清单
- 习惯养成用"触发-行为-奖励"循环
- 每日/每周/每月分别用不同策略

---

## 一、每日例行事项（时间定位法）

### 时间-空间定位表

将一天24小时映射到身体的不同部位（从头到脚）：

| 时间段 | 身体位置 | 定位形象 | 例行事项 |
|--------|----------|----------|----------|
| 6:00-7:00 | 头顶 | 太阳升起 | 起床、洗漱、喝水 |
| 7:00-8:00 | 眼睛 | 看看世界 | 早餐、看新闻、穿衣 |
| 8:00-9:00 | 耳朵 | 听听消息 | 通勤、听播客/音乐 |
| 9:00-12:00 | 嘴巴 | 说话工作 | 上午工作（高效率时段） |
| 12:00-13:00 | 脖子 | 休息转动 | 午餐、午休 |
| 13:00-17:00 | 肩膀 | 扛起重担 | 下午工作 |
| 17:00-18:00 | 手 | 放下工作 | 下班、通勤 |
| 18:00-19:00 | 腹部 | 吃饭时间 | 晚餐准备、用餐 |
| 19:00-21:00 | 腰部 | 自由活动 | 运动/学习/娱乐 |
| 21:00-22:00 | 膝盖 | 弯腰放松 | 洗漱、阅读、准备睡觉 |
| 22:00-6:00 | 脚 | 躺下休息 | 睡觉 |

### 每日清单（挂钩法）

用10个挂钩记忆每日必做事项：

| 挂钩 | 形象 | 每日事项 | 时间 |
|------|------|----------|------|
| 1-蜡烛 | 起床喝水 | 喝一杯温水（300mL） | 6:30 |
| 2-天鹅 | 晨间运动 | 10分钟拉伸/瑜伽 | 6:40 |
| 3-三角 | 早餐 | 营养均衡的早餐 | 7:15 |
| 4-帆船 | 通勤学习 | 听播客/有声书 | 8:00 |

| 9-气球 | 学习 | 30分钟阅读/学习 | 20:00 |

### 每日清单口诀

水伸餐播工午邮运读记

## 二、每周例行事项

### 周计划定位法

将一周7天映射到彩虹七色：

| 星期 | 颜色 | 主题 | 例行事项 |
|------|------|------|----------|
| 周一 | 🔴 红色 | 规划日 | 制定本周计划、回顾上周 |
| 周二 | 🟠 橙色 | 深度工作日 | 处理最重要/最难的任务 |
| 周三 | 🟡 黄色 | 会议日 | 集中安排会议和沟通 |
| 周四 | 🟢 绿色 | 创造日 | 创意工作、写作、设计 |
| 周五 | 🔵 蓝色 | 收尾日 | 完成遗留任务、周报 |
| 周六 | 🟣 紫色 | 个人日 | 学习新技能、社交、爱好 |
| 周日 | ⚪ 白色 | 休息日 | 休息、整理、准备下周 |

### 每周待办清单（挂钩法）

| 挂钩 | 周几 | 待办事项 |
|------|------|----------|
| 1-蜡烛 | 周一 | 写周计划、整理邮件 |
| 2-天鹅 | 周二 | 深度工作（不被打扰） |
| 3-三角 | 周三 | 团队会议、1对1沟通 |
| 4-帆船 | 周四 | 创意工作、学习时间 |
| 5-钩子 | 周五 | 周报、清理待办、归档文件 |
| 6-勺子 | 周六 | 运动、社交、爱好 |
| 7-拐杖 | 周日 | 大扫除、下周计划、采购 |

### 每周检查清单

```
□ 工作：本周计划完成度？
□ 学习：读了什么？学了什么？
□ 健康：运动几次？睡眠如何？
□ 社交：联系了哪些人？
□ 财务：本周支出记录？
□ 整理：桌面/电脑/文件清理？
□ 反思：本周最大的收获和遗憾？
```

## 三、每月例行事项

### 月度计划定位法

将一个月分为四个阶段（用季节比喻）：

| 阶段 | 时间 | 比喻 | 重点事项 |
|------|------|------|----------|
| 播种期 | 第1周 | 春天 | 制定月度目标、分配任务 |
| 生长期 | 第2周 | 夏天 | 全力推进、中期检查 |
| 收获期 | 第3周 | 秋天 | 收尾、完成主要目标 |
| 反思期 | 第4周 | 冬天 | 总结、复盘、规划下月 |

### 每月待办清单

| 挂钩 | 事项 | 时间 |
|------|------|------|
| 1 | 月度目标制定 | 每月1日 |
| 2 | 财务对账（信用卡、账单） | 每月5日 |
| 3 | 家庭大扫除 | 每月第一个周六 |
| 4 | 健康检查（体重、血压） | 每月15日 |
| 5 | 学习复盘（读书/课程进度） | 每月20日 |
| 6 | 人际关系维护（联系老朋友） | 每月15日 |
| 7 | 衣物换季整理 | 每季末 |
| 8 | 证件/订阅检查 | 每月25日 |
| 9 | 月度总结 | 每月最后一天 |
| 10 | 下月计划草稿 | 每月最后一天 |

### 月度复盘模板

```
本月回顾：
1. 完成了什么？（列出3-5个成就）
2. 没完成什么？原因是什么？
3. 学到了什么新东西？
4. 遇到了什么困难？如何克服的？
5. 下月最重要的3个目标是什么？
```

## 四、待办事项的挂钩法系统

### 建立个人待办挂钩系统

**核心原则**：每个挂钩对应一个固定的"场景"或"位置"

| 挂钩编号 | 场景 | 触发条件 | 待办类型 |
|----------|------|----------|----------|
| 1 | 出门前 | 手摸到门把手 | 要带的东西、要办的事 |
| 2 | 坐到工位 | 屁股碰到椅子 | 今天最重要的事 |
| 3 | 打开电脑 | 看到桌面 | 需要处理的邮件/消息 |
| 4 | 午饭后 | 筷子放下 | 下午要做的事 |
| 5 | 下班前 | 看到时钟到17:00 | 明天的计划 |
| 6 | 到家时 | 钥匙插进锁孔 | 家务/采购 |
| 7 | 吃晚饭时 | 坐到餐桌旁 | 今晚要做的事 |
| 8 | 洗澡时 | 水流过身体 | 需要思考的问题 |
| 9 | 上床时 | 头碰到枕头 | 明天早上的准备 |
| 10 | 闭眼前 | 关灯 | 今天感恩的3件事 |

### 使用方法

> 每天出门前，手碰到门把手时（挂钩1），自动回忆："手机、钥匙、钱包、伞带了吗？今天要办什么事？"
>
> 坐到工位时（挂钩2），自动回忆："今天最重要的3件事是什么？"

## 五、习惯养成的记忆策略

### 习惯循环公式

```
触发线索 → 惯常行为 → 奖励反馈
  (Cue)   (Routine)   (Reward)
```

### 10个好习惯的养成方案

| 习惯 | 触发线索 | 惯常行为 | 奖励 |
|------|----------|----------|------|
| 早起 | 闹钟响 | 立即下床，不看手机 | 一杯好咖啡 |
| 运动 | 下班回家 | 换运动服→出门跑步 | 洗个舒服的热水澡 |
| 阅读 | 吃完晚饭 | 坐到沙发上读书30分钟 | 看一集喜欢的剧 |
| 写日记 | 洗完澡 | 坐到书桌前写3件事 | 心理满足感 |
| 喝水 | 到工位 | 倒一杯水放在手边 | 每小时喝完一杯 |
| 冥想 | 早上起床后 | 坐到垫子上闭眼5分钟 | 一天的平静感 |
| 整理 | 离开工位前 | 花2分钟整理桌面 | 明天清爽的开始 |
| 学习 | 通勤路上 | 戴耳机听播客/课程 | 知识增长的成就感 |
| 记账 | 晚上9点 | 打开记账APP记录今天 | 看到月度统计 |
| 早睡 | 晚上10点 | 放下手机→洗漱→上床 | 充足睡眠的精力 |

### 习惯叠加法

将新习惯"叠加"在已有习惯之后：

```
已有习惯 → 新习惯
─────────────────
刷牙之后 → 冥想2分钟
到公司之后 → 写今天最重要的3件事
午饭之后 → 走路10分钟
关电脑之后 → 整理桌面
上床之后 → 写日记
```

### 21天/66天习惯养成时间线

```
第1-7天（最艰难期）：
  - 每天设定提醒
  - 不要求完美，只要做
  - 记录打卡

第8-21天（适应期）：
  - 开始感到习惯成自然
  - 偶尔想跳过，但坚持
  - 关注奖励感

第22-66天（巩固期）：
  - 基本自动化
  - 不做反而不舒服
  - 可以取消提醒

第66天以后（习惯形成）：
  - 完全自动化
  - 需要意志力的是不做
  - 可以叠加下一个新习惯
```

## 六、时间管理清单的定位法

### 艾森豪威尔矩阵定位法

将任务按照"重要-紧急"分为四个象限，用房间位置定位：

```
┌─────────────────┬─────────────────┐
│   紧急且重要      │   重要不紧急      │
│   【厨房】        │   【书房】        │
│   立即做          │   计划做          │
│   · 危机处理       │   · 学习提升       │
│   · 截止日期临近    │   · 健康管理       │
│   · 紧急问题       │   · 人际关系       │
├─────────────────┼─────────────────┤
│   紧急不重要      │   不紧急不重要     │
│   【客厅】        │   【储物间】       │
│   委托他人做       │   尽量不做         │
│   · 某些电话       │   · 刷手机         │
│   · 某些会议       │   · 闲聊           │
│   · 某些邮件       │   · 无意义浏览     │
└─────────────────┴─────────────────┘
```

### 使用方法

> 拿到一个任务时，问自己两个问题：
> 1. 这件事重要吗？（对长期目标有帮助吗？）
> 2. 这件事紧急吗？（有明确截止日期吗？）
>
> 然后放入对应的"房间"：
> - 厨房（紧急重要）→ 立即做
> - 书房（重要不紧急）→ 安排时间做
> - 客厅（紧急不重要）→ 找人帮忙做
> - 储物间（不紧急不重要）→ 不做

### 每日三件事法则

```
每天早上问自己：
"如果今天只能完成3件事，哪3件最重要？"

1. _______________ （最重要的事）
2. _______________ （第二重要的事）
3. _______________ （第三重要的事）

先做第1件，做完再做第2件，以此类推。
```

## 七、习惯养成的常见陷阱与对策

### 陷阱对比表

| 陷阱 | 表现 | 对策 |
|------|------|------|
| 目标太大 | "我要每天跑10公里" | 从"每天跑5分钟"开始 |
| 完美主义 | "今天没做到，算了" | "断一天没关系，明天继续" |
| 缺乏触发 | "总是忘记" | 绑定已有习惯（习惯叠加） |
| 没有奖励 | "太无聊了" | 设置即时奖励 |
| 环境不支持 | "家里没有运动空间" | 改变环境（准备好运动服） |
| 依赖意志力 | "全靠坚持" | 让习惯自动化，减少决策 |

### "两分钟法则"

任何新习惯，先从2分钟版本开始：

| 目标习惯 | 2分钟版本 |
|----------|----------|
| 每天运动30分钟 | 换上运动鞋 |
| 每天阅读1小时 | 读一页书 |
| 每天写日记 | 写一句话 |
| 每天冥想20分钟 | 闭眼深呼吸3次 |
| 每天整理房间 | 整理桌面一个角落 |

**核心理念**：先让习惯"发生"，再逐步扩展。

## 九、中国日常生活流程记忆

### 流程1：网购退货流程

```
步骤1（申请）→ 步骤2（审核）→ 步骤3（寄回）→ 步骤4（退款）
   打开APP      商家同意       打包寄出       收到退款
   点退货       1-3天        选快递        1-7天
```

**记忆画面**：
1. **申请**：手指点手机屏幕→"点"=第一步
2. **审核**：商家点头同意→"点头"=审核通过
3. **寄回**：把东西装进快递盒→"装盒"=寄回
4. **退款**：钱包里多出钱→"进账"=退款

**口诀**："点-头-装-钱"（申请→审核→寄回→退款）

### 流程2：办身份证流程

```
步骤1（准备）→ 步骤2（拍照）→ 步骤3（填表）→ 步骤4（录指纹）→ 步骤5（领证）
   带户口本      现场拍照       填写信息       按指纹         20个工作日
```

**记忆画面**：
1. **准备**：手里拿着户口本→"拿本"=准备材料
2. **拍照**：坐在白色背景前→"白背景"=拍照
3. **填表**：用笔写字→"写字"=填表
4. **录指纹**：大拇指按在机器上→"按指"=录指纹
5. **领证**：拿到新身份证→"拿证"=领证

**口诀**："本-拍-写-按-拿"

### 流程3：医院挂号看病流程

```
步骤1（挂号）→ 步骤2（候诊）→ 步骤3（就诊）→ 步骤4（缴费）→ 步骤5（取药）
   选科室        等叫号        医生问诊       收费窗口       药房取药
```

**记忆画面**：
1. **挂号**：在机器上选科室→"选科"=挂号
2. **候诊**：坐在椅子上等→"等待"=候诊
3. **就诊**：医生问"哪里不舒服"→"问答"=就诊
4. **缴费**：刷卡或扫码付钱→"付钱"=缴费
5. **取药**：拿到药袋→"拿药"=取药

**口诀**："选-等-问-付-拿"

### 流程4：办银行卡流程

```
步骤1（带证件）→ 步骤2（填表）→ 步骤3（设置密码）→ 步骤4（签字）→ 步骤5（拿卡）
   身份证         填申请表       ATM机上设置        签名确认       拿到银行卡
```

**口诀**："证-表-密-签-卡"

### 流程5：高铁乘车流程

```
步骤1（购票）→ 步骤2（进站）→ 步骤3（安检）→ 步骤4（检票）→ 步骤5（乘车）
   12306买票     刷身份证进站    过安检机       刷证/刷脸      找座位坐下
```

**记忆画面**：
1. **购票**：手机上点12306→"点"=购票
2. **进站**：身份证贴在闸机上→"贴证"=进站
3. **安检**：行李过X光机→"过机"=安检
4. **检票**：再次刷身份证或刷脸→"刷脸"=检票
5. **乘车**：找到座位坐下→"坐下"=乘车

**口诀**："点-贴-过-刷-坐"

### 流程编码通用技巧

| 技巧 | 方法 | 示例 |
|------|------|------|
| 首字串联法 | 取每步首字组成口诀 | 网购退货："点-头-装-钱" |
| 数字定位法 | 步骤编号对应身体部位 | 步骤1=头，步骤2=眼... |
| 故事串联法 | 把步骤编成一个小故事 | "我点了一下，商家点头，我装好寄出，钱回来了" |
| 画面递进法 | 每步一个画面，画面间有因果 | 点手机→商家点头→快递盒→钱包进钱 |
