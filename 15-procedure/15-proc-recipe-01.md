# 15-proc-recipe-01.md — 菜谱/烹饪流程记忆

## 记忆方法概述

菜谱记忆的核心挑战在于：食材清单、调料配比、操作步骤、火候控制四个维度需要同时记住。我们采用**步骤编码+定位法+挂钩法**的组合策略：

- **步骤编码**：每个烹饪动作对应一个数字代码
- **定位法**：将厨房空间与操作位置绑定
- **挂钩法**：食材清单用挂钩系统快速记忆

---

## 一、烹饪动作编码表

| 编码 | 动作 | 编码 | 动作 |
|------|------|------|------|
| 1 | 洗 | 6 | 炸 |
| 2 | 切 | 7 | 蒸 |
| 3 | 腌 | 8 | 烤 |
| 4 | 炒 | 9 | 煮 |
| 5 | 炖 | 0 | 拌/装盘 |

**谐音口诀**：洗(1)切(2)腌(3)炒(4)炖(5)，炸(6)蒸(7)烤(8)煮(9)拌(0)

---

## 二、火候编码

| 编码 | 火候 | 标志 |
|------|------|------|
| A | 大火（猛火） | 锅底全红，油烟直冒 |
| B | 中火 | 锅底微红，油面微动 |
| C | 小火（文火） | 锅底暗红，油面平静 |
| D | 微火（保温） | 手感温热，无油烟 |

## 三、中餐6道菜

### 🥘 菜1：宫保鸡丁

**食材清单（挂钩法记忆）**：

| 挂钩 | 食材 | 联想画面 |
|------|------|----------|
| 1（树） | 鸡胸肉300g | 一只鸡站在树上 |
| 2（鹅） | 花生米50g | 鹅在啄花生 |
| 3（山） | 干辣椒8个 | 山上插满辣椒旗 |
| 4（寺） | 花椒10粒 | 寺庙门口撒花椒 |
| 5（虎） | 葱姜蒜各适量 | 虎口含着葱姜蒜 |
| 6（牛） | 黄瓜丁100g | 牛啃黄瓜 |
| 7（鸡） | 胡萝卜丁50g | 鸡叼胡萝卜 |

**调料记忆口诀**："酱醋糖盐各一勺，料酒淀粉不能少"
- 生抽1勺、醋1勺、糖1勺、盐半勺
- 料酒1勺、淀粉1勺、水2勺（调成碗汁）

**步骤序列**：

```
步骤1 [切2] 鸡胸肉切1.5cm丁 → 加盐、料酒、淀粉腌15分钟 [腌3]
步骤2 [切2] 葱切段、姜切片、蒜切末、黄瓜切丁
步骤3 [炒4-B] 热锅中火凉油 → 下花生米炸至微黄捞出 [炸6-C]
步骤4 [炒4-A] 大火爆香干辣椒、花椒 → 出香味下鸡丁
步骤5 [炒4-A] 鸡丁翻炒至变白 → 下葱姜蒜
步骤6 [炒4-B] 倒入碗汁 → 中火翻炒均匀收汁
步骤7 [炒4-A] 下花生米、黄瓜丁 → 大火快炒10秒
步骤8 [拌0] 出锅装盘
```

**编码序列**：2→3→2→6C→4A→4A→4B→4A→0

**火候关键点**：
- 花生米：小火慢炸（C），听到噼啪声立即捞出
- 鸡丁：大火快炒（A），不超过2分钟
- 收汁：中火（B），防止糊锅

### 🥘 菜2：红烧肉

**食材清单（挂钩法）**：

| 挂钩 | 食材 |
|------|------|
| 1 | 五花肉500g（选三层分明的） |
| 2 | 冰糖30g |
| 3 | 八角2个 |
| 4 | 桂皮1小段 |
| 5 | 香叶3片 |
| 6 | 葱姜适量 |
| 7 | 生抽2勺、老抽1勺 |

**步骤序列**：

```
步骤1 [切2] 五花肉切3cm方块
步骤2 [煮9-A] 冷水下锅，大火烧开焯水3分钟 → 捞出洗净
步骤3 [炒4-B] 锅中放少许油，中火炒冰糖至焦糖色（起大泡变小泡）
步骤4 [炒4-A] 大火下肉块翻炒上色 → 每面都裹上糖色
步骤5 [炒4-B] 下八角、桂皮、香叶、葱姜爆香
步骤6 [炒4-B] 加生抽、老抽翻炒均匀
步骤7 [炖5-C] 加热水没过肉 → 大火烧开转小火炖60分钟
步骤8 [炒4-B] 开盖大火收汁至浓稠
步骤9 [拌0] 装盘，撒葱花
```

**编码序列**：2→9A→4B→4A→4B→4B→5C→4B→0

**关键记忆点**：
- 冰糖炒色：中火观察"大泡→小泡→焦糖色"三阶段
- 炖肉：必须加热水（冷水会让肉收缩变硬）
- 收汁：大火但要看住，防止糊底

### 🥘 菜3：麻婆豆腐

**食材清单**：

| 挂钩 | 食材 |
|------|------|
| 1 | 嫩豆腐1块（切2cm方块） |
| 2 | 猪肉末100g |
| 3 | 郫县豆瓣酱2勺 |
| 4 | 花椒粉1勺 |
| 5 | 蒜末、姜末 |
| 6 | 葱花 |
| 7 | 淀粉水适量 |

**步骤序列**：

```
步骤1 [煮9-B] 豆腐块入淡盐水中火焯水2分钟（去腥定型）
步骤2 [炒4-A] 热锅大火炒肉末至变色出油
步骤3 [炒4-B] 下豆瓣酱中火炒出红油（约1分钟）
步骤4 [炒4-B] 下姜末蒜末炒香
步骤5 [煮9-B] 加半碗水烧开 → 轻放入豆腐
步骤6 [煮9-C] 小火煮3分钟入味（不要翻动，轻晃锅）
步骤7 [煮9-B] 淀粉水勾芡，分两次加入
步骤8 [拌0] 装盘 → 撒花椒粉、葱花
```

**编码序列**：9B→4A→4B→4B→9B→9C→9B→0

**灵魂记忆**：麻婆豆腐的"麻辣烫鲜嫩酥香"七字诀——花椒出麻、豆瓣出辣、趁热吃烫、肉末提鲜、豆腐要嫩、肉末要酥、葱花增香。

### 🥘 菜4：清蒸鲈鱼

**食材清单**：

| 挂钩 | 食材 |
|------|------|
| 1 | 鲈鱼1条（约500g） |
| 2 | 葱丝大量 |
| 3 | 姜丝适量 |
| 4 | 蒸鱼豉油3勺 |
| 5 | 料酒2勺 |
| 6 | 热油2勺 |

**步骤序列**：

```
步骤1 [洗1] 鲈鱼去鳞去内脏洗净，鱼身两面划花刀
步骤2 [腌3] 鱼身抹料酒、姜片腌10分钟
步骤3 [切2] 切葱丝、姜丝备用
步骤4 [蒸7-A] 蒸锅大火烧开 → 鱼放入蒸8分钟（1斤=8分钟）
步骤5 [蒸7-A] 关火虚蒸2分钟（不揭盖）
步骤6 [0] 倒掉蒸出的腥水 → 铺上葱姜丝
步骤7 [0] 淋蒸鱼豉油 → 浇上冒烟的热油（听到"滋啦"声）
```

**编码序列**：1→3→2→7A→7A→0→0

**核心记忆**：
- 蒸鱼时间公式：1斤鱼=8分钟大火，每多1两加1分钟
- "倒腥水、铺葱丝、淋豉油、浇热油"四步连贯
- 热油必须冒烟，听到"滋啦"才算成功

**食材清单**：

| 挂钩 | 食材 |

| 1 | 西红柿2个 |
| 2 | 鸡蛋3个 |

**步骤序列**：


## 四、西餐4道菜

### 🥗 菜7：意大利肉酱面 (Bolognese)

**食材清单**：

| 挂钩 | 食材 |
|------|------|
| 1 | 意大利面200g |
| 2 | 牛肉末200g |
| 3 | 番茄3个（或罐头番茄400g） |
| 4 | 洋葱半个 |
| 5 | 胡萝卜1根 |
| 6 | 西芹1根 |
| 7 | 番茄膏2勺 |
| 8 | 橄榄油、盐、黑胡椒、罗勒 |

**步骤序列**：

```
步骤1 [切2] 洋葱、胡萝卜、西芹切碎丁（Mirepoix法式三合一）
步骤2 [煮9-A] 大火烧开水 → 加盐 → 下意面煮8-10分钟（包装标注时间）
步骤3 [炒4-B] 中火橄榄油炒洋葱丁至透明 → 加胡萝卜西芹丁炒5分钟
步骤4 [炒4-A] 大火下牛肉末炒散至变色
步骤5 [炒4-B] 加番茄膏炒1分钟 → 加番茄碎
步骤6 [炖5-C] 小火慢炖30分钟（时不时搅拌） → 加盐、黑胡椒调味
步骤7 [0] 意面捞出 → 浇肉酱 → 磨黑胡椒、罗勒叶装饰
```

**编码序列**：2→9A→4B→4A→4B→5C→0

**西餐记忆要点**：
- Mirepoix（洋葱胡萝卜西芹=2:1:1）是西餐底味三件套
- 意面煮好后保留一杯面汤（可调整酱汁浓稠度）
- 肉酱小火慢炖是灵魂（急不得）

### 🥗 菜8：法式煎牛排 (Pan-seared Steak)

**食材清单**：

| 挂钩 | 食材 |
|------|------|
| 1 | 眼肉/西冷牛排1块（2.5cm厚） |
| 2 | 海盐、黑胡椒 |
| 3 | 黄油20g |
| 4 | 蒜2瓣（拍扁） |
| 5 | 迷迭香/百里香1枝 |
| 6 | 橄榄油少许 |

**步骤序列**：

```
步骤1 [腌3] 牛排提前30分钟取出回温 → 两面撒海盐、黑胡椒
步骤2 [洗1] 用厨房纸吸干表面水分（关键！）
步骤3 [炒4-A] 铸铁锅大火烧至冒烟 → 加橄榄油
步骤4 [煎-A] 牛排放入，大火煎2分钟不翻动（形成焦壳）
步骤5 [煎-A] 翻面煎2分钟
步骤6 [煎-B] 加黄油、蒜、香草 → 中火浇油淋牛排1分钟
步骤7 [0] 出锅 → 静置5分钟（让肉汁回流） → 切片
```

**编码序列**：3→1→4A→煎A→煎A→煎B→0

**熟度记忆**（手指按压法）：
- **一分熟 (Rare)**：拇指碰食指，按掌心虎口肌肉——软塌塌
- **三分熟 (Medium Rare)**：拇指碰中指按——微有弹性（最佳）
- **五分熟 (Medium)**：拇指碰无名指按——较有弹性
- **全熟 (Well Done)**：拇指碰小指按——硬实

|------|------|

## 五、综合记忆技巧

### 1. 步骤编码速记法

将每道菜的步骤编码连成一串，形成"动作密码"：
- 宫保鸡丁：`2-3-2-6C-4A-4A-4B-4A-0`（切腌切炸炒炒炒炒拌）
- 红烧肉：`2-9A-4B-4A-4B-4B-5C-4B-0`（切煮炒炒炒炒炖炒拌）

### 2. 定位法记忆流程

将厨房分为5个区域，每个区域对应操作类型：

| 位置 | 区域 | 对应操作 |
|------|------|----------|
| 门口 | 冰箱区 | 食材准备（洗、切、腌） |
| 左手边 | 灶台区 | 热操作（炒、炖、煮） |
| 右手边 | 调料架 | 调味 |
| 正前方 | 操作台 | 摆盘、拌 |
| 窗边 | 烤箱区 | 蒸、烤 |

### 3. 食材挂钩法扩展

建立固定的10个挂钩，任何菜谱的食材都能快速记忆：

| 挂钩 | 形象 | 记忆食材的用法 |
|------|------|----------------|
| 1-蜡烛 | 主料（肉/豆腐/面） |
| 2-天鹅 | 蔬菜配料 |
| 3-三角 | 调味料 |
| 4-帆船 | 香料/香草 |
| 5-钩子 | 液体调料（酱油/醋/酒） |
| 6-勺子 | 油脂类 |
| 7-拐杖 | 增香辅料（葱姜蒜） |
| 8-葫芦 | 淀粉/勾芡 |
| 9-气球 | 主食/碳水 |
| 10-棒球 | 装饰/点缀 |

### 4. 火候速记口诀

```
大火快炒保脆嫩（A），
中火慢煎出焦香（B），
小火慢炖入味深（C），
微火保温不变形（D）。
```
