# Major System（主谐音系统）

## 一、说明

Major System（主谐音系统）是一种将数字转换为辅音字母，再组合成单词的记忆方法。由 Stanislaus Mink von Wennsshein 在17世纪发明，后由 Major 在19世纪推广，因此得名。

**核心原理**：
- 每个数字对应一组辅音音素
- 通过添加元音（a, e, i, o, u）将辅音组合成有意义的单词
- 单词转化为具体图像进行记忆

**优势**：
- 可以编码任意位数的数字
- 编码灵活，同一个数字可以有多种单词选择
- 英语世界广泛使用，资料丰富

## 二、编码规则

### 辅音对应表

| 数字 | 辅音 | 记忆口诀 |
|------|------|----------|
| **0** | s, z, soft c | **z**ero 的首音 |
| **1** | t, d, th | t/d 有**一**竖 |
| **2** | n | n 有**两**竖 |
| **3** | m | m 有**三**竖 |
| **4** | r | fou**r** 的尾音 |
| **5** | l | L 是罗马数字**5**0 |
| **6** | j, sh, soft ch, dg | j 反过来像 **6** |
| **7** | k, hard c, hard g, q | K 两个**7**背靠背 |
| **8** | f, v | 手写 **8** 像 f |
| **9** | p, b | **9** 像 p 的镜像 |

### 辅音分组详解

| 数字 | 所有对应辅音 | 说明 |
|------|-------------|------|
| 0 | /s/, /z/, /ks/ (soft c) | zero, zebra, city |
| 1 | /t/, /d/, /θ/ (th) | tea, door, think |
| 2 | /n/, /ŋ/ (ng) | no, sing |
| 3 | /m/ | me, sum |
| 4 | /r/ | red, car |
| 5 | /l/ | love, ball |
| 6 | /dʒ/ (j), /ʃ/ (sh), /tʃ/ (ch), /dʒ/ (dg) | jump, ship, church, edge |
| 7 | /k/, /ɡ/, /kw/ (qu) | key, go, queen |
| 8 | /f/, /v/ | fun, very |
| 9 | /p/, /b/ | pen, ball |

### 重要规则
1. **只看辅音**：元音（a, e, i, o, u）和字母 h, w, y 不计入编码
2. **双字母**：双写辅音只算一个（如 tt = 1, ss = 0）
3. **组合辅音**：ch = 6, sh = 6, th = 1, ng = 2, qu = 7
4. **c 的发音**：soft c（如 city）= 0，hard c（如 cat）= 7

## 四、10个完整编码实例

### 实例1：数字 314 → π（3.14）

**编码过程**：
1. 数字：3 - 1 - 4
2. 辅音：m - t/d - r
3. 组合单词：**meter**（米/仪表）→ m(3) + t(1) + r(4)
4. 图像：一个巨大的**仪表盘**

**记忆画面**：圆周率 π 的前三位是 3.14，想象一个巨大的**仪表盘**（meter）显示着 3.14。

---

### 实例2：数字 1492 → 哥伦布发现美洲

**编码过程**：
1. 数字：1 - 4 - 9 - 2
2. 辅音：t/d - r - p/b - n
3. 组合单词：**turbo fan**（涡轮风扇）→ t(1) + r(4) + b(9) + f(8) + n(2) — 但这是5位
4. 换思路：**turban**（头巾）→ t(1) + r(4) + b(9) + n(2) ✓
5. 图像：一条色彩鲜艳的**头巾**

**记忆画面**：哥伦布戴着一条色彩鲜艳的**头巾**，站在船头发现了新大陆（1492年）。

---

### 实例3：数字 1776 → 美国独立

**编码过程**：
1. 数字：1 - 7 - 7 - 6
2. 辅音：t/d - k/g - k/g - j/sh/ch
3. 组合单词：**took cash**（拿了现金）→ t(1) + k(7) + c(7) + sh(6)
4. 图像：一沓**现金**

**记忆画面**：美国国父们在《独立宣言》上签字后，每人**拿了现金**（1776年独立）。

### 实例4：数字 1945 → 二战结束

**编码过程**：
1. 数字：1 - 9 - 4 - 5
2. 辅音：t/d - p/b - r - l
3. 组合单词：**taperel**（无意义）→ 换：**diaper roll**（尿布卷）
4. 更好：**tap rail**（敲击栏杆）→ t(1) + p(9) + r(4) + l(5)
5. 图像：有人在**敲击铁栏杆**

**记忆画面**：1945年二战结束，人们兴奋地**敲击铁栏杆**庆祝胜利。

### 实例5：数字 2008 → 金融危机

**编码过程**：
1. 数字：2 - 0 - 0 - 8
2. 辅音：n - s/z - s/z - f/v
3. 组合单词：**nose off**（鼻子掉了）→ n(2) + s(0) + f(8) — 3位够了
4. 4位：**news view** → n(2) + s(0) + v(8) + 元音 — 不够
5. **niece of** → n(2) + c(0) + f(8) — 3位
6. **nose evidence** → 太长
7. **insufficient** → 不行
8. 用两个词：**nose** (20) + **safe** (08) → 鼻子 + 保险箱

**记忆画面**：2008年金融危机，人们捂着**鼻子**（闻到危险），把钱藏进**保险箱**。

### 实例10：数字 2024 → 现代

**编码过程**：
1. 数字：2 - 0 - 2 - 4
2. 辅音：n - s/z - n - r
3. 组合单词：**insaner**（更疯狂的）→ n(2) + s(0) + n(2) + r(4)
4. 或 **no sensor**（没有传感器）→ n(2) + s(0) + n(2) + s(0) + r(4) — 太长
5. **nose nerd**（鼻子书呆子）→ n(2) + s(0) + n(2) + r(4) + d(1) — 太长
6. **insane**（疯狂的）→ n(2) + s(0) + n(2) — 3位
7. **unison**（齐唱）→ n(2) + s(0) + n(2) — 也是3位
8. 用两个词：**nose** (20) + **nero** (24) → 鼻子 + 尼禄

**记忆画面**：2024年，一个巨大的**鼻子**像罗马皇帝**尼禄**一样俯瞰世界。
