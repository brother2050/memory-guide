# 日期记忆（星期计算）

> 本指南介绍快速心算任意日期对应星期几的方法，基于蔡勒公式（Zeller's Congruence）的简化心算版本，适合日常使用和竞赛训练。

## 一、说明

快速计算任意日期是星期几，是数字记忆的经典应用场景。

**核心公式**：基于蔡勒公式简化的心算版本

**训练目标**：3秒内算出任意日期是星期几

**星期编码**（全文统一）：0=周一, 1=周二, 2=周三, 3=周四, 4=周五, 5=周六, 6=周日

---

## 二、心算公式（推荐）

### 核心公式

```
W = (日期 + 月份代码 + 年份后两位 + 年份后两位÷4 - 闰年调整 + 世纪校正码) mod 7
```

### 月份代码表

| 月份 | 代码 | 助记 |
|------|------|------|
| 1月 | 0 | 一月**零**蛋 |
| 2月 | 3 | 二月**三**八 |
| 3月 | 3 | 三月**三**八 |
| 4月 | 6 | 四月**六**一 |
| 5月 | 1 | 五**一**劳动节 |
| 6月 | 4 | 六月**四** |
| 7月 | 6 | 七月**六** |
| 8月 | 2 | 八月**二** |
| 9月 | 5 | 九月**五**（九五至尊） |
| 10月 | 0 | 十月**零**蛋 |
| 11月 | 3 | 十一月**三** |
| 12月 | 5 | 十二月**五** |

**口诀**："零三三六一四六二五零三五"

### 世纪校正码

| 世纪 | 3-12月 | 1-2月非闰年 | 1-2月闰年 |
|------|--------|------------|----------|
| 2000-2099 | **5** | **6** | **0** |
| 1900-1999 | **6** | **0** | **1** |

> **口诀**："20世纪5和6，闰年1月变成0；19世纪6和0，闰年1月变成1"

### 闰年调整规则

- **3-12月**：无调整（闰年调整=0）
- **1-2月非闰年**：无调整（闰年调整=0）
- **1-2月闰年**：闰年调整=**1**（即从结果中减1）

**闰年判断**：年份能被4整除且不能被100整除，或者能被400整除

### 年份后两位

- **3-12月**：直接用年份后两位（如2024→24）
- **1-2月**：用**上一年**的后两位（如2024年1月→用23）

### 计算步骤

1. **写出日期**
2. **查月份代码**
3. **确定年份后两位**（1-2月用上一年）
4. **计算年份÷4**（取整）
5. **查世纪校正码**
6. **判断是否需要闰年调整**（仅1-2月闰年时减1）
7. **求和取模7**

## 三、公式来源（蔡勒公式）

本公式基于德国数学家Christian Zeller于1882年推导的**蔡勒公式**（Zeller's Congruence）：

```
W = (Y + ⌊Y/4⌋ - ⌊Y/100⌋ + ⌊Y/400⌋ + ⌊13×(M+1)/5⌋ + D - 1) mod 7
```

其中：
- Y = 年份（1-2月用上一年）
- M = 月份（1-2月变为13、14）
- D = 日期
- W = 星期（0=日，1=一，...，6=六）

**月份代码** = ⌊13×(M+1)/5⌋ 的预计算值：

| 月份 | M值 | ⌊13×(M+1)/5⌋ |
|------|-----|---------------|
| 3月 | 3 | 10 |
| 4月 | 4 | 13 |
| 5月 | 5 | 15 |
| 6月 | 6 | 18 |
| 7月 | 7 | 20 |
| 8月 | 8 | 23 |
| 9月 | 9 | 26 |
| 10月 | 10 | 28 |
| 11月 | 11 | 31 |
| 12月 | 12 | 33 |
| 1月（上年13月） | 13 | 36 |
| 2月（上年14月） | 14 | 39 |

**简化心算公式**：将 -⌊Y/100⌋ + ⌊Y/400⌋ 合并为世纪校正码，月份代码减去基准值简化为0-6的范围。

## 五、心算技巧

### 技巧1：模7快速取余

心算时不断减7：

```
37 → 37-35=2
53 → 53-49=4
65 → 65-63=2
134 → 134-133=1
```

**7的倍数速查**：7, 14, 21, 28, 35, 42, 49, 56, 63, 70, 77, 84, 91, 98, 105, 112, 119, 126, 133, 140

### 技巧2：年份÷4速算

| 年份后两位 | ÷4取整 | 速算 |
|-----------|--------|------|
| 00-03 | 0 | 直接用0 |
| 04-07 | 1 | +1 |
| 08-11 | 2 | +2 |
| 12-15 | 3 | +3 |
| 16-19 | 4 | +4 |
| 20-23 | 5 | +5 |
| 24-27 | 6 | +6 |
| 28-31 | 7 | +7 |

### 技巧3：跨年推算

- 平年跨年：星期+1（365=52周+1天）
- 闰年跨年：星期+2（366=52周+2天）

### 技巧4：已知锚点法

记住几个关键日期，从锚点推算其他日期：

| 日期 | 2024年 | 2025年 |
|------|--------|--------|
| 1月1日 | 周一 | 周三 |
| 5月1日 | 周三 | 周四 |
| 7月1日 | 周一 | 周二 |
| 10月1日 | 周二 | 周三 |

### 技巧5：同月推算

已知某月某日是星期几，推算同月其他日期：

```
新星期 = (已知星期 + 天数差) mod 7
```

## 六、快速验证法

### 用已知日期验证

**2024年1月1日 = 周一**（常用验证基准）

### 常见错误排查

| 错误现象 | 可能原因 |
|----------|----------|
| 差1天 | 月份代码记错，或1-2月未用上一年年份 |
| 差2天 | 闰年调整搞错（1-2月闰年需-1） |
| 完全错误 | 世纪校正码用错 |

## 七、训练计划

### 第一阶段：记忆月份代码（1-2天）

1. 背诵口诀："零三三六一四六二五零三五"
2. 默写月份代码表
3. 随机月份→代码的快速反应

### 第二阶段：单步计算（3-5天）

1. 只算3-12月（无需闰年调整）
2. 逐步加入1-2月
3. 最后加入闰年调整

### 第三阶段：完整计算（1-2周）

1. 随机日期完整计算
2. 目标：10秒内完成
3. 逐步提速到3秒

### 第四阶段：日常应用（持续）

1. 每天问自己：今天星期几？用公式验证
2. 看到任何日期都尝试心算
