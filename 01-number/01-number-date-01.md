# 日期记忆（星期计算）

## 一、说明

快速计算任意日期是星期几，是数字记忆的经典应用场景。本文件介绍基于**蔡勒公式**和**基姆拉尔森公式**的记忆编码方法，让你能心算出任何日期对应的星期。

**核心公式**：
- **蔡勒公式**（Zeller's Congruence）：适用于所有日期
- **基姆拉尔森公式**（Kim Larsen's method）：更简化，适合心算

**训练目标**：3秒内算出任意日期是星期几

---

## 二、基姆拉尔森公式（推荐心算用）

### 公式

```
W = (d + 2×m + 3×(m+1)/5 + y + y/4 - y/100 + y/400) mod 7
```

其中：
- d = 日
- m = 月（3月=3，4月=4，...，12月=12，1月=13（上年），2月=14（上年））
- y = 年（1月2月需减1）
- W = 星期（0=一，1=二，...，6=日）

### 简化心算版本

**步骤**：
1. **月份代码**（核心记忆点）
2. **日期**直接用
3. **年份调整**
4. **世纪调整**
5. **求和取模7**

### 年份调整规则

**平年**：年份代码 = 年份后两位
**闰年**：1月2月需额外-1

**年份后两位代码速算**：

```
年份代码 = 年份后两位 + 年份后两位/4（取整）
```

例如：2024年 → 24 + 24/4 = 24 + 6 = 30

|------|--------|----------|

| 1600-1699 | 6 | 莎士比亚时代 |
| 1700-1799 | 4 | 美国独立 |
| 1800-1899 | 2 | 工业革命 |
| 1900-1999 | 0 | 20世纪（我们最常用） |
| 2000-2099 | 6 | 21世纪（当前） |
| 2100-2199 | 4 | 未来 |

**21世纪调整值=6**，这是最常用的。

### 完整计算公式（21世纪）

```
星期 = (日期 + 月份代码 + 年份后两位 + 年份后两位/4 + 6) mod 7
```

结果：0=日，1=一，2=二，3=三，4=四，5=五，6=六

**注意**：有些版本的星期定义不同，这里用0=周日。实际使用时需确认你采用的版本。

## 三、蔡勒公式（精确版）

### 公式

```
W = (Y + Y/4 - Y/100 + Y/400 + [13×(M+1)/5] + D - 1) mod 7
```

其中：
- Y = 年份（1月2月需当作上一年的13月14月）
- M = 月份（3月=3，4月=4，...，12月=12，1月=13，2月=14）
- D = 日期
- W = 星期（0=六，1=日，2=一，3=二，4=三，5=四，6=五）

## 五、心算技巧和简化方法

### 技巧1：模7快速取余

心算时不需要真正做除法，只需不断减7：

```
37 mod 7 = 37 - 35 = 2
54 mod 7 = 54 - 49 = 5
66 mod 7 = 66 - 63 = 3
128 mod 7 = 128 - 126 = 2
```

**记忆**：7的倍数速查：7, 14, 21, 28, 35, 42, 49, 56, 63, 70, 77, 84, 91, 98, 105, 112, 119, 126, 133, 140

### 技巧2：年份代码速算

年份后两位除以4取整，可以用以下方法：

| 年份范围 | 速算方法 | 示例 |
|----------|----------|------|
| 00-03 | 直接用0 | 2002→0 |
| 04-07 | +1 | 2006→1 |
| 08-11 | +2 | 2010→2 |
| 12-15 | +3 | 2014→3 |
| 16-19 | +4 | 2018→4 |
| 20-23 | +5 | 2022→5 |
| 24-27 | +6 | 2026→6 |
| 28-31 | +7 | 2030→7 |

**规律**：每4年加1

### 技巧3：同月不同年快速推算

如果知道某年某月某日是星期几，推算同月不同日：

```
差几天 = 新日期 - 已知日期
新星期 = (已知星期 + 差几天) mod 7
```

例如：已知2024年3月1日是周五，求3月15日：
```
差 = 15 - 1 = 14天 = 2周
3月15日 = 周五 + 14 = 周五（过了整整2周）
```

### 技巧4：跨年推算

平年跨年：星期+1（365 = 52周+1天）
闰年跨年：星期+2（366 = 52周+2天）

例如：2024年1月1日是周一，求2025年1月1日：
```
2024是闰年，所以+2
2025年1月1日 = 周一 + 2 = 周三
```

### 技巧5：已知锚点记忆法

记住几个关键日期作为锚点：

| 日期 | 2024年 | 2025年 | 记忆方式 |
|------|--------|--------|----------|
| 1月1日 | 周一 | 周三 | 元旦 |
| 5月1日 | 周三 | 周四 | 劳动节 |
| 7月1日 | 周一 | 周二 | 建党节 |
| 10月1日 | 周二 | 周三 | 国庆节 |
| 12月25日 | 周三 | 周四 | 圣诞节 |

从锚点推算其他日期只需加减天数。

## 七、快速验证法

### 用已知日期验证公式

**验证基准**：2024年1月1日 = 星期一

用基姆拉尔森公式验证：
```
(1 + 0 + 24 + 6 + 6) mod 7 = 37 mod 7 = 2
```

如果2=周一，则公式正确（需确认你的星期编码：0=周日还是0=周一）

### 日历验证技巧

手机日历是最快速的验证工具：
1. 心算得出结果
2. 打开手机日历核对
3. 如果错误，回溯计算步骤找错

### 常见错误排查

| 错误现象 | 可能原因 | 检查点 |
|----------|----------|--------|
| 差1天 | 月份代码记错 | 核对月份代码表 |
| 差2天 | 闰年未调整 | 检查是否1月2月 |
| 完全错误 | 世纪调整用错 | 确认世纪调整值 |
| 周末对不上 | 星期编码搞混 | 确认0=周日还是周一 |

## 九、蔡勒公式与基姆拉尔森公式对比

| 特性 | 蔡勒公式 | 基姆拉尔森公式 |
|------|----------|----------------|
| 精确度 | 数学精确 | 等价精确 |
| 心算难度 | 较难 | 较易 |
| 月份代码 | 需计算[13×(M+1)/5] | 直接记忆 |
| 闰年处理 | 自动（调整月份） | 需手动-1 |
| 适用场景 | 编程计算 | 心算 |
| 推荐度 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

**建议**：日常心算用基姆拉尔森公式，编程实现用蔡勒公式。
