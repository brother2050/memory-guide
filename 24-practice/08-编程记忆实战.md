## 🎬 场景说明

编程不是死记硬背，但常用算法、设计模式、SQL语句和Git命令需要内化到肌肉记忆。本实战用记忆技巧加速这个过程，让你从"查文档"到"信手拈来"。

**适用人群**：程序员、计算机专业学生、面试备考者

## 任务1：记忆常用算法10个

### 📋 材料

| 编号 | 算法 | 核心思想 | 时间复杂度 | 画面联想 |
|------|------|----------|------------|----------|
| 1 | 冒泡排序 | 相邻比较，大的往后冒 | O(n²) | 气泡从水底冒上来 |
| 2 | 选择排序 | 每次选最小的放前面 | O(n²) | 选最矮的站前面 |
| 3 | 插入排序 | 像打牌一样插入 | O(n²) | 扑克牌按顺序插 |
| 4 | 快速排序 | 选基准，分两边 | O(nlogn) | 一刀切两半 |
| 5 | 归并排序 | 先分后合 | O(nlogn) | 先拆开再合并 |
| 6 | 二分查找 | 每次缩小一半 | O(logn) | 猜数字游戏 |
| 7 | 广度优先(BFS) | 一层一层搜 | O(V+E) | 水波纹扩散 |
| 8 | 深度优先(DFS) | 一条路走到黑 | O(V+E) | 走迷宫 |
| 9 | 动态规划 | 记住已算过的 | O(n²) | 备忘录 |
| 10 | 贪心算法 | 每步选最优 | O(nlogn) | 每次都选最大的 |

### 🔧 操作步骤

1. **原理理解**（5分钟）：理解每个算法的核心思想
2. **画面联想**（3分钟）：将算法过程可视化
3. **代码默写**（5分钟）：默写每个算法的核心代码
4. **复杂度记忆**（3分钟）：记住时间/空间复杂度
5. **场景匹配**（4分钟）：给出问题，选择合适算法

### ✅ 自评标准

| 等级 | 标准 | 用时参考 |
|------|------|----------|
| ⭐ 入门 | 正确回忆 6/10（算法名+核心思想） | 20分钟内 |
| ⭐⭐ 熟练 | 正确回忆 9/10，且能默写代码 | 12分钟内 |
| ⭐⭐⭐ 精通 | 全部正确，且能分析复杂度 | 8分钟内 |

## 任务3：记忆SQL语句10个

### 📋 材料

| 编号 | 语句 | 功能 | 画面联想 |
|------|------|------|----------|
| 1 | SELECT * FROM table WHERE condition | 查询数据 | 从表里选满足条件的行 |
| 2 | INSERT INTO table (col) VALUES (val) | 插入数据 | 往表里加一行 |
| 3 | UPDATE table SET col=val WHERE condition | 更新数据 | 改满足条件的行 |
| 4 | DELETE FROM table WHERE condition | 删除数据 | 删满足条件的行 |
| 5 | CREATE TABLE table (col type) | 创建表 | 建一个新表 |
| 6 | ALTER TABLE table ADD col type | 修改表结构 | 给表加一列 |
| 7 | SELECT col, COUNT(*) FROM table GROUP BY col | 分组统计 | 按某列分组计数 |
| 8 | SELECT * FROM a JOIN b ON a.id=b.id | 连接查询 | 两张表通过ID连接 |
| 9 | SELECT * FROM table ORDER BY col DESC | 排序查询 | 按某列降序排列 |
| 10 | SELECT DISTINCT col FROM table | 去重查询 | 选不重复的值 |

### 🔧 操作步骤

1. **语句理解**（3分钟）：理解每个语句的功能
2. **关键词记忆**（3分钟）：记住SQL关键词（SELECT, FROM, WHERE等）
3. **语法结构**（5分钟）：默写每个语句的完整语法
4. **场景应用**（5分钟）：给出需求，写出SQL语句
5. **遮盖默写**（4分钟）：遮住语句，看功能默写
