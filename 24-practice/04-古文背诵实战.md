## 🎬 场景说明

古文背诵是中国学生从小学到考研都绕不开的任务。本实战从简单的五言绝句到长篇文言文，用画面法和宫殿法让古文从"死记硬背"变成"活灵活现"。

**适用人群**：中小学生、高考/考研备考者
**核心方法**：逐句画面法、结构拆解法、记忆宫殿法

---

## 任务1：记忆《静夜思》（5分钟）

### 📋 材料

**原文：**
```
床前明月光，疑是地上霜。
举头望明月，低头思故乡。
```

**逐句画面联想：**

| 诗句 | 画面描述 | 记忆锚点 |
|------|----------|----------|
| 床前明月光 | 床前洒满了明亮的月光 | 床=睡觉的地方 |
| 疑是地上霜 | 以为是地上结了霜 | 疑=怀疑，霜=冷 |
| 举头望明月 | 抬起头看明亮的月亮 | 举=抬头动作 |
| 低头思故乡 | 低下头思念故乡 | 低=低头动作 |

### 🔧 操作步骤

1. **理解诗意**（1分钟）：先理解每句诗的含义
2. **画面联想**（2分钟）：在脑海中构建4幅画面
3. **朗读3遍**（1分钟）：大声朗读，注意节奏和韵律
4. **遮盖背诵**（1分钟）：遮住原文，完整背诵

### ✅ 自评标准

| 等级 | 标准 | 用时参考 |
|------|------|----------|
| ⭐ 入门 | 能背诵，但有1-2处卡顿 | 5分钟内 |
| ⭐⭐ 熟练 | 流畅背诵，无卡顿 | 3分钟内 |
| ⭐⭐⭐ 精通 | 流畅背诵，且能说出每句含义 | 2分钟内 |

## 任务2：记忆《出师表》第一段（15分钟）

### 📋 材料

**原文：**
```
先帝创业未半而中道崩殂，今天下三分，益州疲弊，此诚危急存亡之秋也。
然侍卫之臣不懈于内，忠志之士忘身于外者，盖追先帝之殊遇，欲报之于陛下也。
诚宜开张圣听，以光先帝遗德，恢弘志士之气，不宜妄自菲薄，引喻失义，以塞忠谏之路也。
```

**逐句拆解与画面联想：**

| 句子 | 拆解 | 画面联想 |
|------|------|----------|
| 先帝创业未半而中道崩殂 | 先帝=刘备，创业未半=事业没完成，中道崩殂=半路去世 | 刘备创业到一半就倒下了 |
| 今天下三分，益州疲弊 | 三分=三国鼎立，益州=蜀汉，疲弊=疲惫 | 三国地图，蜀汉最小最累 |
| 此诚危急存亡之秋也 | 危急存亡=生死关头，秋=时刻 | 一个秋天，树叶凋零，国家危在旦夕 |
| 然侍卫之臣不懈于内 | 侍卫之臣=宫中大臣，不懈=不懈怠 | 宫殿里大臣们坚守岗位 |
| 忠志之士忘身于外者 | 忠志之士=将士，忘身=不顾性命 | 战场上将士们奋勇杀敌 |
| 盖追先帝之殊遇 | 追=追念，殊遇=特殊恩遇 | 将士们想起刘备的知遇之恩 |
| 欲报之于陛下也 | 报=报答，陛下=刘禅 | 将士们跪在刘禅面前 |
| 诚宜开张圣听 | 开张=广开，圣听=听取意见 | 刘禅张开耳朵听 |
| 以光先帝遗德 | 光=发扬，遗德=留下的美德 | 刘备的美德像光一样照耀 |
| 恢弘志士之气 | 恢弘=振奋，志士之气=将士的士气 | 将士们士气大振 |
| 不宜妄自菲薄 | 妄自菲薄=过分看轻自己 | 刘禅不要觉得自己不行 |
| 引喻失义 | 引喻=举例，失义=不合道理 | 说话不要不合道理 |
| 以塞忠谏之路也 | 塞=堵塞，忠谏=忠言进谏 | 忠言的路被堵住了 |

### 🔧 操作步骤

1. **理解全文**（3分钟）：逐句理解古文含义
2. **画面构建**（5分钟）：为每句话创建一个画面
3. **故事串联**（3分钟）：将画面串联成一个完整的故事
4. **朗读3遍**（2分钟）：大声朗读，注意节奏
5. **遮盖背诵**（2分钟）：遮住原文，完整背诵

### ✅ 自评标准

| 等级 | 标准 | 用时参考 |
|------|------|----------|
| ⭐ 入门 | 能背诵60%内容 | 15分钟内 |
| ⭐⭐ 熟练 | 能背诵90%内容 | 10分钟内 |
| ⭐⭐⭐ 精通 | 流畅背诵全文，且能翻译 | 5分钟内 |

## 任务3：记忆《岳阳楼记》全文（30分钟）

### 📋 材料

**结构拆解：**

| 段落 | 内容 | 关键词 | 记忆锚点 |
|------|------|--------|----------|
| 第1段 | 作记缘由 | 滕子京、谪守、重修岳阳楼 | 滕子京被贬到巴陵郡 |
| 第2段 | 洞庭胜状 | 衔远山、吞长江、浩浩汤汤 | 洞庭湖的壮阔景象 |
| 第3段 | 悲景 | 霪雨霏霏、阴风怒号 | 悲凉的秋天景色 |
| 第4段 | 喜景 | 春和景明、波澜不惊 | 明媚的春天景色 |
| 第5段 | 古仁人之心 | 不以物喜、不以己悲 | 范仲淹的忧乐观 |

**重点句子画面联想：**

| 句子 | 画面联想 |
|------|----------|
| 先天下之忧而忧 | 在天下人忧愁之前就忧愁=先知先觉的忧国者 |
| 后天下之乐而乐 | 在天下人快乐之后才快乐=最后才享乐的圣人 |
| 不以物喜，不以己悲 | 不因外物而喜，不因自己而悲=超然物外 |
| 衔远山，吞长江 | 洞庭湖像一张大嘴，衔着山吞着江 |
| 浩浩汤汤，横无际涯 | 水势浩大，无边无际 |

### 🔧 操作步骤

1. **结构梳理**（5分钟）：先理解全文5段的逻辑结构
2. **逐段记忆**（15分钟）：每段用画面联想记忆，每段3分钟
3. **段间连接**（5分钟）：将5段串联，注意过渡句
4. **全文朗读**（3分钟）：大声朗读全文2遍
5. **遮盖背诵**（2分钟）：遮住原文，完整背诵

### ✅ 自评标准

| 等级 | 标准 | 用时参考 |
|------|------|----------|
| ⭐ 入门 | 能背诵60%内容 | 30分钟内 |
| ⭐⭐ 熟练 | 能背诵90%内容 | 20分钟内 |
| ⭐⭐⭐ 精通 | 流畅背诵全文，且能默写 | 10分钟内 |

## 任务4：记忆《离骚》节选（20分钟）

### 📋 材料

**节选原文：**
```
帝高阳之苗裔兮，朕皇考曰伯庸。
摄提贞于孟陬兮，惟庚寅吾以降。
皇览揆余初度兮，肇锡余以嘉名。
名余曰正则兮，字余曰灵均。
纷吾既有此内美兮，又重之以修能。
扈江离与辟芷兮，纫秋兰以为佩。
```

**逐句拆解与画面联想：**

| 句子 | 含义 | 画面联想 |
|------|------|----------|
| 帝高阳之苗裔兮 | 我是高阳帝的后代 | 皇帝家族谱系图 |
| 朕皇考曰伯庸 | 我父亲叫伯庸 | 父亲的画像 |
| 摄提贞于孟陬兮 | 摄提星指向孟春正月 | 星空图，星星指向正月 |
| 惟庚寅吾以降 | 庚寅年我降生 | 婴儿出生的场景 |
| 皇览揆余初度兮 | 父亲观察我初生的气度 | 父亲端详婴儿 |
| 肇锡余以嘉名 | 开始赐给我美好的名字 | 父亲在写名字 |
| 名余曰正则兮 | 给我取名叫正则 | 名牌上写着"正则" |
| 字余曰灵均 | 给我取字叫灵均 | 名牌上写着"灵均" |
| 纷吾既有此内美兮 | 我已经有了内在美 | 内心发光的人 |
| 又重之以修能 | 又加上美好的才能 | 才能像衣服一样加在身上 |
| 扈江离与辟芷兮 | 披着江离和辟芷 | 身上披着香草 |
| 纫秋兰以为佩 | 编织秋兰作为佩饰 | 腰间挂着兰花 |

### 🔧 操作步骤

1. **背景了解**（3分钟）：了解屈原的生平和《离骚》背景
2. **逐句理解**（5分钟）：理解每句的含义
3. **画面构建**（5分钟）：为每句话创建画面
4. **朗读3遍**（3分钟）：注意"兮"字的节奏感
5. **遮盖背诵**（4分钟）：遮住原文，完整背诵

### ✅ 自评标准

| 等级 | 标准 | 用时参考 |
|------|------|----------|
| ⭐ 入门 | 能背诵60%内容 | 20分钟内 |
| ⭐⭐ 熟练 | 能背诵90%内容 | 12分钟内 |
| ⭐⭐⭐ 精通 | 流畅背诵全文，且能解释含义 | 8分钟内 |

## ✅ 预期效果与检验方法

### 完成全部任务后，你应该能够：
- 5分钟内流畅背诵《静夜思》等短诗

- 30分钟内背诵《岳阳楼记》全文

1. **即时检验**：遮住原文，完整背诵

3. **隔日检验**：第二天不复习，直接背诵
