# 发展心理学记忆素材 · Developmental Psychology Encoding

> 编码体系：20个发展阶段 × 皮亚杰四阶段 × 埃里克森八阶段
> 每个阶段：关键任务 → 里程碑 → 理论 → 画面编码

## 一、20个发展阶段总览编码

### DEV-01 胎儿期（Prenatal · 受孕至出生）

| 维度 | 内容 |
|------|------|
| **关键任务** | 器官形成、神经系统发育、感觉能力初步建立 |
| **里程碑** | ①胚芽期（0-2周）着床 ②胚胎期（3-8周）器官分化 ③胎儿期（9周-出生）系统成熟 |
| **核心理论** | 致畸敏感期（teratogens）：酒精/药物/辐射在胚胎期伤害最大 |
| **画面编码** | 🎬 暗室中一颗发光的种子在水波里缓缓分裂，第一周长出脊索（像小闪电），第八周已具人形轮廓，后期听到母体心跳声 |

### DEV-02 新生儿期（Neonatal · 0-28天）

| 维度 | 内容 |
|------|------|
| **关键任务** | 适应子宫外生存、建立基本生理节律 |
| **里程碑** | 觅食反射、吮吸反射、抓握反射、莫罗反射（惊跳） |
| **核心理论** | 新生儿能力被低估：偏好人脸图案、能区分母亲气味 |
| **画面编码** | 🎬 婴儿被轻轻放在胸口，嘴巴自动转向乳房（觅食），小手紧紧握住成人的食指（抓握），听到大声响时四肢张开再抱紧（莫罗） |

### DEV-03 早期婴儿期（Early Infancy · 1-6月）

| 维度 | 内容 |
|------|------|
| **关键任务** | 感知觉快速发展、社会性微笑出现、依恋萌芽 |
| **里程碑** | 2月社交性微笑、3月抬头、4月伸手够物、6月辅食添加 |
| **核心理论** | 鲍尔比依恋理论（前依恋期→依恋形成期）；感觉偏好范式 |
| **画面编码** | 🎬 两个月的婴儿看到妈妈的脸突然绽放笑容（社交微笑），像是灯泡被点亮；四个月时胖乎乎的手伸向悬挂的彩色球 |

### DEV-04 后期婴儿期（Late Infancy · 6-12月）

| 维度 | 内容 |
|------|------|
| **关键任务** | 客体永久性萌芽、陌生人焦虑、分离焦虑 |
| **里程碑** | 8月认生、9-10月拇食指捏取、12月独站/行走 |
| **核心理论** | 皮亚杰感知运动阶段（亚阶段3-4）；安斯沃斯陌生情境测验 |
| **画面编码** | 🎬 妈妈用布盖住玩具，婴儿掀开布找到它（客体永久性）；陌生人靠近时婴儿把脸埋进妈妈肩膀，双手紧抓衣服 |

### DEV-05 幼儿前期（Toddlerhood · 1-3岁）

## 二、皮亚杰认知发展四阶段详细编码

### PIAGET-1 感知运动阶段（Sensorimotor · 0-2岁）

**六个亚阶段：**

| 亚阶段 | 年龄 | 核心能力 | 画面编码 |
|--------|------|----------|----------|
| 1. 反射练习期 | 0-1月 | 先天反射（吮吸/抓握） | 🎬 奶嘴碰到嘴唇自动吮吸 |
| 2. 初级循环反应 | 1-4月 | 重复偶然行为（吸手指） | 🎬 婴儿发现吸手指很舒服，反复做 |
| 3. 次级循环反应 | 4-8月 | 重复对外界的影响（摇铃铛） | 🎬 婴儿拍打悬挂铃铛，听到声音笑了，继续拍 |
| 4. 次级图式协调 | 8-12月 | **目标导向行为**、手段-目的 | 🎬 婴儿推开障碍物够到玩具（有意图的动作） |
| 5. 三级循环反应 | 12-18月 | 主动实验、新颖手段 | 🎬 婴儿从不同高度扔球，观察弹跳差异（小科学家） |
| 6. 心理表征期 | 18-24月 | **客体永久性完全获得**、延迟模仿 | 🎬 妈妈藏起玩具，婴儿先看向别处（心理搜索），然后去正确位置找 |

**核心概念：**
- **客体永久性**（Object Permanence）：理解物体不因看不见而消失
- **A非B错误**：8-12月婴儿在A处找到物体后，即使看到被移到B处，仍去A处找
- **循环反应**：婴儿重复产生有趣结果的行为
- **画面编码**：🎬 皮亚杰实验台——婴儿坐在桌前，玩具被布盖住，小手犹豫后掀开布（客体永恒性的"发现"瞬间）

### PIAGET-2 前运算阶段（Preoperational · 2-7岁）

**两大子阶段：**

| 子阶段 | 年龄 | 核心特征 | 画面编码 |
|--------|------|----------|----------|
| 符号功能期 | 2-4岁 | 符号思维、语言爆发、假装游戏 | 🎬 孩子拿香蕉当电话："喂？" |
| 直觉思维期 | 4-7岁 | 直觉推理、分类萌芽但不守恒 | 🎬 孩子说"月亮跟着我走" |

**核心特征（全部需要画面编码）：**

| 特征 | 说明 | 画面编码 |
|------|------|----------|
| **自我中心** | 无法从他人视角看问题 | 🎬 三山实验：孩子选自己看到的景色给玩偶看 |
| **中心化** | 只关注一个维度 | 🎬 看高瘦杯 vs 矮胖杯：孩子选"高=多" |
| **不可逆性** | 不能逆向思维 | 🎬 不理解2+3=5 → 5-3也等于2 |
| **静态推理** | 只看状态不看变化 | 🎬 看到两排等量硬币，一排拉长后说"长的多" |
| **泛灵论** | 赋予无生命物生命 | 🎬 "风生气了所以刮得大" |
| **人为论** | 万物为人所造 | 🎬 "山是谁造的？人造的！" |
| **转换推理** | 关注起点和终点忽略中间 | 🎬 从家到学校"一下子就到了" |

**守恒实验系列（前运算阶段尚未掌握）：**
- 液体守恒：两个等量水杯 → 倒入不同形状容器 → 判断
- 数量守恒：两排等量硬币 → 一排拉长 → 判断
- 质量守恒：等量橡皮泥 → 一个搓长 → 判断
- 长度守恒：等长木棍 → 一端前移 → 判断
- **画面编码**：🎬 一排玻璃杯并排，从矮胖到高瘦，孩子指着最高的杯子说"这个最多！"旁边实验者微笑着记录

### PIAGET-3 具体运算阶段（Concrete Operational · 7-11岁）

**核心能力获得：**

| 能力 | 说明 | 画面编码 |
|------|------|----------|
| **守恒** | 理解物理变换不改数量 | 🎬 "倒过来还是一样多！" |
| **可逆性** | 能逆向思维 | 🎬 3+4=7 → 7-4=3（轻松写出） |
| **去中心化** | 考虑多个维度 | 🎬 同时比较宽和高来判断面积 |
| **分类** | 层级分类能力 | 🎬 动物→哺乳动物→狗→金毛（能理解层级） |
| **序列化** | 排序能力 | 🎬 把7根不同长度的棍子从短到长排好 |
| **传递性** | 推理A>B、B>C→A>C | 🎬 "小明比小红高，小红比小华高，所以小明比小华高" |

**局限性：**
- 仍需具体事物支撑（不能纯抽象推理）
- **画面编码**：🎬 孩子在桌前用实物（积木/珠子）来解应用题，离开实物就卡住——"具体"是关键词

### PIAGET-4 形式运算阶段（Formal Operational · 11岁+）

**核心能力：**

| 能力 | 说明 | 画面编码 |
|------|------|----------|
| **假设演绎推理** | 从假设推导结论 | 🎬 "如果...那么...所以..." |
| **命题思维** | 对抽象命题推理 | 🎬 讨论"正义是什么" |
| **组合推理** | 系统枚举所有可能 | 🎬 摆钟实验：系统改变绳长/重量/高度/推力 |
| **抽象思维** | 脱离具体内容 | 🎬 理解"自由"这个概念 |
| **理想主义** | 对社会/自我的理想化 | 🎬 "世界应该是什么样的？" |

**经典实验：**
- **摆钟任务**：找出影响摆动频率的因素 → 形式运算者系统控制变量
- **画面编码**：🎬 青少年站在实验台前，面前有不同长度的绳子和不同重量的摆锤，他在笔记本上画出所有组合的矩阵表——系统性思维诞生

## 三、埃里克森心理社会发展八阶段详细编码

### ERIKSON-1 信任vs不信任（Trust vs Mistrust · 0-1岁）

| 维度 | 内容 |
|------|------|
| **核心冲突** | 基本信任感能否建立 |
| **关键任务** | 与主要照顾者建立安全依恋 |
| **发展美德** | **希望**（Hope） |
| **积极结果** | 信任世界是安全可预测的 |
| **消极结果** | 焦虑、不安全感、退缩 |
| **关键照料者行为** | 一致、及时、温暖地回应婴儿需求 |
| **画面编码** | 🎬 深夜婴儿哭泣，妈妈立刻抱起轻拍——婴儿在温暖的怀抱中安静下来，眼睛闭上前最后一刻看到妈妈的脸（信任的原型画面） |

### ERIKSON-2 自主vs羞怯怀疑（Autonomy vs Shame & Doubt · 1-3岁）

| 维度 | 内容 |
|------|------|
| **核心冲突** | 能否在控制与探索中获得自主感 |
| **关键任务** | 如厕训练、自我进食、行走探索 |
| **发展美德** | **意志**（Will） |
| **积极结果** | "我能自己做！" |
| **消极结果** | 怀疑自己能力、过度依赖 |
| **关键教养** | 允许探索+设定安全边界（过度保护→羞怯；过度放任→失控） |
| **画面编码** | 🎬 两岁孩子拿着勺子自己吃饭，满脸都是米饭（自主），旁边妈妈忍住没帮忙，微笑着看着；如果妈妈抢过勺子说"我来喂"——孩子低下头（羞怯的萌芽） |

### ERIKSON-3 主动vs内疚（Initiative vs Guilt · 3-6岁）

| 维度 | 内容 |
|------|------|
| **核心冲突** | 主动探索世界 vs 因越界而内疚 |
| **关键任务** | 制定计划、发起游戏、模仿成人角色 |
| **发展美德** | **目的**（Purpose） |
| **积极结果** | 敢于尝试新事物、有方向感 |
| **消极结果** | 退缩、过度内疚、不敢尝试 |
| **画面编码** | 🎬 孩子用积木搭了一座"城堡"然后推倒重建——"我要造一个更大的！"（主动）；另一个孩子搭到一半被大人批评"搭得不好"，默默放下积木（内疚） |

### ERIKSON-4 勤奋vs自卑（Industry vs Inferiority · 6-12岁）

| 维度 | 内容 |
|------|------|
| **核心冲突** | 能否通过努力获得能力感和成就感 |
| **关键任务** | 学业学习、技能习得、同伴比较 |
| **发展美德** | **能力**（Competence） |
| **积极结果** | "我能做到！我擅长这个！" |
| **消极结果** | "我什么都做不好"——自卑感 |
| **关键影响** | 教师反馈、同伴评价、学业成功体验 |
| **画面编码** | 🎬 孩子举着自己画的画冲向妈妈"看我画的！"（勤奋/自豪）；另一个孩子把考卷揉成一团塞进书包最底层（自卑） |

### ERIKSON-5 同一性vs角色混乱（Identity vs Role Confusion · 12-18岁）

| 维度 | 内容 |
|------|------|
| **核心冲突** | "我是谁？我要成为什么样的人？" |
| **关键任务** | 探索价值观、信仰、职业方向、性别认同 |
| **发展美德** | **忠诚**（Fidelity）——对自我选择的忠贞 |
| **积极结果** | 形成清晰稳定的自我认同 |
| **消极结果** | 角色混乱、价值观漂泊、随波逐流 |
| **玛西亚四种同一性状态** | ①同一性达成（探索+承诺）②同一性延缓（探索中未承诺）③同一性早闭（未探索直接承诺）④同一性扩散（无探索无承诺） |
| **画面编码** | 🎬 青少年的房间墙上贴满乐队海报、球星照片、大学招生简章——各种身份在墙上碰撞；桌上摊开的日记写着"我到底喜欢什么？"（同一性探索的战场） |

### ERIKSON-6 亲密vs孤独（Intimacy vs Isolation · 18-40岁）

| 维度 | 内容 |
|------|------|
| **核心冲突** | 能否建立深层亲密关系（爱情/友情） |
| **关键任务** | 承诺关系、共享自我、容忍脆弱 |
| **发展美德** | **爱**（Love） |
| **积极结果** | 深层联结、相互支持的关系 |
| **消极结果** | 孤立、浅层关系、情感隔离 |
| **前提条件** | 需要先有稳定的同一感才能真正"融合" |
| **画面编码** | 🎬 两个人在雨中合撑一把伞，肩膀靠在一起，不需要说话——亲密是"我可以做我自己"；对面的空荡荡的公寓里一个人对着电视吃饭（孤独） |

### ERIKSON-7 繁殖vs停滞（Generativity vs Stagnation · 40-65岁）

| 维度 | 内容 |
|------|------|
| **核心冲突** | 能否通过养育下一代/贡献社会获得繁殖感 |
| **关键任务** | 养育子女、指导年轻人、社会贡献 |
| **发展美德** | **关怀**（Care） |
| **积极结果** | "我留下了什么？"——传承感 |
| **消极结果** | 停滞、自我沉溺、"空虚感" |
| **繁殖的多种形式** | 生物繁殖（生育）、养育繁殖（教育）、技术繁殖（传承技艺）、文化繁殖（创作） |
| **画面编码** | 🎬 50岁的师傅手把手教徒弟操作精密仪器（繁殖/传承）；另一面是中年人盯着电脑屏幕日复一日，眼神空洞（停滞） |

### ERIKSON-8 自我整合vs绝望（Ego Integrity vs Despair · 65岁+）

| 维度 | 内容 |
|------|------|
| **核心冲突** | 回顾一生能否接受和肯定 |
| **关键任务** | 接受自己的人生、面对死亡、智慧传承 |
| **发展美德** | **智慧**（Wisdom） |
| **积极结果** | "我的一生是完整的、有意义的" |
| **消极结果** | "如果当初..."——悔恨、恐惧死亡 |
| **画面编码** | 🎬 80岁的老人坐在火炉旁，给孙辈讲年轻时的故事，眼睛里有光——"我活过了"（整合）；另一个老人反复念叨"我当年要是..."，眼含泪水（绝望） |

### 按年龄阶段对照（皮亚杰 × 埃里克森）

| 年龄 | 皮亚杰阶段 | 埃里克森阶段 | 综合画面编码 |
|------|------------|------------|------------|
| 0-1岁 | 感知运动（1-4亚阶段） | 信任vs不信任 | 🎬 婴儿在妈妈怀里吃奶（信任），手指抓着妈妈衣角（感知运动反射） |
| 1-2岁 | 感知运动（5-6亚阶段） | 自主vs羞怯 | 🎬 幼儿推开妈妈的手"自己走！"然后摔倒（自主+客体永久性在发展） |
| 2-4岁 | 前运算（符号功能期） | 主动vs内疚 | 🎬 孩子拿棍子当马骑，嘴里喊"驾！"（符号+主动想象） |
| 4-6岁 | 前运算（直觉思维期） | 主动vs内疚 | 🎬 孩子组织小伙伴玩"打仗"游戏（主动+直觉思维+自我中心） |
| 7-11岁 | 具体运算 | 勤奋vs自卑 | 🎬 学生用实物学分数，因为解出难题而骄傲（具体运算+勤奋感） |
| 11-18岁 | 形式运算 | 同一性vs混乱 | 🎬 青少年辩论"什么是公平"，开始思考未来职业（形式运算+同一性探索） |

## 六、记忆宫殿 · 总结性画面编码

### 🏠 发展心理学"生命之屋"

想象一栋十层的建筑，每层代表一个主要发展阶段：

| 楼层 | 阶段 | 画面 | 关键词 |

| 1F | 新生儿 | 婴儿被温柔的手接住，反射性地抓住手指 | 生存 |
| 2F | 婴儿期 | 玩具被布盖住，小手掀开布找到它 | 探索 |
| 3F | 幼儿期 | "不要！我自己来！"鞋子穿反了 | 自主 |
| 4F | 学龄前 | 孩子用香蕉当电话，对着月亮说"它跟我走" | 想象 |
