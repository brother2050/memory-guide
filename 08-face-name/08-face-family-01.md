# 亲友/社交圈记忆训练素材

## 一、核心方法：关系树+特征链

```
亲属关系树 → 面部特征 → 姓名 → 故事锚点
```

**记忆架构：**
- 以自己为根节点，向外扩展关系网络
- 每个人物用"辈分+特征+姓名"三重编码
- 用**家族故事**串联所有人

## 五、扩展社交圈的记忆策略

### 🌐 社交圈分层模型

```
            ┌─────────────────────┐
            │    核心圈（5人）     │ ← 家人、至亲
            │  特征：天天见       │
            ├─────────────────────┤
            │    亲密圈（15人）    │ ← 好友、近亲
            │  特征：每周联系     │
            ├─────────────────────┤
            │    社交圈（50人）    │ ← 同事、邻居、同学
            │  特征：每月联系     │
            ├─────────────────────┤
            │    认识圈（150人）   │ ← 点头之交、网友
            │  特征：偶尔联系     │
            └─────────────────────┘
```

### 各圈层记忆策略

| 圈层 | 人数 | 记忆策略 | 编码深度 |
|------|------|---------|---------|
| 核心圈 | 5人 | 每日回忆+细节编码 | 生日、喜好、习惯全记 |
| 亲密圈 | 15人 | 每周回忆+特征编码 | 关系+特征+姓名+故事 |
| 社交圈 | 50人 | 每月回忆+分类编码 | 关系+特征+姓名 |
| 认识圈 | 150人 | 遇到时快速回忆 | 特征+姓名（够用） |

### 扩展社交圈的快速编码法

**方法1：场景分类法**
- 把新认识的人放入已有场景（如：这个人在"同学会"场景中）
- 用场景触发回忆

**方法2：特征锚定法**
- 每个人只记1个最强特征
- 用特征反向推导姓名和关系

**方法3：故事串联法**
- 把新认识的人和已有记忆串联
- "这个人长得像我大伯"→借用大伯的记忆链

## 六、综合训练方案

### 训练1：家族树默写（15分钟）
1. 从自己出发，画出三代家族树
2. 每个节点写上：姓名+面部特征
3. 标记不确定的地方，下次见面重点观察

### 训练2：亲属称谓快速反应（5分钟）
1. 随机抽取亲属关系描述（如"父亲的哥哥的妻子"）
2. 3秒内说出称谓（大妈/伯母）
3. 联想对应人物的面部特征

### 训练3：社交场景模拟（10分钟）
1. 模拟一场婚礼/同学会/邻里聚会
2. 快速编码所有出场人物
3. 会后默写全部人员信息

### 训练4：新认识的人速编码（即时）
1. 认识新人时，3秒内完成编码
2. 记住：1个特征 + 姓名 + 关系
3. 当天晚上复习一次

### 训练5：亲属关系推理（高级）
1. 给出两个人的关系描述
2. 推理他们的称谓关系
3. 如："我妈妈的哥哥的女儿"→表姐

## 七、常见错误与纠正

| 常见错误 | 原因 | 纠正方法 |
|---------|------|---------|
| 搞混大伯和叔叔 | 都是父亲的兄弟 | 大伯=年纪大+威严（伯=大）；叔叔=年纪小+活泼（叔=小） |
| 分不清姑姑和姨妈 | 都是女性长辈 | 姑姑=爸爸的姐妹（同姓王）；姨妈=妈妈的姐妹（同姓李） |
| 搞混堂兄和表兄 | 都是同辈男性 | 堂兄=同姓王（爷爷的孙子）；表兄=不同姓（外公的孙子） |
| 搞混外公和爷爷 | 都是祖辈男性 | 爷爷=爸爸的爸爸（同姓王）；外公=妈妈的爸爸（不同姓） |
| 搞混侄子和外甥 | 都是晚辈 | 侄子=兄弟的孩子（同姓）；外甥=姐妹的孩子（不同姓） |
| 邻居搞混门牌号 | 长得像或同姓 | 绑定相遇场景：张大爷=遛狗，陈阿姨=菜市场 |
| 同学会上认错人 | 多年不见变化大 | 对比"当年照片"和"现在面貌"，锁定不变的特征 |
