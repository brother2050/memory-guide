# 职场人脉记忆训练素材

## 一、核心方法：层级定位法

```
公司 → 部门 → 职位 → 姓名 → 面部特征
```

**记忆架构：**
- 把公司想象成一栋大楼
- 每层楼是一个部门
- 每个工位对应一个职位和一张脸
- 用**空间定位**锚定**人脸-姓名-职位**

### 会议记忆三步法

**第一步：扫描（会前30秒）**
- 进入会议室，快速扫视所有面孔
- 对每张脸做"第一印象标签"（如：方脸、卷发、大胡子）

**第二步：定位（会中）**
- 结合座位顺序和发言顺序
- "坐①号位的方脸=CEO陈国栋"
- "发言最多的瓜子脸=产品经理林可欣"

**第三步：巩固（会后5分钟）**
- 默写座位图 + 姓名 + 特征
- 错误的地方重点复习

## 六、综合训练方案

### 训练1：部门巡楼（10分钟）
1. 在脑海中"走"一遍公司大楼
2. 每到一个部门，回忆所有人的特征和姓名
3. 卡住的地方标记，重点复习

### 训练2：会议速记（5分钟）
1. 模拟一场12人会议
2. 看座位图，2秒内说出每人的姓名+特征
3. 打乱顺序再试

### 训练3：名片速编码（每张30秒）
1. 准备10张模拟名片
2. 每张30秒完成编码
3. 10分钟后回忆所有名片信息

### 训练4：电梯偶遇（即时反应）
1. 模拟在电梯遇到某位同事
2. 3秒内说出：姓名 + 部门 + 职位
3. 练习"微笑+称呼"的社交反应

### 训练5：新人入职场景
1. 入职第一天见到15位新同事
2. 用层级定位法快速编码
3. 下班前默写全部名单+特征
