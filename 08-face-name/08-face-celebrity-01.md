# 名人面孔记忆训练素材

## 一、核心方法：特征编码三步法

```
观察面部特征 → 提取标志性符号 → 关联姓名与成就
```

**编码原则：**
- 每位名人提炼 **1-2个最具辨识度的面部特征**
- 用 **谐音、字形、联想** 编码姓名
- 将成就与特征做 **视觉化绑定**

## 五、综合训练方案

### 训练1：闪卡速认（每张2秒）
1. 准备40张名人照片
2. 每张看2秒，说出：特征 → 姓名 → 成就
3. 记录错误，反复练习易混淆的

### 训练2：时代分组
1. 将40位名人按时代分组
2. 每组内按特征相似度排序
3. 用火车记忆法串联

### 训练3：相似对辨别
1. 从6组易混淆对中随机抽取
2. 看照片，说出区分关键
3. 限时5秒完成

### 训练4：反向回忆
1. 给出成就描述（如"相对论"）
2. 说出：姓名 → 面部特征 → 时代
3. 正向+反向双向巩固
