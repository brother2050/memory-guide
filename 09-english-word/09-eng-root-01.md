# 词根词缀记忆（基础）— 50个最常用词根编码

> 词根是英语单词的"基因"，掌握词根就像掌握了造字的密码。
> 本文件为每个词根提供：含义→谐音→图像→关联单词，助你批量记忆。

---

## 一、动作类词根（15个）

### 1. port = 携带、搬运
- **谐音**：port → "跑特" → 跑着特别快地搬运
- **图像**：一个搬运工在港口（port）扛着大箱子跑
- **衍生词**：
  1. **transport** (trans- 跨过 + port) = 运输 → 跨过大海搬运
  2. **export** (ex- 出 + port) = 出口 → 从港口搬出去
  3. **import** (im- 进 + port) = 进口 → 搬进港口
  4. **portable** (port + able) = 便携的 → 能搬动的
  5. **report** (re- 回 + port) = 报告 → 把信息带回来

### 2. duct/duc = 引导、带领
- **谐音**：duct → "打个头" → 打头的人就是引导者
- **图像**：一个导游举着旗子，带领（duct）队伍前行
- **衍生词**：
  1. **conduct** (con- 一起 + duct) = 引导；行为 → 一起带领
  2. **produce** (pro- 向前 + duce) = 生产 → 向前引导出产品
  3. **reduce** (re- 回 + duce) = 减少 → 往回引导，缩减
  4. **educate** (e- 出 + duc + ate) = 教育 → 引导出知识
  5. **introduce** (intro- 进入 + duce) = 介绍 → 引导进入

### 3. vert/vers = 转、转向
- **谐音**：vert → "我特" → 我特爱转来转去
- **图像**：一个人在旋转门里转（vert）圈圈
- **衍生词**：
  1. **convert** (con- 一起 + vert) = 转变 → 转到一起
  2. **reverse** (re- 回 + verse) = 反转 → 往回转
  3. **diverse** (di- 分开 + verse) = 多样的 → 转向不同方向
  4. **universe** (uni- 一 + verse) = 宇宙 → 万物转为一体
  5. **introvert** (intro- 向内 + vert) = 内向的人 → 向内转

### 4. ject = 投、掷
- **谐音**：ject → "摘克特" → 摘下来扔出去特别远
- **图像**：一个棒球手投掷（ject）球的画面
- **衍生词**：
  1. **project** (pro- 向前 + ject) = 项目；投射 → 向前投
  2. **reject** (re- 回 + ject) = 拒绝 → 投回去
  3. **inject** (in- 进 + ject) = 注射 → 投进去
  4. **subject** (sub- 下 + ject) = 主题；使服从 → 投到下面
  5. **object** (ob- 对面 + ject) = 物体；反对 → 投到对面

### 5. spect/spec = 看
- **谐音**：spect → "斯拜克特" → 斯拜克特先生特别爱看
- **图像**：一个侦探用放大镜仔细看（spect）证据
- **衍生词**：
  1. **inspect** (in- 进 + spect) = 检查 → 往里看
  2. **respect** (re- 再 + spect) = 尊重 → 再看一眼
  3. **suspect** (sus- 下 + spect) = 怀疑 → 从下面偷看
  4. **spectacle** (spect + acle) = 景象；眼镜 → 看的东西
  5. **expect** (ex- 向外 + spect) = 期待 → 向外看

### 6. dict = 说、讲
- **谐音**：dict → "迪克特" → 迪克特爱说话
- **图像**：一个演讲者在台上说（dict）话
- **衍生词**：
  1. **dictate** (dict + ate) = 口述；命令 → 说给别人记
  2. **predict** (pre- 预先 + dict) = 预测 → 提前说
  3. **contradict** (contra- 反对 + dict) = 反驳 → 反着说
  4. **dictionary** (dict + ionary) = 词典 → 说话的工具书
  5. **verdict** (ver- 真实 + dict) = 判决 → 说出真相

### 7. scrib/script = 写
- **谐音**：scrib → "四哥来不" → 四哥来了也不写作业
- **图像**：一支鹅毛笔在羊皮纸上写（scrib）字
- **衍生词**：
  1. **describe** (de- 向下 + scribe) = 描述 → 写下来
  2. **prescribe** (pre- 预先 + scribe) = 开处方；规定 → 提前写好
  3. **subscribe** (sub- 下 + scribe) = 订阅 → 在下面签字
  4. **scripture** (script + ure) = 经文 → 被写下来的文字
  5. **manuscript** (manu- 手 + script) = 手稿 → 手写的

### 8. tract = 拉、拖
- **谐音**：tract → "踹个它" → 用脚踹着拖走
- **图像**：一辆拖拉机拉（tract）着货物前行
- **衍生词**：
  1. **attract** (at- 向 + tract) = 吸引 → 向自己拉
  2. **extract** (ex- 出 + tract) = 提取 → 拉出来
  3. **contract** (con- 一起 + tract) = 合同；收缩 → 拉到一起
  4. **distract** (dis- 分开 + tract) = 分散注意力 → 拉向不同方向
  5. **subtract** (sub- 下 + tract) = 减去 → 从下面拉走

### 9. ced/cess = 走、行进
- **谐音**：ced → "赛德" → 赛德带头走
- **图像**：一列队伍行进（ced）在大道上
- **衍生词**：
  1. **proceed** (pro- 向前 + ceed) = 继续 → 向前走
  2. **succeed** (suc- 跟随 + ceed) = 成功 → 跟着走上去
  3. **exceed** (ex- 超出 + ceed) = 超过 → 走出界限
  4. **access** (ac- 向 + cess) = 进入；通道 → 向…走去
  5. **recede** (re- 回 + cede) = 后退 → 往回走

### 10. mit/miss = 送、发
- **谐音**：mit → "秘特" → 秘密发送特快
- **图像**：一个信使在送（mit）信
- **衍生词**：
  1. **submit** (sub- 下 + mit) = 提交 → 送到下面
  2. **permit** (per- 通过 + mit) = 允许 → 让通过送出去
  3. **commit** (com- 一起 + mit) = 承诺；犯罪 → 一起送出
  4. **mission** (miss + ion) = 使命 → 被派出的任务
  5. **transmit** (trans- 跨 + mit) = 传输 → 跨越发送

### 11. pos/pon = 放置
- **谐音**：pos → "破四" → 破了四个放地上
- **图像**：一双手把物品轻轻放（pos）在桌上
- **衍生词**：
  1. **compose** (com- 一起 + pose) = 组成；作曲 → 放到一起
  2. **expose** (ex- 外 + pose) = 暴露 → 放到外面
  3. **oppose** (op- 对面 + pose) = 反对 → 放在对面
  4. **propose** (pro- 向前 + pose) = 提议 → 向前放出来
  5. **deposit** (de- 向下 + posit) = 存放 → 放下去

### 12. fac/fact/fect = 做、制造
- **谐音**：fact → "烦个特" → 做烦了特别累
- **图像**：一个工厂（factory）在制造（fact）产品
- **衍生词**：
  1. **factory** (fact + ory) = 工厂 → 做东西的地方
  2. **affect** (af- 向 + fect) = 影响 → 做到…上面
  3. **effect** (ef- 出 + fect) = 效果 → 做出来的结果
  4. **perfect** (per- 完全 + fect) = 完美的 → 完全做好的
  5. **defect** (de- 坏 + fect) = 缺陷 → 做坏了

### 13. duct/duc = 引导（补充衍生词，详见第2条）
- **谐音**：同上
- **衍生词**（补充）：
  1. **deduce** (de- 向下 + duce) = 推断 → 一步步引导出来
  2. **induce** (in- 进 + duce) = 引诱 → 引导进入
  3. **seduce** (se- 离开 + duce) = 勾引 → 引导偏离
  4. **aqueduct** (aque- 水 + duct) = 水渠 → 引导水的通道
  5. **deduct** (de- 向下 + duct) = 扣除 → 从总量中引走

### 14. pel/puls = 推、驱动
- **谐音**：pel → "派哦" → 派人去推动
- **图像**：一群人推（pel）着巨大的石头
- **衍生词**：
  1. **compel** (com- 一起 + pel) = 强迫 → 一起推
  2. **expel** (ex- 出 + pel) = 驱逐 → 推出去
  3. **propel** (pro- 向前 + pel) = 推进 → 向前推
  4. **repel** (re- 回 + pel) = 击退 → 推回去
  5. **impulse** (im- 进 + pulse) = 冲动 → 推进内心

### 15. rupt = 破、断裂
- **谐音**：rupt → "若破特" → 若是破了特严重
- **图像**：一面墙突然破裂（rupt），碎片四溅
- **衍生词**：
  1. **interrupt** (inter- 中间 + rupt) = 打断 → 从中间破开
  2. **corrupt** (cor- 一起 + rupt) = 腐败 → 一起破败
  3. **erupt** (e- 出 + rupt) = 爆发 → 破出来
  4. **abrupt** (ab- 离开 + rupt) = 突然的 → 突然断裂
  5. **bankrupt** (bank + rupt) = 破产 → 银行破了

## 二、状态类词根（10个）

### 16. sta/sist = 站立、稳定
- **谐音**：sta → "死打" → 死死站住打不倒
- **图像**：一尊雕像稳稳站立（sta）在广场上
- **衍生词**：
  1. **stable** (sta + ble) = 稳定的 → 能站住的
  2. **resist** (re- 反 + sist) = 抵抗 → 反着站
  3. **insist** (in- 上 + sist) = 坚持 → 站在上面不动
  4. **consist** (con- 一起 + sist) = 由…组成 → 站在一起
  5. **persist** (per- 一直 + sist) = 坚持 → 一直站着

### 17. ten/tin = 持有、保持
- **谐音**：ten → "疼" → 拿着烫手的东西好疼
- **图像**：双手紧紧握着（ten）一个珍贵的杯子
- **衍生词**：
  1. **contain** (con- 一起 + tain) = 包含 → 持有在一起
  2. **maintain** (main- 手 + tain) = 维持 → 用手保持
  3. **retain** (re- 回 + tain) = 保留 → 拿回来保持
  4. **sustain** (sus- 下 + tain) = 支撑 → 从下面保持
  5. **tenant** (ten + ant) = 租户 → 持有房子的人

### 18. pend/pens = 悬挂、称量
- **谐音**：pend → "盼的" → 盼着悬挂的果实掉下来
- **图像**：一盏灯从天花板上悬挂（pend）着
- **衍生词**：
  1. **depend** (de- 下 + pend) = 依赖 → 挂在下面
  2. **suspend** (sus- 下 + pend) = 暂停；悬挂 → 挂在下面
  3. **expense** (ex- 出 + pense) = 花费 → 称量后付出
  4. **pension** (pens + ion) = 养老金 → 按称量发的钱
  5. **pending** (pend + ing) = 待定的 → 悬而未决

### 19. cap/capt = 抓、拿
- **谐音**：cap → "开扑" → 开始扑过去抓住
- **图像**：一只手抓（cap）住飞来的球
- **衍生词**：
  1. **capture** (capt + ure) = 捕获 → 抓住
  2. **capable** (cap + able) = 有能力的 → 能抓住的
  3. **captive** (capt + ive) = 俘虏 → 被抓的人
  4. **accept** (ac- 向 + cept) = 接受 → 向…抓来
  5. **except** (ex- 出 + cept) = 除了 → 把…拿出去

### 20. voc/vok = 声音、叫喊
- **谐音**：voc → "我靠" → 惊讶时大喊
- **图像**：一个人张大嘴叫喊（voc）
- **衍生词**：
  1. **vocal** (voc + al) = 声音的 → 有声的
  2. **provoke** (pro- 向前 + voke) = 激怒 → 向前叫喊
  3. **evoke** (e- 出 + voke) = 唤起 → 叫出来
  4. **advocate** (ad- 向 + voc + ate) = 提倡 → 为…发声
  5. **vocabulary** (voc + abulary) = 词汇 → 声音的集合

### 21. mut = 变化
- **谐音**：mut → "木头" → 木头也会变化腐烂
- **图像**：一只毛毛虫在变化（mut）成蝴蝶
- **衍生词**：
  1. **mutate** (mut + ate) = 突变 → 发生变化
  2. **mutual** (mut + ual) = 相互的 → 互相变化的
  3. **commute** (com- 一起 + mute) = 通勤 → 来回变化位置
  4. **immutable** (im- 不 + mut + able) = 不变的 → 不能变化的
  5. **permutation** (per- 完全 + mut + ation) = 排列 → 完全变化

### 22. sol = 松开、溶解；太阳
- **谐音**：sol → "扫哦" → 松开扫一下
- **图像**：太阳（sol）下冰块在溶解（sol）
- **衍生词**：
  1. **solve** (sol + ve) = 解决 → 松开难题
  2. **dissolve** (dis- 分开 + solve) = 溶解 → 分开松散
  3. **resolve** (re- 再 + solve) = 决心；解决 → 再次松开
  4. **absolute** (ab- 离开 + solute) = 绝对的 → 完全溶解的
  5. **solar** (sol + ar) = 太阳的 → 与太阳有关的

### 23. grav = 重
- **谐音**：grav → "哥来扶" → 太重了哥来扶一把
- **图像**：一个人搬着特别重（grav）的石头
- **衍生词**：
  1. **gravity** (grav + ity) = 重力 → 重的力量
  2. **grave** (grav + e) = 严重的；坟墓 → 重大的事
  3. **aggravate** (ag- 向 + grav + ate) = 加重 → 使更重
  4. **gravitate** (grav + itate) = 受吸引 → 被重量拉过去
  5. **engrave** (en- 使 + grave) = 雕刻 → 用力刻下去

### 24. viv/vit = 生命、活
- **谐音**：viv → "微微" → 微微一笑表示活着真好
- **图像**：一颗种子发芽，展现生命（viv）力
- **衍生词**：
  1. **vivid** (viv + id) = 生动的 → 充满生命的
  2. **survive** (sur- 超过 + vive) = 存活 → 超越死亡活着
  3. **revive** (re- 再 + vive) = 复活 → 再次活过来
  4. **vital** (vit + al) = 至关重要的 → 生命攸关的
  5. **vitamin** (vit + amin) = 维生素 → 维持生命的胺

### 25. val/vail = 价值、强壮
- **谐音**：val → "哇哦" → 哇哦，好有价值
- **图像**：一箱金子闪耀着价值（val）的光芒
- **衍生词**：
  1. **value** (val + ue) = 价值 → 值多少
  2. **evaluate** (e- 出 + val + uate) = 评估 → 估出价值
  3. **valid** (val + id) = 有效的 → 有价值的
  4. **prevail** (pre- 前 + vail) = 盛行 → 价值在前面
  5. **available** (a- 向 + vail + able) = 可用的 → 可获取价值的

## 三、数量类词根（8个）

### 26. uni = 一
- **谐音**：uni → "有你" → 有你一个就够了
- **图像**：一支独秀，只有一（uni）朵花
- **衍生词**：
  1. **uniform** (uni + form) = 制服；统一的 → 一个形式
  2. **unique** (uni + que) = 独特的 → 唯一的
  3. **unite** (uni + te) = 联合 → 合为一体
  4. **universe** (uni + verse) = 宇宙 → 万物归一
  5. **unicorn** (uni + corn) = 独角兽 → 一只角

### 27. bi = 二
- **谐音**：bi → "必" → 必须有两个
- **图像**：一副眼镜，两个（bi）镜片
- **衍生词**：
  1. **bicycle** (bi + cycle) = 自行车 → 两个轮子
  2. **bilingual** (bi + lingual) = 双语的 → 两种语言
  3. **bilateral** (bi + lateral) = 双边的 → 两边的
  4. **bipolar** (bi + polar) = 双极的 → 两个极点
  5. **annual** → 注意：biannual = 一年两次的

### 28. tri = 三
- **谐音**：tri → "踹" → 连踹三脚
- **图像**：一个三角形，三（tri）条边
- **衍生词**：
  1. **triangle** (tri + angle) = 三角形 → 三个角
  2. **triple** (tri + ple) = 三倍的 → 三重
  3. **trilogy** (tri + logy) = 三部曲 → 三部作品
  4. **trivial** (tri + vial) = 琐碎的 → 三条路交汇处（小事）
  5. **trident** (tri + dent) = 三叉戟 → 三个齿

### 29. cent = 百
- **谐音**：cent → "省特" → 省下特多的百分之一
- **图像**：一枚一分钱硬币，百分之一（cent）
- ⚠️ **中国学生常犯错误**：cent = 百（不是"分"），century = 一百年，percent = 每一百
- **衍生词**：
  1. **century** (cent + ury) = 世纪 → 一百年
  2. **percent** (per + cent) = 百分比 → 每一百
  3. **centimeter** (cent + meter) = 厘米 → 百分之一米
  4. **centipede** (cent + pede) = 蜈蚣 → 百条腿
  5. **centennial** (cent + ennial) = 百年纪念 → 百年一次

### 30. mill = 千
- **谐音**：mill → "米勒" → 米勒磨坊产千斤粮
- **图像**：一个磨坊（mill）里有千（mill）斤粮食
- ⚠️ **易混辨析**：mill（千分之一）vs kilo（千）：millimeter（毫米）vs kilometer（千米）
- **衍生词**：
  1. **million** (mill + ion) = 百万 → 千个千
  2. **millennium** (mill + ennium) = 千年 → 一千年
  3. **millimeter** (mill + meter) = 毫米 → 千分之一米
  4. **millionaire** (million + aire) = 百万富翁 → 拥有百万的人
  5. **millipede** (mill + pede) = 千足虫 → 千条腿

### 31. multi = 多
- **谐音**：multi → "莫踢" → 莫踢多个球
- **图像**：一个多面体，很多（multi）个面
- **衍生词**：
  1. **multiply** (multi + ply) = 乘；增加 → 多重折叠
  2. **multimedia** (multi + media) = 多媒体 → 多种媒体
  3. **multitude** (multi + tude) = 大量 → 多的状态
  4. **multinational** (multi + national) = 跨国的 → 多国的
  5. **multiple** (multi + ple) = 多重的 → 多个的

### 32. semi = 半
- **谐音**：semi → "赛米" → 跑了半米
- **图像**：一个月亮，半（semi）圆的
- **衍生词**：
  1. **semicircle** (semi + circle) = 半圆 → 半个圆
  2. **semiconductor** (semi + conductor) = 半导体 → 一半导电
  3. **semifinal** (semi + final) = 半决赛 → 一半到决赛
  4. **semicolony** (semi + colony) = 半殖民地 → 半个殖民地
  5. **semiconscious** (semi + conscious) = 半意识的 → 一半清醒

### 33. poly = 多
- **谐音**：poly → "婆力" → 婆婆力气大多面手
- **图像**：一个多边形（poly），很多条边
- **衍生词**：
  1. **polygon** (poly + gon) = 多边形 → 多个角
  2. **polyglot** (poly + glot) = 通晓多语言的人 → 多种语言
  3. **polymer** (poly + mer) = 聚合物 → 多个单元
  4. **polyphony** (poly + phony) = 复调 → 多种声音
  5. **polychrome** (poly + chrome) = 多色的 → 多种颜色

## 四、关系/方向类词根（10个）

### 34. graph/gram = 写、画
- **谐音**：graph → "哥来画" → 哥来画画
- **图像**：一个人在画（graph）图表
- **衍生词**：

## 七、记忆技巧总结

### 1. 词根联想法
把词根的谐音编成一个画面，比如：
- **port（搬运）**→ 想象一个搬运工在港口（port）跑着搬箱子
- **spect（看）**→ 想象侦探用放大镜看（spect）证据

### 2. 词根组合法
前缀 + 词根 + 后缀 = 单词
- **trans-port-ation** = 跨过-搬运-名词后缀 = 运输

### 3. 同根词家族记忆
记住一个词根，一串单词一起记：
- **port** → transport, export, import, portable, report, support, passport

### 4. 对比记忆
- **pro-**（向前） vs **re-**（向后）：proceed vs recede
- **ex-**（出） vs **im-**（进）：export vs import

### 5. 分类卡片法
把词根写在卡片正面，含义和衍生词写在背面，每天复习一组。

## 九、中国学生常犯错误与易混词辨析

### 易混词根辨析

| 词根A | 词根B | 区别 | 易混词对 |
|-------|-------|------|----------|
| **spect**（看） | **spec/speci**（种类） | 看 vs 种类 | respect（尊敬）vs species（物种）|
| **pos**（放置） | **pon**（放置） | 同源异形 | expose（暴露）vs opponent（对手）|
| **mit**（送） | **miss**（送） | 同源异形 | commit（承诺）vs mission（使命）|
| **ced**（走） | **ceed**（走） | 同源异形 | precede（先于）vs proceed（继续）|
| **cap**（抓） | **cap**（头） | 不同词根！ | capture（捕获）vs capital（首都）|
| **cur**（关心） | **cur**（跑） | 不同词根！ | cure（治愈）vs occur（发生）|
| **sol**（溶解） | **sol**（太阳） | 不同词根！ | solve（解决）vs solar（太阳的）|
| **val**（价值） | **vail**（强壮） | 同源 | value（价值）vs prevail（盛行）|

### 中国学生常见错误

| 错误 | 正确 | 说明 |
|------|------|------|
| 把 **bi**（二）理解为"生命" | bio = 生命，bi = 二 | bicycle = 两个轮子，biology = 生命学科 |
| 把 **cent**（百）理解为"分" | cent = 百，penny = 分 | century = 一百年，percent = 每一百 |
| 把 **dict**（说）理解为"听" | dict = 说，aud = 听 | dictate = 口述，audio = 音频 |
| 把 **graph**（写）理解为"照片" | graph = 写/画，photo = 光 | photograph = 用光画 = 照片 |
| 混淆 **-able** 和 **-ible** | -able 加在完整动词后，-ible 加在拉丁词根后 | readable vs visible |
| 混淆 **affect** 和 **effect** | affect = v.影响，effect = n.效果 | A for Action, E for End result |
| 混淆 **principal** 和 **principle** | principal = 校长/主要的，principle = 原则 | A = A person, E = Ethical rule |
