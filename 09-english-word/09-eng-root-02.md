## 一、中高级词根（50个）

### 第一组：学术高频词根（1-15）

#### 1. cern/cris = 分辨、判断
- **谐音**：cern → "生" → 生来就有分辨力
- **图像**：法官在仔细分辨（cern）证据
- **衍生词**：
  1. **discern** (dis- 分开 + cern) = 辨别 → 分开判断
  2. **concern** (con- 一起 + cern) = 关心；涉及 → 一起判断
  3. **crisis** (cris + is) = 危机 → 需要判断的时刻
  4. **criterion** (crit + erion) = 标准 → 判断的依据
  5. **critical** (crit + ical) = 批判的；关键的 → 需要判断的

#### 2. nom/nym = 名字、法则
- **谐音**：nom → "诺姆" → 诺姆是名字
- **图像**：一个名牌上写着名字（nom）
- **衍生词**：
  1. **nominal** (nom + inal) = 名义上的 → 只有名字的
  2. **anonymous** (a- 无 + nonym + ous) = 匿名的 → 没有名字的
  3. **synonym** (syn + onym) = 同义词 → 相同名字
  4. **antonym** (ant + onym) = 反义词 → 相反名字
  5. **autonomy** (auto + nomy) = 自治 → 自己的法则

#### 3. mise/mit = 发送、放出
- **谐音**：mise → "卖丝" → 卖丝的要发货
- **图像**：一个快递员在发送（mit）包裹
- **衍生词**：
  1. **premise** (pre + mise) = 前提 → 提前放出的
  2. **compromise** (com + promise) = 妥协 → 共同承诺
  3. **demise** (de + mise) = 死亡 → 放下生命
  4. **surmise** (sur + mise) = 推测 → 从上面放出想法
  5. **promise** (pro + mise) = 承诺 → 向前放出的话

#### 4. liter = 文字、字母
- **谐音**：liter → "李特" → 李特爱识字
- **图像**：一本打开的书，文字（liter）密密麻麻
- **衍生词**：
  1. **literal** (liter + al) = 字面的 → 与文字有关的
  2. **literature** (liter + ature) = 文学 → 文字的艺术
  3. **literacy** (liter + acy) = 识字 → 认识文字
  4. **illiterate** (il + liter + ate) = 文盲 → 不识字的
  5. **literalism** (liter + alism) = 字面主义

#### 5. jur/jus = 法律、正义
- **谐音**：jur → "居" → 居住在法律之下
- **图像**：天平象征法律（jur）的公正
- **衍生词**：
  1. **jury** (jur + y) = 陪审团 → 依据法律判断的人
  2. **justice** (jus + tice) = 正义 → 法律的公正
  3. **justify** (jus + tify) = 证明…正当 → 用法律说明
  4. **jurisdiction** (juris + diction) = 管辖权 → 法律的说话权
  5. **injustice** (in + justice) = 不公正 → 没有正义

#### 6. log = 说话、理性
- **谐音**：log → "老哥" → 老哥爱讲道理（进阶用法）
- **图像**：逻辑链条，环环相扣
- **衍生词**：
  1. **analogy** (ana + logy) = 类比 → 平行地说
  2. **apology** (apo + logy) = 道歉 → 远离（错误）的话
  3. **prologue** (pro + logue) = 序言 → 在前面说
  4. **epilogue** (epi + logue) = 尾声 → 在后面说
  5. **eulogy** (eu + logy) = 颂词 → 说好话

#### 7. cap/cab = 头、首领
- **谐音**：cap → "凯普" → 凯普是首领
- **图像**：一个船长（captain）站在船头
- **衍生词**：
  1. **captain** (cap + tain) = 船长；队长 → 头领
  2. **capital** (cap + ital) = 首都；资本 → 头等的
  3. **cabbage** (cab + bage) = 卷心菜 → 头状的
  4. **capstone** (cap + stone) = 顶石 → 头上的石头
  5. **decapitate** (de + cap + itate) = 斩首 → 去掉头

#### 8. cred = 相信
- **谐音**：cred → "可来的" → 可以来的，可信的

#### 9. cur = 关心、跑

#### 10. plic/plex = 折叠

  4. **implicit** (im + plic + it) = 含蓄的 → 折在里面

#### 11. dict = 说（进阶衍生）
- **衍生词**：
  1. **benediction** (bene + dict + ion) = 祝福 → 说好话
  2. **malediction** (mal + dict + ion) = 诅咒 → 说坏话
  3. **indicate** (in + dic + ate) = 指示 → 向内说
  4. **dedicate** (de + dic + ate) = 奉献 → 宣告下去

  3. **seduce** (se + duce) = 勾引 → 引导偏离
  4. **conduit** (con + duit) = 管道 → 一起引导的通道
  5. **viaduct** (via + duct) = 高架桥 → 引导道路的

#### 13. gest = 带来、运送
- **谐音**：gest → "结实的" → 结实的搬运工
- **图像**：一个搬运工在运送（gest）货物
- **衍生词**：
  1. **suggest** (sug + gest) = 建议 → 从下面带上来

  3. **ingest** (in + gest) = 摄入 → 运送进去
  4. **congestion** (con + gest + ion) = 拥堵 → 运到一起
  5. **register** (re + gist + er) = 登记 → 再次带来

#### 14. reg = 统治、规则
- **谐音**：reg → "瑞哥" → 瑞哥是统治者
- **图像**：国王手持权杖统治（reg）国家
- **衍生词**：
  1. **region** (reg + ion) = 地区 → 统治的范围

  3. **regular** (reg + ular) = 规则的 → 有规律的

#### 15. struct = 建造

## 四、词根组合记忆策略

### 策略1：三段拆解法
任何英语单词都可以拆为：**前缀 + 词根 + 后缀**

```
un + forget + able = unforgettable（难忘的）
不 + 忘记 + 能…的 = 不能被忘记的

trans + port + ation = transportation（运输）
跨过 + 搬运 + 名词 = 运输

in + vis + ible = invisible（看不见的）
不 + 看 + 能…的 = 不能被看到的
```

### 策略2：词根家族树
以词根为核心，像家族树一样展开：

```
         port（搬运）
        /    |     \
  transport  export  import
      |        |       |
  运输的     出口的   进口的
```

### 策略3：前缀变换练习
同一个词根加上不同前缀，意义完全不同：

```
词根：spect（看）
- in + spect = inspect（检查）→ 往里看
- re + spect = respect（尊重）→ 再看一眼
- sus + spect = suspect（怀疑）→ 从下面偷看
- ex + pect = expect（期待）→ 向外看
- pro + spect = prospect（前景）→ 向前看
```

### 策略4：后缀变换练习
同一个词根加上不同后缀，词性变化：

```
词根：act（做）
- act + or = actor（演员）→ 做事的人
- act + ion = action（行动）→ 做的过程
- act + ive = active（活跃的）→ 爱做的
- re + act = react（反应）→ 回应做
- inter + act = interact（互动）→ 在中间做
```

## 五、多词根单词拆解实例

### 实例1：**Communication**（交流）
```
com-（一起） + mun-（公共） + -ic-（连接） + -ation（名词）
→ 一起在公共场合传递信息 = 交流
```

### 实例2：**Unconstitutional**（违宪的）
```
un-（不） + con-（一起） + stitut（站立） + -ion（名词） + -al（形容词）
→ 不按照一起站立的规则 = 不符合宪法的
```

### 实例3：**Internationalization**（国际化）
```
inter-（之间） + nation（国家） + -al（形容词） + -ize（使…化） + -ation（名词）
→ 使国家之间 = 国际化
```

### 实例4：**Misinterpretation**（误解）
```
mis-（错误） + inter-（之间） + pret（价格/价值） + -ation（名词）
→ 在之间错误地估价 = 误解
```

### 实例5：**Biodegradable**（可生物降解的）
```
bio-（生命/生物） + de-（向下/去除） + grad（步/级） + -able（能…的）
→ 能被生物一步步降解的
```

### 实例6：**Psychopharmacology**（精神药理学）
```
psycho-（心理/精神） + pharma-（药） + -co-（连接） + -logy（学科）
→ 研究精神药物的学科
```

### 实例7：**Electroencephalograph**（脑电图仪）
```
electro-（电） + encephalo-（脑） + -graph（写/记录）
→ 记录脑部电信号的仪器
```

### 实例8：**Counterrevolutionary**（反革命的）
```
counter-（反对） + re-（回） + volut（转） + -ion（名词） + -ary（形容词）
→ 反对回到原来转动的 = 反革命的
```

## 六、进阶记忆技巧

### 1. 词根拼图法
把单词看作拼图，每一块是一个词根/前后缀：
```
dis + cour + age + ment = discouragement（沮丧）
分开 + 跑 + 状态 + 名词 = 跑散的状态
```

### 2. 同根对比法
同一词根的不同组合一起记：
```
词根：duct（引导）
- conduct（引导行为）
- produce（向前引导→生产）
- reduce（往回引导→减少）
- educate（引导出→教育）
- introduce（引导进入→介绍）
```

### 3. 前缀方向图
```
向前 ← pro-    re- → 向后/再
向上 ← super-  sub- → 向下
进入 ← in-     ex- → 出去
一起 ← com-    dis- → 分开
```

### 4. 后缀词性速查
```
名词后缀：-tion, -ment, -ness, -ity, -er, -ist
形容词后缀：-able, -ful, -less, -ous, -ive
动词后缀：-ize, -ify, -ate
```
