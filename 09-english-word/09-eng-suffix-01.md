# 后缀/词性记忆 — 30个常用后缀编码

> 后缀是英语单词的"标签"，决定了单词的词性（名词、动词、形容词、副词等）。
> 掌握后缀，就能快速判断词性、批量扩展词汇。
> 本文件为每个后缀提供：含义→谐音→图像→代表词→词性规律→对比记忆。

---

## 一、名词后缀（12个）

### 1. -tion / -sion（行为、状态、结果）
- **含义**：表示动作的过程或结果，最常见名词后缀
- **谐音**：-tion → "神" → 做事做到出神入化
- **图像**：一个工厂生产线上产出一排排名词产品
- **代表词**：
  1. **education** (educate + ion) = 教育 → 教育的行为
  2. **decision** (decide + sion) = 决定 → 决定的结果
  3. **creation** (create + ion) = 创造 → 创造的产物
  4. **expression** (express + ion) = 表达 → 表达的方式
- **词性规律**：动词 + -tion/-sion → 名词
  - express(v.) → expression(n.)
  - decide(v.) → decision(n.)
  - invite(v.) → invitation(n.)

### 2. -ment（行为、结果、手段）
- **含义**：表示行为、结果或手段
- **谐音**：-ment → "门特" → 打开一扇特别的门
- **图像**：一扇大门上写着"-ment"，推开后里面全是名词
- **代表词**：
  1. **development** (develop + ment) = 发展 → 发展的过程
  2. **achievement** (achieve + ment) = 成就 → 达成的结果
  3. **agreement** (agree + ment) = 协议 → 同意的产物
  4. **movement** (move + ment) = 运动 → 移动的行为
  5. **equipment** (equip + ment) = 设备 → 装备的手段
- **词性规律**：动词 + -ment → 名词
  - judge(v.) → judgment(n.)
  - manage(v.) → management(n.)
  - entertain(v.) → entertainment(n.)

### 3. -ness（性质、状态）
- **含义**：表示性质、状态、特征
- **谐音**：-ness → "你死" → 状态到了极点
- **图像**：一面镜子映出一个人的"状态"，镜框上写着"-ness"
- **代表词**：
  1. **happiness** (happy + ness) = 幸福 → 幸福的状态
  2. **darkness** (dark + ness) = 黑暗 → 黑暗的状态
  3. **weakness** (weak + ness) = 弱点 → 虚弱的性质
  4. **kindness** (kind + ness) = 善良 → 善良的品质
  5. **awareness** (aware + ness) = 意识 → 觉察的状态
- **词性规律**：形容词 + -ness → 名词
  - sad → sadness
  - lonely → loneliness
  - careless → carelessness

### 4. -ity / -ty（性质、状态）
- **含义**：表示性质、状态（多与拉丁词根搭配）
- **谐音**：-ity → "一体" → 性质融为一体
- **图像**：一块水晶里封存着一种"性质"
- **代表词**：
  1. **ability** (able + ity) = 能力 → 能够的性质
  2. **reality** (real + ity) = 现实 → 真实的状态
  3. **diversity** (diverse + ity) = 多样性 → 多样的性质
  4. **equality** (equal + ity) = 平等 → 平等的状态
  5. **security** (secure + ity) = 安全 → 安全的状态
- **词性规律**：形容词 + -ity → 名词
  - active → activity
  - possible → possibility
  - creative → creativity

### 5. -er / -or（做某事的人或物）
- **含义**：表示执行动作的人或工具
- **谐音**：-er → "儿" → 做事的人
- **图像**：一个工人戴的帽子上写着"-er"
- **代表词**：
  1. **teacher** (teach + er) = 教师 → 教书的人
  2. **actor** (act + or) = 演员 → 表演的人
  3. **computer** (compute + er) = 计算机 → 计算的机器
  4. **director** (direct + or) = 导演 → 指导的人
  5. **writer** (write + er) = 作家 → 写作的人
- **词性规律**：动词 + -er/-or → 名词（人/物）
  - work → worker
  - visit → visitor
  - drive → driver
- **对比记忆**：-er（英语本族词）vs -or（拉丁词根）
  - teach**er** vs act**or**
  - driv**er** vs direct**or**
  - 规律：词根本身是拉丁语的用-or，日耳曼语的用-er

### 6. -ist（从事某事的人、信仰者）
- **含义**：表示从事某种活动的人或持有某种信仰的人
- **谐音**：-ist → "意思特" → 特有意思的人
- **图像**：一个专家胸前戴着"-ist"的徽章
- **代表词**：
  1. **scientist** (science + ist) = 科学家 → 从事科学的人
  2. **artist** (art + ist) = 艺术家 → 从事艺术的人
  3. **tourist** (tour + ist) = 游客 → 旅行的人
  4. **pianist** (piano + ist) = 钢琴家 → 弹钢琴的人
  5. **optimist** (optim + ist) = 乐观主义者 → 持乐观态度的人
- **词性规律**：名词/词根 + -ist → 名词（人）
  - chemistry → chemist
  - physics → physicist
  - novel → novelist

### 7. -ment（结果、产物）— 已在第2条详述

### 8. -ance / -ence（性质、状态、行为）
- **含义**：表示性质、状态或行为
- **谐音**：-ance → "安思" → 安静地思考状态
- **图像**：一个天平两端分别放着"-ance"和"-ence"
- **代表词**：
  1. **importance** (important + ance) = 重要性 → 重要的性质
  2. **confidence** (confident + ence) = 自信 → 自信的状态
  3. **experience** (experi + ence) = 经验 → 经历的结果
  4. **patience** (patient + ence) = 耐心 → 忍耐的状态
  5. **absence** (absent + ce) = 缺席 → 不在的状态
- **词性规律**：形容词/动词 + -ance/-ence → 名词
  - differ → difference
  - appear → appearance
  - resist → resistance
- **对比记忆**：-ance vs -ence
  - 无绝对规律，但 -ant 结尾的形容词通常加 -ance
  - -ent 结尾的形容词通常加 -ence
  - import**ant** → import**ance** | differ**ent** → differ**ence**

### 9. -dom（领域、状态、集体）
- **含义**：表示领域、状态或集体
- **谐音**：-dom → "都么" → 什么都是的领域

  2. **kingdom** (king + dom) = 王国 → 国王的领域

- **词性规律**：形容词/名词 + -dom → 名词
  - free → freedom
  - king → kingdom
  - martyr → martyrdom

### 10. -ship（关系、身份、技能）
- **含义**：表示关系、身份、状态或技能
- **谐音**：-ship → "谁怕" → 身份够硬谁都不怕
- **图像**：一艘船（ship）上挂着代表身份的旗帜
- **代表词**：
  1. **friendship** (friend + ship) = 友谊 → 朋友的关系
  2. **leadership** (leader + ship) = 领导力 → 领导的能力
  3. **membership** (member + ship) = 会员资格 → 成员的身份
  4. **relationship** (relation + ship) = 关系 → 关联的关系
  5. **hardship** (hard + ship) = 艰难 → 艰难的状态
- **词性规律**：名词 + -ship → 名词
  - partner → partnership
  - citizen → citizenship
  - scholar → scholarship

### 11. -al（行为、过程）
- **含义**：表示行为或过程（名词后缀）
- **谐音**：-al → "哦" → 哦，原来这是一个行为
- **图像**：一本相册（album）记录着各种行为
- **代表词**：
  1. **arrival** (arrive + al) = 到达 → 到达的行为
  2. **survival** (survive + al) = 生存 → 生存的过程
  3. **approval** (approve + al) = 批准 → 批准的行为

  5. **removal** (remove + al) = 移除 → 移除的行为
- **词性规律**：动词 + -al → 名词
  - arrive → arrival
  - propose → proposal
  - deny → denial

### 12. -ure（行为、结果、状态）
- **含义**：表示行为、结果或状态
- **谐音**：-ure → "有啊" → 有结果了
- **图像**：一个实验室里，试管冒出的烟雾形成"-ure"

  4. **creature** (create + ure) = 生物 → 被创造出的东西
  5. **structure** (struct + ure) = 结构 → 建造的结果
- **词性规律**：动词/词根 + -ure → 名词
  - depart → departure
  - expose → exposure
  - mix → mixture

## 二、形容词后缀（10个）

### 13. -able / -ible（能够…的）
- **含义**：表示能够…的、有…倾向的
- **谐音**：-able → "阿波" → 阿波什么都能做
- **图像**：一个超人胸口写着"-able"，表示无所不能
- **代表词**：
  1. **comfortable** (comfort + able) = 舒适的 → 能带来安慰的
  2. **possible** (poss + ible) = 可能的 → 能做到的
  3. **available** (avail + able) = 可用的 → 能利用的
  4. **responsible** (respons + ible) = 负责的 → 能回应的
  5. **valuable** (value + able) = 有价值的 → 有价值的
- **词性规律**：名词/动词 + -able/-ible → 形容词
  - accept → acceptable
  - desire → desirable
  - access → accessible
- **对比记忆**：-able vs -ible
  - -able：通常加在英语本族词或完整的动词后（readable, enjoyable）
  - -ible：通常加在拉丁词根后（visible, possible, flexible）

### 14. -ful（充满…的）
- **含义**：表示充满某种性质的
- **谐音**：-ful → "福" → 充满福气的
- **图像**：一个杯子里满溢出来，上面写着"-ful"
- **代表词**：
  1. **beautiful** (beauty + ful) = 美丽的 → 充满美的
  2. **powerful** (power + ful) = 强大的 → 充满力量的
  3. **grateful** (grate + ful) = 感激的 → 充满感恩的
  4. **hopeful** (hope + ful) = 有希望的 → 充满希望的
  5. **successful** (success + ful) = 成功的 → 充满成功的
- **词性规律**：名词 + -ful → 形容词
  - care → careful
  - pain → painful
  - wonder → wonderful
- **对比记忆**：-ful vs -less（反义对）
  - **hopeful**（有希望的）vs **hopeless**（无望的）
  - **careful**（仔细的）vs **careless**（粗心的）
  - **useful**（有用的）vs **useless**（无用的）

### 15. -less（没有…的）
- **含义**：表示缺乏某种性质的（-ful的反义）
- **谐音**：-less → "累死" → 累死了什么都没有
- **图像**：一个空空如也的仓库，门上写着"-less"
- **代表词**：
  1. **homeless** (home + less) = 无家可归的 → 没有家的
  2. **careless** (care + less) = 粗心的 → 不用心的
  3. **useless** (use + less) = 无用的 → 没有用的
  4. **endless** (end + less) = 无尽的 → 没有尽头的
  5. **fearless** (fear + less) = 无畏的 → 没有恐惧的
- **词性规律**：名词 + -less → 形容词
  - help → helpless
  - meaning → meaningless
  - breath → breathless

### 16. -ous / -ious / -eous（具有…性质的）
- **含义**：表示具有某种性质的
- **谐音**：-ous → "饿死" → 饿死了还是有某种特质
- **图像**：一个人身上披着"-ous"的披风，散发着某种气质
- **代表词**：
  1. **dangerous** (danger + ous) = 危险的 → 有危险的
  2. **famous** (fame + ous) = 著名的 → 有名声的
  3. **serious** (seri + ous) = 严肃的 → 认真的
  4. **curious** (curi + ous) = 好奇的 → 有好奇心的
  5. **courageous** (courage + ous) = 勇敢的 → 有勇气的
- **词性规律**：名词 + -ous → 形容词
  - danger → dangerous
  - poison → poisonous
  - mystery → mysterious

### 17. -ive（有…倾向的、有…性质的）
- **含义**：表示有某种倾向或性质
- **谐音**：-ive → "一五" → 一五一十地表现出来
- **图像**：一个弹簧，表示有某种"倾向"要弹出去
- **代表词**：
  1. **creative** (create + ive) = 创造性的 → 有创造力的
  2. **active** (act + ive) = 积极的 → 有行动力的
  3. **attractive** (attract + ive) = 吸引人的 → 有吸引力的
  4. **effective** (effect + ive) = 有效的 → 有成效的
  5. **expensive** (expense + ive) = 昂贵的 → 有高花费的
- **词性规律**：动词 + -ive → 形容词
  - act → active
  - create → creative
  - attract → attractive

### 18. -al（与…有关的）
- **含义**：表示与某事物有关的（形容词后缀）
- **谐音**：-al → "哦" → 哦，跟这个有关
- **图像**：一条链子连接着单词和它的属性
- **代表词**：
  1. **natural** (nature + al) = 自然的 → 与自然有关的
  2. **personal** (person + al) = 个人的 → 与个人有关的
  3. **national** (nation + al) = 国家的 → 与国家有关的
  4. **traditional** (tradition + al) = 传统的 → 与传统有关的
  5. **environmental** (environment + al) = 环境的 → 与环境有关的
- **词性规律**：名词 + -al → 形容词
  - culture → cultural
  - industry → industrial
  - education → educational

### 19. -ic（与…有关的、像…的）
- **含义**：表示与某事物有关的或像某事物的
- **谐音**：-ic → "一颗" → 一颗有特征的宝石
- **图像**：一块宝石闪耀着"-ic"的光芒
- **代表词**：
  1. **scientific** (science + ific) = 科学的 → 与科学有关的
  2. **historic** (history + ic) = 历史性的 → 与历史有关的
  3. **romantic** (romance + ic) = 浪漫的 → 有浪漫色彩的
  4. **energetic** (energy + etic) = 精力充沛的 → 有能量的
  5. **realistic** (real + istic) = 现实的 → 像现实的
- **词性规律**：名词 + -ic → 形容词
  - hero → heroic
  - drama → dramatic
  - sympathy → sympathetic

### 20. -y（有…的、像…的）
- **含义**：表示具有某种特征的
- **谐音**：-y → "意" → 有意思的
- **图像**：一个毛茸茸的小动物，身上覆盖着"-y"的毛
- **代表词**：
  1. **rainy** (rain + y) = 多雨的 → 有雨的
  2. **sleepy** (sleep + y) = 困倦的 → 想睡的
  3. **noisy** (noise + y) = 吵闹的 → 有噪音的
  4. **healthy** (health + y) = 健康的 → 有健康的
  5. **wealthy** (wealth + y) = 富有的 → 有财富的
- **词性规律**：名词 + -y → 形容词
  - rain → rainy
  - cloud → cloudy
  - dirt → dirty
  - frost → frosty

### 21. -ary / -ory（与…有关的）
- **含义**：表示与某事物有关的
- **谐音**：-ary → "啊瑞" → 啊，瑞雪兆丰年
- **图像**：一个图书馆的标签上写着"-ary"
- **代表词**：
  1. **ordinary** (ordin + ary) = 普通的 → 与秩序有关的
  2. **necessary** (necess + ary) = 必要的 → 与需要有关的
  3. **imaginary** (imagin + ary) = 想象的 → 与想象有关的
  4. **contradictory** (contradict + ory) = 矛盾的 → 与反驳有关的
  5. **satisfactory** (satisfact + ory) = 令人满意的 → 与满足有关的
- **词性规律**：名词/词根 + -ary/-ory → 形容词
  - custom → customary
  - contradict → contradictory

### 22. -ed / -ing（分词形容词）
- **含义**：-ed 表示"感到…的"（被动/感受），-ing 表示"令人…的"（主动/引起）
- **谐音**：-ed → "已的" → 已经感受到的；-ing → "引起" → 引起某种感觉的
- **图像**：-ed 是一个被吓到的人，-ing 是一个吓人的鬼
- **代表词**：
  1. **bored** (感到无聊的) vs **boring** (令人无聊的)
  2. **interested** (感兴趣的) vs **interesting** (有趣的)
  3. **excited** (兴奋的) vs **exciting** (令人兴奋的)
  4. **surprised** (惊讶的) vs **surprising** (令人惊讶的)
  5. **confused** (困惑的) vs **confusing** (令人困惑的)
- **对比记忆**：
  - "I am **bored**"（我感到无聊）→ 我是被动无聊的
  - "The movie is **boring**"（这部电影令人无聊）→ 电影主动让人无聊
  - 口诀：**-ed 感受到，-ing 引起的**

## 三、副词后缀（2个）

### 23. -ly（以…方式）
- **含义**：表示以某种方式（最常见副词后缀）
- **谐音**：-ly → "力" → 用力地做
- **图像**：一双跑鞋上写着"-ly"，代表"方式"
- **代表词**：
  1. **quickly** (quick + ly) = 快速地 → 以快速的方式
  2. **carefully** (careful + ly) = 仔细地 → 以仔细的方式
  3. **happily** (happy + ly) = 快乐地 → 以快乐的方式
  4. **suddenly** (sudden + ly) = 突然地 → 以突然的方式
  5. **probably** (probable + ly) = 可能地 → 以可能的方式
- **词性规律**：形容词 + -ly → 副词
  - slow → slowly
  - beautiful → beautifully
  - easy → easily

### 24. -ward / -wards（朝…方向）
- **含义**：表示朝某个方向
- **谐音**：-ward → "我的" → 我的方向
- **图像**：一个指南针指向"-ward"的方向
- **代表词**：
  1. **forward** (for + ward) = 向前 → 朝前的方向
  2. **backward** (back + ward) = 向后 → 朝后的方向
  3. **upward** (up + ward) = 向上 → 朝上的方向
  4. **outward** (out + ward) = 向外 → 朝外的方向
  5. **homeward** (home + ward) = 向家 → 朝家的方向
- **词性规律**：方向词/名词 + -ward → 副词/形容词
  - in → inward
  - north → northward
  - south → southward

## 四、动词后缀（4个）

### 25. -ize / -ise（使…化）
- **含义**：表示使…化、使成为
- **谐音**：-ize → "爱死" → 爱死这种变化了
- **图像**：一个魔法师挥动魔杖，把东西"-ize"化
- **代表词**：
  1. **realize** (real + ize) = 实现；意识到 → 使成为现实
  2. **organize** (organ + ize) = 组织 → 使有组织
  3. **modernize** (modern + ize) = 现代化 → 使变现代
  4. **analyze** (ana + lyze) = 分析 → 使分解
  5. **recognize** (re + cogn + ize) = 认出 → 使再次认知
- **词性规律**：形容词/名词 + -ize → 动词
  - normal → normalize
  - special → specialize
  - memory → memorize

### 26. -ify / -fy（使…化、使成为）
- **含义**：表示使…化、使成为
- **谐音**：-ify → "一飞" → 一飞冲天般地变化
- **图像**：一个灰姑娘变公主的画面，旁边写着"-ify"
- **代表词**：
  1. **simplify** (simple + ify) = 简化 → 使变简单
  2. **clarify** (clear + ify) = 澄清 → 使变清楚
  3. **beautify** (beauty + ify) = 美化 → 使变美
  4. **identify** (ident + ify) = 识别 → 使确认身份
  5. **satisfy** (satis + fy) = 满足 → 使充分
- **词性规律**：名词/形容词 + -ify → 动词
  - pure → purify
  - intense → intensify
  - glory → glorify

### 27. -en（使变得…）
- **含义**：表示使变得某种状态
- **谐音**：-en → "恩" → 施恩使之变化
- **图像**：一个小人被施了魔法，变大/变小了
- **代表词**：
  1. **widen** (wide + en) = 加宽 → 使变宽
  2. **strengthen** (strength + en) = 加强 → 使变强
  3. **darken** (dark + en) = 使变暗 → 使变黑
  4. **brighten** (bright + en) = 使变亮 → 使变亮
  5. **soften** (soft + en) = 使变软 → 使变软
- **词性规律**：形容词 + -en → 动词
  - short → shorten
  - loose → loosen
  - sharp → sharpen

### 28. -ate（使…、做…）
- **含义**：表示使…或做某事
- **谐音**：-ate → "吃" → 吃了就做了
- **图像**：一个人吃下药丸后开始行动
- **代表词**：
  1. **create** (cre + ate) = 创造 → 做出新东西
  2. **celebrate** (celebr + ate) = 庆祝 → 做庆祝的事
  3. **communicate** (communic + ate) = 交流 → 做交流的事
  4. **separate** (separ + ate) = 分离 → 使分开
  5. **motivate** (motiv + ate) = 激励 → 使有动力
- **词性规律**：词根 + -ate → 动词
  - active → activate
  - valid → validate
  - origin → originate

## 五、同根不同后缀对比记忆（2组专题）

### 对比组1：act 家族 — 一个词根，五种词性

| 后缀 | 单词 | 词性 | 含义 |
|------|------|------|------|
| — | **act** | v./n. | 行动；行为 |
| -ive | **active** | adj. | 积极的 |
| -ivity | **activity** | n. | 活动 |
| -or | **actor** | n. | 演员 |
| -ion | **action** | n. | 行动 |
| -ually | **actually** | adv. | 实际上 |

**记忆口诀**：
> act 是行动，active 积极忙
> activity 活动场，actor 演员上
> action 行动强，actually 实际上

### 对比组2：beauty 家族

| 后缀 | 单词 | 词性 | 含义 |
|------|------|------|------|
| — | **beauty** | n. | 美丽 |
| -ful | **beautiful** | adj. | 美丽的 |
| -fully | **beautifully** | adv. | 美丽地 |
| -ify | **beautify** | v. | 美化 |
| -ician | **beautician** | n. | 美容师 |

**记忆口诀**：
> beauty 美丽是名词
> beautiful 加 ful 变美丽（形容词）
> beautifully 加 ly 美丽地（副词）
> beautify 去 y 加 ify 美化（动词）
> beautician 美容师（名词/人）

### 对比组3：success 家族
