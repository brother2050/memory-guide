## 六、主题记忆的通用策略

### 策略1：定位法（Method of Loci）
把每个主题的词汇放在一个真实场景的不同位置：
```
医学 → 医院的20个位置
法律 → 法院的20个位置
科技 → 科技公司的20个位置
商业 → 公司总部的20个位置
学术 → 大学的20个位置
```

### 策略2：词根归类法
同一词根在不同主题中反复出现：
```
dict（说）→ verdict（法律）, predict（学术）
port（搬运）→ import（商业）, transport（科技）
scrib（写）→ prescription（医学）, manuscript（学术）
```

### 策略3：故事串联法
把一个主题的词汇编成一个完整故事：
```
医学故事：一个病人走进医院（diagnosis），出现症状（symptom），
医生诊断为慢性病（chronic），开了处方（prescription），
经过治疗（therapy）后出院（discharge）。
```

### 策略4：同义词/反义词网
建立词汇之间的关系网：
```
治疗相关：therapy ↔ treatment ↔ remedy ↔ cure
         （治疗）  （处理）    （补救）   （治愈）
诊断相关：diagnosis ↔ identification ↔ detection
         （诊断）    （识别）          （检测）
```

### 策略5：跨主题联想
同一个词根在不同主题中的含义：
```
path（感情/疾病）
医学：pathology（病理学）
学术：pathos（感染力）
科技：path（路径）→ 文件路径
```

> 💡 **核心建议**：主题记忆的关键是"场景化"。把词汇放进真实的场景中，用定位法串联起来，比单独记忆效率高3-5倍。建议每个主题花一周时间，配合词根拆解和同义词/反义词关联。

## 记忆方法对比

| 方法 | 优点 | 缺点 | 适合人群 | 推荐指数 |
|------|------|------|----------|----------|
| 场景定位法 | 每个主题一个真实场景 | 场景需要熟悉 | 所有学习者 | ⭐⭐⭐⭐⭐ |
| 词根归类法 | 跨主题同词根关联 | 需要掌握词根 | 有词根基础的学习者 | ⭐⭐⭐⭐⭐ |
| 同义词/反义词网 | 词汇间关系网络化记忆 | 网络太大会混乱 | 进阶学习者 | ⭐⭐⭐⭐ |

| 跨主题联想法 | 同词根在不同主题中对比 | 需要多主题同时学习 | 高级学习者 | ⭐⭐⭐ |
