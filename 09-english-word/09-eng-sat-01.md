## 一、GRE/SAT高频词50个（按字母分组）

### A组（8个）

#### 1. **Aberrant**（异常的）
- **词根**：ab-（离开）+ err（走）+ -ant → 走偏的
- **谐音**：阿伯让特 → 阿伯让特立独行，行为异常
- **挂钩**：A-1 → 想象一个字母A走路走歪了
- **画面**：一个字母A走出正常路线，歪歪扭扭

#### 2. **Acrimony**（尖刻、激烈）
- **词根**：acr-（尖锐）+ -imony → 尖锐的状态
- **谐音**：阿克瑞莫你 → 阿克瑞莫你说话这么尖刻
- **挂钩**：A-2 → 想象两把尖刀交叉
- **画面**：一个人嘴里吐出尖刀般的话语

#### 3. **Amalgamate**（合并）
- **词根**：am-（一起）+ algam（混合）+ -ate → 混合在一起
- **谐音**：阿莫噶美特 → 阿莫把噶美特合并了
- **挂钩**：A-3 → 想象两团泥巴被揉在一起
- **画面**：两团不同颜色的泥巴被手揉成一团

#### 4. **Anomalous**（反常的）
- **词根**：a-（无）+ nomal（规则）+ -ous → 没有规则的
- **谐音**：阿诺莫乐死 → 阿诺莫乐死了，太反常了
- **挂钩**：A-4 → 想象一个骰子扔出了7点（反常）
- **画面**：一个六面骰子显示7点，所有人惊讶

#### 5. **Apathy**（冷漠）
- **词根**：a-（无）+ pathy（感情）→ 没有感情
- **谐音**：阿帕西 → 阿帕西对什么都不在乎
- **挂钩**：A-5 → 想象一块冰，没有温度
- **画面**：一个人面无表情地看着灾难发生

#### 6. **Arduous**（艰巨的）
- **词根**：ard-（艰难）+ -uous → 艰难的状态
- **谐音**：阿丢额死 → 阿丢额死都觉得艰巨
- **挂钩**：A-6 → 想象一座陡峭的山
- **画面**：一个人艰难地攀登一座几乎垂直的山

#### 7. **Articulate**（善于表达的）
- **词根**：artic-（关节）+ -ulate → 像关节一样清晰连接
- **谐音**：阿提Q来特 → 阿提Q来特别善于表达
- **挂钩**：A-7 → 想象一个人演讲时手势清晰
- **画面**：一个演讲者口齿清晰，手势优雅

#### 8. **Audacious**（大胆的）
- **词根**：aud-（大胆）+ -acious → 大胆的状态
- **谐音**：奥迪额舍斯 → 奥迪额舍斯开得太大胆了
- **挂钩**：A-8 → 想象一个人跳伞
- **画面**：一个人从飞机上大胆地跳下去

### C组（8个）

#### 9. **Capricious**（善变的）
- **词根**：capr-（山羊）+ -icious → 像山羊一样跳来跳去
- **谐音**：可普瑞舍斯 → 可普瑞舍斯今天这样明天那样
- **挂钩**：C-1 → 想象一只山羊跳来跳去
- **画面**：一只山羊在草地上不停跳来跳去

#### 10. **Castigate**（严厉批评）

- **谐音**：卡死特给特 → 卡死特给特严厉的批评
- **挂钩**：C-2 → 想象一个老师严厉批评学生
- **画面**：一个老师用戒尺敲桌子，学生低头认错

#### 11. **Cogent**（有说服力的）

- **画面**：一个律师指着证据，陪审团频频点头

#### 12. **Conundrum**（难题）

- **画面**：一个人对着魔方苦思冥想

#### 13. **Corroborate**（证实）

- **谐音**：可若波瑞特 → 可若波瑞特来证实就好了
- **挂钩**：C-5 → 想象两个证人互相证实
- **画面**：两个证人在法庭上互相证实对方的说法

#### 14. **Cursory**（粗略的）

- **挂钩**：C-6 → 想象一个人快速翻书
- **画面**：一个人快速翻书，每页只看一眼

#### 15. **Cynical**（愤世嫉俗的）

## 二、词根归类记忆

### 词根：loqu/locut = 说
```
loquacious（话多的）→ loqu + acious
eloquent（雄辩的）→ e + loqu + ent
grandiloquent（夸大的）→ grand + iloqu + ent
soliloquy（独白）→ sol + iloqu + y
```

### 词根：path = 感情
```
apathy（冷漠）→ a + pathy
empathy（共情）→ em + pathy
antipathy（反感）→ anti + pathy
sympathy（同情）→ sym + pathy
```

### 词根：magn = 大
```
magnanimous（宽宏大量的）→ magn + anim + ous
magnify（放大）→ magn + ify
magnitude（大小）→ magn + itude
magnificent（壮丽的）→ magn + ific + ent
```

### 词根：err = 走/犯错
```
aberrant（异常的）→ ab + err + ant
error（错误）→ err + or
erratic（不稳定的）→ err + atic
erroneous（错误的）→ err + oneous
```

### 词根：sequ/secut = 跟随
```
obsequious（谄媚的）→ ob + sequ + ious
consecutive（连续的）→ con + secut + ive
subsequent（随后的）→ sub + sequ + ent
consequence（后果）→ con + sequ + ence
```

### 词根：voc/vok = 声音
```
equivocal（模棱两可的）→ equi + voc + al
vociferous（喧哗的）→ voc + ifer + ous
provocative（挑衅的）→ pro + voc + ative
advocate（提倡）→ ad + voc + ate
```

## 六、高频词的考试应用技巧

### 1. 词根推测法
遇到生词时，用词根推测含义：
```
不认识的词：MISANTHROPE
拆解：mis-（恨）+ anthrope（人）→ 恨人的人 → 厌世者
```

### 2. 上下文验证法
用上下文验证词根推测：
```
"The misanthrope avoided all social gatherings."
→ 厌世者避免所有社交聚会 → 推测正确
```

### 3. 排除法
用词根排除明显错误的选项：
```
选项A：philanthrope（爱人的人）→ phil-（爱）
选项B：misanthrope（恨人的人）→ mis-（恨）
选项C：anthropoid（类人的）→ anthrop-（人）
选项D：anthology（选集）→ anth-（花）
→ 根据上下文选B
```

### 4. 同义词替换法
用已知词替换生词：
```
原文：The acrimonious debate lasted for hours.
替换：The bitter/sharp debate lasted for hours.
→ 理解为"尖刻的辩论"
```
