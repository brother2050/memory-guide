## 📥 导入方法（以 Anki 2.1.5x / 24.x+ 为例）

1. 打开 Anki，点击「文件」→「导入」，选择目标 `.tsv` 文件
2. **笔记类型**：选「基本」（Basic）；**牌组**：选择或新建目标牌组
3. **分隔符**：勾选「Tab」（制表符）——本目录文件不含 `#separator` 指令头，需手动指定
4. **字段映射**：第 1 列 →「正面」(Front)、第 2 列 →「背面」(Back)、第 3 列 →「标签」(Tags)
   - 首行为字段名 `Question / Answer / Tags`，Anki 会自动识别并跳过；若导入器未识别，在字段映射处勾选「第一行是字段名」
5. **取消勾选「允许 HTML in fields」**——卡片含代码符号（如 `(?P<y>…)`、`<=`），禁用 HTML 后可原样显示；全部卡片均为纯文本，不依赖 HTML 格式
6. 点击「导入」，提示导入成功即完成

> 提示：60 个文件可逐个导入到同一牌组（卡片互不重复），也可按主题分别建牌组。重复导入同一文件会产生重复卡片，更新时请先删除旧牌组再导入。

## 📊 格式说明

每个 TSV 文件格式：
```text
Question\tAnswer\tTags
```

- **Question**：问题（正面）
- **Answer**：答案（背面）
- **Tags**：标签（用于分类和筛选，空格分隔——与 Anki 导入约定一致，原逗号分隔已统一）
- 编码约定：UTF-8（无 BOM）、LF 换行、每文件恰好 1 行表头、无空单元格、无重复行

## 💡 使用建议

1. **先导入核心文件**：00-99编码表 + 01-记忆科学基础 + 02-核心记忆技巧
2. **按需导入专项**：根据你的学习目标选择对应学科文件
3. **配合间隔重复**：每天复习15-20分钟，利用Anki的FSRS算法自动安排复习
4. **自定义卡片**：导入后可根据个人需要编辑和补充卡片
