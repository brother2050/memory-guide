## 📥 导入方法

1. 打开 Anki
2. 点击「文件」→「导入」
3. 选择 `.tsv` 文件
4. 设置：
   - 分隔符：**制表符**
   - 第一行：**字段名**（Question, Answer, Tags）
   - 笔记类型：**基本**
   - 牌组：选择目标牌组
5. 点击「导入」

## 📊 格式说明

每个 TSV 文件格式：
```
Question\tAnswer\tTags
```

- **Question**：问题（正面）
- **Answer**：答案（背面）
- **Tags**：标签（用于分类和筛选）

## 💡 使用建议

1. **先导入核心文件**：00-99编码表 + 01-记忆科学基础 + 02-核心记忆技巧
2. **按需导入专项**：根据你的学习目标选择对应学科文件
3. **配合间隔重复**：每天复习15-20分钟，利用Anki的FSRS算法自动安排复习
4. **自定义卡片**：导入后可根据个人需要编辑和补充卡片
