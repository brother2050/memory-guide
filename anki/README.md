## 📥 导入方法

1. 打开 Anki
2. 点击「文件」→「导入」
3. 选择 `.tsv` 文件
4. 设置：
   - 分隔符：**制表符**
   - 第一行：**字段名**（Question, Answer, Tags）
   - 笔记类型：**基本**
   - 牌组：选择目标牌组
5. 点击「导入」

## 📊 格式说明

每个 TSV 文件格式：
```
Question\tAnswer\tTags
```

- **Question**：问题（正面）
- **Answer**：答案（背面）
- **Tags**：标签（用于分类和筛选）

## 🔄 更新
