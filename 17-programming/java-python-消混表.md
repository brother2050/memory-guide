## 一、高频混点 TOP 20（按串写频率排序）

### 1.1 控制流与循环

| # | 功能 | Python | Java | 差异口诀 / 画面 |
|---|------|--------|------|----------------|
| 1 | 遍历 0..9 | `for i in range(10):` | `for (int i = 0; i < 10; i++)` | 蛇**钻进**区间（in range），咖啡**三段式**体检（init; cond; step） |
| 2 | 遍历元素 | `for x in items:` | `for (Item x : items)` | Python 直接"in 进去"；Java 冒号读作"中的每个" |
| 3 | 分支关键字 | `elif` | `else if` | 蛇缩写吞掉了"s if" |
| 4 | 代码块边界 | 缩进 | `{}` 大括号 | 蛇靠**对齐**认家门，咖啡用**大括号**锁门 |
| 5 | 语句结尾 | 无分号 | `;` 分号 | 咖啡每句话都要"落印"（;）才算数 |

### 1.2 函数与类型

| # | 功能 | Python | Java | 差异口诀 / 画面 |
|---|------|--------|------|----------------|
| 6 | 定义函数 | `def f(a, b):` | `int f(int a, int b) {}` | Python 递**斧**头（def）就开工；Java 先**登记**返回类型才放行 |
| 7 | 无返回 | 不写 return / `None` | `void` | Java 有"空房间"（void）；Python 什么都不返回就是 None |
| 8 | 空值 | `None` | `null` | 一个是"无物"（None），一个是"空引用"（null）——Python 的 None 是对象，Java 的 null 不是 |
| 9 | 布尔字面量 | `True / False` | `true / false` | 蛇抬头挺胸（大写 T），咖啡低调（小写） |
| 10 | 默认参数 | `def f(a=1)` 支持 | 不支持（用重载） | 蛇给参数**备好默认行李**；Java 用重载**多开几个门** |
| 11 | Lambda | `lambda x: x+1` | `(x) -> x+1` | 蛇用**冒号**分隔参数和身体；咖啡用**箭头**射出去 |

### 1.3 字符串与容器

| # | 功能 | Python | Java | 差异口诀 / 画面 |
|---|------|--------|------|----------------|
| 12 | 字符串格式化 | `f"{x}"` | `String.format("%s", x)` | 蛇把变量**含在嘴里**（f-string）；咖啡按**占位符**填表（%s） |
| 13 | 字符串比较 | `==` 比内容 | `.equals()` 比内容（`==` 比引用！） | **Java 头号陷阱**：`==` 在 Java 是"是不是同一个对象"——口诀"Java 比内容要问 equals" |
| 14 | 长度 | `len(arr)` | `arr.length`（数组）/ `arr.size()`（集合） | 蛇用**全局量尺** len()；咖啡物件**自带**尺子 |
| 15 | 列表追加 | `lst.append(x)` | `list.add(x)` | 蛇**append**（贴上去），咖啡**add**（加进来） |
| 16 | 列表排序 | `sorted(lst)` 返回新列表；`lst.sort()` 原地返回 None | `list.sort()` 原地；`Collections.sort(list)` | **Python 陷阱**：`sort()` 返回 None！要新列表用 `sorted()` |
| 17 | 切片/子列表 | `lst[1:3]` | `list.subList(1, 3)` | 蛇直接**在身上划刀**（方括号冒号）；咖啡请**服务员**取（subList） |

### 1.4 异常与工程

| # | 功能 | Python | Java | 差异口诀 / 画面 |
|---|------|--------|------|----------------|
| 18 | 捕获/抛出 | `try/except`、`raise` | `try/catch`、`throw` | 蛇**except**（除…之外都接住）；咖啡**catch**（伸手接住），抛的时候蛇 raise（举起），咖啡 throw（扔出） |

## 二、判别练习（做卡前先自测）

**看代码说语言 + 说出哪行"串"了（如果串了）：**

1. `for (item in items) { print(item) }` —— 混在哪？
   - 答案：这是"缝合怪"。Python 是 `for item in items:`（无括号无大括号）；Java 是 `for (Item item : items)`（冒号不是 in）。差别句："Python 的 for 直接 in，Java 的 for 用冒号表示'中的每个'。"
2. `if x = None:` —— 混在哪？
   - 答案：两个都错。Python 里 `=` 是赋值，比 None 用 `is None`；Java 里和 `null` 比用 `==`（比较用 `equals` 的是对象内容）。差别句："Python 查空用 `is None`，Java 查空用 `== null`。"
3. `list.add(x)` 写在 Python 里 —— 会怎样？
   - 答案：`AttributeError`，Python 列表是 `append()`。差别句："蛇 append，咖啡 add。"
