## 🎯 中央擂台：30个高频面试题编码

### 题目01：两数之和 (Two Sum)
- **题意**：数组中找两个数使其和等于目标值
- **最优解**：哈希表，一次遍历
- **思路**：遍历数组，用哈希表存 `target - nums[i]`，遇到匹配的就返回
- **时间**：O(n) | **空间**：O(n)
- **🖼️ 画面**：你在超市🛒找两样东西加起来刚好花完100元。每看一样东西，就在脑中记住"还差多少"
- **代码骨架**：
```python
def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        comp = target - n
        if comp in seen:
            return [seen[comp], i]
        seen[n] = i
```

### 题目02：三数之和 (3Sum)
- **题意**：找所有和为0的三元组（不重复）
- **最优解**：排序 + 双指针
- **思路**：固定一个数，对剩余部分用双指针找两数之和
- **时间**：O(n²) | **空间**：O(1)
- **🖼️ 画面**：三人拔河比赛🤼 — 固定一个人，另外两人从两端往中间靠

### 题目03：盛最多水的容器 (Container With Most Water)
- **题意**：找两条线使围成的水面积最大
- **最优解**：双指针，从两端向中间移动较短的那条
- **时间**：O(n) | **空间**：O(1)
- **🖼️ 画面**：两块木板🪵夹水 — 短板决定水位，移动短板可能找到更高的

### 题目04：无重复字符的最长子串 (Longest Substring Without Repeating)
- **题意**：找不含重复字符的最长子串
- **最优解**：滑动窗口 + 哈希表
- **思路**：右指针扩展窗口，遇到重复字符时左指针收缩
- **时间**：O(n) | **空间**：O(min(m,n))
- **🖼️ 画面**：**蛇吃豆子**🐍 — 蛇身不能有重复颜色的豆子，遇到重复的就从尾巴吐掉

### 题目05：最长回文子串 (Longest Palindromic Substring)
- **题意**：找字符串中的最长回文
- **最优解**：中心扩展法（从每个字符向两边扩展）
- **时间**：O(n²) | **空间**：O(1)
- **🖼️ 画面**：**蝴蝶翅膀**🦋 — 从身体中心向两边展开，左右对称就是回文

### 题目06：字符串转整数 (atoi)
- **题意**：实现字符串到整数的转换
- **关键点**：处理空格、正负号、溢出、非法字符
- **🖼️ 画面**：**翻译官**🗣️ — 一字一字翻译，遇到不认识的就停

### 题目07：反转链表 (Reverse Linked List)
- **题意**：反转一个单链表
- **最优解**：三指针迭代法（prev, curr, next）
- **时间**：O(n) | **空间**：O(1)
- **🖼️ 画面**：**贪吃蛇掉头**🐍 — 蛇头变蛇尾，蛇尾变蛇头，每个节点的next指针反向
- **代码骨架**：
```python
def reverse_list(head):
    prev, curr = None, head
    while curr:
        nxt = curr.next
        curr.next = prev
        prev = curr
        curr = nxt
    return prev
```

### 题目08：合并两个有序链表 (Merge Two Sorted Lists)
- **题意**：将两个有序链表合并为一个
- **最优解**：双指针，逐一比较挂到新链表
- **时间**：O(m+n) | **空间**：O(1)
- **🖼️ 画面**：**拉链合并**🤐 — 两条有序拉链合为一条

### 题目09：环形链表 (Linked List Cycle)
- **题意**：判断链表是否有环
- **最优解**：快慢指针（Floyd龟兔赛跑）
- **时间**：O(n) | **空间**：O(1)
- **🖼️ 画面**：**操场跑步**🏃 — 快的同学迟早会追上慢的同学（套圈=有环）

### 题目10：合并K个升序链表 (Merge K Sorted Lists)
- **题意**：合并K个有序链表
- **最优解**：最小堆（优先队列）
- **时间**：O(NlogK) | **空间**：O(K)
- **🖼️ 画面**：**K条传送带**🏭汇入一条 — 每条带上取最小的那个，用堆维护

### 题目11：有效的括号 (Valid Parentheses)
- **题意**：判断括号字符串是否有效（`()`、`[]`、`{}`正确配对）
- **最优解**：栈
- **思路**：遇到左括号入栈，遇到右括号检查栈顶是否匹配
- **时间**：O(n) | **空间**：O(n)
- **🖼️ 画面**：**俄罗斯套娃**🪆 — 打开一个左括号，必须从里到外依次合上对应的右括号

### 题目12：最小栈 (Min Stack)
- **题意**：支持O(1)获取最小值的栈
- **最优解**：辅助栈同步记录最小值
- **🖼️ 画面**：**双层托盘**🍽️ — 正常栈放食物，辅助栈同步放当前最便宜的菜

### 题目13：柱状图中最大矩形 (Largest Rectangle in Histogram)
- **题意**：找柱状图中能围成的最大矩形面积
- **最优解**：单调栈
- **时间**：O(n) | **空间**：O(n)
- **🖼️ 画面**：**积木墙**🧱 — 找连续积木能围成的最大矩形，用栈记录递增高度

### 题目14：二叉树中序遍历 (Inorder Traversal)
- **题意**：左→根→右遍历二叉树
- **最优解**：递归或迭代（用栈模拟）
- **时间**：O(n) | **空间**：O(h)
- **🖼️ 画面**：**读书📖** — 先读左页（左子树），再读标题（根），再读右页（右子树）

### 题目15：二叉树的层序遍历 (Level Order Traversal)
- **题意**：逐层从左到右遍历
- **最优解**：BFS（队列）
- **时间**：O(n) | **空间**：O(n)
- **🖼️ 画面**：**拍集体照📸** — 第一排先拍，第二排再拍，逐层进行

### 题目16：二叉树的最大深度 (Max Depth)
- **题意**：求二叉树的最大深度
- **最优解**：递归 `max(depth(left), depth(right)) + 1`
- **时间**：O(n) | **空间**：O(h)
- **🖼️ 画面**：**测水深**🌊 — 左右两条支流，取更深的那条 +1

### 题目17：验证二叉搜索树 (Validate BST)
- **题意**：判断是否是合法的BST
- **最优解**：递归传递上下界
- **🖼️ 画面**：**考试监考**👨‍🏫 — 每个节点的值必须在(下界, 上界)范围内

### 题目18：二叉树的最近公共祖先 (LCA)
- **题意**：找两个节点的最近公共祖先
- **最优解**：递归（后序遍历思想）
- **🖼️ 画面**：**家谱树**👨‍👩‍👧 — 找两个人的最近共同祖先

### 题目19：翻转二叉树 (Invert Binary Tree)
- **题意**：镜像翻转二叉树
- **最优解**：递归交换左右子树
- **🖼️ 画面**：**照镜子**🪞 — 左右对称翻转

### 题目20：搜索旋转排序数组 (Search in Rotated Sorted Array)
- **题意**：在旋转后的有序数组中搜索目标值
- **最优解**：改进的二分搜索
- **时间**：O(logn) | **空间**：O(1)
- **🖼️ 画面**：**旋转寿司🍣** — 盘子转了一下，但还是有序的，用二分法找

### 题目21：寻找旋转排序数组中的最小值 (Find Min in Rotated Sorted Array)
- **题意**：找旋转排序数组的最小值
- **最优解**：二分搜索，比较mid和right
- **🖼️ 画面**：**断点寻找**🔍 — 找到数组"断开"的地方就是最小值

### 题目22：爬楼梯 (Climbing Stairs)
- **题意**：每次爬1或2级，求到第n级有多少种方式
- **最优解**：DP（本质是斐波那契数列）
- **状态转移**：`dp[i] = dp[i-1] + dp[i-2]`
- **时间**：O(n) | **空间**：O(1) 滚动变量
- **🖼️ 画面**：**上楼梯**🪜 — 到第10级，要么从第9级来（+1），要么从第8级来（+2）

### 题目23：零钱兑换 (Coin Change)
- **题意**：用最少的硬币凑出目标金额
- **最优解**：完全背包DP
- **状态转移**：`dp[i] = min(dp[i], dp[i - coin] + 1)`
- **🖼️ 画面**：**自动售货机**🪙 — 怎么用最少的硬币凑出金额？每种硬币试试

### 题目24：最长递增子序列 (LIS)
- **题意**：找数组中最长的严格递增子序列长度
- **最优解**：贪心+二分 → O(nlogn)
- **🖼️ 画面**：**叠罗汉🤸** — 每人只能站在比自己轻的人上面

### 题目25：最大子数组和 (Maximum Subarray)
- **题意**：找连续子数组的最大和
- **最优解**：Kadane算法（DP）
- **状态转移**：`dp[i] = max(nums[i], dp[i-1] + nums[i])`
- **时间**：O(n) | **空间**：O(1)
- **🖼️ 画面**：**股票📈** — 找连续几天收益最高的区间。当前和为负就重新开始

### 题目26：买卖股票的最佳时机 (Best Time to Buy and Sell Stock)
- **题意**：一次交易求最大利润
- **最优解**：一次遍历，维护历史最低价
- **时间**：O(n) | **空间**：O(1)
- **🖼️ 画面**：**炒股**📊 — 记住历史最低价买入，之后每一天算利润

### 题目27：LRU缓存 (LRU Cache)
- **题意**：实现最近最少使用缓存（O(1)的get和put）
- **最优解**：哈希表 + 双向链表
- **🖼️ 画面**：**书架📚** — 新书放最左边，翻过的书移到最左边，满了就从最右边扔掉
- **核心结构**：HashMap存key→Node，双向链表维护访问顺序

### 题目28：岛屿数量 (Number of Islands)
- **题意**：统计二维网格中'1'组成的岛屿数量
- **最优解**：DFS/BFS，遇到'1'就感染整个岛屿
- **时间**：O(M×N) | **空间**：O(M×N)
- **🖼️ 画面**：**航拍数岛**🛩️ — 发现一块陆地就标记整座岛，继续找下一座

### 题目29：课程表 (Course Schedule)
- **题意**：判断课程之间是否存在循环依赖（拓扑排序）
- **最优解**：BFS（Kahn算法）或 DFS检测环
- **时间**：O(V+E) | **空间**：O(V+E)
- **🖼️ 画面**：**先修课地图**🗺️ — 高数→线代→概率论，如果有环就选不了课

### 题目30：实现 Trie (前缀树)
- **题意**：实现一个Trie，支持insert、search、startsWith
- **最优解**：树形结构，每个节点有26个子指针
- **🖼️ 画面**：**字典树📖** — 共享前缀的单词共用路径，像一棵字母树
- **时间**：O(m) m为单词长度 | **空间**：O(总字符数)

## 📦 选手装备区：数据结构快速编码

### 数据结构01：数组 (Array)
- **本质**：连续内存，随机访问
- **核心操作**：访问O(1)、搜索O(n)、插入/删除O(n)
- **🖼️ 画面**：**停车位**🅿️ — 编号连续，直接跳到第N个很快，但中间插一个要挪后面所有
- **面试关键词**：下标访问、双指针、滑动窗口、前缀和

### 数据结构02：链表 (Linked List)
- **本质**：非连续内存，通过指针串联
- **核心操作**：访问O(n)、插入/删除O(1)（已知位置时）
- **🖼️ 画面**：**寻宝链🗺️** — 每张藏宝图告诉你下一张在哪，必须按顺序找
- **面试关键词**：快慢指针、反转、合并、环检测

### 数据结构03：栈 (Stack)
- **本质**：后进先出 (LIFO)
- **核心操作**：push O(1)、pop O(1)、peek O(1)
- **🖼️ 画面**：**叠盘子**🍽️ — 最后放的最先拿，只能从顶部操作
- **面试关键词**：括号匹配、单调栈、表达式求值、DFS

### 数据结构04：队列 (Queue)
- **本质**：先进先出 (FIFO)
- **核心操作**：enqueue O(1)、dequeue O(1)
- **🖼️ 画面**：**排队买奶茶🧋** — 先排的先买到
- **面试关键词**：BFS、滑动窗口最大值、优先队列

### 数据结构05：哈希表 (Hash Table)
- **本质**：通过哈希函数将key映射到数组下标
- **核心操作**：增删查平均O(1)，最坏O(n)
- **🖼️ 画面**：**快递柜📦** — 快递单号(key)通过算法直接算出柜子号(下标)
- **面试关键词**：去重、计数、两数之和、缓存

### 数据结构06：树 (Tree)
- **本质**：层级结构，每个节点最多一个父节点
- **核心类型**：二叉树、BST、AVL、红黑树
- **🖼️ 画面**：**家谱树👨‍👩‍👧‍👦** — 根是祖先，分支是后代
- **面试关键词**：遍历（前/中/后/层序）、深度、平衡、LCA

### 数据结构07：图 (Graph)
- **本质**：节点+边的网络结构
- **存储方式**：邻接矩阵 O(V²)、邻接表 O(V+E)
- **🖼️ 画面**：**地铁线路图🚇** — 站点是节点，线路是边
- **面试关键词**：DFS、BFS、拓扑排序、最短路径、连通分量

### 数据结构08：堆 (Heap)
- **本质**：完全二叉树，大顶堆/小顶堆
- **核心操作**：插入O(logn)、取最值O(logn)、查看最值O(1)
- **🖼️ 画面**：**金字塔🥇** — 顶部永远是最大/最小值
- **面试关键词**：Top K、中位数、合并K个有序、优先队列

## ⏱️ 计时器区：时间/空间复杂度记忆

### 复杂度层级（从小到大）

| 复杂度 | 名称 | n=10 | n=100 | n=1000 | 🖼️ 画面 |
|--------|------|------|-------|--------|---------|
| O(1) | 常数 | 1 | 1 | 1 | **闪电**⚡ — 不管多大数据，一下就好 |
| O(logn) | 对数 | 3 | 7 | 10 | **折纸**📄 — 每次对折，厚度翻倍但次数很少 |
| O(n) | 线性 | 10 | 100 | 1000 | **走楼梯**🚶 — n级台阶走n步 |
| O(nlogn) | 线性对数 | 30 | 700 | 10000 | **排序**🃏 — 排序的"正常速度" |
| O(n²) | 平方 | 100 | 10000 | 10⁶ | **握手**🤝 — n个人两两握手 |
| O(n³) | 立方 | 1000 | 10⁶ | 10⁹ | **三维网格**🧊 — 三层嵌套循环 |
| O(2^n) | 指数 | 1024 | 10³⁰ | 10³⁰⁰ | **病毒传播**🦠 — 每个传染两个，爆炸式增长 |
| O(n!) | 阶乘 | 3628800 | 10¹⁵⁷ | ∞ | **全排列**🎰 — 可能性疯狂增长 |

### 复杂度快速判断口诀

> **单循环** → O(n)
> **双层嵌套** → O(n²)
> **每次减半** → O(logn)
> **减半+遍历** → O(nlogn)
> **所有子集** → O(2^n)
> **所有排列** → O(n!)

### 常见算法复杂度速查

| 算法/操作 | 时间 | 空间 |
|-----------|------|------|
| 数组访问 | O(1) | O(1) |
| 哈希表查找 | O(1)平均 | O(n) |
| 二分搜索 | O(logn) | O(1) |
| 遍历数组 | O(n) | O(1) |
| 排序（快排/归并/堆排） | O(nlogn) | O(1)~O(n) |
| 二叉树遍历 | O(n) | O(h) |
| 图DFS/BFS | O(V+E) | O(V) |
| Dijkstra | O((V+E)logV) | O(V+E) |
| 动态规划（背包） | O(nW) | O(nW) |

## 📋 裁判席：答题模板与框架

### 模板1：STAR法（行为面试题）

> **S**ituation → **T**ask → **A**ction → **R**esult

| 步骤 | 内容 | 时间占比 | 🖼️ 画面 |
|------|------|----------|---------|
| S - 情境 | 描述背景和挑战 | 20% | **舞台布景**🎭 |
| T - 任务 | 你的具体职责 | 10% | **任务卡**📋 |
| A - 行动 | 你做了什么 | 50% | **动作戏**🎬 |
| R - 结果 | 成果和数据 | 20% | **奖杯**🏆 |

**STAR回答模板**：
```
"在[项目/场景]中（S），我负责[具体任务]（T）。
我采取了[具体行动1]、[行动2]、[行动3]（A），
最终实现了[量化结果]，如性能提升X%、用户增长Y%（R）。"
```

**示例**：
> "在电商平台的秒杀项目中（S），我负责优化高并发下的库存扣减（T）。
> 我采用了Redis预扣库存+异步写入数据库的方案，引入分布式锁防超卖（A），
> 最终将QPS从500提升到5000，零超卖事故（R）。"

### 模板2：系统设计题框架（RESHADED）

| 步骤 | 英文 | 内容 | 时间 |

## 🧩 补充：面试高频编码模式

### 模式1：双指针
- **适用**：有序数组、链表、回文
- **画面**：左右两只手👋从两端向中间靠拢
- **典型题**：两数之和（有序版）、三数之和、接雨水、回文判断

### 模式2：滑动窗口
- **适用**：连续子数组/子串问题
- **画面**：一扇窗户🪟在数组上滑动，左右边界动态调整
- **典型题**：最长无重复子串、最小覆盖子串、最大连续1的个数

### 模式3：快慢指针
- **适用**：链表环检测、找中点
- **画面**：🐢兔子和🐢乌龟赛跑
- **典型题**：环形链表、链表中点、快乐数

### 模式4：BFS/DFS模板
- **适用**：图/树的遍历、最短路径、连通性
- **BFS画面**：波纹扩散🌊 | **DFS画面**：钻地洞🏰
- **典型题**：岛屿数量、课程表、单词接龙

### 模式5：动态规划模板
```
1. 定义 dp[i] 或 dp[i][j] 的含义
2. 写状态转移方程
3. 确定初始值
4. 确定遍历顺序
5. 推导验证
```
- **画面**：**多米诺骨牌**🀄 — 前面的状态决定后面的状态

### 模式6：回溯模板
```python
def backtrack(path, choices):
    if 结束条件:
        result.append(path[:])
        return
    for choice in choices:
        if 不合法: continue
        path.append(choice)
        backtrack(path, 新choices)
        path.pop()
```
- **画面**：**迷宫探索**🔀 — 走到死路就退回来换条路

### 模式7：单调栈
- **适用**：下一个更大/更小元素
- **画面**：**叠罗汉🤸** — 栈里永远保持从大到小（或从小到大）
- **典型题**：每日温度、柱状图最大矩形、股票跨度

## 💡 终极记忆技巧汇总

### 1. 数据结构选型口诀
> 查找快 → **哈希表**
> 有序 → **BST / 堆**
> LIFO → **栈**
> FIFO → **队列**
> 层级 → **树**
> 网络 → **图**
> 连续 → **数组**
> 链接 → **链表**

### 2. 算法选择口诀
> 有序数组 → **二分**
> 子数组/子串 → **滑动窗口**
> 最短路径 → **BFS**（无权）/ **Dijkstra**（有权）
> 所有组合 → **回溯**
> 最优解 → **DP** 或 **贪心**
> 拓扑序 → **BFS(入度法)** 或 **DFS(后序)**

### 3. 复杂度记忆锚点
> O(1) = 闪电⚡
> O(logn) = 折纸📄
> O(n) = 走路🚶
> O(nlogn) = 排序🃏
> O(n²) = 握手🤝
> O(2^n) = 病毒🦠
> O(n!) = 全排列🎰

### 4. 面试心态口诀
> **先想后写** — 先说思路再动手
> **边写边说** — 解释每一步的意图
> **先暴力后优化** — 暴力解是起点，不是终点
> **主动测试** — 写完主动用例子验证
