## 三、全库编号约定（坐标系，发布后不改）

1. **知识点编号**：`PY-模块号-序号`。模块号 = 文件号（01~22）；序号两位从 01 起、连续、不复用（新增只往后追加）。例：py-04 内第 7 点 = `PY-04-07`。
2. **标题格式**：`### PY-04-07 字典推导式 Dict Comprehension`（编号 + 中文名 + 英文原词）。
3. **关联格式**：`→ PY-xx-yy：一句关系`，单向引用、被引方不反指；跨篇目标序号未定时写 `→ PY-xx（篇名）：一句关系`，由 [INDEX](INDEX.md) 合并期补全序号。
4. **方法引用**：一律用方法 ID（M01~M42、M07-R）并链到 [方法地图](../../方法地图.md#m00) 对应锚点，不自造方法名。
5. **锚点登记表**：每篇末尾登记本篇锚点，ID 列填 PY-ID；py-00 的阶段锚点用 `PY-00-01~07`。
6. **一处一写**：跨篇内容写"→ 见 PY-xx-yy"，不复制正文（防止两份不一致）；全库只有 [INDEX](INDEX.md) 允许全量汇总。
7. **实测铁规**：每篇"怎么写"代码块都在 Python 3.12 实测通过，输出为真实输出。
