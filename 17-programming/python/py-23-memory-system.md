## 一、为什么"背了很多却不成体系"

| 病 | 症状 | 根因 | 治法 |
|----|------|------|------|
| 散点无主线 | 记得住点，想不起全貌 | 只有 L3、无 L1/L2 骨架 | 三层体系（§二） |
| 域多乱撞 | A 的锚点跑到 B 上 | 锚点无组织、无边界 | 23 意象域 = 23 城区，各管一段 |
| 提取无路径 | 想不起"学过没、在哪" | 缺定位坐标 | 统一提取路径（§二） |

**一句话**：不是你记性差，是记忆没有**地址**。本篇给全部知识发地址：城区（篇）→ 地标（组块）→ 物件（锚点）。

## 二、三层记忆体系

```
L1 知识树（骨架）    23 篇 = 23 个城区，每篇 4~6 个地标（组块）      → 管"有没有、在哪"
L2 城市主线（路线）  一条"Python 大道"故事串起 23 站               → 管"什么顺序、怎么连"
L3 锚点物件（细节）  318 个锚点 = 地标上的物件（各篇登记表）        → 管"具体内容是什么"
```

- **L1 知识树**：[INDEX](INDEX.md) 的阅读顺序表，树保证"不重不漏"。
- **L2 城市主线**：本篇 §三~§五，线保证"有条理、不散"。
- **L3 锚点物件**：各篇"📌 锚点登记表"，物件保证"细节记得准"。

**统一提取路径**（任何问题都这么走）：

```
听到问题 → 判定属于哪个城区（L1）→ 顺大街走到该站（L2）→ 找到地标与物件（L3）→ 还原成代码/答案
```

例："dict 和 list 查找谁快？" → 城区：站 4 快递驿站（容器）→ 地标：字典·取件码柜 vs 列表·货架区 → 物件：取件码 vs 货位号 → 答案：dict O(1)、list O(n)。

## 五、一条主线故事（一口气串全城 · 故事链 M02）

> 背法：不看表，把下面 23 句连成一个故事讲出来。讲不顺的地方就是你缺的站。

小派**进城**先在**厨房**把灶点着（01 环境），到**仓库**给货物拴标签（02 变量），调去**邮局**分拣信件（03 字符串），管起**快递驿站**的包裹柜（04 容器），周末在**超市收银**练出一手算账（05 运算）；每天**坐地铁**练熟换乘与闸机（06 控制流），进**工厂**管流水线进出料（07 函数），接私活学**装修**给毛坯贴墙纸（08 装饰器），被**家族企业**录用学会立户与族谱（09 OOP），年会看演出发现**遥控器**能操纵一切（10 魔术方法），下车间值守**售货机**一个个吐货（11 迭代生成），赶上**消防演习**学会报警与收尾（12 异常）；周末到**图书馆**进修借书手续（13 模块），去**五金市场**买齐量具（14 标准库），到**银行**办业务练存取（15 文件），看**码头安检**把行李扫出特征（16 正则）；考证进**设计院**画图纸盖质检章（17 类型），上**立交桥**指挥车流（18 并发），搬家到**收纳所**断舍离（19 内存），最后进 **4S 店**把住质检线（20 工程）；路过**警示长廊**记住前人踩的坑（21 易混），到**驾校**通过考试拿到驾照（22 复习）——出师。

## 六、四步成体系（把三层用起来）

| 步 | 动作 | 用到 | 与[八步流水线](../../56-编程语言记忆方法.md)对应 |
|----|------|------|------|
| ① 建树 | 读 [py-00](py-00-roadmap.md) + 本篇 §三，先在纸上默画 23 站地图 | L1/L2 | P1~P2 |
| ② 走城 | 每学一篇，先定位"这是哪一站"，再进去看地标 | L1→L2 | P3 |
| ③ 挂锚 | 学每个知识点，把锚点物件**放到该站地标上**（放到柜台上） | L2→L3 | P4~P5 |
| ④ 自测 | 合上书**从城门走**到该站讲出知识点 | 全层 | P7~P8 |

> 关键是②③"**放到站里**"：锚点飘在城外 = 散乱的开始。

## 七、20 分钟闭眼走城（整库复习协议）

1. **闭眼/望窗外**（2 分钟）：从城门按 §五 顺序默走 23 站。
2. **每站停 30 秒**（约 12 分钟）：报出该站 4~6 个地标（组块名），挑 1~2 个展开讲知识点。
3. **卡壳就打标记**（持续进行）：走不动的站 = 待复习，记入 [templates/记忆训练进度追踪表](../../templates/记忆训练进度追踪表.md)。
4. **收尾定向补**（5 分钟）：只回看打标记的站，重做该篇自测（[py-22 §一](py-22-review-drill.md)）。

> 📝 每次走城用 [templates/Python城走城打卡表](../../templates/Python城走城打卡表.md) 记录（23 站打卡 + 卡壳修复流水线 + SRS 回走排期）。

排期：走城（整体提取）+ 篇内自测（细节提取）交替，配 1/2/7/15/30 天 SRS（[py-22](py-22-review-drill.md)）。**走城永远先于重读**。
