## 一、换乘指示牌·if（口号：走到岔口看牌子）

### PY-06-01 if / elif / else 分支
- **是什么**：条件分支（branch）——按条件真假选一条路走；`elif` 是多块指示牌依次看，`else` 是兜底路线。
- **为什么**：进站后去 A 线还是 B 线取决于票种/目的地 → 单一顺序执行无法表达"分岔"→ if 让解释器按条件跳过某段字节码 → elif 自上而下短路匹配，命中即止。
- **怎么写**：
```python
ticket = "学生票"
if ticket == "全价票":
    price = 5
elif ticket == "学生票":
    price = 2.5
else:
    price = 0
print(ticket, price)
```
→ 运行输出：`学生票 2.5`
- **何时用/不用**：互斥条件分支用 if/elif/else；值域是"多选一的字面量/形状"可用 match-case（PY-06-12）。
- **锚点**：三岔路口的换乘指示牌：先看第一块（if），不对再看下一块（elif），都不对走默认通道（else）。
- **易错**：elif 顺序敏感（更严的条件放前面）；`if x:` 后忘冒号或缩进错位 → SyntaxError/IndentationError。
- **关联**：`→ PY-06-02：一行版分支` ｜ `→ PY-05-09：条件吃的是真值`。

### PY-06-02 条件表达式（三元表达式）
- **是什么**：`值A if 条件 else 值B`——把分支压缩进一个表达式，返回值而不是执行语句。
- **为什么**：为"取个值"写 4 行 if 太重 → 三元把选择变成表达式可直接赋值/传参 → 表达式意味着两边都必须是"值"→ 嵌套三元可读性差，最多一层。
- **怎么写**：
```python
bag = []
print("空手" if not bag else "有行李")
print("放行" if len(bag) <= 2 else "走大件通道")
```
→ 运行输出：`空手 ⏎ 放行`
- **何时用/不用**：二选一取值用它；两个分支都有副作用（print/多条语句）就老实写 if。
- **锚点**：一行迷你指示牌：左右两个箭头中间夹一句"有行李→右"，比整块大牌子省地方。
- **易错**：`a if b else c` 里 a 是真分支（在最前），与 if 语句的书写顺序相反；嵌套要加括号。
- **关联**：`→ PY-06-01：完整 if` ｜ `→ PY-05-14：它在优先级最底一档`。

### PY-06-03 条件组合与真值陷阱
- **是什么**：用 and/or/not、链式比较、`in` 组合条件；条件整体按真值判断（truthy/falsy）。
- **为什么**："早高峰且持月票"是两个条件的组合 → 组合运算符把多个判定编成一条 → 但 `if x == 1 or 2:` 会把 `2` 当恒真条件 → 所以每个比较都要写完整。
- **怎么写**：
```python
hour, ticket = 8, "月票"
print(hour < 9 and ticket == "月票", not (hour > 9) or ticket == "单程票")
print(1 < hour < 12)                  # 链式比较 = and 串联
```
→ 运行输出：`True True ⏎ True`
- **何时用/不用**：条件超过 3 个子句就拆中间变量（`is_peak = hour < 9`），别写超长布尔串。
- **锚点**：进站前两道口：安检口 and 票检口都过才放行；not 是"反向闸"，把条件倒过来说。
- **易错**：`if x == 1 or 2:` 恒真（应写 `x in (1, 2)`）；`not a in b` 读作 `not (a in b)`，更清晰写 `a not in b`。
- **关联**：`→ PY-05-07：逻辑运算` ｜ `→ PY-05-14：优先级决定谁先算`。

## 二、环线跑圈·for（口号：按时刻表跑）

### PY-06-04 for 循环与 range
- **是什么**：`for x in 可迭代` 逐个取元素执行循环体；`range(start, stop, step)` 生成等差班次序列（左闭右开）。
- **为什么**："按时刻表一站一站停靠"是固定次数的重复 → for 把重复代码写一次、循环变量自动推进 → range 左闭右开让 `range(len(x))` 不越界 → 循环变量在循环外仍保留最后值。
- **怎么写**：
```python
for stop in range(1, 4):            # 1..3 号站台，左闭右开
    print(f"{stop}号站台", end=" ")
print(list(range(0, 10, 3)))        # 步长 = 3
```
→ 运行输出：`1号站台 2号站台 3号站台 [0, 3, 6, 9]`
- **何时用/不用**：次数/元素已知用 for；别用 `for i in range(len(lst))` 硬套下标，直接 `for x in lst`。
- **锚点**：环线列车按时刻表跑圈：时刻表是 range（班次号），列车是循环变量，每站停一次是循环体。
- **易错**：`range(1, 4)` 不含 4；`range(10, 0)` 为空，倒序要 `range(10, 0, -1)`。
- **关联**：`→ PY-06-05：遍历技巧` ｜ `→ PY-11 迭代器：for 的底层协议`。

### PY-06-05 遍历技巧：enumerate / zip
- **是什么**：`enumerate(x, start=1)` 给元素配编号，`zip(a, b)` 把多条序列并行拉链式配对。
- **为什么**：报站要"第几站+站名"，双语报站要"中文名+外语名"同步 → 手动维护下标易错位 → enumerate/zip 在循环里直接解包出所需字段 → zip 以最短序列为准，长的那条被截断。
- **怎么写**：
```python
lines = ["1号线", "2号线"]
for i, name in enumerate(lines, 1): print(i, name, end="; ")
for name, color in zip(lines, ["红", "蓝"]): print(name, color, end="; ")
print()
```
→ 运行输出：`1 1号线; 2 2号线; 1号线 红; 2号线 蓝;`
- **何时用/不用**：要下标用 enumerate；要并行多序列用 zip；长度不齐要补位用 `itertools.zip_longest`（→ PY-14）。
- **锚点**：站点编号牌（enumerate）与双线并行的换乘对照表（zip）：两列站名拉链般对齐。
- **易错**：zip 静默截断到最短序列，长度不一致会"悄悄丢数据"，先 `assert len(a) == len(b)` 或用 zip_longest。
- **关联**：`→ PY-04-15：循环内就是解包` ｜ `→ PY-06-14：别在循环里改被遍历的序列`。

### PY-06-06 for-else 子句
- **是什么**：for 后可跟 else：循环**正常跑完**（没被 break）才执行 else 块。
- **为什么**："搜完全部车次都没找到问题件"这个结论需要一个去处 → 循环后置标志位既啰嗦又易忘 → for-else 把"跑完了没被 break"语义内建 → break 会跳过 else，continue 不会。
- **怎么写**：
```python
for code in ["SF001", "SF002"]:
    if code == "SF999": break
else: print("全部查验通过")      # 没 break 才执行
```
→ 运行输出：`全部查验通过`
- **何时用/不用**："找东西没找到"的兜底消息用 for-else；团队不熟该语法时用标志位或函数 return 更易读。
- **锚点**：终点站广播："本次列车全程未触发换乘"——只有没在中途 break 出闸，才听得到这句广播。
- **易错**：把 else 误读成"没进循环才执行"（其实是"没 break"）；continue 不影响 else。
- **关联**：`→ PY-06-08：while-else 同规则` ｜ `→ PY-06-09：break 是唯一跳过 else 的开关`。

## 三、站台等车·while（口号：条件满足才上车）

### PY-06-07 while 循环与死循环防御
- **是什么**：`while 条件:` 条件为真就重复执行；条件不更新就会死循环。
- **为什么**：站台等车不知道要等几班（次数未知）→ while 按"条件"而非"次数"驱动 → 每轮重新求值条件 → 循环体必须让条件朝假的方向移动，否则永远转。
- **怎么写**：
```python
wait = 3
while wait > 0:                  # 条件满足才继续
    print("还有", wait, "分钟", end="; "); wait -= 1   # 忘了更新就死循环
print("发车")
```
→ 运行输出：`还有 3 分钟; 还有 2 分钟; 还有 1 分钟; 发车`
- **何时用/不用**：次数未知、按条件重复用 while；能用 for 数清的次数别用 while。
- **锚点**：站台等车：显示屏（条件）亮着就继续等，车来了（条件变假）才上车走人。
- **易错**：忘记更新条件变量 = 死循环（Ctrl+C 救场）；`while x = 1:` 少写一个 `=` 是 SyntaxError。
- **关联**：`→ PY-06-04：已知次数用 for` ｜ `→ PY-06-15：while True + 哨兵`。

### PY-06-08 while-else 子句
- **是什么**：while 后也可跟 else：条件**自然耗尽**（不是 break）才执行。
- **为什么**：末班车正常收车要播广播，中途被叫停则不播 → 与 for-else 同一套语义 → break 跳过 else → 让"正常结束"和"被打断"两种出口分流。
- **怎么写**：
```python
n = 3
while n > 0: n -= 1
else: print("正常耗尽才进 else, n =", n)
n = 3
while n > 0: n -= 1; break
else: print("break 跳过 else")
```
→ 运行输出：`正常耗尽才进 else, n = 0`（第二段的 else 未打印）
- **何时用/不用**：需要区分"搜完没找到"与"中途找到退出"时用；否则省略 else 更简单。
- **锚点**：收车广播只在末班车正点收车时播放；一旦 break 提前离站，广播就不响了。
- **易错**：while-else 易被误当成"条件一开始为假才执行"；唯一判据是**有没有 break**。
- **关联**：`→ PY-06-06：同一语义的 for 版` ｜ `→ PY-06-09：break 的副作用`。

## 四、闸机三兄弟（口号：break 出站、continue 跳站、pass 空站）

### PY-06-09 break：跳出整个循环
- **是什么**：break 立即终止**最内层**循环，跳到循环之后的语句。
- **为什么**：在 K2 站换乘就要下车，没必要坐完全程 → break 提前结束不相干的迭代 → 循环后的代码继续执行 → 但它只出一层，嵌套时外层还在跑。
- **怎么写**：
```python
for train in ["K1", "K2", "K3"]:
    if train == "K2": print("在", train, "换乘出闸"); break
    print(train, "通过")
print("出闸后不再看后面的车次")
```
→ 运行输出：`K1 通过 ⏎ 在 K2 换乘出闸 ⏎ 出闸后不再看后面的车次`
- **何时用/不用**：找到目标/满足即止用 break；只想跳过本次用 continue（PY-06-10）。
- **锚点**：换乘出闸：闸机"咔"一声，后面的站全都不用看了。
- **易错**：break 只跳一层（嵌套要两层各 break 或用标志位/return）；break 会跳过 for/while 的 else。
- **关联**：`→ PY-06-16：嵌套跳出` ｜ `→ PY-06-06：break 跳过 else`。

### PY-06-10 continue：跳过本次迭代
- **是什么**：continue 结束**本次**迭代，直接进入下一轮（取下一个元素）。
- **为什么**：施工站不停靠，但线路还要继续跑 → continue 只丢弃当前轮 → 后面的元素照常处理 → 与 break 的区别是"还继续不继续跑圈"。
- **怎么写**：
```python
for station in ["A站", "施工站", "B站"]:
    if station == "施工站": continue    # 跳过本次，进下一站
    print("停靠", station)
```
→ 运行输出：`停靠 A站 ⏎ 停靠 B站`
- **何时用/不用**：过滤掉不合格的一批用 continue（卫语句提前缩进）；整段循环该结束用 break。
- **锚点**：跳站不停：列车过站不减速，下一站照常停。
- **易错**：continue 在 while 里不会自动更新条件（自己更新，否则死循环）；它不影响 else 子句。
- **关联**：`→ PY-06-09：出站与跳站之别` ｜ `→ PY-06-07：while 中先更新条件`。

### PY-06-11 pass：空站台占位
- **是什么**：pass 是空语句（no-op），什么都不做；用于语法上必须有语句体的位置。
- **为什么**：先搭好 if/函数骨架，细节稍后填 → Python 用缩进划分块，空块会 SyntaxError → pass 占位让骨架可运行 → 它不是"跳过本次"（那是 continue）。
- **怎么写**：
```python
def check(code):     # 先占位，稍后实现
    pass
for i in range(2): pass           # 空循环体合法
print("pass 只占位；check() 已可调用:", check("SF001"))
```
→ 运行输出：`pass 只占位；check() 已可调用: None`
- **何时用/不用**：写骨架/空异常分支用 pass；循环里"只想跳过"用 continue，两者语义不同。
- **锚点**：施工中的空站台：站牌还在（语法完整），但列车不停、站里没人（什么都不做）。
- **易错**：pass 与 `...`（Ellipsis）都可占位，但 `...` 常作未实现标记；空循环体写 pass 不改变循环行为。
- **关联**：`→ PY-06-10：continue 是跳站不是空站` ｜ `→ PY-07 函数：函数体占位`。

## 五、智能闸机·match-case（3.10+）

### PY-06-12 match-case 基础（Python 3.10+）
- **是什么**：结构化模式匹配（structural pattern matching）：`match` 取值、`case` 匹配分支、`case _` 通配兜底。
- **为什么**：票种分通道若用 if/elif 越写越长且无法表达"形状匹配"→ match-case 把"值/结构匹配"变成一等语法 → 分支**不贯穿**（不像 C 的 switch 要 break）→ 匹配失败落到 `_`。
- **怎么写**：
```python
ticket = "学生票"
match ticket:                     # 3.10+ 结构匹配，无 break、不贯穿
    case "全价票": print("票价 5 元")
    case "学生票" | "老年票": print("票价 2.5 元")   # 或模式
    case _: print("请补票")       # 通配，相当于 else
```
→ 运行输出：`票价 2.5 元`
- **何时用/不用**：多路值匹配/结构解构用 match-case（需 3.10+）；简单二三分支、低版本兼容就用 if/elif。
- **锚点**：智能闸机按票种开不同通道：票面一贴，对应通道亮绿灯，只开一道。
- **易错**：match-case 是 3.10+ 语法，低版本直接 SyntaxError；case 之间不贯穿，别写多余的 break。
- **关联**：`→ PY-06-01：if/elif 的对照` ｜ `→ PY-06-13：模式进阶`。

### PY-06-13 模式进阶：序列 / 映射 / 守卫
- **是什么**：case 支持序列模式（`["包裹", code]`）、映射模式（`{"kind": "急件"}`）、守卫（`case x if 条件`）。
- **为什么**：进站行李有"列表包裹/字典急件/普通单号"等不同**形状**→ 模式匹配在分支头直接解构形状 → 变量在 case 里自动绑定 → 守卫负责形状之外的附加条件。
- **怎么写**：
```python
def describe(item):
    match item:
        case ["包裹", code]: return f"包裹 {code}"      # 序列模式
        case {"kind": "急件"}: return "急件专柜"        # 映射模式
        case code if isinstance(code, str) and code.startswith("SF"): return f"普通件 {code}"   # 守卫
        case _: return "未知"
print(describe(["包裹", "SF001"]), describe({"kind": "急件"}), describe("SF002"), describe(123))
```
→ 运行输出：`包裹 SF001 急件专柜 普通件 SF002 未知`
- **何时用/不用**：按数据形状分派（解析消息、协议帧）用它；纯布尔条件分支 if 更直白。
- **锚点**：闸机识别票面图案：长条票走左边、卡片票走右边、带"急件"红章的走专柜。
- **易错**：小写名是**捕获变量**（`case code:` 会吞掉一切），字面量/点路径才是常量匹配；守卫里抛异常会直接炸出 match（所以先 isinstance 再 startswith）。
- **关联**：`→ PY-06-12：基础分支` ｜ `→ PY-17 typing：模式匹配与类型收窄`。

## 六、调度台技巧（口号：别在跑动中改铁轨）

### PY-06-14 循环中修改容器的坑
- **是什么**：遍历列表时增删元素会跳过元素（下标移动与元素移动互相打架）。
- **为什么**：for 按下标推进，remove 会让后面的元素前移一格 → 下一次迭代就跳过一个 → 行为隐蔽、结果"好像差不多对"→ 正确做法是遍历副本或重建列表。
- **怎么写**：
```python
nums = [1, 2, 2, 3]
for n in nums:
    if n == 2: nums.remove(n)     # 边遍历边删 → 跳元素
print(nums, [n for n in nums if n != 2])   # 漏删 1 个 / 重建才安全
```
→ 运行输出：`[1, 2, 3] [1, 3]`
- **何时用/不用**：要边遍历边改就遍历副本（`for x in lst[:]`）或推导式重建；字典边遍历边改大小会 RuntimeError。
- **锚点**：列车跑到一半换铁轨：下一根枕木被抽走，列车直接跳站（漏元素）。
- **易错**：`for x in lst:` 中 `lst.remove(x)` 会漏删（实测留下一个 2），看似删干净了实际留尾巴。
- **关联**：`→ PY-04-03：删除操作` ｜ `→ PY-04-14：推导式重建`。

### PY-06-15 死循环防御与哨兵退出
- **是什么**：`while True` 配 `break` 的"永动+出口"写法；哨兵（sentinel）值是约定的结束标志。
- **为什么**：循环次数不定、退出条件在循环中间 → while True 把"退出权"交给循环体 → 哨兵让退出条件显式可读 → 忘记写 break 就是真死循环。
- **怎么写**：
```python
queue = ["K1", "K2", "终点"]
while True:                                      # 环线：必须自带出口
    if (train := queue.pop(0)) == "终点": break   # 哨兵值 = 终点牌
    print("发出", train)
```
→ 运行输出：`发出 K1 ⏎ 发出 K2`
- **何时用/不用**：退出条件多于一个/在中间用 while True + break；单一条件直接 `while 条件` 更清楚。
- **锚点**：环线地铁永不停，必须立一块"终点牌"（哨兵）：见到牌子立刻收车 break。
- **易错**：哨兵值要与真实数据区分开（None 常用）；`while True` 里没有任何 break = 卡死。
- **关联**：`→ PY-05-13：海象让取值+判断合并` ｜ `→ PY-06-07：条件式 while`。

### PY-06-16 嵌套循环的提前退出
- **是什么**：break 只退出最内层循环；多层同时退出要靠标志位、异常或函数 return。
- **为什么**：换乘枢纽逐条线路找人，内层 break 只是"这条线找完"，外层还在跑 → 于是需要外层二次判断 → 但标志位写法绕，最干净是把两层循环包进函数用 return。
- **怎么写**：
```python
targets, found = [["A", "B"], ["C", "枢纽"], ["D"]], False
for line in targets:
    for station in line:
        if station == "枢纽": found = True; break   # break 只退出内层！
    if found: break                                 # 外层还得自己判
print("找到枢纽:", found)
```
→ 运行输出：`找到枢纽: True`
- **何时用/不用**：两层以上要"找到即停"就封装函数 `return`（一行 `next((x for x in ...), None)` 更妙）；只有一层直接 break。
- **锚点**：换乘枢纽找人：内层只扫一条线，找不到还得回到枢纽大厅（外层）继续换下条线。
- **易错**：只写内层 break 时外层空转（白算）；标志位忘了复位会提前退出。
- **关联**：`→ PY-06-09：break 的作用域` ｜ `→ PY-07 函数：用 return 控制出口`。

## ✅ 自测清单（合上本篇，先写再看）
1. 用一行代码输出 1~10 里能被 3 整除的数（推导式）。
> 答案：`print([x for x in range(1, 11) if x % 3 == 0])` → `[3, 6, 9]`
2. `for i in range(3): continue` 之后 else 会执行吗？break 呢？
> 答案：continue 不影响 else（会执行）；break 会跳过 else。
3. while 循环里只写 `continue` 有什么风险？
> 答案：条件没更新就是死循环——continue 不负责推进条件（见 PY-06-10）。
4. match-case 里 `case name:` 和 `case "name":` 有何区别？
> 答案：小写 `name` 是捕获变量（匹配一切），`"name"` 是字面量匹配。
5. 遍历列表时删所有偶数，错写 `for x in lst: if x % 2 == 0: lst.remove(x)` 会怎样？
> 答案：跳元素漏删（见 PY-06-14）；应改 `lst = [x for x in lst if x % 2]`。
6. 两层循环找到目标后如何立即全部退出？给两种办法。
> 答案：①标志位+外层判断；②包进函数直接 return（PY-06-16）。
7. `while True` 写法最大的风险是什么？如何防御？
> 答案：漏写 break 死循环；保证每个路径都有出口/哨兵值。
