# Linux命令记忆 — 50个常用命令编码

> 记忆策略：每个命令 → 功能场景 → 缩写来源 → 谐音锚点 → 视觉画面
> 目标：看到命令名 → 脑中浮现画面 → 自动回忆用法

---

## 一、文件与目录操作（15个）
> 定位宫殿：**文件柜房间**

### 1. ls — 列出目录内容
- **功能**：查看当前目录下的文件和文件夹
- **缩写**：**l**i**s**t
- **谐音**：「览赏」→ 浏览欣赏
- **画面**：打开文件柜，一眼扫过所有文件夹标签
- **常用**：`ls -la`（详细+隐藏）、`ls -lh`（人类可读大小）
- **编码**：`览赏文件柜` → 打开柜门一览无余

### 2. cd — 切换目录
- **功能**：进入/切换到指定目录
- **缩写**：**c**hange **d**irectory
- **谐音**：「串得」→ 串门到别的目录
- **画面**：从一个房间走到另一个房间
- **常用**：`cd ~`（回家）、`cd ..`（回上一层）、`cd -`（回上次）
- **编码**：`串门cd` → 走进新房间

### 3. pwd — 显示当前路径
- **功能**：打印当前工作目录的完整路径
- **缩写**：**p**rint **w**orking **d**irectory
- **谐音**：「飘位得」→ 飘在哪个位置
- **画面**：GPS定位器显示"你在这里"
- **编码**：`GPS定位pwd` → 我在哪

### 4. mkdir — 创建目录
- **功能**：创建新文件夹
- **缩写**：**m**a**k**e **dir**ectory
- **谐音**：「没课了」→ 没课了建个新教室
- **画面**：在文件柜里放一个新空文件夹
- **常用**：`mkdir -p a/b/c`（递归创建）
- **编码**：`造文件夹mkdir` → make+dir

### 5. rm — 删除文件
- **功能**：删除文件或目录
- **缩写**：**r**e**m**ove
- **谐音**：「扔」→ 扔掉文件
- **画面**：把文件扔进碎纸机
- **常用**：`rm -rf`（强制递归删除，危险！）
- **编码**：`扔rm` → 扔进碎纸机
- **⚠️ 警告**：`rm -rf /` 自毁命令，永远不要执行

### 6. cp — 复制文件
- **功能**：复制文件或目录
- **缩写**：**c**o**p**y
- **谐音**：「抄批」→ 抄写一批
- **画面**：复印机，原件放进去，复印件出来
- **常用**：`cp -r dir1 dir2`（递归复制目录）
- **编码**：`复印cp` → 复印机

### 7. mv — 移动/重命名
- **功能**：移动文件或重命名
- **缩写**：**m**o**v**e
- **谐音**：「挪位」→ 挪动位置
- **画面**：把文件从一个抽屉拿到另一个抽屉
- **常用**：`mv old.txt new.txt`（重命名）
- **编码**：`挪动mv` → 搬文件

### 8. touch — 创建空文件
- **功能**：创建空文件或更新时间戳
- **缩写**：touch（触摸）
- **谐音**：「踏触」→ 踩一脚留下印记
- **画面**：手指在空白纸上点一下，纸就"出生"了
- **编码**：`一点就生touch` → 指尖创建

### 9. cat — 查看文件内容
- **功能**：连接并打印文件内容
- **缩写**：con**cat**enate（连接）
- **谐音**：「看它」→ 看看文件内容
- **画面**：打开文件夹，把纸上的字念出来
- **常用**：`cat file.txt`、`cat -n`（显示行号）
- **编码**：`看猫cat` → 猫蹲在文件上读

### 10. less / more — 分页查看
- **功能**：分页查看长文件
- **缩写**：less = "less is more"的反讽；more = 看更多
- **谐音**：「乐思」/「默」→ 安静地翻页
- **画面**：翻阅一本厚书，一页一页看
- **常用**：`less file.log`（q退出，/搜索）
- **编码**：`翻书less` → 空格翻页，q退出

### 11. head / tail — 查看头尾
- **功能**：查看文件的前/后几行
- **缩写**：head = 头；tail = 尾巴
- **谐音**：「黑的」/「忒哦」→ 看头看尾
- **画面**：长卷轴，先看开头再看结尾
- **常用**：`tail -f log.txt`（实时跟踪日志）
- **编码**：`头尾head/tail` → 卷轴首尾

### 12. find — 查找文件
- **功能**：在目录树中搜索文件
- **缩写**：find（找到）
- **谐音**：「翻得」→ 翻箱倒柜地找
- **画面**：侦探在文件柜丛林中搜索目标文件
- **常用**：`find / -name "*.log"`、`find . -mtime -7`（7天内修改）
- **编码**：`侦探翻找find` → 递归搜索

### 13. locate — 快速定位文件
- **功能**：基于数据库快速查找文件
- **缩写**：locate（定位）
- **谐音**：「落kei特」→ 落地定位
- **画面**：GPS卫星瞬间锁定目标位置
- **常用**：`locate filename`（需先`updatedb`）
- **编码**：`GPS秒定位locate` → 比find快但需更新数据库

### 14. ln — 创建链接
- **功能**：创建硬链接或软链接（符号链接）
- **缩写**：**l**i**n**k
- **谐音**：「连」→ 连接
- **画面**：两个文件夹之间拉一根绳子
- **常用**：`ln -s target link_name`（软链接）
- **编码**：`拉绳ln` → ln -s创建快捷方式

### 15. du / df — 磁盘使用
- **功能**：du查看目录大小，df查看磁盘空间
- **缩写**：**d**isk **u**sage / **d**isk **f**ree
- **谐音**：「度」/「得福」→ 量尺寸/得福气还有多少空间
- **画面**：du=用尺量每个文件夹；df=看仓库还剩多少空间
- **常用**：`du -sh *`、`df -h`
- **编码**：`量尺寸du/看仓库df` → du量目录，df看磁盘

## 二、文本处理（10个）
> 定位宫殿：**编辑部办公室**

### 16. grep — 文本搜索
- **功能**：在文件中搜索匹配的行
- **缩写**：**g**lobal **r**egular **e**xpression **p**rint
- **谐音**：「grep」→ 「哥rep」→ 哥帮你搜
- **画面**：编辑拿着红笔在报纸上圈出所有关键词
- **常用**：`grep -r "error" /var/log`、`grep -i`（忽略大小写）、`grep -v`（反选）
- **编码**：`红笔圈词grep` → 全局正则搜索

### 17. awk — 文本分析
- **功能**：按列处理文本数据
- **缩写**：取自三位创始人姓氏首字母（Aho, Weinberger, Kernighan）
- **谐音**：「awk」→ 「拗克」→ 拗开文本
- **画面**：Excel表格，按列切割数据
- **常用**：`awk '{print $1}'`（打印第一列）、`awk -F: '{print $1}' /etc/passwd`
- **编码**：`切列刀awk` → 按列切割处理

### 18. sed — 流编辑器
- **功能**：对文本进行替换、删除等操作
- **缩写**：**s**tream **ed**itor
- **谐音**：「sed」→ 「塞的」→ 塞入替换
- **画面**：自动纠错笔，找到错字自动替换
- **常用**：`sed 's/old/new/g'`（全局替换）、`sed -i`（原地修改）
- **编码**：`自动纠错sed` → 流式替换

### 19. sort — 排序
- **功能**：对文本行排序
- **缩写**：sort（排序）
- **谐音**：「sort」→ 「扫它」→ 扫一遍排好
- **画面**：一堆名片按字母顺序排好
- **常用**：`sort -n`（数字排序）、`sort -r`（逆序）、`sort -k2`（按第2列）
- **编码**：`排名片sort` → 排序

### 20. uniq — 去重
- **功能**：去除相邻重复行
- **缩写**：**uniq**ue（唯一）
- **谐音**：「优你客」→ 优中选一
- **画面**：流水线上重复的罐头被推掉
- **常用**：`sort file | uniq`（先排序再去重）、`uniq -c`（计数）
- **编码**：`去重筛uniq` → 需先sort

### 21. wc — 字数统计
- **功能**：统计行数、单词数、字节数
- **缩写**：**w**ord **c**ount
- **谐音**：「文查」→ 查文字数
- **画面**：编辑数稿子有多少字
- **常用**：`wc -l`（行数）、`wc -w`（单词数）
- **编码**：`数字数wc` → word count

### 22. cut — 按列剪切
- **功能**：提取文件的每行指定部分
- **缩写**：cut（剪切）
- **谐音**：「卡它」→ 卡一下剪开
- **画面**：用剪刀沿着虚线剪开表格
- **常用**：`cut -d: -f1 /etc/passwd`、`cut -c1-5`（取字符）
- **编码**：`剪刀cut` → 按分隔符剪切

### 23. tr — 字符替换
- **功能**：替换或删除字符
- **缩写**：**tr**anslate（翻译/转换）
- **谐音**：「替啊」→ 替换啊
- **画面**：密码轮，每个字母转到对应的新字母
- **常用**：`tr 'a-z' 'A-Z'`（小写转大写）、`tr -d '\n'`（删除换行）
- **编码**：`密码轮tr` → 字符映射转换

### 24. diff — 文件比较
- **功能**：比较两个文件的差异
- **缩写**：**diff**erence（差异）
- **谐音**：「敌服」→ 找出敌人的不同
- **画面**：两份文件并排，不同处用红笔标出
- **常用**：`diff file1 file2`、`diff -u`（统一格式）
- **编码**：`找不同diff` → 比较差异

### 25. xargs — 参数传递
- **功能**：将标准输入转为命令参数
- **缩写**：**x**（传输）**arg**ument**s**（参数）
- **谐音**：「叉args」→ 叉起来传参数
- **画面**：传送带把包裹一个个送到执行器
- **常用**：`find . -name "*.log" | xargs rm`、`xargs -I {}`（占位符）
- **编码**：`传送带xargs` → 管道转参数

## 三、权限与用户管理（8个）
> 定位宫殿：**保安室**

### 26. chmod — 修改权限
- **功能**：修改文件/目录权限
- **缩写**：**ch**ange **mod**e
- **谐音**：「chmod」→ 「厂模式」→ 工厂切换模式
- **画面**：保险箱的三把钥匙（读/写/执行），分配给不同人
- **常用**：`chmod 755 file`、`chmod +x script.sh`
- **编码**：`分配钥匙chmod` → rwx=421，三组（所有者/组/其他）
- **权限速记**：`r=4, w=2, x=1` → 7=rwx, 6=rw-, 5=r-x, 4=r--

### 27. chown — 修改所有者
- **功能**：修改文件所有者和组
- **缩写**：**ch**ange **own**er
- **谐音**：「厂翁」→ 工厂换个老板
- **画面**：房产证上的名字从张三改成李四
- **常用**：`chown user:group file`、`chown -R`（递归）
- **编码**：`换房主chown` → 改所有者

### 28. sudo — 以管理员执行
- **功能**：以超级用户权限执行命令
- **缩写**：**s**uper**u**ser **do**
- **谐音**：「速读」→ 速速执行（有权限）
- **画面**：掏出管理员金卡，门卫立刻放行
- **常用**：`sudo command`、`sudo -u user command`
- **编码**：`金卡通行sudo` → 超级权限

### 29. su — 切换用户
- **功能**：切换到其他用户
- **缩写**：**s**witch **u**ser / **s**ubstitute **u**ser
- **谐音**：「速」→ 快速切换身份
- **画面**：换上别人的工牌进入不同区域
- **常用**：`su - root`、`su - user`
- **编码**：`换工牌su` → 切换用户身份

### 30. passwd — 修改密码
- **功能**：修改用户密码
- **缩写**：**pass**wor**d**
- **谐音**：「怕死的」→ 怕被破解，改个密码
- **画面**：保险箱密码锁，转到新密码
- **常用**：`passwd username`（管理员改别人密码）
- **编码**：`改密码锁passwd` → password

### 31. useradd / userdel — 添加/删除用户
- **功能**：管理系统用户
- **缩写**：user + add/delete
- **谐音**：「优ser加/得乐」→ 用户加入/得离开
- **画面**：保安室往花名册上加名字/划掉名字
- **常用**：`useradd -m username`、`userdel -r username`
- **编码**：`花名册加减useradd/userdel`

### 32. groups / id — 查看用户组
- **功能**：查看用户所属的组
- **缩写**：groups = 组；id = 身份标识
- **谐音**：「group丝」/「id」→ 查分组/查身份
- **画面**：查看工牌上的部门和编号
- **常用**：`id username`、`groups`
- **编码**：`查工牌id/groups`

### 33. umask — 默认权限掩码
- **功能**：设置新建文件的默认权限
- **缩写**：**u**ser **mask**
- **谐音**：「优mask」→ 用户面具（遮住某些权限）
- **画面**：新文件出生时自动戴上面具，遮掉部分权限
- **常用**：`umask 022`（新建文件644，目录755）
- **编码**：`面具umask` → 新文件默认权限

## 四、进程与系统管理（10个）
> 定位宫殿：**机房控制室**

### 34. ps — 查看进程
- **功能**：显示当前进程快照
- **缩写**：**p**rocess **s**tatus
- **谐音**：「瞥视」→ 瞥一眼进程状态
- **画面**：监控大屏上显示所有运行中的程序
- **常用**：`ps aux`（所有进程）、`ps -ef`（全格式）
- **编码**：`监控屏ps` → 进程快照

### 35. top / htop — 实时监控
- **功能**：实时显示系统资源和进程
- **缩写**：top = 顶部（排在最前面的进程）
- **谐音**：「top」→ 「套普」→ 套路普通的监控
- **画面**：仪表盘实时跳动，CPU/内存/进程一览无余
- **常用**：`top`、`htop`（更友好的版本）
- **编码**：`仪表盘top` → 实时监控

### 36. kill — 终止进程
- **功能**：发送信号给进程（默认终止）
- **缩写**：kill（杀）
- **谐音**：「kill」→ 「剋哦」→ 干掉进程
- **画面**：按下红色终止按钮，程序关闭
- **常用**：`kill PID`、`kill -9 PID`（强制杀）、`kill -15 PID`（优雅终止）
- **编码**：`红按钮kill` → 终止进程

### 37. bg / fg — 后台/前台
- **功能**：将进程放到后台/前台运行
- **缩写**：**b**ack**g**round / **f**ore**g**round
- **谐音**：「bg」/「fg」→ 背景/前景
- **画面**：舞台演出，bg=退到幕后，fg=拉到台前
- **常用**：`Ctrl+Z`暂停→`bg`后台→`fg`前台
- **编码**：`舞台前后bg/fg` → Ctrl+Z/bg/fg

### 38. jobs — 查看后台任务
- **功能**：列出当前shell的后台任务
- **缩写**：jobs（工作/任务）
- **谐音**：「job丝」→ 查看工作清单
- **画面**：任务看板上列着所有后台任务
- **常用**：`jobs -l`（显示PID）
- **编码**：`任务看板jobs` → 后台任务列表

### 39. nohup — 不挂断运行
- **功能**：退出终端后进程继续运行
- **缩写**：**no** **h**ang **up**（不挂断）
- **谐音**：「no hang」→ 不挂断
- **画面**：进程穿上防弹衣，终端关闭也不受影响
- **常用**：`nohup command &`（后台+不挂断）
- **编码**：`防弹衣nohup` → 终端断了也活着

### 40. systemctl — 系统服务管理
- **功能**：管理系统服务（启动/停止/重启/状态）
- **缩写**：**system** **c**on**t**ro**l**
- **谐音**：「systemctl」→ 「系统ctl」→ 系统控制
- **画面**：总控制台，一排开关控制各个服务
- **常用**：`systemctl start/stop/restart/status nginx`
- **编码**：`总开关systemctl` → 服务控制

### 41. crontab — 定时任务
- **功能**：设置定时执行的任务
- **缩写**：**cron**（时间）+ **tab**（表）
- **谐音**：「cron」→ 「控」→ 定时控制
- **画面**：闹钟定时器，设定时间自动触发
- **常用**：`crontab -e`（编辑）、`crontab -l`（列表）
- **编码**：`定时闹钟crontab` → 分时日月周

### 42. df / free — 磁盘/内存
- **功能**：df查看磁盘空间，free查看内存
- **缩写**：**d**isk **f**ree / free（空闲）
- **谐音**：「得福」/「free」→ 磁盘得福/内存空闲
- **画面**：df=仓库容量表；free=内存条使用率
- **常用**：`df -h`、`free -m`
- **编码**：`仓库表df/内存条free`

### 43. uname — 系统信息
- **功能**：显示系统信息
- **缩写**：**u**nix **name**
- **谐音**：「优name」→ 查系统名
- **画面**：电脑背面的配置标签
- **常用**：`uname -a`（全部信息）、`uname -r`（内核版本）
- **编码**：`配置标签uname` → 系统名

## 五、网络操作（7个）
> 定位宫殿：**通讯室**

### 44. curl — URL请求
- **功能**：发送HTTP请求
- **缩写**：**c**lient **URL**
- **谐音**：「curl」→ 「克哦」→ 克隆网页内容
- **画面**：浏览器地址栏，输入URL获取网页
- **常用**：`curl -O url`（下载）、`curl -X POST`、`curl -H "header"`
- **编码**：`网页抓手curl` → HTTP客户端

### 45. wget — 下载文件
- **功能**：从网络下载文件
- **缩写**：**w**eb **get**
- **谐音**：「wget」→ 「web get」→ 网上拿
- **画面**：下载箭头↓，文件从云端拉到本地
- **常用**：`wget url`、`wget -c url`（断点续传）
- **编码**：`下载箭头wget` → 从网上获取

### 46. ssh — 远程登录
- **功能**：安全连接远程服务器
- **缩写**：**s**ecure **sh**ell
- **谐音**：「ssh」→ 「思思互」→ 互相连接
- **画面**：远程遥控器，坐在家里控制远方的电脑
- **常用**：`ssh user@host`、`ssh -p port`
- **编码**：`远程遥控ssh` → 安全shell连接

### 47. scp — 远程复制
- **功能**：在本地和远程之间复制文件
- **缩写**：**s**ecure **c**o**p**y
- **谐音**：「scp」→ 「速copy」→ 安全快速复制
- **画面**：传送门，文件从一边传到另一边
- **常用**：`scp file user@host:/path`、`scp -r dir user@host:/path`
- **编码**：`传送门scp` → 安全远程复制

### 48. ping — 网络连通测试
- **功能**：测试与目标主机的连通性
- **缩写**：ping（声呐脉冲）
- **谐音**：「ping」→ 「乒」→ 乒乓球弹过去弹回来
- **画面**：声呐发出脉冲，等待回声
- **常用**：`ping google.com`、`ping -c 4`（发4个包）
- **编码**：`声呐ping` → 发脉冲等回声

### 49. netstat / ss — 网络状态
- **功能**：查看网络连接、端口、路由表
- **缩写**：**net**work **stat**istics / **s**ocket **s**tatistics
- **谐音**：「net stat」/「ss」→ 网络统计
- **画面**：通讯室的连接面板，每条线路亮灯表示连接状态
- **常用**：`ss -tlnp`（监听端口）、`netstat -tlnp`
- **编码**：`连接面板ss` → 查端口连接

### 50. iptables / firewall — 防火墙
- **功能**：管理网络安全规则
- **缩写**：**ip** **tables**（IP规则表）
- **谐音**：「iptables」→ 「IP桌子」→ IP规则桌
- **画面**：安检门，每个包裹按规则检查放行或拒绝
- **常用**：`iptables -L`（列出规则）、`iptables -A INPUT -p tcp --dport 80 -j ACCEPT`
- **编码**：`安检门iptables` → 网络过滤规则

## 六、管道与组合记忆

### 经典管道组合
```bash
# 1. 查找并统计
find . -name "*.py" | wc -l
# 画面：侦探找到所有py文件→交给计数员数数

# 2. 搜索并排序
grep "error" app.log | sort | uniq -c | sort -rn
# 画面：红笔圈出错误→排序→去重→按频率排序

# 3. 查看前10大文件
du -sh * | sort -rh | head -10
# 画面：量尺寸→按大小排序→取前10

# 4. 批量替换
find . -name "*.txt" | xargs sed -i 's/old/new/g'
# 画面：侦探找文件→传送带→自动纠错笔

# 5. 实时监控日志
tail -f /var/log/syslog | grep --line-buffered "error"
# 画面：卷轴实时展开→红笔实时圈错

# 6. 查看端口占用
ss -tlnp | grep :80
# 画面：连接面板→红笔圈80端口

# 7. 统计IP访问量
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -20
# 画面：切列刀取IP→排序→去重计数→取前20
```

### 管道思维链
```
数据源 → 过滤 → 转换 → 排序 → 去重 → 统计 → 输出
  │        │       │       │       │       │       │
 cat    grep    awk/cut  sort   uniq     wc    head/tail
```
