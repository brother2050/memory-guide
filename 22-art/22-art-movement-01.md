# 22-art-movement-01.md — 艺术流派记忆编码

> 20个艺术流派，助记谐音+画面联想，轻松记住年代、特征、代表人物。

---

## 编码 01 · 文艺复兴 (Renaissance)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1400–1600（14–16 世纪） |
| 特征 | 复兴古希腊罗马、透视法、人体解剖学、人文主义、理想美 |
| 代表人物 | 达芬奇、米开朗基罗、拉斐尔、波提切利、提香 |
| 谐音 | "文艺复兴"→ 文艺重新兴旺（复兴=重新兴起） |
| 画面 | 意大利佛罗伦萨，达芬奇、米开朗基罗、拉斐尔三杰在穹顶教堂前讨论透视法 |

> 💡 记忆锚点：文艺复兴是"人"的觉醒——从神的世界回到人的世界。

---

## 编码 02 · 巴洛克 (Baroque)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1600–1750（17–18 世纪初） |
| 特征 | 宏伟壮观、戏剧性光影、强烈情感、华丽装饰、曲线造型 |
| 代表人物 | 伦勃朗、鲁本斯、卡拉瓦乔、贝尼尼、维米尔 |
| 谐音 | "巴洛克"→ 巴不得落（洛克）下华丽的排场 |
| 画面 | 金色大教堂内部，卡拉瓦乔式的强烈明暗对比，鲁本斯的丰腴裸体在穹顶上 |

> 💡 记忆锚点：巴洛克是"戏剧化"的艺术——光打到脸上，像舞台聚光灯。

---

## 编码 03 · 洛可可 (Rococo)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1720–1780（18 世纪） |
| 特征 | 轻盈精致、粉彩色调、贝壳曲线、贵族享乐、田园爱情 |
| 代表人物 | 弗拉戈纳尔、布歇、华托 |
| 谐音 | "洛可可"→ 洛（落）下来的可可粉，甜蜜轻飘 |
| 画面 | 凡尔赛宫的闺房，粉红色墙壁上布满贝壳状金色雕花，贵族男女在秋千上调情 |

> 💡 记忆锚点：洛可可是巴洛克的"少女版"——粉色、甜蜜、不谈政治只谈恋爱。

---

## 编码 04 · 新古典主义 (Neoclassicism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1760–1830（18 世纪末–19 世纪初） |
| 特征 | 回归古典、理性克制、清晰线条、英雄主题、道德教化 |
| 代表人物 | 大卫、安格尔、卡诺瓦 |
| 谐音 | "新古典"→ 新的古典（用古罗马精神对抗洛可可的浮华） |
| 画面 | 卢浮宫中，大卫的《拿破仑加冕》巨幅油画，线条精确如建筑蓝图 |

> 💡 记忆锚点：新古典主义是法国大革命的"官方美术"——用罗马英雄画革命领袖。

---

## 编码 05 · 浪漫主义 (Romanticism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1790–1850（18 世纪末–19 世纪中） |
| 特征 | 情感至上、自然崇拜、异域风情、英雄悲剧、个人表达 |
| 代表人物 | 德拉克罗瓦、籍里柯、弗里德里希、透纳、戈雅 |
| 谐音 | "浪漫"→ 浪花般的漫溢情感（反对理性的束缚） |
| 画面 | 德拉克罗瓦的自由女神举旗冲锋，身后是暴风雨般的天空和燃烧的城市 |

> 💡 记忆锚点：浪漫主义是对新古典主义的"反叛"——不要理性要激情！

---

## 编码 06 · 现实主义 (Realism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1840–1880（19 世纪中叶） |
| 特征 | 描绘日常生活、反对理想化、关注底层、客观真实 |
| 代表人物 | 库尔贝、米勒、杜米埃、列宾 |
| 谐音 | "现实"→ 现在的实际情况（不美化不虚构） |
| 画面 | 库尔贝的《石工》，两个衣衫褴褛的工人弯腰砸石头，没有英雄光环 |

> 💡 记忆锚点：现实主义者说"画你看到的"——农民和工人第一次成为画的主角。

---

## 编码 07 · 印象派 (Impressionism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1860–1886（19 世纪后半叶） |
| 特征 | 户外写生、捕捉光影瞬间、碎笔触、色彩并置、日常生活 |
| 代表人物 | 莫奈、雷诺阿、德加、毕沙罗、西斯莱 |
| 谐音 | "印象"→ 只画印象（模糊的光影感觉，不画细节） |
| 画面 | 巴黎郊外草地午餐，阳光透过树叶洒下斑驳光点，笔触可见 |

> 💡 记忆锚点：印象派画家把画架搬到户外——"光线变了？换一幅！"

---

## 编码 08 · 后印象派 (Post-Impressionism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1886–1905（19 世纪末） |
| 特征 | 超越光影、强调结构与情感、个人风格鲜明、象征性色彩 |
| 代表人物 | 梵高、塞尚、高更、修拉 |
| 谐音 | "后印象"→ 印象派之后（对印象派的"升级"和"反叛"） |
| 画面 | 梵高的漩涡星空 + 塞尚的几何山 + 高更的原始岛屿——三种不同的"后" |

> 💡 记忆锚点：后印象派四个人四种方向——梵高要情感，塞尚要结构，高更要原始，修拉要科学。

---

## 编码 09 · 野兽派 (Fauvism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1905–1908（20 世纪初） |
| 特征 | 极端鲜艳色彩、粗犷笔触、简化造型、色彩自由 |
| 代表人物 | 马蒂斯、德兰、弗拉芒克 |
| 谐音 | "野兽"→ 野兽般的色彩（评论家说"多纳泰罗被野兽包围了"） |
| 画面 | 马蒂斯的《舞蹈》，几个红色裸体手拉手在绿色草地上狂舞 |

> 💡 记忆锚点：野兽派只有三年寿命，但马蒂斯用了一辈子——"我梦想的是一种平衡、纯洁、宁静的艺术"。

---

## 编码 10 · 立体主义 (Cubism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1907–1920（20 世纪初） |
| 特征 | 多视角同时呈现、几何碎片化、解构物体、单色调 |
| 代表人物 | 毕加索、布拉克、格里斯、莱热 |
| 谐音 | "立体"→ 把平面打碎成立体的多角度碎片 |
| 画面 | 毕加索画一张脸同时出现正面和侧面，像把立方体展开 |

> 💡 记忆锚点：立体主义是毕加索和布拉克的"二人转"——他们把物体拆成积木再重组。

---

## 编码 11 · 达达主义 (Dadaism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1916–1924（一战期间及战后） |
| 反艺术、荒诞、偶然性、拼贴、反战、质疑一切 |
| 代表人物 | 杜尚、阿尔普、曼·雷、施维特斯 |
| 谐音 | "达达"→ 婴儿学语的"达达"（无意义的声音，反对一切有意义的艺术） |
| 画面 | 杜尚把小便池签上名送去展览，旁边贴满报纸碎片和随机拼贴 |

> 💡 记忆锚点：达达主义者说"艺术是什么？什么都不是！"——他们在用荒诞回应战争的荒诞。

---

## 编码 12 · 超现实主义 (Surrealism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1924–1960s（20 世纪） |
| 特征 | 梦境与潜意识、荒诞组合、自动写作、弗洛伊德影响 |
| 代表人物 | 达利、马格利特、米罗、恩斯特、弗里达 |
| 谐音 | "超现实"→ 超越现实（梦境比现实更真实） |
| 画面 | 达利的融化的钟挂在枯枝上，马格利特的烟斗写着"这不是烟斗" |

> 💡 记忆锚点：超现实主义者相信——梦境才是真正的现实，清醒只是表象。

---

## 编码 13 · 抽象表现主义 (Abstract Expressionism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1943–1965（二战后·美国） |
| 特征 | 巨幅画布、自发性笔触、情感宣泄、行动绘画/色域绘画 |
| 代表人物 | 波洛克、德·库宁、罗斯科、纽曼、克莱因 |
| 谐音 | "抽象表现"→ 抽象地表现内心（不需要画具体的东西） |
| 画面 | 波洛克在地上的巨幅画布周围跳舞甩颜料，罗斯科的巨幅色块让人哭泣 |

> 💡 记忆锚点：抽象表现主义是美国第一个原创艺术运动——"纽约取代巴黎成为艺术中心"。

---

## 编码 14 · 波普艺术 (Pop Art)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1955–1970（20 世纪中叶） |
| 特征 | 大众文化图像、鲜艳色彩、重复排列、商业与艺术融合 |
| 代表人物 | 沃霍尔、利希滕斯坦、汉密尔顿、霍克尼 |
| 谐音 | "波普"→ popular（流行）的缩写，流行即艺术 |
| 画面 | 沃霍尔的玛丽莲·梦露头像重复排列成网格，利希滕斯坦的漫画大圆点 |

> 💡 记忆锚点：波普艺术家说"艺术不在画廊里，在超市货架上"——罐头也是艺术。

---

## 编码 15 · 极简主义 (Minimalism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1960–1975（20 世纪中后叶） |
| 特征 | 极度简化、几何形式、工业材料、去除个人表达、客观性 |
| 代表人物 | 唐纳德·贾德、丹·弗莱文、安德烈、勒维特 |
| 谐音 | "极简"→ 极致的简单（少即是多） |
| 画面 | 白色展厅中只有几个相同的金属方盒子排列在地板上，荧光灯管靠在墙上 |

> 💡 记忆锚点：极简主义者说"如果你能减掉的都减掉了，剩下的就是对的"。

---

## 编码 16 · 中国画 (Chinese Painting)

| 项目 | 内容 |
|------|------|
| 年代 | 约公元前 2000 年至今（数千年传承） |
| 特征 | 毛笔水墨、散点透视、留白意境、诗书画印一体、师法自然 |
| 代表人物 | 顾恺之、范宽、郭熙、倪瓒、八大山人、齐白石、张大千 |
| 谐音 | "中国画"→ 中间留白的国画（留白是最大的画面） |
| 画面 | 宣纸上山峦叠嶂、云雾缭绕，一角小亭、一叶扁舟，大量留白 |

> 💡 记忆锚点：中国画的"空"不是没有，是"此处无物胜有物"——留白即是天空、水面、云雾。

---

## 编码 17 · 浮世绘 (Ukiyo-e)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1603–1868（江户时代·日本） |
| 特征 | 木版画、美人画/役者绘/风景画、平面化、轮廓线鲜明、蓝白色调 |
| 代表人物 | 葛饰北斋、歌川广重、喜多川歌麿、东洲斋写乐 |
| 谐音 | "浮世"→ 浮在世上的享乐（江户时代的世俗生活） |
| 画面 | 葛饰北斋的巨浪下，蓝色富士山远眺，木版画的线条清晰可数 |

> 💡 记忆锚点：浮世绘是"大众艺术"——便宜的版画让平民也能拥有艺术，后来"冲"到了欧洲。

---

## 编码 18 · 表现主义 (Expressionism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1905–1920（20 世纪初·德国/北欧） |
| 特征 | 扭曲变形、强烈色彩、内心情感外化、焦虑与恐惧 |
| 代表人物 | 蒙克、基尔希纳、诺尔德、康定斯基（早期）、席勒 |
| 谐音 | "表现"→ 表达内心表现（不是画看到的，是画感受到的） |
| 画面 | 蒙克的呐喊人形，基尔希纳的扭曲街道，席勒的痉挛般人体 |

> 💡 记忆锚点：表现主义画家的内心比外面的世界更扭曲——他们画的是焦虑的自画像。

---

## 编码 19 · 未来主义 (Futurism)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1909–1944（20 世纪初·意大利） |
| 特征 | 速度与力量、机器美学、动态线条、歌颂现代科技、反传统 |
| 代表人物 | 波丘尼、巴拉、塞韦里尼、卡拉 |
| 谐音 | "未来"→ 奔向未来的速度（崇拜汽车、飞机、工业） |
| 画面 | 波丘尼的《空间中连续性的独特形体》，一个奔跑的青铜人形被风吹得变形 |

> 💡 记忆锚点：未来主义者崇拜速度——"一辆赛车比萨莫色雷斯的胜利女神更美"。

---

## 编码 20 · 装置艺术 (Installation Art)

| 项目 | 内容 |
|------|------|
| 年代 | 约 1960 年代至今（20 世纪后半叶至今） |
| 特征 | 三维空间作品、观众参与、临时性、跨媒介、观念驱动 |
| 代表人物 | 卡普尔、埃利亚松、白南准、蔡国强、草间弥生 |
| 谐音 | "装置"→ 装上配置（在空间中安装整个体验） |
| 画面 | 蔡国强的火药爆破在天安门广场上空形成巨大脚印，埃利亚松的瀑布挂在美术馆里 |

> 💡 记忆锚点：装置艺术不是"挂墙上"的——你走进去，成为作品的一部分。
