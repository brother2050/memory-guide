## 二、函数类公式（函数宫殿）

函数宫殿共收录18个核心公式，涵盖三角函数、对数、指数、二次函数、数列等代数内容。

**记忆策略：**
- **三角函数**：用「僧人sin」和「渔夫cos」两个角色，通过「异名同名」「加减变号」等口诀区分
- **对数指数**：用「对讲机」和「树」的形象，记住「降级运算」规律
- **数列公式**：用「栅栏」和「比萨」的画面，区分等差等比

每个公式包含：编码口诀 → 画面联想 → 故事串联 → 对比记忆卡，共四层记忆保障。

### 1. 两角和差公式（正弦）

$$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$$

- **编码**：「正弦 = 异名相乘，符号不变」
- **画面**：一个**僧人**（sin）和一个**和尚**（cos）在**异**地（异名）相**乘**着木筏（±），符号旗帜飘扬方向不变
- **故事**：门厅里，僧人sinα和和尚cosβ在异地相遇，坐上木筏漂流，旗子方向（±）不变

### 2. 两角和差公式（余弦）

$$\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$$

- **编码**：「余弦 = 同名相乘，符号相反」
- **画面**：两个**渔夫**（cos-cos）在**同**一个渔场（同名）钓鱼，但他们总唱**反**调（符号相反）
- **故事**：客厅里，两个渔夫cosα和cosβ在同一渔场钓鱼，一个唱高音一个唱低音，正好反调
- **⚠️ 对比记忆**：sin用「异名不变」，cos用「同名相反」——僧人异乡不变心，渔夫同场唱反调

### 3. 二倍角公式（正弦）

$$\sin 2\alpha = 2\sin\alpha\cos\alpha$$

- **编码**：「双倍的僧人 = 2个僧人×和尚」
- **画面**：一对**双胞胎僧人**（2α）站在厨房门口，一个sin一个cos，两人合力抬着数字**2**
- **故事**：厨房门边，双胞胎僧人合力抬起大大的"2"字招牌

### 4. 二倍角公式（余弦）

$$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$$

- **编码**：「渔夫双倍 = 渔夫² - 僧人² = 三种等价面孔」
- **画面**：一个渔夫戴了**三副面具**：第一副脸上画着cos²-sin²，第二副画着2cos²-1，第三副画着1-2sin²
- **故事**：厨房里渔夫cos2α有三张面具可换，但本质是同一张脸
- **⚠️ 对比记忆**：sin2α只有一种形式，cos2α有三种——渔夫善变，僧人单纯

### 5. 正切和差公式

$$\tan(\alpha \pm \beta) = \frac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha\tan\beta}$$

- **编码**：「坦克（tan）相撞 = 上加下减，上下反号」
- **画面**：两辆**坦克**在阳台相遇，上面那辆加速（+），下面那辆减速（-），方向相反
- **故事**：阳台上两辆玩具坦克相撞，上面的往前冲，下面的往后退

### 6. 半角公式（正弦）

$$\sin\frac{\alpha}{2} = \pm\sqrt{\frac{1-\cos\alpha}{2}}$$

- **编码**：「半僧人 = 根号下(1-渔夫)/2」
- **画面**：一个**半个身体的僧人**（半角sin）站在根号形状的拱门下，手里拿着"1-渔夫"的牌子除以2

### 7. 半角公式（余弦）

$$\cos\frac{\alpha}{2} = \pm\sqrt{\frac{1+\cos\alpha}{2}}$$

- **编码**：「半渔夫 = 根号下(1+渔夫)/2」
- **画面**：半个渔夫站在同样的拱门下，但牌子上是"1+渔夫"
- **⚠️ 对比记忆**：sin半角用减号，cos半角用加号——僧人苦行要减，渔夫丰收要加

### 8. 正弦定理

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

- **编码**：「边与对角的正弦比 = 外接圆直径」
- **画面**：一个大**圆桌**（2R=外接圆直径）上坐着三个客人a/b/c，每人面前放着对面位置的僧人sinA/sinB/sinC
- **故事**：几何宫殿大门的圆桌上，客人a对面坐着僧人sinA，大家比例相同

### 9. 余弦定理

$$c^2 = a^2 + b^2 - 2ab\cos C$$

- **编码**：「毕达哥拉斯的修正版 = 勾股定理 - 2ab×渔夫」
- **画面**：毕达哥拉斯站在广场中央的三角形里，原本的c²=a²+b²上被一个渔夫cosC扣掉了2ab的部分
- **⚠️ 对比记忆**：直角时cos90°=0，退化为勾股定理——渔夫消失了

### 10. 和差化积

$$\sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$$

- **编码**：「两僧人合体 = 2×半僧和×半渔差」
- **画面**：两个僧人sinA和sinB在喷泉边合体，变成2倍的"半僧人"（平均角）乘以"半渔夫"（差角）

### 11. 积化和差

$$\sin\alpha\cos\beta = \frac{1}{2}[\sin(\alpha+\beta) + \sin(\alpha-\beta)]$$

- **编码**：「僧×渔 = 半×(僧和+僧差)」
- **画面**：僧人和渔夫的乘积在花园里被劈成两半，一半变成sin和，一半变成sin差

### 12. 对数定义

$$\log_a N = x \Leftrightarrow a^x = N$$

- **编码**：「对数 = 问底数a的x次方等于多少N」
- **画面**：一个**对讲机**（对数）对着大树（log形状）喊话：「a啊，你x次方后变成N了吗？」
- **故事**：门厅的对讲机挂在树上，不断询问底数a

### 13. 对数运算法则

$$\log_a(MN) = \log_a M + \log_a N$$

- **编码**：「对数的乘法变加法」
- **画面**：对讲机看到两个M和N相乘，自动把乘号变成加号——它只会做加法
- **⚠️ 对比记忆**：对数把乘→加，除→减，幂→乘——「降级运算」

### 14. 对数换底公式

$$\log_a b = \frac{\log_c b}{\log_c a}$$

- **编码**：「换底 = 新底做分母」
- **画面**：对讲机换了新底座c，原来的b站到上面（分子），原来的a沉到底下（分母）

### 15. 自然指数与对数

$$e^{\ln x} = x, \quad \ln e^x = x$$

- **编码**：「e和ln是天生一对，互为逆运算」
- **画面**：字母e和ln手牵手转圈，转了一圈回到原点x

### 16. 指数运算法则

$$a^m \cdot a^n = a^{m+n}, \quad (a^m)^n = a^{mn}$$

- **编码**：「同底相乘指数加，幂的幂指数乘」
- **画面**：两个a的快递包裹（m和n）堆在一起，标签上的指数数字自动相加；套了两层箱子（幂的幂），指数相乘

### 17. 二次函数顶点公式

$$x = -\frac{b}{2a}, \quad y = \frac{4ac - b^2}{4a}$$

- **编码**：「顶点x = 负b除以2a」
- **画面**：抛物线的顶端坐着一个**顶**着帽子的人，帽子上写着"-b/2a"
- **故事**：几何宫殿广场的抛物线喷泉顶点，帽子人的位置就是最值

### 18. 韦达定理

$$x_1 + x_2 = -\frac{b}{a}, \quad x_1 \cdot x_2 = \frac{c}{a}$$

- **编码**：「两根之和 = -b/a，两根之积 = c/a」
- **画面**：**卫达**（韦达）骑着一匹马，马背上驮着两根萝卜（两根），一根标着"和=-b/a"，另一根标着"积=c/a"

### 19. 等差数列求和

$$S_n = \frac{n(a_1 + a_n)}{2} = na_1 + \frac{n(n-1)}{2}d$$

- **编码**：「等差求和 = 项数×首尾平均」
- **画面**：一排等距的**栅栏**（等差），把首尾两根柱子的平均高度乘以柱子数量

### 20. 等比数列求和

$$S_n = \frac{a_1(1 - q^n)}{1 - q} \quad (q \neq 1)$$

- **编码**：「等比求和 = 首项×(1-公比ⁿ)/(1-公比)」
- **画面**：一个**比萨**（等比）被切成q^n份，分子是"1减去这些份"，分母是"1减去公比"

## 三、几何类公式（几何宫殿）

几何宫殿共收录10个核心公式，涵盖圆、椭圆、双曲线、距离、向量、球等几何内容。

**记忆策略：**
- **圆锥曲线**：用「鹅蛋」（椭圆）、「双臂」（双曲线）的形象，记住标准方程
- **距离公式**：用「点到线」和「平行铁轨」的画面，区分点到线距和平行线距
- **向量运算**：用「两支箭」的形象，点积看投影（cos），叉积看面积（sin）

每个公式配有「对比记忆卡」，帮助区分椭圆vs双曲线、点积vs叉积等易混公式。

### 21. 圆的面积与周长

$$C = 2\pi r, \quad S = \pi r^2$$

- **编码**：「周长 = 2πr（两圈派），面积 = πr²（派的平方）」
- **画面**：一个**派**（π）被切成两圈（2πr）的甜甜圈形状，面积是派乘以半径的平方

### 22. 扇形面积

$$S = \frac{1}{2}r^2\theta = \frac{1}{2}lr$$

- **编码**：「扇形面积 = ½×半径²×弧度 = ½×弧长×半径」
- **画面**：一把**扇子**（扇形）打开，面积就是扇骨（r）的平方乘以角度再减半

### 23. 椭圆方程

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

- **编码**：「椭圆 = x²/a² + y²/b² = 1，a是长半轴，b是短半轴」
- **画面**：一个**鹅蛋**（椭圆）被x和y两条线穿过，长轴a像鹅蛋的长方向，短轴b像窄方向

### 24. 椭圆焦距关系

$$c^2 = a^2 - b^2$$

- **编码**：「焦距² = 长² - 短²」
- **画面**：鹅蛋里住着两个**焦点**（c），它们的距离由长轴和短轴的差决定
- **⚠️ 对比记忆**：椭圆c²=a²-b²（长减短），双曲线c²=a²+b²（加）——椭圆压缩，双曲线拉伸

### 25. 双曲线方程

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$

- **编码**：「双曲线 = x²/a² - y²/b² = 1，中间是减号」
- **画面**：两条**曲线**像双臂张开，中间用减号连接——与椭圆的加号形成对比

### 26. 点到直线距离

$$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$

- **编码**：「点到线距离 = 代入绝对值 / 根号A²+B²」
- **画面**：一个**点**（x₀,y₀）站在直线Ax+By+C=0前面，把坐标塞进去，除以斜边长度

### 27. 两平行线距离

$$d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$$

- **编码**：「平行线距 = C值之差 / 根号A²+B²」
- **画面**：两条平行铁轨，距离就是两个C值的差除以同一个斜边

### 28. 向量数量积

$$\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta$$

- **编码**：「点积 = 模长乘积×夹角余弦」
- **画面**：两支**箭**（向量）射出，点积就是它们的长度乘上cos渔夫的值

### 29. 向量叉积模长

$$|\vec{a} \times \vec{b}| = |\vec{a}||\vec{b}|\sin\theta$$

- **编码**：「叉积模 = 模长乘积×夹角正弦 = 平行四边形面积」
- **画面**：两支箭交叉，形成的平行四边形面积就是叉积模——僧人sin值决定面积大小
- **⚠️ 对比记忆**：点积用cos（渔夫），叉积用sin（僧人）——点积看投影，叉积看面积

### 30. 球的体积与表面积

$$V = \frac{4}{3}\pi r^3, \quad S = 4\pi r^2$$

- **编码**：「球体积 = 4/3πr³，球面积 = 4πr²」
- **画面**：一个**足球**被切成三层（4/3），体积与r的三次方成正比；表面积是4个πr²的圆片拼成
- **故事**：花园里一个足球被切成三层，外面包着4片圆标签

## 四、微积分类公式（微积宫殿）

微积宫殿共收录10个核心公式，涵盖求导法则、积分公式、微积分基本定理等内容。

**记忆策略：**
- **求导法则**：用「sin僧人变cos渔夫」的形象，记住互为转世的关系
- **积分公式**：用「求导的逆运算」思路，指数加1除以新指数
- **牛顿-莱布尼茨**：用「两端各站一人」的画面，理解定积分与原函数的关系

**核心对比：** 求导是指数下楼梯（n→n-1），积分是指数上楼梯（n→n+1）。

### 31. 基本求导公式

$$(\sin x)' = \cos x, \quad (\cos x)' = -\sin x$$

- **编码**：「sin求导变cos，cos求导变负sin」
- **画面**：实验台上sin僧人求导后cos成渔夫；渔夫cos求导后变成sin僧人的**负**面——互为转世
- **⚠️ 对比记忆**：sin→cos（正变余），cos→-sin（余变负正）——记住sin开头，后续符号交替

### 32. 指数函数求导

$$(e^x)' = e^x, \quad (a^x)' = a^x \ln a$$

- **编码**：「e^x求导不变，a^x求导多乘lna」
- **画面**：字母e^x在显微镜下求导，完全不变（天然美）；a^x求导后多了一条lna的尾巴

### 33. 对数函数求导

$$(\ln x)' = \frac{1}{x}, \quad (\log_a x)' = \frac{1}{x\ln a}$$

- **编码**：「lnx求导 = 1/x，简洁优雅」
- **画面**：树形log求导后变成倒数1/x，像照镜子一样

### 34. 幂函数求导

$$(x^n)' = nx^{n-1}$$

- **编码**：「幂函数求导 = 指数下移，指数减1」
- **画面**：x的n次方在黑板上，指数n跳下来站到前面，自己变成n-1

### 35. 乘法求导法则（莱布尼茨）

$$(uv)' = u'v + uv'$$

- **编码**：「乘积求导 = 前导后不导 + 前不导后导」
- **画面**：两个小朋友u和v手拉手走路，轮流一个人走（求导）一个人站（不导），两趟的和
- **故事**：书架上两本书叠在一起，轮流抽出一本检查

### 36. 除法求导法则

$$\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$$

- **编码**：「商的求导 = (上导×下 - 上×下导) / 下²」
- **画面**：分数线上面u和下面v，分子是"高减低"（u'v-uv'），分母是v的平方
- **⚠️ 对比记忆**：乘法是加号（+），除法是减号（-）且多除以v²

### 37. 链式求导法则（复合函数）

$$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$$

- **编码**：「链式法则 = 层层拆解，像拆链条」
- **画面**：一串**链条**（chain）每个环节du/dx、dy/du依次相乘，中间变量u消掉

### 38. 基本积分公式

$$\int x^n dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$$

- **编码**：「积分 = 指数加1，除以新指数，加C」
- **画面**：黑板上求导的逆过程——指数n往上跳变成n+1，然后除以自己
- **⚠️ 对比记忆**：求导是指数减1，积分是指数加1——方向相反

### 39. 自然对数积分

$$\int \frac{1}{x} dx = \ln|x| + C$$

- **编码**：「1/x积分 = ln|x|，唯一的例外」
- **画面**：x的-1次方是唯一不能用幂函数积分公式的，它变成了ln——像一个特殊通道

### 40. 牛顿-莱布尼茨公式（微积分基本定理）

$$\int_a^b f(x)dx = F(b) - F(a)$$

- **编码**：「定积分 = 原函数在上下限的差」
- **画面**：**牛顿**和**莱布尼茨**在实验台两端各站一个（a和b），中间用f(x)连线，差值就是面积
- **故事**：这是微积分的核心——把求面积（积分）和求斜率（导数）连接起来的桥梁

## 五、易混淆公式对比卡

| 对比项 | 公式A | 公式B | 记忆口诀 |
|--------|-------|-------|---------|
| 和角sin vs cos | sin(α±β)=sinαcosβ±cosαsinβ | cos(α±β)=cosαcosβ∓sinαsinβ | sin异名不变号，cos同名变号 |
| 二倍角sin vs cos | sin2α=2sinαcosα（一种） | cos2α=cos²α-sin²α（三种） | 僧人单纯，渔夫善变 |
| 半角sin vs cos | sin半角用1-cosα | cos半角用1+cosα | 僧人苦行要减，渔夫丰收要加 |
| 椭圆 vs 双曲线 | c²=a²-b² | c²=a²+b² | 椭圆压缩用减，双曲线拉伸用加 |
| 点积 vs 叉积 | 用cosθ（标量） | 用sinθ（向量/面积） | 点积看投影（渔夫），叉积看面积（僧人） |
| 乘法导 vs 除法导 | (uv)'=u'v+uv' | (u/v)'=(u'v-uv')/v² | 乘加除减，除法多v² |
| 求导 vs 积分 | 指数n→n-1 | 指数n→n+1 | 求导下楼梯，积分上楼梯 |
| eˣ vs aˣ 求导 | (eˣ)'=eˣ（不变） | (aˣ)'=aˣlna（多尾巴） | e是天然美，a要化妆（加lna） |

## 六、公式推导链记忆

**三角函数推导链：**
```
定义 sin=对边/斜边 → 单位圆 → 和角公式 → 二倍角 → 半角 → 和差化积/积化和差
```
- 记忆路径：从定义出发，每一步都是上一步的**特例或变形**

**微积分推导链：**
```
极限定义 → 导数定义(f'(x)=lim) → 求导法则 → 不定积分(逆运算) → 定积分(牛顿-莱布尼茨)
```
- 记忆路径：导数和积分是**互逆**关系，像上楼和下楼

## 记忆方法对比表

| 方法 | 优点 | 缺点 | 适合人群 | 推荐指数 |
|------|------|------|----------|----------|
| **角色编码法**（僧人sin/渔夫cos） | 公式有"人格"，不易混淆 | 需要先建立角色系统 | 视觉型/故事型学习者 | ⭐⭐⭐⭐⭐ |
| **宫殿定位法**（函数/几何/微积宫殿） | 三座宫殿分类清晰 | 构建宫殿需要前期投入 | 有宫殿基础的人 | ⭐⭐⭐⭐⭐ |
| **对比记忆卡法** | 精准区分易混公式 | 只适用于成对公式 | 容易混淆公式的人 | ⭐⭐⭐⭐ |
| **推导链记忆法** | 理解公式之间的逻辑关系 | 需要理解推导过程 | 理解型学习者 | ⭐⭐⭐⭐ |
| **口诀记忆法** | 短小精悍，朗朗上口 | 只能记住大方向，细节不足 | 考前冲刺 | ⭐⭐⭐ |
| **手写强化法** | 肌肉记忆辅助 | 耗时较长 | 所有人（作为辅助） | ⭐⭐⭐ |

### 🎮 流行文化增强编码示例

| 公式 | 原编码 | 增强版（动漫/游戏/影视） | 记忆点 |
|------|--------|--------------------------|--------|
| sin(α±β) | 僧人异地相乘 | 像《火影忍者》两个不同忍村(sin×cos)的忍者联手 | 🔗 异名=不同村子 |
| cos(α±β) | 渔夫同场唱反调 | 像《海贼王》同一海贼团(cos×cos)的两个成员内讧 | 🔗 同名反号=同团内讧 |
| 椭圆 c²=a²-b² | 鹅蛋压缩 | 像《龙珠》里悟空在重力训练室被压扁 | 🔗 椭圆=被压扁的圆 |
| 双曲线 c²=a²+b² | 双臂拉伸 | 像《进击的巨人》巨人双臂张开 | 🔗 双曲线=张开的双臂 |
| (eˣ)'=eˣ | e天然美不变 | 像《美少女战士》水手月亮变身前后都美 | 🔗 eˣ=天然美=不变 |
| 牛顿-莱布尼茨 | 两端各站一人 | 像《复仇者联盟》钢铁侠和美国队长各站一端 | 🔗 两端=定积分上下限 |
