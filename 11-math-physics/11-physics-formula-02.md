## 四、静电学公式（电荷台区域）

### 1. 库仑定律

$$F = k\frac{q_1 q_2}{r^2}$$

- **编码**：「电荷力 = k×电荷积/距离²」
- **画面**：两个⚡电荷q₁和q₂在电荷台上，像🏹弓箭一样互相排斥或吸引，距离越远力越弱
- **⚠️ 对比记忆**：与万有引力F=Gm₁m₂/r²结构相同——都是平方反比

### 2. 电场强度定义

$$E = \frac{F}{q}$$

- **编码**：「电场 = 力/试探电荷」
- **画面**：在⚡电荷台放一个小小的试探电荷q，测量它受到的力F，比值就是电场E

### 3. 点电荷电场

$$E = k\frac{Q}{r^2}$$

- **编码**：「点电荷电场 = kQ/r²」
- **画面**：一个大⚡电荷Q在中心，周围电场像**太阳光芒**向外辐射，强度随距离平方衰减

### 4. 电势能

$$U = k\frac{q_1 q_2}{r}$$

- **编码**：「电势能 = kq₁q₂/r（比力多一层）」
- **画面**：两个电荷的电势能是力×距离的积分，比库仑力多一个r在分母（不是r²了）

### 5. 电势

$$V = k\frac{Q}{r}$$

- **编码**：「电势 = kQ/r（单位电荷的电势能）」
- **画面**：电势是把试探电荷设为1时的电势能——像"电压的高度"

### 6. 电容定义

$$C = \frac{Q}{U}$$

- **编码**：「电容 = 电荷/电压」
- **画面**：🫙罐子（电容）能装多少⚡电荷Q取决于电压U——C越大装得越多

### 7. 平行板电容器

$$C = \frac{\varepsilon_0 A}{d}$$

- **编码**：「电容 = ε₀×面积/距离」
- **画面**：两块平行金属板，面积A越大、距离d越近，电容C越大——像把🫙罐子做大做扁

### 8. 电容器储能

$$W = \frac{1}{2}CU^2 = \frac{Q^2}{2C}$$

- **编码**：「电容储能 = ½CU² = Q²/2C」
- **画面**：🫙罐子里储存的能量——有CU²和Q²/2C两种写法
- **⚠️ 对比记忆**：与动能Eₖ=½mv²形式相同——电容对应质量，电压对应速度

## 五、电路公式（电路板区域）

### 9. 欧姆定律

$$U = IR$$

- **编码**：「电压 = 电流 × 电阻」
- **画面**：🔌插头通电，电流I流过🚧挡路石(电阻)R，产生电压降U
- **场景**：电路板上串联电阻

### 10. 电阻定律

$$R = \rho\frac{L}{A}$$

- **编码**：「电阻 = 电阻率×长度/截面积」
- **画面**：🚧挡路石的电阻取决于材质(ρ)、长度L（越长越难通过）、截面积A（越粗越容易）

### 11. 电功率

$$P = UI = I^2R = \frac{U^2}{R}$$

- **编码**：「功率 = UI = I²R = U²/R，三种等价形式」
- **画面**：💡灯泡的功率——知道任意两个量就能算，像三把钥匙开同一把锁

### 12. 焦耳定律

$$Q = I^2Rt$$

- **编码**：「热量 = I²Rt」
- **画面**：🔥焦耳用I²Rt公式计算电热丝产生的热量——电流越大产热越快（平方关系！）

## 六、磁场与电磁感应（磁场线圈区域）

### 13. 安培力

$$F = BIL\sin\theta$$

- **编码**：「安培力 = 磁感应强度×电流×长度×sin夹角」
- **画面**：🔌通电导线在🧲磁场B中，受到安培力F——电流I、导线长度L、夹角θ都影响力的大小

### 14. 洛伦兹力

$$F = qvB\sin\theta$$

- **编码**：「洛伦兹力 = 电荷×速度×磁场×sin夹角」
- **画面**：⚡电荷以速度v在🧲磁场B中运动，受到洛伦兹力F——使电荷做**圆周运动**
- **⚠️ 对比记忆**：安培力作用在导线上（宏观），洛伦兹力作用在电荷上（微观）——安培力是洛伦兹力的宏观表现

### 15. 磁通量

$$\Phi = BS\cos\theta$$

- **编码**：「磁通量 = 磁感应强度×面积×cos夹角」
- **画面**：🧲磁铁的磁力线穿过线圈S，cosθ衡量线圈与磁场的"垂直程度"

### 16. 法拉第电磁感应定律

$$\varepsilon = -N\frac{\Delta\Phi}{\Delta t}$$

- **编码**：「感应电动势 = -匝数×磁通量变化率」
- **画面**：🧲**法拉第**在线圈中转磁铁，匝数N越多、磁通量变化越快，感应电动势越大
- **记忆口诀**：「法拉第发电：磁通变，电动势生，N匝放大，负号是楞次」

### 17. 楞次定律（方向判断）

$$\varepsilon = -\frac{d\Phi}{dt} \quad \text{（负号体现楞次定律）}$$

- **编码**：「感应电流的方向总是阻碍磁通量的变化」
- **画面**：🧲磁铁靠近线圈时，线圈产生**排斥**的磁场；磁铁远离时，产生**吸引**的磁场——总是"反抗变化"

### 18. 自感电动势

$$\varepsilon_L = -L\frac{dI}{dt}$$

- **编码**：「自感 = -自感系数×电流变化率」
- **画面**：线圈自己产生的感应电动势——电流变化越快、自感系数L越大，自感电动势越大

## 七、光学公式（光学暗室区域）

### 19. 折射定律（斯涅尔定律）

$$n_1 \sin\theta_1 = n_2 \sin\theta_2$$

- **编码**：「入射角×折射率 = 折射角×折射率」
- **画面**：🔦光线从空气进入水，角度弯折——折射率n越大，光线弯得越厉害

### 20. 全反射临界角

$$\sin C = \frac{n_2}{n_1} \quad (n_1 > n_2)$$

- **编码**：「临界角 = 小折射率/大折射率」
- **画面**：🔦光线从水（n₁大）射向空气（n₂小），角度太大时全部反射——**全反射**

### 21. 双缝干涉（明纹条件）

$$d\sin\theta = k\lambda \quad (k=0,\pm1,\pm2,...)$$

- **编码**：「明纹 = 缝距×sin角度 = 整数倍波长」
- **画面**：🔦光通过两条缝，形成明暗交替的条纹——明纹处光程差是波长的整数倍

### 22. 单缝衍射（暗纹条件）

$$a\sin\theta = k\lambda \quad (k=\pm1,\pm2,...)$$

- **编码**：「暗纹 = 缝宽×sin角度 = 整数倍波长」
- **⚠️ 对比记忆**：双缝干涉明纹用缝距d，单缝衍射暗纹用缝宽a——明暗互换，缝的角色互换

### 23. 薄膜干涉（等厚干涉）

$$2nd = (k+\frac{1}{2})\lambda \quad \text{(增强)}$$

- **编码**：「薄膜增强 = 2×折射率×厚度 = 半整数倍波长」
- **画面**：肥皂泡🫧的彩色条纹——薄膜上下表面反射的光干涉，厚度d决定颜色

## 八、近代物理公式（量子阁楼区域）

### 24. 光电效应方程

$$E_k = h\nu - W_0$$

- **编码**：「光电子动能 = 光子能量 - 逸出功」
- **画面**：**爱因斯坦**用🎾光子(hν)撞击金属表面，电子获得的动能=光子能量减去逸出功W₀
- **记忆口诀**：「光电效应：光子来，能量减逸出，剩下的给电子」

### 25. 光子能量

$$E = h\nu = \frac{hc}{\lambda}$$

- **编码**：「光子能量 = h×频率 = hc/波长」
- **画面**：🎾光子的能量由频率ν决定——频率越高（波长越短）能量越大

### 26. 德布罗意波长

$$\lambda = \frac{h}{p} = \frac{h}{mv}$$

- **编码**：「粒子波长 = h/动量」
- **画面**：🎱台球（粒子）也有波长！质量越大波长越短——宏观物体波长太小测不到

### 27. 玻尔原子模型

$$E_n = -\frac{13.6}{n^2} \text{ eV}$$

- **编码**：「第n轨道能量 = -13.6/n² eV」
- **画面**：🪐**玻尔**的原子像太阳系，电子在第n个轨道上，能量是-13.6/n²——n越大能量越高（负得越少）

### 28. 能级跃迁

$$h\nu = E_m - E_n \quad (m > n)$$

- **编码**：「光子能量 = 高能级 - 低能级」
- **画面**：电子从高轨道m跳到低轨道n，释放🎾光子，能量等于两能级之差

### 29. 质能方程

$$E = mc^2$$

- **编码**：「能量 = 质量 × 光速²」
- **画面**：🌞**爱因斯坦**站在太阳前——太阳每秒损失几百万吨质量，全部转化为能量E=mc²
- **记忆口诀**：「E=mc²，质量变能量，光速是桥梁」

### 30. 质量亏损与核能

$$\Delta E = \Delta m \cdot c^2$$

- **编码**：「核能 = 质量亏损 × c²」
- **画面**：⚛️原子核反应前后质量减少了Δm，减少的质量全部变成能量——这就是核能的来源

## 十、易混淆公式对比卡

| 对比项 | 公式A | 公式B | 记忆口诀 |
|--------|-------|-------|---------|
| 库仑定律vs万有引力 | F=kq₁q₂/r² | F=Gm₁m₂/r² | 都是平方反比，一个用电荷一个用质量 |
| 安培力vs洛伦兹力 | F=BILsinθ | F=qvBsinθ | 安培力是宏观(导线)，洛伦兹力是微观(电荷) |
| 电容储能vs动能 | W=½CU² | Eₖ=½mv² | 形式相同：C对应m，U对应v |
| 双缝明纹vs单缝暗纹 | dsinθ=kλ(明) | asinθ=kλ(暗) | 双缝明=单缝暗，缝的角色互换 |
| 电场Evs电势V | E=kQ/r² | V=kQ/r | 电场是r²分母，电势是r分母——电势"更温柔" |
| 感应电动势vs自感 | ε=-NΔΦ/Δt | ε_L=-LdI/dt | 外部磁通变→感应，自身电流变→自感 |
