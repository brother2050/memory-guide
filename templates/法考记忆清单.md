# ⚖️ 法考记忆清单

> 法考备考需要记忆大量法条和概念。用记忆宫殿+对比法+间隔重复，高效掌握。

## 📖 使用说明

### 什么时候用？
- 法考备考全程（建议提前6-12个月开始）
- 每天更新掌握程度，每周回顾进度

### 怎么用？
1. **选择科目**：从薄弱科目开始，或按考试重点排序
2. **选择记忆方法**：根据知识点类型选择合适的记忆技巧
3. **标记掌握程度**：用5个方框表示掌握程度（⬜⬜⬜⬜⬜）
4. **跟踪进度**：每周记录各科进展

### 掌握程度说明
| 符号 | 含义 | 标准 |
|------|------|------|
| ⬜⬜⬜⬜⬜ | 未开始 | 还没学习这个知识点 |
| 🟨⬜⬜⬜⬜ | 初步了解 | 知道概念，但记不牢 |
| 🟨🟨⬜⬜⬜ | 基本掌握 | 能回忆80%内容 |
| 🟨🟨🟨⬜⬜ | 熟练掌握 | 能准确回忆并举例 |
| 🟨🟨🟨🟨⬜ | 精通 | 能灵活运用，举一反三 |
| 🟨🟨🟨🟨🟨 | 完全掌握 | 考试必得分 |

### 小贴士
- 民法和刑法是重点科目，建议优先攻克
- 用对比法区分相似概念（如正当防卫vs紧急避险）
- 每周做一次模拟题，检验记忆效果
