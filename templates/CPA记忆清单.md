# 💰 CPA记忆清单

> CPA考试知识点多且杂。用记忆宫殿+编码+间隔重复，系统化记忆。

## 📖 使用说明

### 什么时候用？
- CPA备考全程（建议提前8-12个月开始）
- 每天更新掌握程度，每周回顾进度

### 怎么用？
1. **选择科目**：从薄弱科目开始，或按考试重点排序
2. **选择记忆方法**：根据知识点类型选择合适的记忆技巧
3. **标记掌握程度**：用5个方框表示掌握程度（⬜⬜⬜⬜⬜）
4. **跟踪进度**：每周记录各科进展

### 掌握程度说明
| 符号 | 含义 | 标准 |
|------|------|------|
| ⬜⬜⬜⬜⬜ | 未开始 | 还没学习这个知识点 |
| 🟨⬜⬜⬜⬜ | 初步了解 | 知道概念，但记不牢 |
| 🟨🟨⬜⬜⬜ | 基本掌握 | 能回忆80%内容 |
| 🟨🟨🟨⬜⬜ | 熟练掌握 | 能准确回忆并举例 |
| 🟨🟨🟨🟨⬜ | 精通 | 能灵活运用，举一反三 |
| 🟨🟨🟨🟨🟨 | 完全掌握 | 考试必得分 |

### 小贴士
- 会计是基础科目，建议优先攻克
- 税法适合用编码法记忆税率和计算公式
- 审计用程序记忆法，把审计流程串联起来
- 每周做一次模拟题，检验记忆效果
