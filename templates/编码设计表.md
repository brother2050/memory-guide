# 🎨 编码设计表

> 用于设计和评估记忆编码。好的编码是记忆的基础——谐音准确、画面具体、反查唯一。

## 📖 使用说明

### 什么时候用？
- 设计两位数编码（00-99）
- 设计扑克牌编码
- 设计专业术语编码
- 评估现有编码的质量

### 怎么用？
1. **确定目标信息**：要编码什么？（如：两位数、扑克牌、专业术语）
2. **列出候选编码**：每个信息点想2-3个候选方案
3. **四个维度评估**：谐音准确度、画面具体度、反查唯一性、普适性
4. **冲突检查**：确保新编码不与已有编码冲突
5. **确定最终编码**：选择最优方案，写下画面描述

### 四个维度说明
| 维度 | 说明 | 评判标准 |
|------|------|----------|
| 谐音准确度 | 编码与原始信息的谐音相似度 | 高=几乎一样，中=大致相似，低=勉强关联 |
| 画面具体度 | 编码转化后的画面是否具体生动 | 具体=有颜色/动作/细节，抽象=模糊不清 |
| 反查唯一性 | 看到编码能否唯一反推出原始信息 | 唯一=只能想到一个，有冲突=可能混淆 |
| 普适性 | 编码是否容易被大多数人理解 | 普适=通用知识，小众=只有自己懂 |

**冲突检查**（以编码"13=医生"为例）：
- [x] 与已有编码无同字冲突（没有其他编码也用"医生"）
- [x] 与已有编码无同类冲突（没有其他编码也用职业类）
- [x] 与已有编码无语义链冲突（"医生"和"医院"不会混淆）
- [x] 与已有编码无部件冲突（"医"字没有出现在其他编码中）

**最终编码**：
- 编码：13 = 医生
- 画面描述：一个穿白大褂的医生，戴着听诊器，手里拿着注射器

## 💡 编码设计技巧

1. **优先用谐音**：谐音是最自然的联想路径
2. **画面要具体**：有颜色、有动作、有细节的画面更容易记住
3. **避免抽象概念**："自由""幸福"这类词不好想象，换成具体物品
4. **保持一致性**：同类信息用同类编码（如人物类、动物类、物品类）
5. **定期审查**：每隔一段时间检查编码是否仍然好用，及时替换不顺手的
