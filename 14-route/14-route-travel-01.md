> 从天安门**大门**(01)进去，遇到**灵芝**(02)导游，坐在**椅子**(03)上休息后乘**帆船**(04)到王府井。第二天用**钩子**(05)爬上长城，用**勺子**(06)舀十三陵的水。第三天拄着**拐杖**(07)坐高铁到西安，**篱笆**(08)围住钟楼，**猫**(09)在回民街吃肉夹馍。第四天挥**棒球**(10)打兵马俑，用**筷子**(11)夹华清池的温泉蛋，**婴儿**(12)在大雁塔前拍照。第五天**医生**(13)陪我坐高铁到成都，用**钥匙**(14)开酒店门。第六天**鹦鹉**(15)带我看熊猫，**石榴**(16)在宽窄巷子裂开，**试管冒泡古街。第七天**篱笆**(18)围住都江堰，**药酒**(19)在青城山酿造，最后抽着**香烟**(20)飞回北京。

## 四、旅行证件号码的记忆

### 证件号码编码规则

```
身份证号（18位）：分段编码
  前6位：地区码 → 谐音编码（如110101=北京东城）
  中间8位：出生日期 → 日期编码
  后4位：顺序码+校验码 → 数字编码

护照号（9位）：分段编码
  前2位：字母 → 谐音编码
  后7位：数字 → 数字编码
```

### 身份证号记忆示例

**号码：110101 19900315 001X**

```
分段：
  11-筷子 01-门 01-门 → 筷子插在两扇门上（北京东城）
  1990-一九九零 → 19(药酒) + 90(酒瓶) → 药酒装在酒瓶里
  0315 → 03(椅) + 15(鹦鹉) → 椅子上有只鹦鹉
  001X → 00(鸡蛋) + 01(门) + X → 鸡蛋从门里滚出来，上面写着X

完整故事：
  筷子(11)插在两扇门(01+01)上，门后有药酒(19)装在酒瓶(90)里，
  椅子(03)上鹦鹉(15)在看，鸡蛋(00)从门(01)里滚出来写着X。
```

### 护照号记忆示例

**号码：E12345678**

```
分段：
  E → 谐音"鹅" → 02-鹅
  12-婴儿 34-山寺 56-蜗牛 78-青蛙

完整故事：
  灵芝(02)嘴里叼着婴儿(12)，婴儿在吃山寺(34)，
  面条上爬着蜗牛(56)，蜗牛旁边有只青蛙(78)。
```

### 银行卡号记忆示例

**号码：6225 8888 1234 5678**

```
分段：
  62-牛儿 25-二胡 → 牛儿拉二胡
  8888 → 88(爸爸) + 88(爸爸) → 两个爸爸在跳舞
  12-婴儿 34-山寺 → 婴儿听山寺钟声
  56-蜗牛 78-青蛙 → 蜗牛和青蛙赛跑

完整故事：
  牛儿(62)拉二胡(25)，两个爸爸(88+88)在跳舞，
  婴儿(12)听山寺钟声(34)，蜗牛(56)和青蛙(78)赛跑。
```

### 手机号记忆示例

**号码：138 1234 5678**

```
分段：
  13-医生 81-蚂蚁 → 医生养蚂蚁
  12-婴儿 34-山寺 → 婴儿听山寺钟声
  56-蜗牛 78-青蛙 → 蜗牛骑青蛙

完整故事：
  医生(13)养蚂蚁(81)，给婴儿(12)喂山寺(34)，
  蜗牛(56)骑着青蛙(78)来看病。
```

### 证件号码速记口诀

```
身份证：6+8+4，地区生日和序号
护照号：2字母+7数字，分段记忆最高效
银行卡：4-4-4-4四段式，每段故事串起来
手机号：3-4-4分三段，谐音故事记心间
```
