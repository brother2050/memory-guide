
## 二、楼层→房间→设施的编码体系

### 三级编码结构

```
层级1：楼层（宏观定位）
  B2=20, B1=10, 1F=01, 2F=02, 3F=03 ...

层级2：房间号（中观定位）
  房间号后两位 → 对应编码
  301 → 01(门), 312 → 12(婴儿), 325 → 25(二胡)

层级3：设施位置（微观定位）
  门=01, 窗=02, 桌=03, 椅=04, 柜=05, 灯=06
```

### 编码组合示例

```
找"3楼312房间的窗户"

  楼层：03-椅子
  房间：12-婴儿
  设施：02-鹅（窗户）

组合记忆：椅子上坐着婴儿，婴儿旁边有只鹅在窗台上

定位顺序：先找3楼 → 再找312号 → 再找窗户位置
```

## 三、用定位法（Method of Loci）记忆建筑布局

### 步骤

1. **选定记忆宫殿**：选择你熟悉的建筑（如你的家）
2. **建立对应关系**：建筑的每个区域 → 记忆宫殿的一个位置
3. **放置记忆内容**：将需要记忆的信息以夸张画面形式放在对应位置
4. **路线遍历**：按固定路线走一遍，回忆所有信息

### 实例：用自己家记忆医院布局

| 记忆宫殿位置 | 医院对应区域 | 放置的画面 |
|--------------|--------------|------------|
| 大门口 | 挂号大厅 | 门口排着长队，有人举着号牌 |
| 玄关 | 导诊台 | 玄关柜上站着一个穿白大褂的小人 |
| 客厅沙发 | 候诊区 | 沙发上坐满了穿病号服的布偶 |
| 厨房 | 药房 | 厨房里摆满了药瓶，锅里在熬中药 |
| 卧室 | 诊室 | 床上有个医生拿着听诊器 |
| 卫生间 | 检验科 | 马桶里装着试管和尿杯 |
| 阳台 | 手术室 | 阳台灯很亮，阳台上在做"手术" |
| 储藏室 | 放射科 | 储藏室里发出X光（荧光棒） |

### 进阶：双层定位法

```
第一层：建筑本身的空间结构
  ↓ 映射
第二层：记忆宫殿的具体位置

优势：即使没去过那栋建筑，也能通过记忆宫殿"预演"路线
```

## 四、紧急逃生路线记忆

### 核心原则

```
1. 永远记住最近的两个出口（主出口 + 备用出口）
2. 逃生方向：向下优先，远离火源
3. 关键设施位置：灭火器、消防栓、安全出口标志
```

### 逃生路线编码系统

| 编码 | 含义 | 记忆画面 |
|------|------|----------|
| E1 | 第一逃生出口（主） | 01-门 → 绿色发光的门 |
| E2 | 第二逃生出口（备） | 02-鹅 → 鹅指引你跑 |
| F1 | 最近灭火器 | 03-椅 → 椅子旁有灭火器 |
| A1 | 报警按钮 | 04-帆 → 帆形状的红色按钮 |
| S1 | 集合点 | 05-钩 → 钩子形状的集合标志 |

### 逃生路线记忆实例

**商场5楼火灾逃生**：

```
记忆链条：
  你在5F电影院(05-钩) → 听到警报(04-帆)
  → 看到安全出口标志(01-门) → 沿楼梯往下跑
  → 经过4F(04-帆) → 3F(03-椅) → 2F(02-鹅) → 1F(01-门)
  → 冲出大门(01-门) → 到达广场集合点(05-钩)

口诀：钩帆门，向下奔，鹅椅帆门到大门
```

**酒店房间逃生**：

```
入住后第一时间记忆（30秒法则）：

1. 数你的房间到最近安全出口有几扇门
   → 编码：我的房间(312=婴儿) → 走廊 → 安全出口(01-门)
   → 画面：婴儿爬过走廊，推开安全门

2. 摸黑走一遍（闭眼记忆）
   → 从房间门出发，右手摸墙，数转弯次数
   → 编码：右转(08-篱笆) → 直行(10-棒球) → 左转(07-拐杖)

3. 记住灭火器位置
   → 走廊中间的灭火器 = 编码 03-椅（椅子旁挂着红色灭火器）
```

### 逃生记忆口诀

```
入住先看逃生图，数门摸路记拐弯
主门备门都要记，灭火器在走廊间
烟大弯腰捂口鼻，向下跑完到集合
```

### 常见建筑逃生特点

| 建筑类型 | 逃生特点 | 记忆要点 |
|----------|----------|----------|
| 高层写字楼 | 防烟楼梯间、避难层 | 编码：每15层一个避难层=15-鹦鹉 |
| 商场 | 多出口、自动扶梯不可用 | 编码：找绿色EXIT=01-门 |
| 医院 | 病人行动不便、担架通道 | 编码：担架=03-椅（椅子形状） |
| 地铁站 | 向上跑、跟随人流 | 编码：向上=01-门（地面出口） |
| 学校 | 操场集合、班级点名 | 编码：操场=05-钩（旗杆钩子） |
