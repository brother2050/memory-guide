## 一、DNA/RNA/蛋白质编码

### DNA（脱氧核糖核酸）— 双螺旋梯子

**结构编码**：🧬 一个旋转的彩色梯子

| 组件 | 编码图像 | 记忆要点 |
|------|----------|----------|
| 磷酸基团 | 🟡 黄色珠子（梯子两侧的绳子） | 骨架，连接核苷酸 |
| 脱氧核糖 | 🔵 蓝色五边形（绳子上的结） | 五碳糖，比核糖少一个氧 |
| 碱基 | 🟢🔴 四色台阶（梯子的横档） | A-T配对（2个氢键），G-C配对（3个氢键） |
| 双螺旋 | 🧬 旋转的梯子 | 反向平行：一条5'→3'，另一条3'→5' |

### 四种碱基编码

| 碱基 | 全称 | 谐音 | 编码图像 | 配对 |
|------|------|------|----------|------|
| A | 腺嘌呤（Adenine） | "阿德尼" | 🍎 苹果（Apple的A） | 配对T |
| T | 胸腺嘧啶（Thymine） | "踢命" | 🌡️ 温度计（Temperature的T） | 配对A |
| G | 鸟嘌呤（Guanine） | "瓜宁" | 🐦 鸟在吃瓜（鸟嘌呤） | 配对C |
| C | 胞嘧啶（Cytosine） | "西托辛" | 🔵 蓝色圆圈（Circle的C） | 配对G |

### 配对口诀

> **"苹果配温度计，鸟配蓝圈"**
> A-T: 🍎🌡️（苹果放在温度计上）
> G-C: 🐦🔵（鸟站在蓝色圆圈上）

**氢键记忆**：
- A-T 两个氢键 → 像两根筷子夹住（容易分开）
- G-C 三个氢键 → 像三把锁锁住（更稳定）

> 口诀：**"AT两键GC三，GC含量热稳定"**

### RNA（核糖核酸）— 单链信使

| 组件 | 与DNA的区别 | 编码图像 |
|------|-------------|----------|
| 核糖 | 多一个氧（核糖 vs 脱氧核糖） | 🔴 红色五边形（比蓝色多一口气） |
| 碱基U | U代替T（尿嘧啶 Uracil） | 🌂 雨伞（Umbrella的U）代替温度计 |
| 单链 | 不是双螺旋 | 一条绳子不是梯子 |

### 三种RNA编码

| 类型 | 功能 | 谐音 | 编码图像 |
|------|------|------|----------|
| mRNA | 信使RNA，携带遗传信息 | "m=信（message）" | 📜 一封密信（带着密码子序列） |
| tRNA | 转运RNA，搬运氨基酸 | "t=搬（transfer）" | 🧲 一块磁铁搬运货物（氨基酸） |
| rRNA | 核糖体RNA，组成核糖体 | "r=工厂（ribosome）" | 🏭 工厂的框架结构 |

### 蛋白质

| 概念 | 编码图像 | 记忆要点 |
|------|----------|----------|
| 氨基酸 | 🧱 彩色积木 | 20种氨基酸=20种积木 |
| 肽键 | 🔗 链条环 | 积木之间用链条连接 |
| 一级结构 | 一条直线积木链 | 氨基酸序列 |
| 二级结构 | 🌀 螺旋弹簧 | α螺旋和β折叠 |
| 三级结构 | 🎀 打结的绳子 | 三维折叠 |
| 四级结构 | 🎁 多条绳子缠在一起 | 多个亚基组装 |

## 二、遗传密码表记忆（20个氨基酸）

### 密码子基础

- 4种碱基，3个一组 → 64种密码子
- 61个编码氨基酸 + 3个终止密码子
- **起始密码子**：AUG（甲硫氨酸/蛋氨酸）
- **终止密码子**：UAA、UAG、UGA

### 终止密码子记忆

> **UAA = "U Are Away"（你走了）**
> **UAG = "U Are Gone"（你消失了）**
> **UGA = "U Go Away"（你滚蛋）**

### 密码子简并性记忆技巧

**"三的倍数就是多"**：
- 亮氨酸(Leu)有6个密码子 → 最多
- 丝氨酸(Ser)有6个密码子 → 并列最多
- 甲硫氨酸(Met)只有1个密码子(AUG) → 唯一（同时也是起始密码子）
- 色氨酸(Trp)只有1个密码子(UGG) → 唯一

**记忆口诀**：
> "蛋色唯一不简并，亮丝最多有六个"
> （甲硫氨酸和色氨酸只有1个密码子，亮氨酸和丝氨酸各有6个）

## 三、中心法则流程记忆

### 中心法则流程图

```
        ┌──────────────┐
        │     DNA      │ ← 遗传信息的"总部"
        └──┬───────┬───┘
     复制↙       ↘转录
    ┌────┐      ┌────┐
    │DNA │      │RNA │
    └────┘      └──┬─┘
                   │翻译
                   ↓
                ┌────┐
                │蛋白质│ ← 生命功能的"执行者"
                └────┘

  特殊路径（病毒）：
  RNA → RNA（RNA复制）
  RNA → DNA（逆转录）← 逆转录病毒（如HIV）
```

### 流程步骤记忆宫殿

**三步走宫殿法**：

| 步骤 | 过程 | 模板→产物 | 编码图像 | 谐音 |
|------|------|-----------|----------|------|
| 1. 复制 | DNA→DNA | 旧DNA模板合成新DNA | 🖨️ 复印机复制文件 | "复印" |
| 2. 转录 | DNA→RNA | DNA模板合成mRNA | 📝 抄写员在抄写 | "抄写" |
| 3. 翻译 | RNA→蛋白质 | mRNA密码子翻译成氨基酸链 | 🌐 翻译官把密信翻译成行动 | "翻译" |

### 复制细节编码

| 组件 | 编码图像 | 记忆要点 |
|------|----------|----------|
| 解旋酶 | ✂️ 剪刀 | 剪开双链的氢键 |
| DNA聚合酶 | 🧵 缝纫机 | 沿着模板缝合新链 |
| 引物酶 | 🏁 起跑旗 | 放置RNA引物开始合成 |
| 前导链 | ➡️ 直路 | 连续合成（5'→3'） |
| 后随链 | 🔄 弯路 | 不连续合成（冈崎片段） |
| 连接酶 | 🔗 链条 | 连接冈崎片段 |

### 转录细节编码

| 组件 | 编码图像 | 记忆要点 |
|------|----------|----------|
| RNA聚合酶 | 🚂 火车头 | 沿DNA模板链前进合成RNA |
| 启动子 | 🚦 红绿灯 | 转录起始信号（如TATA box） |
| 终止子 | 🛑 停车标志 | 转录终止信号 |
| 模板链 | 📋 模板纸 | 3'→5'方向读取 |
| 编码链 | 📄 正文纸 | 5'→3'方向，序列与mRNA相同（T→U） |

### 翻译细节编码

| 组件 | 编码图像 | 记忆要点 |
|------|----------|----------|
| 核糖体 | 🏭 工厂 | 蛋白质合成的车间 |
| mRNA | 📜 密信 | 携带密码子的信使 |
| tRNA | 🧲 磁铁搬运工 | 搬运氨基酸，反密码子配对 |
| 起始密码子AUG | 🏁 起跑线 | 翻译开始 |
| 终止密码子UAA/UAG/UGA | 🏁 终点线 | 翻译结束 |

### 翻译过程故事法

> 一封**密信（mRNA）**送到**工厂（核糖体）**门口。
> 工厂读到**起跑线密码AUG**，第一个**磁铁搬运工（tRNA）**搬来**蛋氨酸（🥚）**。
> 接着一个接一个的搬运工排队送来**彩色积木（氨基酸）**，
> 积木用**链条（肽键）**串起来，越串越长。
> 工厂读到**终点密码（UAA）**，搬运工说"**U Are Away**"，翻译结束！
> 一条**蛋白质链**诞生了，开始折叠成三维形状。

### 遗传方式速记口诀

> **"常隐：无中生有为隐性，生女患病为常隐"**
> **"常显：有中生无为显性，生女正常为常显"**
> **"X隐：母患子必患，女患父必患"**
> **"X显：父患女必患，子患母必患"**

### 遗传系谱图判断法

```
步骤1: 判断显隐性
  ├── 双亲正常→子女患病 → 隐性
  └── 双亲患病→子女正常 → 显性

步骤2: 判断常/X染色体
  ├── 隐性：看女患者的父亲和儿子
  │   ├── 父亲正常 → 常隐
  │   └── 父亲患病 → 可能X隐
  └── 显性：看男患者的母亲和女儿
      ├── 母亲正常 → 常显
      └── 母亲患病 → 可能X显
```

## 🔴 遗传学常见错误提醒

| ❌ 常见错误 | ✅ 正确表述 | 记忆锚点 |
|------------|-----------|----------|
| DNA复制只在细胞核中进行 | 线粒体和叶绿体中也进行DNA复制 | 半自主细胞器 |
| 基因都在染色体上 | 线粒体和叶绿体中也有基因 | 细胞质基因 |
| 显性基因一定比隐性基因多 | 显隐性与基因频率无关 | 显性≠频率高 |
| 杂合子自交后代一定3:1 | 3:1是理想比例，实际有偏差 | 3:1=理论值 |
| 基因突变一定有害 | 基因突变多数中性，少数有利或有害 | 突变≠有害 |
| 基因重组只发生在减数分裂 | 基因重组主要发生在减数分裂 | 减数分裂=重组 |
| 染色体变异只影响数量 | 染色体变异包括结构变异和数量变异 | 结构+数量 |
| 所有遗传病都是单基因遗传病 | 遗传病包括单基因、多基因和染色体异常遗传病 | 三类遗传病 |
| 近亲结婚一定生出遗传病患儿 | 近亲结婚增加遗传病风险，不是一定生出 | 风险增加≠一定 |
| 基因治疗已经完全成熟 | 基因治疗仍在发展中，存在风险 | 基因治疗=发展中 |

### 遗传学核心概念层级图
```
遗传学
├── 遗传的分子基础
│   ├── DNA结构(双螺旋)
│   ├── DNA复制(半保留复制)
│   ├── 转录(DNA→mRNA)
│   └── 翻译(mRNA→蛋白质)
├── 遗传的基本规律
│   ├── 分离定律(一对相对性状)
│   ├── 自由组合定律(两对相对性状)
│   └── 连锁与互换(基因在同一条染色体上)
├── 变异
│   ├── 基因突变(DNA碱基对改变)
│   ├── 基因重组(基因重新组合)
│   └── 染色体变异(结构/数量改变)
└── 遗传病
    ├── 单基因遗传病(显/隐性)
    ├── 多基因遗传病
    └── 染色体异常遗传病
```
