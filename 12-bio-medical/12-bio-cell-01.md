## 一、细胞工厂类比法

### 核心理念：细胞 = 一座超级工厂

把整个细胞想象成一座**高度自动化的生化工厂**，每个细胞器就是工厂里的一个部门。

│                                                  │
│  ┌──────────────────────────────────────────┐    │
│  │ 🏗️ 细胞壁 = 工厂围墙（植物细胞）         │    │
│  │  ┌──────────────────────────────────┐    │    │
│  │  │ 🧱 细胞膜 = 工厂大门（保安系统）  │    │    │
│  │  │                                  │    │    │
│  │  │  🏛️ 细胞核 = 总部大楼（CEO办公）  │    │    │
│  │  │  ├─ 染色体 = 蓝图档案室           │    │    │
│  │  │  └─ DNA = 蓝图原件                │    │    │    │
│  │  │                                  │    │    │
│  │  │  ⚡ 线粒体 = 发电站               │    │    │

## 二、25个细胞结构和功能详细编码

### 1. 细胞膜（Cell Membrane）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞最外层（动物细胞）或细胞壁内侧（植物细胞） |
| 形状 | 薄薄的一层膜，厚约7-8nm |
| 功能 | 控制物质进出（选择透过性）、细胞识别、信息传递 |
| 谐音 | "细胞门"（细胞的大门） |
| 画面 | 🧱 一堵智能墙，有选择性地开关各种通道，有的物质能过，有的被拦住 |
| 工厂类比 | 工厂大门+保安系统：检查进出人员和货物，放行需要的，拒绝不需要的 |

**结构记忆**：磷脂双分子层 = 两排油脂分子背对背排列
- 亲水头部（朝外）= 🟡 黄色小球
- 疏水尾部（朝内）= 🔵 两条蓝色尾巴
- 蛋白质 = 🟢 嵌在膜中的绿色门（通道蛋白、载体蛋白）

### 2. 细胞质（Cytoplasm）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞膜以内、细胞核以外的全部区域 |
| 形状 | 胶状物质，半透明 |
| 功能 | 细胞代谢的主要场所，各种细胞器悬浮其中 |
| 谐音 | "细胞酱"（像果酱一样的胶状物质） |
| 画面 | 🌊 一锅浓稠的果酱，里面漂浮着各种小工具 |
| 工厂类比 | 工厂车间的地面和空间：所有设备和工人都在这里工作 |

### 3. 细胞核（Nucleus）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞中央（通常） |
| 形状 | 球形或椭球形，直径约5-10μm |
| 功能 | 遗传信息库，控制细胞代谢和遗传 |
| 谐音 | "细胞核"（核心，像果核） |
| 画面 | 🏛️ 一座宏伟的总部大楼，里面有蓝图档案室（染色体）和CEO（DNA） |
| 工厂类比 | 工厂总部大楼：CEO在这里制定所有生产计划，发出所有指令 |

**关键结构**：
- **核膜（双层膜）**：总部大楼的外墙，有核孔（门卫）
- **核仁**：总部里的"人事部"，负责rRNA的合成和核糖体组装
- **染色质/染色体**：蓝图档案室，储存所有遗传蓝图
- **核孔**：总部大楼的传送门，大分子进出的通道

### 4. 线粒体（Mitochondria）

| 维度 | 编码 |
|------|------|
| 位置 | 散布在细胞质中 |
| 形状 | 棒状或椭球形，直径0.5-1μm，有双层膜 |
| 功能 | 有氧呼吸的主要场所，"细胞的动力车间"，产生ATP |
| 谐音 | "线粒体"→"献力体"（奉献力量的身体） |
| 画面 | ⚡ 一座小型发电站，烟囱冒着烟（消耗O₂，释放CO₂），不断输出电力（ATP） |
| 工厂类比 | 工厂发电站：燃烧燃料（有机物+O₂），产生电力（ATP），供全厂使用 |

**内部结构记忆**：
- 外膜 = 发电站外墙（平滑）
- 内膜 = 发电站内部管道（向内折叠形成**嵴**，增加表面积）
- 基质 = 管道内的液体（含DNA、核糖体——半自主细胞器！）
- 嵴 = 🏔️ 山脊一样的褶皱

**有氧呼吸三阶段**：
1. 糖酵解（细胞质基质）→ 葡萄糖→2丙酮酸+2ATP+2NADH
2. 丙酮酸氧化+柠檬酸循环（线粒体基质）→ 产生CO₂+NADH+FADH₂
3. 电子传递链+氧化磷酸化（线粒体内膜）→ 产生大量ATP（约34个）

> 口诀：**"糖酵解在质中，丙酮酸进线粒体，嵴上电子传传传，ATP哗哗来"**

### 5. 叶绿体（Chloroplast）

| 维度 | 编码 |
|------|------|
| 位置 | 植物细胞的细胞质中 |
| 形状 | 扁平椭球形，直径3-6μm，双层膜 |
| 功能 | 光合作用的场所，"养料制造车间"和"能量转换站" |
| 谐音 | "叶绿体"→"也绿体"（也是绿色的身体） |
| 画面 | 🌿 一座太阳能电站，屋顶铺满绿色太阳能板（类囊体），把阳光变成糖（有机物） |
| 工厂类比 | 工厂太阳能板+食品加工厂：用阳光+CO₂+水，制造糖（食物） |

**内部结构记忆**：
- 外膜 = 太阳能电站外墙
- 内膜 = 电站内墙
- 基质（stroma）= 电站内部空间（暗反应场所）
- 类囊体（thylakoid）= 📚 一摞摞扁平的绿色饼（光反应场所）
- 基粒（grana）= 类囊体堆叠形成的柱状结构
- 叶绿素 = 🟢 绿色颜料，吸收红光和蓝紫光

**光合作用两阶段**：
1. **光反应**（类囊体薄膜）：光能→ATP+NADPH+O₂
2. **暗反应/碳反应**（基质）：CO₂→C₃→G3P→葡萄糖

> 口诀：**"光反应在类囊体，水光解产ATP；暗反应在基质里，CO₂固定变糖吃"**

### 6. 内质网（Endoplasmic Reticulum, ER）

| 维度 | 编码 |
|------|------|
| 位置 | 从核膜延伸出来的膜性管道网络 |
| 形状 | 扁平囊泡和管道交织成网 |
| 功能 | 蛋白质合成加工（粗面ER）、脂质合成（滑面ER） |
| 谐音 | "内织网"（内部编织的网） |
| 画面 | 🏗️ 一条生产流水线，管道四通八达，粗面ER上站满了工人（核糖体），滑面ER光滑无工人 |
| 工厂类比 | 工厂生产流水线：粗面ER = 有工人的生产线（造蛋白质），滑面ER = 自动化生产线（造脂质） |

**两种类型**：
- **粗面内质网（RER）**：表面附着核糖体 → 蛋白质合成和初步加工
- **滑面内质网（SER）**：表面光滑无核糖体 → 脂质合成、解毒、Ca²⁺储存

> 口诀：**"粗面有颗粒，专造蛋白质；滑面光溜溜，脂质和解毒"**

### 7. 高尔基体（Golgi Apparatus）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞核附近 |
| 形状 | 一摞扁平囊泡，有形成面（凸面）和成熟面（凹面） |
| 功能 | 蛋白质的加工、分类、包装和运输 |
| 谐音 | "高尔基"→"搞尔寄"（搞好打包寄出去） |
| 画面 | 📦 一个快递打包中心：货物从流水线送来，工人分类、贴标签、打包、发货 |
| 工厂类比 | 工厂包装发货中心：把生产线上做好的产品分类包装，贴上地址标签，发送到目的地 |

**记忆要点**：
- 形成面（cis面）= 入货口（接收来自内质网的蛋白质）
- 成熟面（trans面）= 发货口（包装好的囊泡运输出去）
- 在植物细胞中 → 还参与细胞壁的形成

### 8. 溶酶体（Lysosome）

| 维度 | 编码 |
|------|------|
| 位置 | 散布在细胞质中 |
| 形状 | 球形囊泡，单层膜 |
| 功能 | "消化车间"，含多种水解酶，分解衰老细胞器和外来物质 |
| 谐音 | "溶酶体"→"融酶体"（用酶融化一切的身体） |
| 画面 | 🗑️ 一个冒着酸气的垃圾桶，里面的强酸酶能溶解任何废物 |
| 工厂类比 | 工厂废物处理车间：把废品、旧设备拆解回收，把有害物质中和处理 |

**记忆要点**：
- 内部pH≈5（酸性环境，适合酶活性）
- 自噬作用 = 🔄 回收旧细胞器
- 异噬作用 = 🦠 消化外来物质（如细菌）
- 如果溶酶体破裂 → 细胞自溶（细胞被自己消化）

### 9. 核糖体（Ribosome）

| 维度 | 编码 |
|------|------|
| 位置 | 游离在细胞质中或附着在粗面内质网上 |
| 形状 | 极小的颗粒（约20-30nm），由大小两个亚基组成 |
| 功能 | 蛋白质合成的场所，"生产蛋白质的机器" |
| 谐音 | "核糖体"→"核糖粒"（生产核糖的小颗粒） |
| 画面 | 🔧 一群微型组装工人，每人拿着扳手，把氨基酸一个个拧在一起做成蛋白质 |
| 工厂类比 | 工厂组装工人：按照mRNA的指令（图纸），把氨基酸（零件）组装成蛋白质（产品） |

**记忆要点**：
- 由rRNA和蛋白质组成
- 原核生物：70S（50S+30S）
- 真核生物：80S（60S+40S）
- 游离核糖体 → 合成细胞内使用的蛋白质
- 附着核糖体 → 合成分泌蛋白、膜蛋白

### 10. 中心体（Centrosome）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞核附近 |
| 形状 | 由两个互相垂直的中心粒组成，每个中心粒是9组三联微管 |
| 功能 | 与细胞分裂有关，形成纺锤体 |
| 谐音 | "中心体"→"中心柱"（中心的柱子，指挥分裂） |
| 画面 | 🎯 一个十字准星，在细胞分裂时指挥纺锤丝像蜘蛛网一样展开 |
| 工厂类比 | 工厂分裂指挥官：当工厂要一分为二时，它指挥搬运队把货物平均分到两个新工厂 |

**记忆要点**：
- 只存在于动物细胞和低等植物细胞
- 高等植物细胞没有中心体，但仍能形成纺锤体
- 在有丝分裂间期复制，分裂期移向两极

### 11. 液泡（Vacuole）

| 维度 | 编码 |
|------|------|
| 位置 | 植物细胞中央（大液泡） |
| 形状 | 泡状结构，成熟植物细胞有一个大液泡，占细胞体积90% |
| 功能 | 储存水分、营养物质、代谢废物；维持细胞形态 |
| 谐音 | "液泡"→"液宝"（液体的宝库） |
| 画面 | 💧 一个巨大的透明水球占据了细胞中央，里面溶解着花青素（紫色）、糖分和有机酸 |
| 工厂类比 | 工厂中央仓库/水箱：储存原料和废品，调节工厂内部水压 |

**记忆要点**：
- 植物细胞的大液泡 → 维持细胞的膨压（挺拔）
- 液泡膜具有选择透过性
- 花青素在液泡中 → 花的颜色由液泡决定

### 12. 细胞壁（Cell Wall）

| 维度 | 编码 |
|------|------|
| 位置 | 植物细胞最外层 |
| 形状 | 坚硬的外壳，厚约0.1μm |
| 功能 | 支持和保护细胞，维持细胞形态 |
| 谐音 | "细胞壁"→"细胞必"（细胞必须有的保护墙） |
| 画面 | 🏗️ 一层坚硬的砖墙围在细胞外面，比细胞膜更外层 |
| 工厂类比 | 工厂围墙：保护工厂不受外界侵害，给工厂提供结构支撑 |

**记忆要点**：
- 主要成分：纤维素（植物）、几丁质（真菌）、肽聚糖（细菌）
- 全透性（不是选择透过性）
- 细胞壁≠细胞膜

### 13. 染色体（Chromosome）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞核内 |
| 形状 | 棒状结构（分裂期可见），由DNA+蛋白质组成 |
| 功能 | 遗传信息的载体 |
| 谐音 | "染色体"→"染色梯"（被染料染上颜色的梯子） |
| 画面 | 🪜 一条被染成深色的X形梯子，由DNA双螺旋缠绕组蛋白形成 |
| 工厂类比 | 蓝图档案室里的卷轴：平时松散（染色质），需要时卷紧（染色体） |

**记忆要点**：
- 染色质 = 间期松散状态（DNA+蛋白质的松散复合物）
- 染色体 = 分裂期紧缩状态（螺旋化后可见）
- 同一种物质的两种形态！

> 口诀：**"间期是线（染色质），分裂是棒（染色体），同一物质两种样"**

### 14. DNA（脱氧核糖核酸）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞核（主要）、线粒体、叶绿体（少量） |
| 形状 | 双螺旋结构 |
| 功能 | 储存遗传信息，自我复制 |
| 谐音 | "DNA"→"大拿"（遗传界的大拿） |
| 画面 | 🧬 一条旋转的彩色梯子，梯子横档是碱基对 |

（详见遗传学记忆系统 12-bio-genetics-01.md）

### 15. RNA（核糖核酸）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞核、细胞质 |
| 形状 | 单链 |
| 功能 | 遗传信息的传递和表达 |
| 谐音 | "RNA"→"人拿"（人拿去传递信息） |
| 画面 | 📜 一条单链纸条，上面写着遗传密码 |

### 16. 蛋白质（Protein）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞各处 |
| 形状 | 多种形状：球状、纤维状、膜蛋白等 |
| 功能 | 结构支持、催化反应（酶）、运输、免疫、调节等 |
| 谐音 | "蛋白质"→"蛋白蛋"（像蛋白一样的物质） |
| 画面 | 🧱 各种形状的彩色积木，有的像螺旋弹簧，有的像折叠的纸鹤 |

### 17. ATP（三磷酸腺苷）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞各处（主要在线粒体和叶绿体产生） |
| 形状 | 核苷酸衍生物，含三个磷酸基团 |
| 功能 | 细胞的直接能源物质，"能量通货" |
| 谐音 | "ATP"→"爱提款"（爱从ATP里提取能量） |
| 画面 | 🔋 一个充电电池，三个磷酸基团像三层蛋糕，断掉一层释放能量 |

**记忆要点**：
- ATP → ADP + Pi + 能量（水解释放能量）
- ADP + Pi + 能量 → ATP（光合/呼吸储存能量）
- 细胞中ATP含量很少，但转化速度极快

> 口诀：**"ATP是电池，用完充电再继续；断磷放能合磷存，时时刻刻在循环"**

### 18. NADPH（还原型辅酶Ⅱ）

| 维度 | 编码 |
|------|------|
| 位置 | 叶绿体（光反应产生）、细胞质 |
| 形状 | 辅酶分子 |
| 功能 | 光合作用暗反应的还原剂，提供[H]和能量 |
| 谐音 | "NADPH"→"拿得泼H"（拿着泼出去的H原子） |
| 画面 | 🧪 一个装满H原子的试管，准备泼向CO₂使其还原 |

### 19. mRNA（信使RNA）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞核（转录产生）→细胞质（翻译场所） |
| 形状 | 单链，携带密码子序列 |
| 功能 | 携带DNA的遗传信息到核糖体，指导蛋白质合成 |
| 谐音 | "mRNA"→"密信RNA"（m=message，传递密信的RNA） |
| 画面 | 📜 一封从总部大楼（细胞核）发出的密信，上面写着生产指令（密码子），送到工厂车间（核糖体） |

### 20. tRNA（转运RNA）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞质 |
| 形状 | 三叶草形（二级结构），有反密码子环和氨基酸结合位点 |
| 功能 | 搬运氨基酸到核糖体，识别mRNA上的密码子 |
| 谐音 | "tRNA"→"挑RNA"（挑着氨基酸的RNA） |
| 画面 | 🧲 一个三叶草形的磁铁，一头吸着氨基酸，另一头读着密码子 |

### 21. rRNA（核糖体RNA）

| 维度 | 编码 |
|------|------|
| 位置 | 核糖体内 |
| 形状 | 与蛋白质结合形成核糖体的大小亚基 |
| 功能 | 核糖体的结构和催化成分 |
| 谐音 | "rRNA"→"构RNA"（构成核糖体的RNA） |
| 画面 | 🏗️ 核糖体的骨架和梁柱，没有它核糖体就散架 |

### 22. 基因表达（Gene Expression）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞核（转录）+ 核糖体（翻译） |
| 形状 | 信息流：DNA→RNA→蛋白质 |
| 功能 | 将基因中的遗传信息转化为功能性蛋白质 |
| 谐音 | "基因表达"→"基因表答"（基因表达出来，表答出来） |
| 画面 | 📖→📜→🧱 从蓝图（DNA）抄写指令（RNA），再按指令生产产品（蛋白质） |

> 口诀：**"中心法则要牢记，DNA转录成RNA，RNA翻译成蛋白质"**

### 23. 转录（Transcription）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞核内 |
| 形状 | DNA双链解开，以一条链为模板合成mRNA |
| 功能 | 将DNA的遗传信息"抄写"到mRNA上 |
| 谐音 | "转录"→"转路"（把信息从DNA这条路上转到mRNA那条路上） |
| 画面 | 📝 一个抄写员（RNA聚合酶）在蓝图（DNA）旁边，一字一句地抄写到新纸（mRNA）上 |

**转录步骤**：
1. **起始**：RNA聚合酶结合启动子，DNA双链解开
2. **延伸**：RNA聚合酶沿DNA模板链移动，合成mRNA
3. **终止**：到达终止子，RNA聚合酶脱落，mRNA释放

### 24. 翻译（Translation）

| 维度 | 编码 |
|------|------|
| 位置 | 核糖体（细胞质中） |
| 形状 | 核糖体沿mRNA移动，tRNA运送氨基酸 |
| 功能 | 将mRNA的密码子序列"翻译"为氨基酸序列（蛋白质） |
| 谐音 | "翻译"→"翻义"（把密码子的含义翻出来） |
| 画面 | 🌐 一个翻译官（核糖体）读着外语（密码子），把每个词（密码子）翻译成对应的氨基酸 |

**翻译步骤**：
1. **起始**：核糖体小亚基+mRNA+起始tRNA（携带甲硫氨酸，识别AUG）→大亚基结合
2. **延伸**：tRNA逐个进入核糖体A位→肽键形成→核糖体沿mRNA移动
3. **终止**：遇到终止密码子（UAA/UAG/UGA）→释放因子进入→多肽链释放

### 25. 信号转导（Signal Transduction）

| 维度 | 编码 |
|------|------|
| 位置 | 细胞膜→细胞质→细胞核 |
| 形状 | 信号分子→受体→第二信使→级联反应→细胞响应 |
| 功能 | 细胞接收外界信号并作出反应的机制 |
| 谐音 | "信号转导"→"信号转到"（信号转来转去，传导到目的地） |
| 画面 | 📡 一个多米诺骨牌阵列：第一个牌（信号分子）推倒受体牌，引发一连串骨牌倒塌，最终到达细胞核的牌（基因表达改变） |

**信号转导三步**：
1. **接收**：信号分子（如激素）与细胞膜受体结合
2. **转导**：激活细胞内信号通路（第二信使如cAMP，蛋白激酶级联）
3. **响应**：细胞产生特定反应（如基因表达改变、酶活性调节）

## 三、细胞分裂过程记忆

### 有丝分裂（Mitosis）

用**"间前中后末"**五个字记忆：

```
间期 → 前期 → 中期 → 后期 → 末期
(G₁/S/G₂)  (PMAT)  (排列)  (分离)  (重建)
```

#### 间期（Interphase）

| 阶段 | 事件 | 编码图像 |
|------|------|----------|
| G₁期 | 细胞生长，蛋白质合成 | 📈 细胞变大，储备物资 |
| S期 | DNA复制，染色体复制 | 🧬 DNA像拉链一样被复制一份 |
| G₂期 | 继续生长，为分裂做准备 | 🔧 检查设备，准备开工 |

> 口诀：**"G₁长大S复制，G₂准备要分裂"**

#### 前期（Prophase）

| 事件 | 编码图像 |
|------|----------|
| 染色质螺旋化→染色体 | 🪜 松散的线卷紧变成X形棒子 |
| 核膜、核仁消失 | 🏛️ 总部大楼的墙塌了 |
| 中心体移向两极，纺锤体形成 | 🎯 两个十字准星分别飞向两端，中间拉出丝线 |

> 口诀：**"前期膜仁消失现两体"**（核膜核仁消失，染色体和纺锤体出现）

#### 中期（Metaphase）

| 事件 | 编码图像 |
|------|----------|
| 染色体排列在赤道板上 | 📏 所有X形棒子整齐排成一排在细胞中央 |
| 纺锤丝连接着丝点 | 🧵 丝线从两端连到每个X的中间点 |

> 口诀：**"中期形定数晰赤道齐"**（形态固定，数目清晰，整齐排列在赤道板）

#### 后期（Anaphase）

| 事件 | 编码图像 |
|------|----------|
| 着丝点分裂，姐妹染色单体分开 | ✂️ 剪刀剪开X形棒的中间，两条臂分别飞向两极 |
| 纺锤丝牵引染色体移向两极 | 🧵 丝线把分开的棒子拉向两端 |
| 染色体数目加倍 | 📊 从46条变成92条 |

> 口诀：**"后期点裂数增均两极"**（着丝点分裂，数目增加，均匀移向两极）

#### 末期（Telophase）

| 事件 | 编码图像 |
|------|----------|
| 染色体解螺旋→染色质 | 🪜 棒子松开变回线 |
| 核膜、核仁重新出现 | 🏛️ 新的总部大楼墙重新建好 |
| 纺锤体消失 | 🧵 丝线消失 |
| 细胞质分裂（胞质分裂） | ✂️ 细胞中央缢裂（动物）或形成细胞板（植物） |

> 口诀：**"末期膜仁重现现两体"**（核膜核仁重新出现，染色体和纺锤体消失）

### 有丝分裂完整口诀

> **"间期复制做准备，前期膜仁消失现两体，中期形定数晰赤道齐，后期点裂数增均两极，末期膜仁重现现两体，胞质分裂成两子"**

### 有丝分裂各期核心数字

| 期 | 染色体数（人2n=46） | DNA数 | 染色单体数 |
|----|---------------------|-------|------------|
| G₁ | 46 | 46 | 0 |
| S | 46 | 46→92 | 0→92 |
| G₂ | 46 | 92 | 92 |
| 前期 | 46 | 92 | 92 |
| 中期 | 46 | 92 | 92 |
| 后期 | 92 | 92 | 0 |
| 末期 | 46（每个子细胞） | 46（每个子细胞） | 0 |

### 减数分裂（Meiosis）速记

| 阶段 | 关键事件 | 编码 |
|------|----------|------|
| 减Ⅰ前期 | 同源染色体配对（联会），交叉互换 | 💕 两对同源染色体手牵手 |
| 减Ⅰ中期 | 同源染色体排列在赤道板两侧 | 📏 四分体排排站 |
| 减Ⅰ后期 | 同源染色体分离（非同源自由组合） | 👋 同源染色体挥手告别 |
| 减Ⅱ | 类似有丝分裂，姐妹染色单体分开 | ✂️ 和有丝分裂后期一样 |

> 口诀：**"减一同源分家，减二姐妹分家"**

## 五、蛋白质合成全流程记忆

### 从DNA到蛋白质的完整路径

```
DNA（细胞核·蓝图原件）
    ↓ 转录（RNA聚合酶抄写）
mRNA前体（细胞核·草稿）
    ↓ 加工（加帽、加尾、剪接）
mRNA（细胞核→核孔→细胞质·正式文件）
    ↓ 翻译（核糖体+tRNA执行）
多肽链（核糖体·半成品）
    ↓ 折叠+修饰（内质网+高尔基体加工）
蛋白质（成品·运往目的地）
```

### 分泌蛋白的完整旅程

1. **核糖体**合成多肽链 → 2. **粗面内质网**初步加工（折叠、糖基化）→ 3. **高尔基体**进一步加工、分类、包装 → 4. **囊泡**运输到细胞膜 → 5. **胞吐**释放到细胞外

> 口诀：**"核糖体造，内质网修，高尔基包，囊泡送，胞吐出"**

## 六、综合记忆宫殿

### 细胞分裂的"五幕剧"

把有丝分裂想象成一场**五幕舞台剧**：

| 幕 | 剧情 | 核心事件 |
|----|------|----------|
| 第一幕：间期 | 后台准备 | 演员化妆（DNA复制），道具准备（蛋白质合成） |
| 第二幕：前期 | 开幕 | 幕布拉开（核膜消失），演员上台（染色体出现），舞台灯亮（纺锤体形成） |
| 第三幕：中期 | 高潮前奏 | 演员整齐排列在舞台中央（赤道板） |
| 第四幕：后期 | 高潮 | 演员分成两组，各自走向舞台两端（着丝点分裂，染色体移向两极） |
| 第五幕：末期 | 谢幕 | 演员退场（染色体解螺旋），舞台重新布置（核膜重建），舞台一分为二（胞质分裂） |

### 信号转导的"电话系统"

1. **电话铃响** → 信号分子到达细胞膜
2. **接电话** → 受体与信号分子结合
3. **转接内线** → 第二信使（cAMP）激活
4. **多级转接** → 蛋白激酶级联反应
5. **最终通知** → 细胞核收到指令，改变基因表达
