## 三、案例→法条关联记忆

### 案例1：未成年人游戏充值
```
事实：10岁孩子充值5万元游戏币
法条：第19条（限制民事行为能力人）
关联：10岁 < 18岁 → 限制行为能力 → 充值行为效力待定
画面：药酒坛子里的孩子（限制行为能力），偷偷充值游戏
```

### 案例2：好意同乘事故
```
事实：朋友免费搭车出事故受伤
法条：第1217条（好意同乘）
关联：非营运机动车 → 好意同乘 → 减轻赔偿责任
画面：后院运动场上的好朋友一起遛弯（好意同乘），出了小事故
```

### 案例3：高空抛物
```
事实：楼上扔花盆砸伤行人
法条：第1254条（高空抛物）
关联：高空抛物 → 查不到具体侵权人 → 可能加害的建筑物使用人补偿
画面：后院楼上掉下花盆，整栋楼的人都要补偿
```

### 案例4：离婚冷静期
```
事实：夫妻申请离婚
法条：第1077条（离婚冷静期）
关联：申请离婚 → 30天冷静期 → 30天内可撤回
画面：花园门口的30天倒计时沙漏，冷静期内可以反悔
```

### 案例5：遗嘱效力
```
事实：老人立多份遗嘱
法条：第1142条（遗嘱效力）
关联：多份遗嘱 → 以最后的遗嘱为准
画面：地下室竹简架上多卷竹简，最后一卷最有效力
```

## 六、记忆训练方法

### 1. 宫殿漫游法
```
走进宫殿大门（总则）→ 看到天平（平等）→ 看到妻子画像（诚信）
→ 走进右侧房间（物权）→ 看到看门狗（物权保护）
→ 走进左侧房间（合同）→ 坐在酒桌旁（合同形式）
→ 上阁楼（人格权）→ 看到鸽子笼（人格权）
→ 到花园（婚姻）→ 看到禁止牌（婚姻禁止）
→ 下地下室（继承）→ 打开保险箱（继承顺序）
→ 到后院（侵权）→ 走小路（过错责任）
```

### 2. 概念→画面快速联想
```
法人 → 发光的人 → 法律拟制人格
物权 → 物犬 → 对物的支配权
债权 → 寨圈 → 请求权
```

### 3. 案例→法条双向训练
```
看到"高空抛物" → 第1254条 → 查不到侵权人→可能加害人补偿
看到"第19条" → 限制行为能力 → 8岁以上未成年人
```
