# 刑法记忆 — 编码训练

## 一、刑法重要罪名编码（30个）

### 编码说明
- **罪名**：核心罪名
- **构成要件**：主体、主观、客体、客观
- **刑罚**：法定刑
- **画面**：记忆场景
- **谐音**：辅助编码

---

### 【侵犯人身权利罪】— 身体桩上半身

#### 1. 故意杀人罪（第232条）

| 要素 | 内容 |
|------|------|
| 构成要件 | 故意非法剥夺他人生命 |
| 刑罚 | 死刑、无期徒刑或十年以上有期徒刑；情节较轻，三年以上十年以下 |
| 谐音 | "232"→饿散饿；"故意杀人"→故杀 |
| 画面 | 头顶上有人故意拿着刀（故杀），情节严重判死刑 |

> **记忆链**：头顶 → 饿散饿(232) → 故意杀人 → 最重可判死刑

## 二、罪名→构成要件→刑罚关联链

### 关联链模板
```
罪名 → 条文号(谐音) → 身体位置 → 构成要件关键词 → 刑罚档位
```

### 示例关联链

#### 故意杀人罪
```
故意杀人 → 232(饿散饿) → 头顶 → 故意+非法+剥夺生命 → 死刑/无期/10年以上(情节较轻3-10年)
```

#### 抢劫罪
```
抢劫 → 263(饿留散) → 肚子 → 暴力/胁迫+强行取财 → 3-10年(八种加重10年以上/无期/死刑)
```

#### 诈骗罪
```
诈骗 → 266(饿留留) → 屁股 → 虚构事实/隐瞒真相+骗取财物 → 3年以下/3-10年/10年以上或无期(数额分档)
```

#### 贪污罪
```
贪污 → 382(三八二) → 右臂 → 国家工作人员+职务便利+侵吞公共财物 → 3年以下/3-10年/10年以上或无期或死刑(数额分档)
```

#### 交通肇事罪

## 五、记忆训练方法

### 1. 身体桩快速定位法
```
摸头顶 → 故意杀人(232)
摸肚子 → 抢劫(263)
摸右臂 → 贪污(382)/受贿(385)
摸左腿 → 寻衅滋事(293)
摸右脚 → 贩毒(347)
```

### 2. 罪名→条文号→刑罚速查
```
看到"诈骗" → 266(饿留留) → 屁股 → 数额分三档量刑
看到"交通肇事" → 133(医生散) → 左臂 → 3年以下/逃逸3-7年/逃逸致死7年以上
```

### 3. 易混罪名对比速记
```
抢劫(263/肚子) vs 抢夺(267/大腿) vs 敲诈(274/小腿)
盗窃(264/腰) vs 诈骗(266/屁股) vs 侵占(270/脚踝)
```

### 4. 刑期数字快速反应
```
听到"3年以下" → 伞 → 轻刑
听到"10年以上" → 要你 → 重刑
听到"死刑" → 最重刑罚
```

## 七、犯罪构成四要件速记

```
主体：谁犯罪？（自然人/单位）
主观：故意还是过失？（心态）
客体：侵害了什么？（法益）
客观：做了什么？（行为+结果）
```

### 四要件记忆画面
```
主体 → 人（犯罪的人）
主观 → 心（心态：故意/过失）
客体 → 益（法益：被侵害的利益）
客观 → 行（行为：做了什么）
画面：一个人（主体）用心（主观）侵害了利益（客体）的行为（客观）
```
