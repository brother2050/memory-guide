## 案例1:于欢案(正当防卫 vs 故意伤害)

### 事实
- 2016年,山东聊城,于欢母亲苏银霞被讨债人员长时间非法拘禁、侮辱
- 多人围堵在苏银霞公司,对她进行辱骂、抽耳光、鞋子捂嘴等侮辱行为
- 警察到场后说"要账可以,但不能打人"后离开
- 于欢情绪崩溃,持刀刺伤4人,其中1人(杜志浩)因失血性休克死亡

### 争议
- 于欢的行为是正当防卫还是故意伤害?
- 是否属于防卫过当?
- 非法拘禁和侮辱是否构成"不法侵害"?

### 法条
- **《刑法》第20条**:正当防卫
  - 第1款:为了保护合法权益,对正在进行的不法侵害采取的制止行为,不负刑事责任
  - 第2款:防卫过当,应当减轻或免除处罚
  - 第3款:特殊防卫权(对严重危及人身安全的暴力犯罪)

### 判决
- 一审:故意伤害罪,无期徒刑(认为不构成正当防卫)
- 二审(改判):故意伤害罪,有期徒刑5年(认定为防卫过当)

### 记忆画面
```
画面:一个儿子(于欢)看到母亲被侮辱,像被关在笼子里的狮子,
      笼子外面的人侮辱母亲,警察看了一眼就走了,
      狮子冲破笼子咬伤了侮辱者。
      法官说:"狮子可以保护母亲,但咬得太重了。"
```

### 记忆链
```
于欢案 → 母亲被侮辱+非法拘禁 → 儿子持刀伤人 →
正当防卫 vs 故意伤害 → 防卫过当 → 5年
```

## 案例2:昆山龙哥案(特殊防卫权)

### 事实
- 2018年,江苏昆山,刘海龙(龙哥)驾车与于海明发生轻微交通事故
- 龙哥下车对于海明拳打脚踢,后从车中取出长刀砍向于海明
- 砍击过程中刀脱手,于海明捡起刀追砍龙哥数刀
- 龙哥因伤势过重死亡

### 争议
- 于海明捡刀追砍的行为是正当防卫还是事后防卫?
- 龙哥刀脱手后,不法侵害是否已经结束?
- 是否适用特殊防卫权?

### 法条
- **《刑法》第20条第3款**:特殊防卫权
  - 对正在进行行凶、杀人、抢劫、强奸、绑架以及其他严重危及人身安全的暴力犯罪,采取防卫行为,造成不法侵害人伤亡的,不属于防卫过当,不负刑事责任

### 判决
- 公安机关撤案:于海明的行为属于正当防卫,不负刑事责任

### 记忆画面
```
画面:一条龙哥(刘海龙)拿着大刀砍人,刀飞出去了,
      被砍的人捡起刀反过来砍龙哥。
      法官说:"龙哥的刀虽然脱手了,但危险还没结束,
      被砍的人有权继续防卫直到危险消除。"
```

### 记忆链
```
昆山案 → 龙哥砍人+刀脱手 → 于海明捡刀追砍 →
特殊防卫权(第20条第3款)→ 正当防卫→不负刑事责任
```

## 案例3:江歌案(故意杀人+民事赔偿)

### 事实
- 2016年,日本东京,江歌在公寓门口被陈世峰用刀刺死
- 江歌是为了保护室友刘鑫(后改名刘暖曦)而遇害
- 陈世峰因追求刘鑫被拒而行凶
- 江歌母亲江秋莲在国内起诉刘鑫,要求民事赔偿

### 争议
- 刘鑫是否有过错?
- 刘鑫是否应对江歌的死亡承担民事责任?
- 刘鑫锁门的行为是否构成侵权?

### 法条
- **《民法典》第1165条**:过错责任原则
- **《民法典》第1179条**:人身损害赔偿
- **《民法典》第1183条**:精神损害赔偿

### 判决
- 刑事:陈世峰在日本被判有期徒刑20年
- 民事:刘鑫(刘暖曦)赔偿江歌母亲各项损失及精神损害抚慰金共计69.6万元

### 记忆画面
```
画面:江歌像一堵墙挡在门口保护室友刘鑫,
      刘鑫在门里面锁上了门,
      门外的江歌被刺身亡。
      法官说:"你锁门的行为有错,要赔偿。"
```

### 记忆链
```
江歌案 → 江歌保护刘鑫 → 陈世峰行凶 → 刘鑫锁门有过错 →
过错责任(第1165条)→ 民事赔偿69.6万
```

## 案例4:药家鑫案(故意杀人罪)

### 事实
- 2010年,西安,药家鑫驾车撞倒行人张妙
- 药家鑫下车查看后,因怕被记住车牌号,持刀连刺张妙6刀致其死亡
- 药家鑫逃离现场后被抓获

### 争议
- 药家鑫的行为是交通肇事还是故意杀人?
- 撞人后持刀杀人是否属于数罪并罚?
- 主观上是直接故意还是间接故意?

### 法条
- **《刑法》第232条**:故意杀人罪
  - 死刑、无期徒刑或十年以上有期徒刑
- **《刑法》第133条**:交通肇事罪

### 判决
- 故意杀人罪,死刑,剥夺政治权利终身
- 2011年6月执行死刑

### 记忆画面
```
画面:药家鑫开车撞了人,不仅不救人,反而拿刀连刺6刀。
      法官说:"撞人是交通肇事,但拿刀杀人就是故意杀人,
      两个行为分别定罪,杀人罪判死刑。"
```

### 记忆链
```
药家鑫案 → 撞人后持刀刺死 → 交通肇事+故意杀人 →
第232条故意杀人罪 → 死刑
```

## 案例5:许霆案(盗窃罪 vs 侵占)

### 事实
- 2006年,广州,许霆在ATM机取款时发现:取1000元只扣1元
- 许霆连续取款171次,共取出17.5万元
- 许霆携款潜逃,一年后被抓获

### 争议
- 许霆的行为是盗窃还是侵占?
- ATM机故障是否影响犯罪性质?
- 量刑是否过重?

### 法条
- **《刑法》第264条**:盗窃罪
  - 数额较大:三年以下有期徒刑
  - 数额巨大:三年以上十年以下有期徒刑
  - 数额特别巨大:十年以上有期徒刑或无期徒刑

### 判决
- 一审:盗窃罪,无期徒刑(认为数额特别巨大)
- 二审(改判):盗窃罪,有期徒刑5年,并处罚金2万元
- 法院认为:ATM机故障不影响盗窃性质,但量刑过重,适用刑法第63条第2款在法定刑以下判处

### 记忆画面
```
画面:许霆站在ATM机前,机器像漏钱的口袋一样疯狂吐钱,
      许霆像捡钱一样连续取了171次。
      法官说:"机器坏了不是你的钱,你拿走就是盗窃,
      但判无期太重了,改判5年。"
```

### 记忆链
```
许霆案 → ATM故障连续取款17.5万 → 盗窃罪(第264条)→
一审无期→二审改判5年 → 刑法第63条减轻处罚
```

## 案例6:聂树斌案(冤案平反)

### 事实
- 1994年,河北石家庄,聂树斌因一起强奸杀人案被逮捕
- 1995年,聂树斌被执行死刑
- 2005年,另一嫌疑人王书金落网,供述该案系其所为
- 2016年,最高法再审改判聂树斌无罪

### 争议
- 原审证据是否确实充分?
- 是否存在刑讯逼供?
- 疑罪从无原则是否得到贯彻?

### 法条
- **《刑事诉讼法》第55条**:证据确实、充分的标准
- **《刑事诉讼法》第200条**:疑罪从无
- **《国家赔偿法》**:冤案赔偿

### 判决
- 2016年最高法再审:撤销原判,改判聂树斌无罪
- 家属获得国家赔偿

### 记忆画面
```
画面:聂树斌像一只被冤枉的鸟,关在笼子里21年,
      真正的凶手王书金在外面逍遥。
      最后法官打开笼子说:"对不起,证据不足应该无罪释放。"
```

### 记忆链
```
聂树斌案 → 1995年被执行死刑 → 2005年真凶出现 →
2016年再审无罪 → 疑罪从无+国家赔偿
```

## 案例7:电梯劝阻吸烟案(公平责任)

### 事实
- 2017年,河南郑州,杨某在电梯内吸烟
- 段某(医生)劝阻吸烟,双方发生言语争执
- 杨某情绪激动,离开电梯后不久心脏病发作死亡
- 杨某家属起诉段某要求赔偿

### 争议
- 段某的劝阻行为是否有过错?
- 劝阻吸烟与死亡之间是否有因果关系?
- 是否适用公平责任?

### 法条
- **《民法典》第1165条**:过错责任
- **《民法典》第1186条**:公平责任(原《侵权责任法》第24条)

### 判决
- 一审:段某补偿1.5万元(适用公平责任)
- 二审(改判):段某不承担赔偿责任
- 法院认为:段某劝阻吸烟是正当行为,没有过错,不应承担侵权责任

### 记忆画面
```
画面:医生段某在电梯里像纠察队一样劝阻吸烟,
      杨某情绪激动离开后心脏病发。
      法官说:"劝阻吸烟是正当的,不是侵权,不用赔。"
```

### 记忆链
```
电梯劝烟案 → 劝阻吸烟→争执→心脏病发死亡 →
过错责任(第1165条)→ 无过错不担责 → 二审改判不赔
```

## 案例8:冷冻胚胎案(人格物)

### 事实
- 2014年,江苏宜兴,一对夫妻(沈某、刘某)因不孕在医院做试管婴儿
- 胚胎冷冻保存在医院
- 夫妻双方在车祸中双双去世
- 双方父母(4位老人)争夺冷冻胚胎的处置权

### 争议
- 冷冻胚胎的法律性质是什么?(物?人格物?)
- 胚胎能否继承?
- 医院能否拒绝返还?

### 法条
- **《民法典》第1009条**:人体胚胎的法律保护
- **民法理论**:人格物(具有人格利益的物)

### 判决
- 法院判决:冷冻胚胎具有生命伦理属性,不能简单作为物来处理
- 考虑到双方父母的情感利益和伦理需求,判决医院将胚胎交由双方老人共同处置

### 记忆画面
```
画面:冷冻库里有一颗小胚胎,像一颗种子,
      四位老人(爷爷奶奶外公外婆)围着种子争抢,
      法官说:"这颗种子有生命的温度,不能简单分给谁,
      让四位老人一起守护它。"
```

### 记忆链
```
冷冻胚胎案 → 夫妻双亡→争夺胚胎 → 胚胎的人格物属性 →
不能简单继承 → 四位老人共同处置
```

## 案例9:个人信息保护案(隐私权)

### 事实
- 某App未经用户同意收集用户通讯录、位置、相册等个人信息
- 用户发现后向法院起诉,要求App停止侵害并赔偿损失
- App辩称:用户同意了隐私政策

### 争议
- App的隐私政策是否构成有效同意?
- 过度收集个人信息是否违法?
- 用户如何举证?

### 法条
- **《个人信息保护法》第13条**:处理个人信息的合法性基础
- **《个人信息保护法》第14条**:同意应当自愿、明确
- **《民法典》第1032-1039条**:隐私权和个人信息保护

### 判决
- 法院判决:App的隐私政策属于格式条款,"一揽子同意"不构成有效同意
- App应停止过度收集行为,删除已收集的非必要个人信息
- 赔偿用户精神损害抚慰金

### 记忆画面
```
画面:App像一只贪吃的章鱼,伸出无数触手偷偷收集用户信息,
      用户的隐私被触手缠绕。
      法官说:"章鱼的触手伸得太长了,用户没有真正同意,
      砍掉多余触手,赔钱。"
```

### 记忆链
```
信息保护案 → App过度收集 → "一揽子同意"无效 →
个人信息保护法第13/14条 → 停止侵害+赔偿
```

## 案例10:高空抛物入刑案

### 事实
- 2021年,江苏常州,李某因与楼下邻居发生矛盾
- 李某从14楼扔下菜刀、砧板等物品
- 幸未造成人员伤亡,但楼下多辆汽车被砸坏
- 李某被公安机关立案侦查

### 争议
- 高空抛物是否构成犯罪?
- 适用哪个罪名?(以危险方法危害公共安全罪 vs 高空抛物罪)
- 未造成人员伤亡是否影响定罪?

### 法条
- **《刑法》第291条之二**:高空抛物罪(2021年3月1日施行)
  - 从建筑物或其他高空抛掷物品,情节严重的,处一年以下有期徒刑、拘役或管制
- **《民法典》第1254条**:高空抛物的民事责任

### 判决
- 高空抛物罪,有期徒刑6个月,并处罚金

### 记忆画面
```
画面:14楼有人像扔飞刀一样往下扔菜刀、砧板,
      楼下的人东躲西藏。
      法官说:"高空抛物现在有专门的罪名了,
      从建筑物扔东西,情节严重就是犯罪。"
```

### 记忆链
```
高空抛物案 → 14楼扔菜刀砧板 → 高空抛物罪(第291条之二)→
2021年新增罪名 → 6个月有期徒刑
```

## 四、案例分析框架记忆

### 分析框架模板
```
1. 案件事实梳理
   - 时间、地点、人物
   - 行为经过
   - 结果

2. 争议焦点识别
   - 法律定性争议
   - 事实认定争议
   - 量刑/赔偿争议

3. 法条适用
   - 实体法条文
   - 程序法条文
   - 司法解释

4. 判决结论
   - 定性结论
   - 量刑/赔偿结论
   - 社会影响
```

### 记忆口诀
```
事实争议法条判,四步分析记心间,
事实经过要清晰,争议焦点找关键,
法条适用要准确,判决结论是终点。
```

## 六、记忆训练方法

### 1. 故事→法条正向训练
```
看到"龙哥刀脱手" → 第20条第3款 → 特殊防卫权
看到"ATM漏钱" → 第264条 → 盗窃罪
```

### 2. 法条→案例反向训练
```
看到"第20条" → 于欢案/昆山案 → 正当防卫
看到"第232条" → 药家鑫案 → 故意杀人
```

### 3. 画面快速回忆
```
想到"笼中狮子" → 于欢案 → 母亲被侮辱 → 防卫过当 → 5年
想到"章鱼触手" → 信息保护案 → 过度收集 → 个保法 → 赔偿
```

### 4. 争议焦点速记
```
于欢案争议:正当防卫 vs 故意伤害
昆山案争议:刀脱手后不法侵害是否结束
许霆案争议:盗窃 vs 侵占
```

### 5. 综合测试
```
问:昆山案适用哪条法律?→ 第20条第3款(特殊防卫权)
问:第264条对应哪个案例?→ 许霆案(盗窃罪)
问:江歌案的核心争议是什么?→ 刘鑫锁门是否有过错
```

## 🔴 法律案例常见错误提醒

| ❌ 常见错误 | ✅ 正确表述 | 记忆锚点 |
|------------|-----------|----------|
| 正当防卫不需要承担任何责任 | 正当防卫不负刑事责任，但可能承担民事责任 | 刑事≠民事 |
| 紧急避险造成的损害由避险人承担 | 紧急避险造成的损害由引起险情发生的人承担 | 引起者承担 |
| 无限防卫权可以随意使用 | 无限防卫权只适用于严重暴力犯罪 | 严重暴力=无限防卫 |
| 故意杀人一定判死刑 | 故意杀人不一定判死刑，要看情节 | 故意杀人≠死刑 |
| 所有犯罪都需要故意 | 犯罪可以是故意或过失 | 故意/过失=两种心态 |
| 未成年人犯罪不需要承担刑事责任 | 14-16周岁对8种严重犯罪负刑事责任 | 14-16=8种犯罪 |
| 精神病人犯罪不需要承担刑事责任 | 间歇性精神病人在精神正常时犯罪应负刑事责任 | 间歇性=正常时负责 |
| 犯罪未遂不需要承担刑事责任 | 犯罪未遂应当承担刑事责任，但可以比照既遂从轻或减轻 | 未遂=负责+从轻 |
| 共同犯罪中所有人责任相同 | 共同犯罪中主犯、从犯、胁从犯责任不同 | 主从胁=不同责任 |
| 自首一定免除处罚 | 自首可以从轻或减轻处罚，犯罪较轻的可以免除 | 自首≠免除 |

### 刑法核心概念对比表

| 对比项 | 故意犯罪 | 过失犯罪 |
|--------|---------|----------|
| 定义 | 明知危害结果，希望或放任 | 应当预见而没有预见，或轻信能避免 |
| 分类 | 直接故意/间接故意 | 疏忽大意/过于自信 |
| 处罚 | 较重 | 较轻 |
| 记忆 | 「故意=明知故犯」 | 「过失=不小心」 |
