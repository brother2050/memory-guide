# 法律概念记忆 — 编码训练

## 一、50个法律专业术语编码

### 编码说明
- **含义**：核心定义
- **谐音**：辅助记忆发音
- **画面**：具象化场景
- **故事**：联想故事

---

### 【宪法类】宫殿A（红色宫殿）

#### 1. 宪法

| 要素 | 内容 |
|------|------|
| 含义 | 国家根本法，规定国家根本制度和根本任务，具有最高法律效力 |
| 谐音 | 先发（先制定的法律） |
| 画面 | 一本红色大书从天上先掉下来（先发），落在所有法律之上 |
| 故事 | 红色宫殿门口，一本巨大的红书从天而降，所有其他法律都向它鞠躬 |

#### 2. 国体

| 要素 | 内容 |
|------|------|
| 含义 | 国家的阶级性质，即社会各阶级在国家中的地位 |

| 画面 | 一口大锅里煮着不同阶级的人（人民民主专政） |
| 故事 | 红色宫殿大厅里，一口大锅体（国体）里，人民是主人 |

## 二、术语间逻辑关系记忆

### 关系网1：宪法→民法→刑法→诉讼法

```
宪法（根本法）
├── 规定基本权利 → 民法保护民事权利
│   ├── 物权（对物的权利）
│   ├── 债权（对人的权利）
│   └── 人格权（人身权利）
├── 规定基本义务 → 刑法惩罚违反义务的行为
│   ├── 犯罪（违反刑法）
│   └── 刑罚（惩罚手段）
└── 规定国家机构 → 行政法规范行政行为
    ├── 行政行为
    └── 行政诉讼（民告官）
```

### 关系网2：法律行为体系

```
法律行为
├── 民事法律行为（民法）
│   ├── 有效行为
│   ├── 无效行为
│   └── 可撤销行为
├── 行政行为（行政法）
│   ├── 行政处罚
│   ├── 行政许可
│   └── 行政强制
└── 犯罪行为（刑法）
    ├── 故意犯罪
    └── 过失犯罪
```

### 关系网3：权利救济体系

```
权利被侵害
├── 民事纠纷 → 民事诉讼/仲裁/调解
├── 行政侵权 → 行政复议/行政诉讼
├── 犯罪侵害 → 刑事诉讼（公诉/自诉）
└── 国际争端 → 国际法院/仲裁
```

```
│   ├── 犯罪构成：主体、主观、客体、客观

│   ├── 民事诉讼：起诉、举证、调解、上诉
│   ├── 刑事诉讼：侦查、起诉、审判
│   └── 行政诉讼：民告官

├── E区 黄色宫殿（行政法）：政府行为
│   ├── 行政行为：处罚、许可、强制
│   ├── 行政复议：上级审查

├── F区 紫色宫殿（国际法）：国家间关系

│   ├── 国际私法：法律冲突
│   └── 国际经济法：贸易、投资
│
└── G区 白色宫殿（法理/法律史）：基础理论
    ├── 法系：大陆法系、英美法系
    ├── 法律渊源：宪法、法律、法规
    └── 法律解释：文义、体系、目的
```

## 🔴 法律概念常见错误提醒

| ❌ 常见错误 | ✅ 正确表述 | 记忆锚点 |
|------------|-----------|----------|
| 法人=法定代表人 | 法人是组织，法定代表人是代表法人行使职权的自然人 | 法人=组织 |
| 权利=权力 | 权利是私权利(可放弃)，权力是公权力(不可放弃) | 权利私权力公 |
| 违法=犯罪 | 违法包括犯罪，但一般违法不等于犯罪 | 违法>犯罪 |
| 合同=协议 | 合同是民事法律行为，协议范围更广 | 合同⊂协议 |
| 物权=债权 | 物权是绝对权(对世权)，债权是相对权(对人权) | 物权绝对债权相对 |
| 代理=代表 | 代理人以被代理人名义，代表人以法人名义 | 代理≠代表 |
| 诉讼=仲裁 | 诉讼是公力救济，仲裁是社会救济 | 诉讼公力仲裁社会 |
| 调解=和解 | 调解有第三方介入，和解是双方自行协商 | 调解有第三方 |
| 法律责任=法律义务 | 法律义务是应为，法律责任是违反义务的后果 | 义务先责任后 |
| 法律关系=社会关系 | 法律关系是受法律调整的社会关系 | 法律关系=法律调整 |
