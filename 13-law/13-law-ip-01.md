## 一、专利法核心条款编码

### 📋 专利法关键条款速记表

| 条款 | 内容 | 编码记忆 |
|------|------|----------|
| 第2条 | 发明创造包括发明、实用新型、外观设计 | **"发型外观"** — 发(明)、型(实用新型)、外(观设计) |
| 第5条 | 违反法律、社会公德的发明创造不授予专利 | **"违法缺德不给专利"** |
| 第22条 | 授予专利权的条件：新颖性、创造性、实用性 | **"新创实"** — 谐音"新创世"，像开创新世界 |
| 第25条 | 不授予专利权：科学发现、智力活动规则、疾病诊断方法等 | **"发现规则病不给"** — 科学发现、规则、治病方法 |
| 第42条 | 发明专利权期限20年，实用新型和外观设计10年 | **"发二十，型观十"** |
| 第47条 | 宣告无效的专利权视为自始不存在 | **"无效=从来没有"** |
| 第62条 | 强制许可：未充分实施/紧急状态/公共利益 | **"不干急用公益强许可"** |

### 🔑 专利三性编码（最核心考点）

```
新颖性 → "新" → 全世界没人做过
         记忆：你发明的东西，全球范围内是新的

创造性 → "创" → 有实质性进步
         记忆：不是简单拼凑，要有质的飞跃

实用性 → "实" → 能制造或使用
         记忆：不是空想，要能落地

编码故事："新创世" — 创造一个新世界，需要新东西+有突破+能实现
```

### 🔑 不授予专利权的客体编码

```
排除清单（第25条）：

1. 科学发现     → "发现≠发明" → 牛顿发现万有引力不能专利
2. 智力活动规则  → "游戏规则不能专利" → 棋谱、教学方法
3. 疾病诊断方法  → "看病方法不能专利" → 望闻问切
4. 动物和植物品种 → "活物不能专利" → 新品种玉米不行（但培育方法可以）
5. 原子核变换方法 → "核变不专利" → 太危险太基础
6. 平面印刷品的图案 → "只有图案不行" → 要有立体设计

编码口诀："发智病动原平" → "发现治病，动物原来平（安）"
```

## 二、商标法核心条款编码

### 📋 商标法关键条款速记表

| 条款 | 内容 | 编码记忆 |
|------|------|----------|
| 第4条 | 自然人、法人或其他组织可以申请商标注册 | **"人法组都能注册"** |
| 第8条 | 任何能够区分商品来源的标志均可注册 | **"能区分就能注"** |
| 第9条 | 申请注册的商标应有显著特征 | **"商标要有辨识度"** |
| 第10条 | 不得作为商标使用：国旗国徽等 | **"国旗国徽不能当商标"** |
| 第11条 | 缺乏显著特征的不得注册：通用名称、描述性标志 | **"太通用太描述不行"** |
| 第13条 | 驰名商标保护：跨类保护 | **"驰名跨类护"** |
| 第39条 | 注册商标有效期10年 | **"商标十年一轮"** |
| 第40条 | 期满可续展，每次续展有效期10年 | **"续展又是十年"** |
| 第57条 | 商标侵权行为：未经许可使用相同/近似商标 | **"乱用别人商标就是侵权"** |

### 🔑 商标注册条件编码

```
商标注册"五要件"：

1. 显著性    → "要有辨识度" → "可口可乐"有显著性，"饮料"没有
2. 非描述性  → "不能直接描述" → "甜"不能注册在糖果上
3. 非通用性  → "不能是通用名" → "苹果"不能注册在水果上（但可以注册在手机上）
4. 非冲突性  → "不能跟已注册的撞" → 在先申请原则
5. 非禁用性  → "不能违反第10条" → 国旗国徽地名等禁止

编码口诀："显描通关禁" → "先描通关（游戏）禁（用）"
```

### 🔑 商标侵权类型编码

```
商标侵权"四种情形"：

1. 相同商品 + 相同商标 → "双同" → 100%侵权
2. 相同商品 + 近似商标 → "同品近标" → 容易混淆
3. 类似商品 + 相同商标 → "似品同标" → 容易混淆
4. 类似商品 + 近似商标 → "双似" → 可能混淆

编码矩阵：
            同商标    近似商标
  同商品    【必侵】   【高危】
  似商品    【高危】   【可能侵】

记忆："同同必侵，似似看混"
```

## 三、著作权法核心条款编码

### 📋 著作权法关键条款速记表

| 条款 | 内容 | 编码记忆 |
|------|------|----------|
| 第2条 | 中国公民、法人作品不论是否发表均受保护 | **"写了就有权"** |
| 第3条 | 作品类型：文字、口述、音乐、戏剧、曲艺、舞蹈、杂技、美术、建筑、摄影、电影、图形、模型等 | **"文口音戏曲舞杂美建影图模"** |
| 第9条 | 著作权包括人身权和财产权 | **"人财两权"** |
| 第10条 | 人身权：发表权、署名权、修改权、保护完整权 | **"发署修保"** → "发现署名修改保护" |
| 第21条 | 发表权保护期：作者终生+死后50年 | **"生加五十"** |
| 第22条 | 署名权、修改权、保护完整权保护期不受限制 | **"署修保永存"** |
| 第23条 | 财产权保护期：作者终生+死后50年 | **"财产生加五十"** |
| 第35条 | 合理使用：为个人学习研究等 | **"个人学习免费用"** |
| 第37条 | 法定许可：教科书编写等 | **"教科书可以适当用"** |

### 🔑 著作权权利体系编码

```
著作权
├─ 人身权（永久保护）
│  ├─ 发表权    → "决定公不公开" → "发"表=公开
│  ├─ 署名权    → "决定挂谁的名" → "署"名=签名
│  ├─ 修改权    → "决定改不改"   → "修"改
│  └─ 保护完整权 → "决定能不能乱改" → "保"护
│
└─ 财产权（有期限）
   ├─ 复制权    → "复印/翻拍"
   ├─ 发行权    → "卖/送"
   ├─ 出租权    → "租"
   ├─ 展览权    → "展览"
   ├─ 表演权    → "演"
   ├─ 放映权    → "放电影"
   ├─ 广播权    → "广播"
   ├─ 信息网络传播权 → "网上发"
   ├─ 摄制权    → "拍电影"
   ├─ 改编权    → "改编"
   ├─ 翻译权    → "翻译"
   └─ 汇编权    → "汇编"

编码口诀（财产权12项）：
"复发出展演放广网摄改翻汇"
→ "付出展出演出，放广播网上，摄改编翻译汇编"
```

## 四、20个知识产权概念具象化

| # | 概念 | 具象化记忆 |
|---|------|------------|
| 1 | 新颖性 | 🌟 **新衣服** — 你穿了一件全世界没人穿过的衣服 |

| 3 | 实用性 | 🔧 **能用** — 不是纸上画的饼，是能吃到嘴里的饼 |
| 4 | 优先权 | 🎫 **VIP通道** — 在国外申请后12个月内，在国内申请享有优先日 |
| 5 | 强制许可 | 🏛️ **政府征用** — 你不卖？政府说必须卖（限特殊情况） |
| 6 | 驰名商标 | 👑 **明星商标** — 太出名了，跨行业也不能仿冒 |
| 7 | 商标续展 | 🔄 **续费会员** — 10年到期续费，不续就作废 |
| 8 | 商标异议 | 🚫 **公开反对** — 公告期内有人喊"这商标不该给" |
| 9 | 合理使用 | 📚 **免费抄作业** — 为学习研究可以免费用，但要注明出处 |

| 13 | 普通许可 | 🚶 **大众授权** — 权利人想给谁就给谁 |
| 14 | 职务发明 | 🏢 **上班搞的** — 工作中搞出来的发明，专利归单位 |

## 七、典型案例的关联记忆

### 📌 专利法经典案例

#### 案例1：华为诉三星专利侵权案（2016）

```
【案情】华为起诉三星侵犯其4G标准必要专利
【焦点】标准必要专利的FRAND原则（公平、合理、无歧视）
【关联知识点】
  · 标准必要专利（SEP）→ 行业标准绕不开的专利
  · FRAND原则 → 专利权人承诺按公平条件许可
  · 禁令救济的限制 → 不能滥用禁令威胁

【记忆编码】"华为三星4G大战，FRAND原则是底线"
【故事联想】华为像一个守门员（SE-Patent），三星要进门必须按规矩（FRAND）付费
```

#### 案例2：高通反垄断案（2015）

```
【案情】国家发改委认定高通滥用市场支配地位，罚款60.88亿元
【焦点】专利许可中的捆绑销售、不公平高价
【关联知识点】
  · 市场支配地位的认定
  · 滥用行为的类型
  · 专利权行使的边界

【记忆编码】"高通被罚六十亿，捆绑高价不合理"
【故事联想】高通像一个垄断菜市场的老板，把好菜（标准必要专利）和烂菜（非必要专利）捆绑卖
```

#### 案例3：朗科U盘专利案

```
【案情】朗科公司拥有"用于数据处理系统的快闪电子式外存储方法"发明专利
【焦点】基础方法专利的保护范围
【关联知识点】
  · 方法专利的保护延及产品
  · 专利池和交叉许可
  · 专利运营模式

【记忆编码】"朗科U盘专利，方法延及产品"
【故事联想】朗科发明了U盘的"灵魂"（方法），谁造U盘都要给朗科交钱
```

## 知识产权法案例辅助记忆

### 案例1：专利侵权判定

**案例**：甲公司拥有一项"可折叠手机屏幕"的发明专利，乙公司生产了类似功能但结构不同的折叠屏手机。

**法律分析**：
- 专利法第64条：发明或者实用新型专利权的保护范围以其权利要求的内容为准
- 全面覆盖原则：被控侵权技术方案包含了权利要求记载的全部技术特征，落入专利权保护范围
- 等同原则：以基本相同的手段，实现基本相同的功能，达到基本相同的效果

**记忆锚点**：「全面覆盖+等同原则=专利侵权判定」

### 案例2：商标侵权

**案例**：甲公司注册了"康师傅"商标，乙公司使用"康帅傅"商标销售方便面。

**法律分析**：
- 商标法第57条：未经商标注册人的许可，在同一种商品上使用与其注册商标近似的商标，容易导致混淆的，属于侵犯注册商标专用权
- "康帅傅"与"康师傅"构成近似商标，容易导致消费者混淆

**记忆锚点**：「近似商标+混淆=商标侵权」

### 案例3：著作权合理使用

**案例**：甲在论文中引用了乙已发表的文章中的三段话，并注明出处。

**法律分析**：
- 著作权法第24条：为介绍、评论某一作品或者说明某一问题，在作品中适当引用他人已经发表的作品，可以不经著作权人许可，不向其支付报酬
- 合理使用条件：①已发表作品 ②适当引用 ③注明出处 ④不影响正常使用

**记忆锚点**：「已发表+适当引用+注明出处=合理使用」

### 🔴 知识产权常见错误提醒

| ❌ 常见错误 | ✅ 正确表述 | 记忆锚点 |
|------------|-----------|----------|
| 想法可以申请专利 | 专利保护的是技术方案，不是想法 | 想法≠专利 |
| 注册商标可以永久使用 | 商标有效期10年，需续展 | 商标要续展 |
| 网上转载文章不需要授权 | 除合理使用外，转载需授权 | 转载需授权 |
| 公司名字=商标 | 公司名称和商标是不同的知识产权 | 名称≠商标 |
| 专利申请=专利授权 | 申请后需审查，不一定能授权 | 申请≠授权 |
