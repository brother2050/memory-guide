# 宪法/法律条文记忆 — 编码训练

## 一、中国宪法重要条款编码记忆（20条）

### 编码说明
- **条文号**：用数字编码定位
- **关键词**：提取核心法律要素
- **画面**：具象化场景
- **定位**：身体桩/宫殿桩关联

---

### 1. 第一条 — 国体（人民民主专政）

| 要素 | 内容 |
|------|------|
| 条文号 | 第1条 |
| 关键词 | 社会主义、人民民主专政、共产党领导 |
| 谐音 | "1"→衣（衣服）；"专政"→转正 |
| 画面 | 一件红旗衣服，上面写着"转正通知书"，颁发给人民 |
| 定位 | **头顶**（第一条=最高的位置） |

> **记忆链**：头顶红旗衣 → 转正通知 → 人民民主专政 → 共产党领导

## 五、记忆训练方法

### 1. 条文→关键词正向训练
```
看到第X条 → 立即说出核心关键词
例：第33条 → 公民在法律面前一律平等
```

### 2. 关键词→条文反向训练
```
看到关键词 → 立即说出条文号
例：选举权 → 第34条
```

### 3. 谐音→画面快速联想
```
听到"山鸡" → 37 → 人身自由
听到"石榴" → 46 → 受教育权
```

### 4. 身体桩快速定位
```
摸到胸口 → 33 → 平等权
摸到心脏 → 13 → 私有财产保护
```

### 5. 综合测试
```
宪法第几条规定了依法治国？→ 第5条 → 老虎穿法衣
```
