## 📝 编码系统说明

每个专项文件遵循统一的编码格式：

- **谐音法**：利用发音相似性建立联想
- **画面法**：将抽象信息转化为具体视觉图像
- **宫殿法**：将信息放置在熟悉的空间位置中
- **故事法**：用连贯的故事串联零散信息
- **对比法**：通过对比区分易混淆内容
