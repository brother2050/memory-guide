## 一、30个常用和弦编码

> **编码体系（唱名谐音一步）**：C=哆啦A梦、D=热狗、E=米饭、F=发糕、G=挂锁、A=拉面、B=西瓜；♯=井字架（象形，升）、♭=勺子（象形，降），升降音=符号+本音（如 C#=井哆啦、Eb=勺米）。见 [乐理基础 §2.1](16-music-theory-01.md)。

## 三、和弦转位对比

### 3.1 三和弦转位编码

以C和弦（C E G）为例：

| 位置 | 名称 | 组成 | 低音 | 编码画面 | 音响效果 |
|------|------|------|------|----------|----------|
| 原位 | Root Position | C E G | C | 站立的人（根音在脚） | 稳定、坚定 |
| 第一转位 | 1st Inversion | E G C | E | 倒立的人（三音在脚） | 漂浮、柔和 |
| 第二转位 | 2nd Inversion | G C E | G | 侧翻的人（五音在脚） | 悬浮、不稳定 |

**记忆口诀：**
- 原位 = "根在下"（Root = 站着）
- 第一转位 = "三在下"（Third = 倒立）
- 第二转位 = "五在下"（Fifth = 侧翻）

### 3.2 七和弦转位编码

以C7（C E G Bb）为例：

| 位置 | 名称 | 组成 | 低音 | 编码画面 |
|------|------|------|------|----------|
| 原位 | Root | C E G Bb | C | 四层宝塔（根在底） |
| 第一转位 | 1st | E G Bb C | E | 宝塔倒数第二层朝下 |
| 第二转位 | 2nd | G Bb C E | G | 宝塔侧倒 |
| 第三转位 | 3rd | Bb C E G | Bb | 宝塔完全倒立 |

### 3.3 转位对比练习

用C大调I-IV-V-I进行，对比原位和转位的连接：

```
原位连接（跳跃大）：
C(C E G) → F(F A C) → G(G B D) → C(C E G)
低音：C → F → G → C（跳跃进行）

转位连接（平滑）：
C(C E G) → F(A C F) → G(B D G) → C(C E G)
低音：C → A → B → C（级进进行）

最优声部连接：
C(E G C) → F(A C F) → G(B D G) → C(E G C)
低音：C → F → G → C
```

**记忆法则：** "转位让低音级进，声部更平滑"

## 方法选择指南

### 🎯 根据你的场景选择

```
你需要记忆什么类型的和弦知识？
│
├── 🎹 和弦构成（C=CEG, Am=ACE等）
│   → 推荐：谐音编码法 + 键盘实操法
│   → 用哆啦-米饭-挂锁记住音名，键盘上弹出来
│   → 每天：3-5个和弦
│
├── 🎵 和弦进行（I-V-vi-IV等）
│   → 推荐：和弦进行故事法 + 代表歌曲法
│   → 用《Let It Be》记住I-V-vi-IV
│   → 每天：1-2个进行
│
├── 🎨 和弦色彩（大三明亮/小三忧郁等）
│   → 推荐：色彩情感编码法 + 听觉训练
│   → 红色=大三，蓝色=小三，听辨练习
│   → 每天：10分钟听辨
│
└── 🎼 即兴伴奏/作曲
    → 推荐：功能分析法 + 和弦宫殿法
    → 理解T-S-D功能，宫殿中快速提取
    → 每天：30分钟练习
```
### ⚠️ 常见错误

| 错误 | 表现 | 正确做法 |
|------|------|---------|
| 和弦类型混淆 | 大三和弦和小三和弦、增和弦和减和弦分不清 | 用听觉区分：大三=明亮快乐，小三=忧伤柔和，增=紧张，减=不稳定 |
| 不结合听觉 | 只看谱子不听声音 | 每学一个和弦必须在钢琴/吉他上弹出来，用耳朵记住声音 |
| 混淆和弦进行 | I-IV-V和I-V-vi-IV搞混 | 用经典歌曲记忆：I-V-vi-IV=《Let It Be》，I-IV-V=《Twist and Shout》 |
| 忽略转位 | 只会根音位置的和弦 | 学习第一转位和第二转位，让和弦连接更流畅 |
| 不练习和弦切换 | 单个和弦会弹，切换时卡顿 | 用节拍器练习：C→G→Am→F，从60BPM开始逐步加速 |

### ❓ 常见问题FAQ

**Q: 这个主题最核心的记忆方法是什么？**
A: 根据内容类型选择：有序信息用记忆宫殿，无序信息用联想法，数字用谐音编码，概念用画面法。详见[02-核心记忆技巧.md](../02-核心记忆技巧.md)。

**Q: 学了记不住怎么办？**
A: 使用间隔重复（Anki）巩固。学完当天复习一次，第2天、第7天、第30天各复习一次。详见[02-核心记忆技巧.md](../02-核心记忆技巧.md#5-间隔重复-spaced-repetition)。

**Q: 有什么快速入门的方法？**
A: 先用画面法将抽象信息转化为具体图像，再用记忆宫殿放置。每天练习15分钟，2周即可见效。
