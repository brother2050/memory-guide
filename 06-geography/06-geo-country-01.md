# 06-geo-country-01.md — 国家记忆（亚洲 + 欧洲）

> 编码体系：每个国家通过「位置 → 形状 → 特征 → 编码」四步法建立稳固记忆。
> 结合地图定位法（在脑中展开地图，逐区域锚定）和谐音编码（国家名→谐音词→图像）。

---

## 一、记忆方法论

### 1. 地图定位法
- 在脑中展开一张世界地图
- 按大洲分区，每个分区内从北到南、从西到东扫描
- 每个国家绑定一个「地图锚点」（如半岛顶端、海峡旁边、岛屿形状）
- 高频复习时闭眼"看地图"，逐个点名

### 2. 谐音编码法
- 将国家名转化为发音相近的中文词
- 将谐音词转化为具体画面
- 画面越荒诞、越夸张，记忆越深

### 3. 四步记忆公式
```
位置（在哪） → 形状（像什么） → 特征（有什么） → 编码（怎么记）
```

## 四、综合记忆策略

### 分区记忆口诀
- **东亚五国**：中日韩朝蒙 → "钟日寒朝蒙"（金钟、太阳、寒冬、朝阳、蒙古包）
- **东南亚核心**：越泰缅柬马印菲新 → "越太缅捡马印飞新"
- **西欧四强**：英法德意 → "英法德意"（英雄发了德意志的主意）
- **北欧四宝**：挪瑞芬丹冰 → "挪瑞芬丹冰"（挪位瑞雪芬芳丹青冰清）

### 地图锚定练习
闭上眼，从以下路径在脑中"走"地图：
1. 从中国出发 → 向东到日本 → 向南到东南亚各国
2. 从俄罗斯出发 → 向西到北欧 → 到西欧 → 到南欧
3. 从地中海出发 → 向东到土耳其 → 到西亚

## 五、进阶技巧

### 1. 国家间关系记忆
- **邻国链**：中国→蒙古→俄罗斯→乌克兰→波兰→德国→法国→西班牙
- **海峡对望**：英国↔法国（英吉利海峡）、西班牙↔摩洛哥（直布罗陀）
- **半岛链**：印度半岛→阿拉伯半岛→小亚细亚半岛→巴尔干半岛→亚平宁半岛→伊比利亚半岛

### 2. 国旗辅助记忆
- 🇫🇷 法国：蓝白红竖条 → 像六边形地图的三个面
- 🇩🇪 德国：黑红黄横条 → 啤酒的三种颜色层
- 🇯🇵 日本：白底红圆 → 太阳升起的岛国
- 🇨🇭 瑞士：白十字红底 → 十字巧克力
- 🇳🇴 挪威：蓝底白边十字 → 峡湾上的十字路口

### 3. 编码强化练习

> 越南的S蛇骑着泰国大象，大象踩到缅甸的风筝，风筝飘到柬埔寨的扇子上……
