## 二、太阳（Sun）

### 基本数据

| 属性 | 数值 | 记忆编码 |
|------|------|----------|
| 类型 | 黄矮星（G2V） | G2=哥俩好 |
| 直径 | 139.2万公里 | 一生就爱（1392）|
| 质量 | 地球的33万倍 | 三三得九（33万）|
| 表面温度 | 5500°C | 五五开（5500）|
| 核心温度 | 1500万°C | 一五得五 |
| 年龄 | 46亿年 | 四六二十四 |
| 寿命 | 约100亿年 | 一百年 |

### 太阳结构编码（从内到外）

**"核辐对日色日"**（谐音：核辐射对日色日）

1. **核心（Core）** → 画面：太阳的心脏在跳动，每秒进行核聚变
2. **辐射区（Radiative Zone）** → 画面：光子像在人群中挤着走，需要17万年才能穿过
3. **对流区（Convective Zone）** → 画面：沸腾的火锅，热气不断翻滚
4. **光球层（Photosphere）** → 画面：太阳的"皮肤"，我们看到的太阳表面
5. **色球层（Chromosphere）** → 画面：日全食时看到的红色边缘
6. **日冕（Corona）** → 画面：太阳戴的皇冠，温度反而比表面高（百万度）

### 太阳活动编码

- **太阳黑子** → 画面：太阳脸上的雀斑，周期11年
- **太阳耀斑** → 画面：太阳打了个大喷嚏
- **日珥** → 画面：太阳边缘喷出的火焰喷泉
- **太阳风** → 画面：太阳吹出的隐形大风，吹出极光
- **日冕物质抛射** → 画面：太阳呕吐，抛出大量物质

## 十二、小行星带（Asteroid Belt）

### 位置与特征

- 位于火星和木星之间（2.2-3.2 AU）
- 包含数百万颗小行星
- 总质量只有月球的4%

### 主要小行星编码

1. **谷神星（Ceres）** → 矮行星，直径950km
2. **智神星（Pallas）** → 第二大，直径512km
3. **婚神星（Juno）** → 第三大，直径257km
4. **灶神星（Vesta）** → 最亮的小行星
5. **健神星（Hygiea）** → 第四大

**记忆画面：**
> 在火星和木星之间有一条由数百万块岩石碎片组成的"碎石路"。谷神星是这条路上最大的一块石头，被升级为矮行星。传说这里原本应该有一颗行星，但被木星的引力撕碎了。

## 记忆方法对比表

| 方法 | 优点 | 缺点 | 适合人群 | 推荐指数 |
|------|------|------|----------|----------|
| **行星顺序口诀法** | "水金地火木土天海"朗朗上口 | 只能记住顺序，不能记住特征 | 初学者 | ⭐⭐⭐⭐⭐ |
| **数字编码法** | 精确记忆距离/周期等数据 | 需要先掌握数字编码体系 | 有数字编码基础的人 | ⭐⭐⭐⭐ |
| **神话人物编码法** | 每颗行星对应一个神话人物 | 需要了解罗马/希腊神话 | 对神话感兴趣的人 | ⭐⭐⭐⭐⭐ |
| **博物馆宫殿法** | 八大行星=八个展厅 | 构建宫殿需要投入 | 有宫殿基础的人 | ⭐⭐⭐⭐ |
| **特征对比法** | 最大/最亮/最冷等对比记忆 | 只能记住极端值 | 考前冲刺 | ⭐⭐⭐ |
| **诗歌口诀法** | 完整信息浓缩成诗 | 信息密度高，不易理解 | 喜欢诗歌的人 | ⭐⭐⭐⭐ |

## 方法选择指南

### 🎯 根据你的场景选择

```
你需要记忆什么类型的天文知识？
│
├── 🌍 行星顺序（八大行星排列）
│   → 推荐：行星顺序口诀法 + 神话人物编码法
│   → 先背口诀"水金地火木土天海"，再用神话人物丰富
│   → 时间：30分钟搞定
│
├── 📊 行星数据（距离/直径/周期等）
│   → 推荐：数字编码法 + 特征对比法
│   → 将数字转化为画面，对比记忆极端值
│   → 每天：1-2颗行星的数据
│
├── 🔭 行星特征（大气/地貌/卫星等）
│   → 推荐：神话人物编码法 + 博物馆宫殿法
│   → 每颗行星=一个神话人物的特征故事
│   → 每天：1颗行星的完整特征
│
├── 🌌 太阳系全景（行星+矮行星+小行星带）
│   → 推荐：博物馆宫殿法 + 诗歌口诀法
    → 博物馆13个展厅覆盖全部
    → 每天：2-3个展厅
│
└── ⚡ 考前冲刺（快速复习全部）
    → 推荐：口诀速记法 + 特征对比法
    → 口诀过一遍顺序，对比过一遍特征
    → 每天：15分钟
```

### ⚡ 快速入门路径

| 阶段 | 时间 | 目标 | 方法 |
|------|------|------|------|
| 入门 | 第1天 | 记住八大行星顺序 | 口诀法 |
| 进阶 | 第2-3天 | 记住每颗行星特征 | 神话人物编码 |
| 精通 | 第4-7天 | 掌握太阳系全景 | 博物馆宫殿+数据编码 |
